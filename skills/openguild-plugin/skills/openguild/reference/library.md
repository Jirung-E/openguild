# Reference library

The library is a notes/reference-docs store in the guild, organized into
folders (design notes, research, links, etc. — anything worth keeping
alongside the project but not tied to a single quest).

```bash
openguild library list [--folder <name>]
openguild library show <name>
openguild library new <name> --file <PATH> [--folder <name>]
openguild library update <name> --file <PATH>
openguild library delete <name>

openguild library folder list
openguild library folder new <name>
openguild library folder delete <name>
```

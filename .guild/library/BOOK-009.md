# 디자인 언어

openguild GUI 의 글자 · 간격 · 그림자 · 움직임 · 부품 · 원칙. 정한 것과 **왜 그렇게 정했는지**를 여기
둔다. 규칙(`frontend-design-language`)은 이 문서를 가리키기만 한다 — 설명이 두 곳에 있으면 어긋난다.

정한 경위는 [[DEV-427]] · [[DEV-428]].

## 방향

- **성격은 지금 것 그대로** — GitHub 다크 계열. 새 방향을 잡지 않았다.
- **단계는 최소로** (admin). 쓰이던 값을 세어 가장 많이 쓰이던 값을 단계로 삼고, 가까운 값은 거기로
  옮겼다. 단계가 많으면 "어느 단계를 쓸지" 가 또 갈려서 다시 섞인다.
- **어색한 곳은 그 자리에서 고친다.** 토큰을 한 번에 적용하고 전후 화면을 비교해 넘치거나 잘린 곳만
  손봤다.
- 값은 전부 `gui/frontend/src/lib/styles/global.css` 에 있다. 모두 rem 이라 UI 배율을 따라간다.

## 토큰

### 글자 크기 — 5단계

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--fs-xs` | 0.72rem · 11.5px | 배지 · 알약 · 보조 설명 · 퀘스트 번호 |
| `--fs-sm` | 0.8rem · 12.8px | 목록 줄 · 버튼 · 입력칸 |
| `--fs-md` | 0.875rem · 14px | 본문 기본 · 문서 본문 |
| `--fs-lg` | 1rem · 16px | 구역 제목 · 창(모달) 제목 · 문서 제목 |
| `--fs-xl` | 1.25rem · 20px | 화면 제목 — **한 가지 크기** |

- 예전 42가지(0.8 / 0.82 / 0.825rem 처럼 눈으로 구별 안 되는 값 포함)를 묶었다.
- **대상이 아닌 것**: 아이콘 · × 글리프 크기(글자가 아니라 그림 크기), em(부모를 따라 줄어드는 자리),
  보드 노드처럼 보드 확대·축소를 따르는 px.

### 간격 — 8단계 (gap · padding · margin 공용)

| 토큰 | 값 | 주로 |
|---|---|---|
| `--sp-2` | 0.125rem | 알약 위아래 |
| `--sp-4` | 0.25rem | 아이콘과 글자 사이 |
| `--sp-6` | 0.375rem | 버튼 위아래 · 촘촘한 줄 |
| `--sp-8` | 0.5rem | 버튼 사이 · 기본 gap |
| `--sp-12` | 0.75rem | 버튼 좌우 · 카드 안 |
| `--sp-16` | 1rem | 패널 안쪽 · 구역 사이 |
| `--sp-24` | 1.5rem | 큰 구역 사이 |
| `--sp-32` | 2rem | 화면 여백 |

이름은 100% 배율의 px. 0.1rem 미만(테두리급)과 2rem 넘는 값(레이아웃 치수)은 대상이 아니다.

### 그림자 — 떠 있는 것만

| 토큰 | 쓰는 곳 |
|---|---|
| `--shadow-sm` | 툴팁 · 떠 있는 툴바 · 작은 팝업 |
| `--shadow-md` | 드롭다운 · 메뉴 · 미리보기 팝업 |
| `--shadow-lg` | 모달 · 확인 창 |
| `--ring` | 키보드 초점 · 고른 것의 테두리 |

다크는 진하게, 라이트는 옅게 따로 둔다(예전엔 라이트에서도 `rgba(0,0,0,0.6)` 이라 지나치게 진했다).
보드의 강조 빛(선행 · 하위 · 다음 색 번짐)과 안쪽 테두리(inset)는 **표시**라서 그림자 토큰이 아니다.

### 움직임 · 굵기 · 줄 간격

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--dur-fast` | 0.12s | 마우스 올림 — 색 · 배경 · 테두리 |
| `--dur-mid` | 0.2s | 펼치기 · 폭 · 모달 등장 |
| `--dur-slow` | 0.4s | 눈에 띄게 할 때만 |
| `--fw-regular` · `medium` · `semibold` · `bold` | 400 · 500 · 600 · 700 | |
| `--lh-tight` | 1 | 한 줄짜리 버튼 · 알약 |
| `--lh-snug` | 1.35 | 목록 · 카드 · 설명 |
| `--lh-body` | 1.6 | 긴 글 · 문서 본문 |

동작 줄이기 설정이면 시간 토큰이 모두 0 이 된다. 무한 반복 애니메이션(불러오는 중 표시 등)은 대상이 아니다.

## 부품

여러 화면에 나오는 것은 **하나씩만** 정의한다.

| 부품 | 상태 |
|---|---|
| 버튼 | [[DEV-428]] 에서 정리 중 |
| 알약 | `check:pill` 로 단일 출처 |
| 입력칸 · 팝업 | 아직 화면마다 따로 — 다음 정리 대상 |

## 원칙

- **밀도** — 촘촘하게. 정보가 많은 도구라서 기본 글자는 md(14px), 목록 줄은 sm, 보조 정보는 xs.
  구역은 여백으로 나누고, 선은 꼭 필요한 곳에만.
- **아이콘** — 화면 장식 아이콘은 `Icon` 컴포넌트의 SVG 만 쓴다(글자색을 따른다). 이모지는 댓글 반응 ·
  사용자가 쓴 글 · admin 이 정한 도서관 타일에만.
- **강조 색** — 파랑(accent)은 고른 것 · 초점 · 링크에만. 초록은 저장 · 만들기 같은 **주 동작 버튼
  하나**에만. 빨강은 지우기처럼 되돌릴 수 없는 일에만. 한 화면에 주 동작은 하나.
- **떠 있는 것** — 그림자는 화면 위에 떠 있는 것에만. 화면에 붙은 카드 · 패널은 테두리만.

## 새 값이 필요할 때

1. 먼저 가장 가까운 단계를 써 본다 — 대부분 그걸로 된다.
2. 정말 안 맞으면 그 자리에 `/* token-ok: 이유 */` 를 단다(아이콘 크기처럼). 검사(`check:tokens`)가
   이 표시 없는 리터럴을 막는다.
3. 여러 곳에서 같은 새 값이 필요하면 단계를 하나 더하는 것을 admin 과 정한다 — `global.css` 와 이 문서를
   함께 고친다.

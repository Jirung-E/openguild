## 1. 기본 출력을 요약으로, 전체는 `--full`

```
$ openguild quest show DEV-002
DEV-002  데이터베이스 스키마 변경
  status   : Open (게시됨)
  urgency  : 3
  relations: parent REQ-002
```

관계 요약(있는 것만: `parent <slug>` / `sub N` / `prereq N` / `succ N`)을 남긴
이유는, 관계가 있는지조차 안 보이면 결국 `--full` 을 다시 치게 되기 때문이다.
관계가 하나도 없으면 그 줄도 없다.

`--full` 은 예전 기본 출력 그대로(본문·관계 목록·태그·기한).

## 2. `--field` 다중 지원

```
$ openguild quest show DEV-002 --field title status urgency
title: 데이터베이스 스키마 변경
status: Open
urgency: 3

$ openguild quest show DEV-002 --field title        # 하나면 값만 (기존 동작)
데이터베이스 스키마 변경

$ openguild quest show DEV-002 --field title status --json
{ "status": "Open", "title": "데이터베이스 스키마 변경" }
```

여러 줄 값(description, 관계 목록)은 라벨 아래로 들여쓴다.

## 3. 관계 필드는 원래 있었다 — help 가 빠져 있었을 뿐

admin 질문("연관관계 출력이 parent 말고 없는지")의 답: **`sub_quests` /
`prerequisites` / `successors` 가 이미 구현돼 있었다**(DEV-291). 다만 `--help`
의 사용 가능 목록에 빠져 있어 존재를 알 수 없었다. 이번에 help·에러 메시지·
스킬 문서에 모두 반영했다. `status_ko` 도 같은 이유로 누락돼 있었다.

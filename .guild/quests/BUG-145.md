BUG-103(git checkout 후 updated_at 일괄 오탐)은 core/src/incremental.rs 에
내용 비교 게이트를 넣어 Done 처리됐으나, **동일 증상이 재발**한다.

## 재현 (2026-07-18, 이번 세션 실사고)

git checkout 을 하지 않았는데도, 개발 중 GUI(`openguild-gui`)를 이
저장소 자체 길드(`OPENGUILD_GUILD=<repo>`)에 대고 여러 번 실행하니
관련 없는 quest 17개(BUG-137, DEV-015/205/211/228/229/241/247/248/249/
250/252/254/255/258/259, REQ-001)의 `.md` frontmatter `updated_at` 이
일괄 변조됨. `git diff` 상 **내용 변경은 0, 오직 updated_at 만** 바뀜.
변조 타임스탬프가 14:34:02 / 14:36:28 로 뭉쳐 있어 시동 sync 계열의
일괄 rewrite 로 보임.

## 의심 지점

- BUG-103 의 내용 비교 게이트(`is_content_identical_to_db`)는
  `sync_changed_quest_files` / `refresh_quest_if_stale` 에 적용됐는데,
  GUI 시동 경로(`incremental::sync_on_open`, lib.rs 에서 호출)가 이
  게이트를 실제로 타는지 확인 필요 — 안 타거나, mtime 비교 후 다른
  경로로 write-back 하는 것으로 의심.
- GUI 가 recents 등록 / reindex / 파일 워처를 통해 별도로 `.md` 를
  rewrite 하는 경로가 있는지도 점검.

## 영향

개발자가 GUI 로 자기 길드를 열어보기만 해도 무관한 quest 들이
"수정됨"으로 잡혀 커밋 노이즈 / 리뷰 혼란 유발. BUG-103 과 동일한
사용자 경험 문제라 근본 재수정 필요.

## 참고

- [[BUG-103]] 의 수정/테스트 재확인부터.
- 재현은 이 저장소 자체를 길드로 열어 `openguild-gui` 2~3회 재시동.

## 테스트 방법

`git status` 클린 상태에서 `openguild-gui` 를 이 저장소 길드로 여러 번
재시동 → 무관한 quest `.md` 의 updated_at 이 **안 바뀌는지** 확인.
실제 외부 편집(내용 변경)은 여전히 정상 감지되는지도 회귀 확인.

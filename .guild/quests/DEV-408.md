## 무엇

([[BOOK-004]] "스크립트 여러 개")

- `scripts = [...]` 에 적은 파일의 함수는 한 공간에 모여 이름만으로 서로 부른다. 이름이 겹치면 불러올 때 오류.
- `import "경로" as 이름` — **폴더 밖도 허용.** 경로는 글자 그대로(불러올 때 목록을 알 수 있게). 지금은 `import` 자체를 막아 두었다.
- 허용 화면에 불러오는 파일 목록. **처음에 한 번만 허락** — 그 파일이 바뀌어도 다시 묻지 않고, 그 사실을 화면에 적는다.
- 공유할 플러그인은 상대 경로를 권한다고 안내.

## 확인

- 두 플러그인이 같은 공통 파일을 불러 쓴다.
- 변수로 적은 경로는 불러올 때 거절된다.

## 현상

도서관 트리에는 보이는데 옮기기·이름 바꾸기가 "folder not found" 로 실패하는 폴더가 있다.

- `library folder new 설계/초안` → 트리에 `설계` 가 보이지만 `설계` 는 등록된 폴더가 아니다.
  `library folder move 기타 설계/기타` → `folder not found: 설계`. GUI 에서 `기타` 를 `설계` 로 끌어도 같다.
- 문서만 `--folder 회의/2026` 으로 둔 경우 `회의`, `회의/2026` 둘 다 트리에 보이지만 이름 바꾸기가 안 된다.

## 원인

트리(`library-tree.ts`)는 등록된 폴더 + 그 조상 + 문서 경로(+조상)를 폴더로 그린다.
`move_folder`(DEV-397)는 등록된 폴더 목록(`library_folders`)만 보고 있음/없음을 판단한다.

## 발견

DEV-397 문서 갱신 중 USAGE 예시를 스크래치 길드에서 직접 돌리다 발견.

## 구현 / 확인한 것

- `move_folder` 의 있음/없음 판단을 **트리가 그리는 폴더 집합**(등록된 폴더 + 문서 경로, 각각의 조상까지)으로 바꿨다
  (`visible_folders`). 옮길 폴더·옮겨 갈 부모·이름 겹침 세 판단 모두 같은 집합을 본다 — 문서 경로로만 있는
  폴더와 겹치는 이름도 이제 거절된다(전에는 합쳐졌다).
- 등록 안 된 폴더를 옮기면 등록된 하위와 문서가 따라가고, 그 폴더 자체는 여전히 등록 없이 경로로만 남는다(트리 모양은 같다).
- 시험: `folders_seen_only_in_the_tree_can_be_moved_and_moved_into` — 수정 전 코드로 되돌리면 실패, 복원하면 통과.
- 실제 바이너리(스크래치 길드): `folder move 기타 설계/기타`, 문서만 있는 `회의` → `모임` 성공, `없는곳/설계` 는 계속 거절.
- 브라우저(127.0.0.1:3300, 같은 스크래치 길드): 탐색기에서 `옮길것` 을 등록 안 된 `설계` 로 드래그 → `설계/옮길것`,
  트리에서 문서 경로로만 있는 `모임` 이름 바꾸기 → 문서가 `모임록/2026` 으로. 콘솔 오류 없음.

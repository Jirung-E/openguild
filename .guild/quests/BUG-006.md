## 증상

`gui/frontend/src/lib/components/QuestBoard.svelte:176` 의 `arranging` 변수가
일반 `let` 선언 — Svelte 5 의 reactivity 시스템이 추적 못 함. 값이 바뀌어도 UI
재렌더 안 트리거.

`svelte-check` 출력:
```
WARNING "src\lib\components\QuestBoard.svelte" 176:6
  "`arranging` is updated, but is not declared with `$state(...)`. Changing its
  value will not correctly trigger updates"
  https://svelte.dev/e/non_reactive_update
```

## 영향

자동 정렬 (`autoArrange`) 등이 실행 중일 때 UI 에 "정렬 중..." / spinner 등 시각
표시가 의도대로 안 뜰 가능성. 동작 자체는 됨 — 사용자 피드백만 미흡.

## 수정 (2026-05-18)

`gui/frontend/src/lib/components/QuestBoard.svelte` line 270:
```diff
- let arranging = false;
+ let arranging = $state(false);
```

영향 — line 1610 의 `<button ... disabled={arranging}>` 이 정렬 중에 실제로
disabled 처리되고, 정렬 완료 시 다시 활성화됨 (Svelte 5 runes mode 의 reactivity
정상 작동).

다른 미선언 reactive 변수도 점검 — `svelte-check` 결과 잔여 8건은 모두 a11y
(DEV-025) 관련이고 non_reactive_update 없음.

## 테스트 방법

### 자동 (완료)
- `npm run check` → warnings 9 → **8** (이 변수의 non_reactive_update 제거).
- `npm test -- --run` → 63 통과 (회귀 없음).

### 사용자 검증 필요 (수동)
1. `cd gui/frontend && npm run build` 후 `cargo run -p openguild-gui` 또는 `npm run dev`.
2. Quest Board 에서 정렬 버튼 (예: 하이라이트 노드들 그룹 정렬) 클릭.
3. 정렬 진행 중 (애니메이션 동안) 버튼이 **disabled** 상태로 보임.
4. 정렬 완료 후 버튼 다시 활성.
5. 회귀: 다른 board 인터랙션 (드래그 / 줌 / 선택) 영향 없는지.

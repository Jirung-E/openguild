댓글을 쓰고 나서 마우스로 보내기 단추를 찾아 눌러야 한다. 키보드에서 손을 떼지 않고
**Ctrl+Enter** 로 바로 달 수 있게 한다(admin 요청, 윈도우 기준).

## 어디에

`ComposeDock` 이 맡는다. 댓글(`QuestCommentsSection`)과 메모(`QuestNoteSection`)가 같은
것을 쓰고, 이미 `onsubmit` 을 props 로 받고 있다 — 거기서 한 번 처리하면 둘 다 된다.
`onsubmit` 이 없는 곳(보내기 단추가 없는 자리)에서는 아무 일도 없어야 한다.

## 놓치기 쉬운 것

| | |
|---|---|
| 맥 | Cmd+Enter 도 같이 받는다. 맥에서 Ctrl 은 손에 안 붙는다 |
| 한글 입력 | **조합 중인 Enter 를 삼키면 안 된다.** `isComposing` 이 참이면 글자를 확정하는 Enter 다 — 그걸 보내기로 받으면 쓰다 만 댓글이 달린다 |
| 편집기 토글 | 입력칸이 `textarea` 일 때도 CodeMirror 일 때도 먹어야 한다. CodeMirror 는 자기 keymap 이 따로 있다 |
| 보낼 수 없을 때 | `submitDisabled` 면 눌러도 안 간다 — 단추와 같은 규칙 |

## 알려주기

단추 툴팁에 `Ctrl+Enter` 를 같이 적는다(맥은 `⌘Enter`). 단축키는 보이지 않으면 없는 것과
같다.

사용자 보고 (2026-08-01, 웹 모드 실기): 접힌 메뉴("…"/☰) 팝업이 열린
상태에서 다른 곳을 클릭해도 안 닫힘.

## 원인
`Nav.svelte` 의 `moreOpen` 토글 — 드롭다운 안 링크 클릭 시 닫는
핸들러(`onclick={() => (moreOpen = false)}`)만 있고, **바깥 클릭 시
닫는 핸들러 자체가 없었음**.

## 수정
`TitleBar.svelte` 의 ☰ 메뉴와 동일 패턴 — `window` 에 `mousedown`
리스너(capture)를 달아 `.more-wrap` 바깥 클릭 시 `moreOpen = false`.

## 테스트 방법
1. 웹 모드(`just dev-frontend` + `just dev-server`)에서 창을 좁혀
   "…" 메뉴가 뜨는 상태로 만든다.
2. "…" 클릭해서 드롭다운 연 뒤, 드롭다운 밖 아무 곳이나 클릭.
3. 드롭다운이 닫히는지 확인. 항목 클릭 시 이동 + 닫힘(기존 동작)도
   회귀 없는지 같이 확인.

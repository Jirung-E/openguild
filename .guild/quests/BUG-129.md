admin 요청: 도서관에서 드래그&드랍으로 폴더 이동이 되도록 하고 싶다.

## 구현 범위(admin 확인 필요 — 우선 문서 이동만 구현)
"폴더 이동"은 이 앱에서 기존에 문서 상세의 "폴더 이동" 버튼(다른 폴더로
옮기는 기능)을 가리키는 용어로 이미 쓰이고 있어(문서를 폴더 사이로
옮기는 것), 이번엔 그 동작을 드래그&드롭 제스처로도 할 수 있게 구현했음.

**폴더 자체(하위 문서/폴더를 통째로 데리고)를 다른 폴더 밑으로 옮기는
기능은 이번 범위에 넣지 않음** — 폴더는 실제 디렉토리가 아니라
`.guild/library/folders.toml` 의 가상 경로 목록이라, 폴더를 옮기려면
그 경로로 시작하는 모든 하위 폴더 + 모든 문서의 path 를 한 번에
cascade 재기록하는 새 백엔드 기능이 필요함(순환 방지 검증도 포함) —
문서 단위 이동보다 훨씬 큰 별도 작업이라 필요하면 후속 요청으로 진행.

## 구현
- 문서(book-item/tile)에 `draggable`, `dragstart` 시 book_id 를
  `dataTransfer` 에 기록.
- 드롭 대상: tree 모드의 폴더 행(LibraryFolderTree), explorer 모드의 폴더
  타일 + breadcrumb 각 조각 + 상위 폴더 버튼 + "도서관"(루트) 크럼/헤더.
  드래그 오버 시 시각 강조(점선 outline).
- 드롭하면 기존 "폴더 이동" 버튼과 동일한 `libraryApi.update(id, {path})`
  호출.

## 테스트 방법
- `cd gui/frontend && npm run check && npm run check:no-hex && npm test -- --run`.
- 실기: 트리뷰/아이콘뷰 양쪽에서 문서를 폴더로 드래그해 이동되는지,
  상위 폴더 버튼/루트로도 드래그해 이동되는지, 드래그 중 대상이
  시각적으로 강조되는지.

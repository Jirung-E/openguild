search 가 `quest_id` (slug, 예 `DEV-037`) 와 부분 number (`037`, `BUG-`) 도
매칭하도록 확장. `title_only` 와 무관 — slug 는 메타 정보지 본문이 아니므로
항상 매치.

## 구현 (2026-05-21)

### Backend
- `core::services::quests::list`:
  - `SLUG_EXPR = LOWER(qt.prefix || '-' || printf('%03d', q.number)) LIKE LOWER(?)`
  - 각 search 토큰의 OR 절에 slug 비교 추가.
  - title_only=true: 2개 bind (title + slug).
  - title_only=false: 3개 bind (title + description + slug).

### Frontend (gui)
- `quest-list.ts::filterQuests`:
  - 토큰 비교 시 `q.quest_id.toLowerCase().includes(t)` 도 OR.
  - `titleOnly=true` 여도 slug 는 항상 검사.

### 자동 테스트 +10
- server +4: 전체 slug / 부분 number / prefix / title_only 와 결합.
- frontend +6: 전체 / 부분 / prefix / 대소문자 / titleOnly / 다중 match.

## 회귀

- 기존 search 동작 (title + description) 변경 없음 — slug OR 추가.
- title_only 의 동작 (description 제외) 유지 — slug 만 추가로 OR.

반영 완료 (두 댓글 모두):

- 댓글: 첨부 버튼 + 비미디어 paste/drop 을 본문 첨부 버튼과 동일하게 quest/campaign 첨부 섹션으로 라우팅 (인라인 링크 X). 이미지/동영상은 댓글 인라인 임베드 유지.
- 메모 / 규칙 페이지: 첨부 섹션이 없으므로 이미지·동영상만 인라인 허용, 그 외 파일은 차단 + 안내("이미지·동영상만 첨부할 수 있습니다. 다른 파일은 첨부 섹션을 이용하세요").
- Ctrl+Z: 댓글 textarea 삽입을 execCommand('insertText') 로 바꿔 네이티브 undo 보존.

구현: editor-attach 에 textarea onAttach 라우팅 + CodeMirror mediaOnly 옵션 추가, QuestCommentsSection 에 onAttach prop. svelte-check / no-hex 통과. 실제 동작은 앱에서 한 번 확인 부탁드립니다(첨부는 Tauri 데스크탑 전용).

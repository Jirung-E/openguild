## 기능
Settings 페이지의 "표시" 섹션에 UI 크기 슬라이더.

## 사용
1. 상단 Nav 의 ⚙ 아이콘으로 Settings 진입.
2. "표시" 섹션의 슬라이더 (50% ~ 200%, 10% 단위) 드래그 또는 키보드 좌우.
3. 즉시 반영. localStorage 자동 저장 → 다음 실행 시 복원.
4. "초기화" 버튼으로 100% 로 reset (현재 100% 면 비활성화).

## 구현
- `lib/stores/uiScale.ts` — writable<number> + localStorage 영속 (key `openguild.uiScale`). 0.5 ~ 2.0 clamp.
- `applyUiScaleToDocument(s)` 가 `<html>` 의 font-size 갱신 (base 16px × scale).
- rem 기반 layout 전체가 비례 확대/축소.
- HTTP / Tauri 양쪽 동작 (옵션 A — root font-size). Tauri webview `setZoom` (옵션 C) 는 별도.

## 테스트
1. 슬라이더 50% / 100% / 150% / 200% 로 → UI 크기 변하는지.
2. 새로고침 / 앱 재시작 후 마지막 값 유지되는지.
3. "초기화" 버튼 → 100% / 슬라이더도 100% 위치.
4. localStorage 직접 ("openguild.uiScale" = "99") 변경 후 새로고침 → MAX 로 clamp.
5. QuestBoard 의 cy node 크기 / Home 의 px 직접 사용 영역에서 layout 깨짐 확인 (있으면 후속 fix 대상).

## 자동 검증
- `npm test uiScale` — 9 vitest (default / 영속 / clamp / garbage / set / reset / applyToDocument).

## 향후 (이 quest 범위 외)
- Tauri webview setZoom (옵션 C) — px 직접 사용 영역까지 자동 확대.
- Nav 우상단 ⚙ 옆 +/- 즉시 변경 버튼.
- 다크 / 라이트 모드 (DEV-074) 와의 통합.

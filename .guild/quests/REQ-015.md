## 요청

도서관 리스트뷰와 규칙 페이지에서 **구분선을 드래그해 좌우 영역 폭을 조절**할
수 있게 한다.

## 현황

둘 다 `grid-template-columns` 로 좌측 폭이 고정이다.

| 화면 | 현재 |
|------|------|
| 도서관 | `grid-template-columns: 16.25rem 1fr` |
| 규칙 | `grid-template-columns: 15rem 1fr` |

[[BUG-254]] 에서 px → rem 으로 바꿔 UI 배율은 따라가게 됐지만, 사용자가 직접
조절할 수단은 없다.

## 참고 — 이미 있는 구현

검색 팔레트의 미리보기 영역에 **세로 크기 조절 핸들**(`.dp-resize`)이 있다.
아래 가장자리를 드래그해 높이를 바꾸는 방식이고, 값은 저장하지 않는다.

이번 건은 **가로**이고 두 페이지에 공통이므로, 그 코드를 그대로 쓰기보다
공용 액션/컴포넌트로 뽑는 편이 낫다.

## 정할 것

1. **폭을 기억할지** — `localStorage` 영속(팔레트의 `worklogViewMode` 선례)
   vs 세션 한정. 영속이면 길드별로 나눌지도.
2. **최소/최대 폭** — 너무 좁히면 목록이 못 읽히고, 너무 넓히면 본문이 죽는다.
3. **모바일** — 두 페이지 모두 좁은 폭에서 `grid-template-columns: 1fr` 로
   한 줄이 된다. 그때는 핸들을 숨겨야 한다.
4. **배율과의 관계** — 저장값을 px 로 두면 배율을 다시 안 따라간다. rem 으로
   저장하거나, 저장은 px 로 하되 배율 변경 시 비례 조정이 필요한지 판단.

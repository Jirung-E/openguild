git/GitHub 모델 채택: openguild 자체는 인증(로그인/세션/계정)을 소유하지 않는다. git 이 자체 인증을 하지 않고 외부에서 identity(committer)를 받아쓰듯, openguild 도 외부에서 주어진 identity 를 신뢰만 하고 attribution/데이터 격리 목적으로 사용한다.

- 로컬(Tauri) 모드: `git config user.name` 과 유사한 로컬 프로필 값(간단한 설정) — 로그인 UI 없음.
- 서버(remote) 모드: 요청에 실려오는 신뢰된 header/token 의 identity 를 그대로 수용 — openguild 는 그 값을 검증하지 않고 전달받아 attribution/user_id 격리에만 사용. 실제 인증(로그인/세션/비밀번호 관리)은 openguild 를 감싸는 별도 서비스의 책임.

[[DEV-174]] (사용자 분리 — 로그인/멀티유저) 를 축소 대체한다. [[DEV-021]] (JWT 인증 — openguild 자체 발급/검증) 은 이 방향과 전제가 맞지 않아 함께 취소되었다.

베타 1.1.0(C-003) 목표. [[DEV-168]] (작업기록 유저별 분리) 의 선행 조건.

## 고침
`+layout.svelte` 미저장 가드: 뒤로 · 앞으로 가기(popstate)를 취소한 경우 "버리고 이동" 은 `goto(url)` 대신 `history.go(nav.delta)` — 기록 안에서 같은 칸 수만큼 움직인다. 링크 이동은 전과 같이 `goto`.

## 확인 (WebKit, 시험용 길드, 홈 → 도서관 → 문서 A)
- 편집 → 뒤로 → 버리고 이동: `/library`, 확인 창 1번, 편집 닫힘.
- 다시 뒤로: `/` (고치기 전에는 문서 A 로 돌아감).
- 앞으로: `/library`, 한 번 더: `/library?id=BOOK-001` — 기록이 그대로.
- 편집 → 뒤로 → 취소: 문서 A 에서 편집 유지. 이어서 뒤로 → 버리고 이동 → 뒤로 도 위와 같음.

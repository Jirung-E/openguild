사용자 보고: 리눅스에서 독바(태스크바)에 앱 아이콘이 제대로 표시 안 됨 —
기본 시스템 아이콘으로 표시되는 중.

조사 방향:
- Linux 에서 창 아이콘은 데스크탑 환경이 .desktop 파일(Icon= 항목)과 창의
  WM_CLASS/app_id 매칭으로 결정 — AppImage/deb 패키징에 .desktop + 아이콘
  설치가 포함돼 있는지 확인 필요(tauri.conf.json bundle.icon 은 있음,
  targets 가 "nsis" 뿐이라 Linux 번들 설정 자체가 없을 가능성 큼).
- Wayland 은 app_id ↔ .desktop 파일명 일치가 필수. tauri identifier
  (io.openguild.desktop)와 .desktop 파일명 정합 확인.
- 개발 모드(cargo tauri dev)에선 원래 기본 아이콘일 수 있음 — 배포 빌드
  기준으로 재현 확인 필요.

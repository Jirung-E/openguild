사용자 보고: 리눅스에서 독바(태스크바)에 앱 아이콘이 제대로 표시 안 됨 —
기본 시스템 아이콘으로 표시되는 중.

조사 방향:
- Linux 에서 창 아이콘은 데스크탑 환경이 .desktop 파일(Icon= 항목)과 창의
  WM_CLASS/app_id 매칭으로 결정 — AppImage/deb 패키징에 .desktop + 아이콘
  설치가 포함돼 있는지 확인 필요(tauri.conf.json bundle.icon 은 있음,
  targets 가 "nsis" 뿐이라 Linux 번들 설정 자체가 없을 가능성 큼).
- Wayland 은 app_id ↔ .desktop 파일명 일치가 필수. tauri identifier
  (io.openguild.desktop)와 .desktop 파일명 정합 확인.
- 개발 모드(cargo tauri dev)에선 원래 기본 아이콘일 수 있음 — 배포 빌드
  기준으로 재현 확인 필요.

## 근본 원인 (실기 검증, 2026-07-18)

실제 Ubuntu/GNOME(Ubuntu Dock) + NVIDIA 리눅스 데스크톱에서 직접 재현/검증.

- `cargo tauri build --bundles deb` 로 실제 .deb 를 빌드해 확인한 결과
  tauri.conf.json 의 `bundle.targets`(deb/rpm/appimage)와 `icon` 설정은
  이미 정상 — 생성된 `.desktop` 파일의 `Icon=`/`StartupWMClass=` 도
  실제 창의 `WM_CLASS` 와 정확히 일치했고, 아이콘 파일도
  `~/.local/share/icons/hicolor/.../apps/` 에 정상 설치되어
  `Gtk.IconTheme` 로 정상 조회됨. 즉 애초 조사 방향(패키징/아이콘 누락)은
  틀렸음 — 패키징은 처음부터 정상이었다.
- 브랜드 뉴 WM_CLASS + 사전 설치된 매칭 `.desktop` 파일로 여러 번
  재현해도 Ubuntu Dock 은 계속 일반 톱니바퀴 아이콘만 표시 — WM_CLASS
  매칭 경로 자체가 원인이 아님을 확인.
- `xprop` 로 정상 동작하는 앱(gnome-calculator 등)과 우리 창의 X11
  프로퍼티를 전부 diff 한 결과, 정상 앱에는 있고 우리 창에는 없는 게
  `_GTK_APPLICATION_ID` 프로퍼티였다. GNOME Shell/Ubuntu Dock 은 이
  프로퍼티가 있으면 우선적으로 사용해 앱을 식별한다.
- tao(Tauri 의 windowing 크레이트) 소스 확인: Linux 에서
  `gtk::Application::new(app_id, ...)` 호출 시 `app_id` 가 기본 `None`
  이라 `_GTK_APPLICATION_ID` 가 전혀 설정되지 않음. tauri 코어
  (`tauri-2.11.2/src/app.rs`)에는 이미 이걸 위한 설정 플래그
  `config.app.enable_gtk_app_id` 가 있고, true 면 `identifier`
  (`io.openguild.desktop`)를 GTK app id 로 그대로 넘겨준다 — 다만
  기본값이 `false` 라 여태 꺼져 있었음.

## 수정

`gui/tauri.conf.json` 의 `app` 에 `"enableGTKAppId": true` 추가
(tauri-utils 문서: "If set to true 'identifier' will be set as GTK app ID
on systems that use GTK").

## 검증 (실기, 2026-07-18)

빌드 전: `_GTK_APPLICATION_ID` 프로퍼티 자체가 없음 → 독바 톱니바퀴.
빌드 후 재실행: `xprop` 로 `_GTK_APPLICATION_ID(UTF8_STRING) =
"io.openguild.desktop"` 확인, Ubuntu Dock 에 실제 openguild 아이콘
(빨/초/파 사각형 로고)이 정상 표시되는 것을 스크린샷으로 확인.

## 테스트 방법

1. 리눅스에서 빌드(`cargo build --release -p openguild-gui` 또는
   `cargo tauri build`) 후 실행.
2. 독바(태스크바/dock)에 실제 openguild 로고(빨/초/파 겹친 사각형)가
   뜨는지 확인 — 톱니바퀴 등 기본 아이콘이면 재현.
3. 만약 여전히 기본 아이콘이면: 같은 세션에서 이 앱을 이미 여러 번 다른
   방식으로 실행해본 적이 있다면 GNOME Shell 이 이전 상태를 캐시하고
   있을 수 있음 — 로그아웃/재로그인(또는 `killall -SIGQUIT gnome-shell`,
   X11 세션 한정)으로 완전히 새로 시작한 뒤 재확인 부탁.

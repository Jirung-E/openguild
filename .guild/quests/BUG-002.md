## 증상

GUI 를 새로 켜면 노드들이 이전 드래그 상태가 아닌 lane 한 가운데에 1열로 줄지어 표시됨.

## 원인 확정

두 가지 원인이 겹쳐 있었음:

1. **`reindex` 가 `quest_positions` 를 wipe** — position 은 SQL 캐시에만 저장되고
   파일에 없는데, `reindex` 가 모든 position 행을 DELETE 후 복원하지 않았음. dogfood
   상에서 직접 검증: 27개 position 이 있는 상태에서 reindex → 0개. 자동으로 reindex
   가 돌지는 않지만 사용자가 외부 편집 후 한번이라도 실행하면 모든 board 위치가 손실됨.
2. **`init()` 의 lane 중앙 강제 clipping** — 저장된 `p.x` 가 현재 lane 범위 밖이면
   (예: DEV-024 머지로 `testing` 이 lane 2 에 삽입되며 `done`/`cancelled`/`on_hold` 의
   lane index 가 한 칸 씩 밀림 → 저장된 좌표들이 새 lane 범위 밖) `laneLeft + LANE_W / 2`
   로 강제. 같은 lane 의 여러 노드가 모두 한 점으로 → 1열로 겹침.

추가로 보조 원인: position 없는 신규 quest 의 auto-arrange 도 lane 중앙 단일 column
으로 떨어져 같은 증상.

## 수정

`core/src/reindex.rs`:
- 0 단계 추가: `quest_positions` 를 slug 키로 메모리에 백업 (slug = `prefix-001` 형식).
  reindex 가 quest 의 정수 PK 를 재배정하므로 slug 가 안정 키.
- 5b 단계 추가: 살아남은 slug 의 position 을 새 정수 id 로 재INSERT.
- `ReindexReport.positions_restored` 필드 추가, `openguild-server reindex` 출력에 노출.
- 회귀 테스트 2건 (`reindex_preserves_positions_across_rebuild`,
  `reindex_drops_position_for_deleted_quest`).

`gui/frontend/src/lib/components/QuestBoard.svelte` `init()`:
- 저장 좌표가 현재 lane 범위 밖일 때 lane 중앙 강제 → 옛 lane 내부 offset 을 새 lane
  으로 평행이동 (`offsetInOldLane` 로 컬럼 유지). 1열 stacking 해소.
- position 없는 신규 quest 의 auto-arrange — 단일 column → 3 column (`COL_OFFSETS` 가
  lane 의 3 column 중심 사용). 자연스러운 grid 정렬.

### 사용자 검증 필요 (수동)
**핵심**: GUI 에서 노드를 옮기고 재시작 했을 때 위치가 유지되는지.

1. `openguild-server host` 실행 (또는 이미 떠있으면 OK).
2. `cd gui/frontend && npm run dev` 후 http://localhost:5173 접속.
3. Quest Board 에서 임의 노드 2-3개를 화면 다른 자리로 드래그.
4. 브라우저 새로고침 (Ctrl+R) → 이동한 위치 그대로 유지되어야 함.
5. 서버 재시작 (Ctrl+C → 다시 `host`) → 다시 새로고침 → 여전히 유지.
6. `openguild-server reindex` 실행 → 출력에 `positions : N 복원` 표시 (N = 노드 수).
   다시 새로고침 → 모든 위치 그대로.
7. 회귀 (lane 외 좌표): SQL 직접 또는 status 변경으로 lane 변경 후 GUI 재시작 →
   노드들이 새 lane 안에서 옛 column offset 유지 (한 점으로 겹치지 않음).

회귀 체크 — 기존 동작 깨지지 않았는지:
- 드래그 중 다른 lane 으로 떨어뜨리면 status 변경 confirm 모달 떠야 함.
- 노드 정렬 (auto-arrange / sort) 버튼 동작.
- 다중 선택 박스 드래그, 노드 간 화살표 표시.

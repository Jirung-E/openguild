## 구조 변경 메모 (기록)

- entry 가 `li` → `div` 로 바뀜 — root + 답글을 `li.entry-card` 하나로 감싸기 위해. **`id="comment-N"` 은 유지**라 `#comment-N` deep link / 답글의 `↩ #p` 점프는 계속 동작.
- `#N` 은 anchor → button (본문 접기 토글) 으로 바뀜 — "댓글 #N 로 링크 복사" 용도로 anchor 가 필요해지면 별도 컨텍스트 메뉴 등으로 복원해야 함.
- 이모지 popup (`.reaction-picker`) 은 `position: absolute; bottom: calc(100% + 4px)` — 댓글이 화면 최상단에 있을 때 위로 뜰 공간이 없으면 잘릴 수 있음 (테스트 시 확인 포인트). 잘리면 viewport 감지 후 아래로 flip 하는 후속 필요.

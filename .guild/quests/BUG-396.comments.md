## 고침
도서관 문서를 쓰는 다섯 곳(`set_book_tags` · `create_book` · `update_book_with` · `delete_book` · `move_folder` 의 하위 문서)에서 파일을 쓴 직후 `file_mtime::touch`. 캠페인 · 타입 · 상태 · 태그 정의 · 첨부는 이미 하고 있었다(격리 길드에서 쓰기마다 `check drift` 로 확인).

## 확인
- 격리 길드(CLI, 고치기 전): library update · 제목 · 태그 · 폴더 이동 · 삭제 뒤 `check drift` 가 해당 BOOK 을 보고. 새로 만들기 · 첨부 · 캠페인 · 타입 · 상태 · 태그 정의는 깨끗.
- 새 시험 `library_writes_leave_no_drift`: 고치기, 태그, 폴더 이동, 삭제 뒤 drift 깨끗. touch 를 빼면 첫 단계(update)에서 실패.
- `just test` 통과(Rust 1342, 화면 1016).
- 문서: 규칙 `file-truth-db-cache` 의 바깥 편집 반영 표에 도서관 줄과 "touch 를 빼먹으면" 문장. 다른 대상에는 도서관 drift 를 설명하는 곳 없음.

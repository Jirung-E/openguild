## 증상

admin: *"길드 전체 허용/전체허용 해제 버튼이 왜 다른 위치에 있는거냐. 그리고 이름이
왜저래. 그냥 '전체 허용/ 전체 해제'로 하는게 덜 헷갈릴거같은데. 또 전체 허용중에는 왜
개별 철회가 불가능한거냐?"* — 이어서 *"자동 허용 모드도 있어야함."*

| 문제 | 원인 |
|---|---|
| 허용 버튼은 목록 맨 아래, 해제 버튼은 위 안내문 | [[BUG-285]] 가 해제 버튼만 옮겼다 — 반쪽 수정 |
| "이 길드를 전부 허용" / "길드 전체 허용 해제" | 일괄 조작이 아니라 **모드**를 켜고 끄는 이름이다 |
| 전체 허용 중 개별 철회 불가 | `trusted_guilds` 플래그가 `is_granted` 에서 개별 동의보다 먼저 단락된다 |

"일괄 조작" 과 "앞으로 올 것도 묻지 않기" 가 버튼 하나에 뭉쳐 있었다.

## 수정 — 셋으로 가른다

| 조작 | 뜻 |
|---|---|
| **전체 허용** | 지금 있는 플러그인 전부에 개별 동의를 남긴다 |
| **전체 해제** | 지금 있는 플러그인 전부를 철회한다 |
| **자동 허용** (켜기/끄기) | 새로 추가되거나 바뀐 플러그인도 묻지 않고 돈다 |

- 세 조작은 목록 위 **한 자리**에 둔다. 개별 허용/철회는 **언제든** 먹는다.
- 자동 허용 중에도 **직접 철회한 것은 안 돈다.** 철회를 기록해 두지 않으면 자동 허용이
  그 자리에서 다시 살려 버린다(지금 개별 철회가 안 되는 것과 같은 모양).
- 자동 허용을 **끄면 지금 돌던 것은 그대로 돈다** — 모드는 앞으로 올 것에 대한 것이다.
  전부 멈추려면 전체 해제.
- 이미 신뢰를 켜 둔 길드는 그대로 자동 허용이 켜진 상태다(파일 필드 이름 유지 —
  설치된 앱이 같은 `~/.openguild/plugin-consent.json` 을 읽는다).
- CLI: `plugin allow --all --yes`, `plugin revoke --all`. `trust`/`untrust` 는 자동 허용
  켜기/끄기로 뜻을 맞춘다.

## 구현

- 동의 파일에 `denied`(직접 철회한 이름) 추가. 판정 순서를 **직접 철회 → 지금 모양에 대한
  동의 → 자동 허용** 으로 바꿨다 — 예전엔 신뢰 플래그가 맨 앞이었다.
- `grant_all` / `revoke_all` — 전체 허용·해제. 파일을 한 번만 쓴다.
- `enable_auto_allow` / `disable_auto_allow` — 끌 때는 자동 허용 덕에 돌던 것들의 지금
  모양을 개별 동의로 굳힌 뒤 끈다.
- 파일 필드 `trusted_guilds` 이름은 유지(설치된 앱이 같은 파일을 읽는다). 새 필드
  `denied` 는 옛 앱이 무시한다.
- 데스크톱: `plugin_allow_all` / `plugin_revoke_all` / `plugin_set_auto_allow`. 설정 화면은
  목록 위 `.plugin-bulk` 한 줄에 [전체 허용] [전체 해제] ☐자동 허용. 전체 허용과 자동 허용
  켜기는 확인을 거친다(보지 않은 코드를 돌리게 하므로). 옛 안내문·"개별 철회 불가" 글 제거.
- CLI: `plugin allow --all [--yes]`, `plugin revoke --all`. `trust`/`untrust` 는 자동 허용
  켜기/끄기로 뜻과 문구를 맞췄다. `revoke <이름>` 의 JSON 은 예전 모양(문자열) 유지.

## 확인한 것

- 코어 시험: 자동 허용 중 철회가 이긴다 / 끄고 켜도 철회가 남는다 / 끄면 돌던 것 유지,
  그 뒤 바뀐 것은 묻는다 / 전체 허용 뒤 개별 철회·새 플러그인은 묻는다 / 전체 해제 뒤
  개별 허용 / 옛 파일(신뢰만 있음)은 자동 허용으로 읽히고 필드 이름이 안 바뀐다.
- 되돌려 봄: 자동 허용을 판정 맨 앞으로 되돌리면 철회 시험이, 끌 때 굳히기를 빼면
  끄기 시험이 각각 실패.
- 화면 시험: 세 조작이 목록 **앞** 한 줄에 있고 옛 자리 요소가 없다 / 자동 허용 중에도
  철회 버튼이 눌린다.
- 실제 CLI(임시 길드, 플러그인 둘): trust → 둘 다 돎 → alpha 철회 → beta 만 → untrust →
  beta 그대로 → `allow --all` 은 목록만 → `--yes` 로 둘 다 → `revoke --all` 로 둘 다 대기.
- **화면은 데스크톱에서만 확인할 수 있다** — 허용·철회는 로컬 데스크톱 전용이라 웹에는
  이 줄이 안 그려진다.

## 테스트 방법

- 자동 허용 중 개별 철회 → 그 플러그인만 안 돈다. 다시 허용하면 돈다.
- 자동 허용 중 새 플러그인·바뀐 플러그인 → 묻지 않고 돈다.
- 자동 허용을 끄면 돌던 것은 계속 돌고, 그 뒤에 추가·변경된 것은 묻는다.
- 전체 허용 / 전체 해제가 개별 상태를 한 번에 바꾸고, 그 뒤 개별 조작이 먹는다.
- 설정 화면에서 세 조작이 한 자리에 있다.

## 무엇

도서관에서 문서(또는 폴더)를 **복사해서 파일 탐색기에 붙여넣을 수 있게** 한다. 이때 **폴더 구조가
유지되어야 한다** — 폴더를 복사하면 그 아래 문서와 하위 폴더가 같은 모양으로 나온다.

## 한 것 (2026-09-20)

**나가는 쪽(도서관 → 파일 시스템)을 했다.** 핵심은 도서관의 폴더가 진짜 디렉터리가 아니라는
것이다 — 문서는 전부 `.guild/library/BOOK-NNN.md` 로 나란히 있고 폴더는 문서가 적어 둔 값이다.
그래서 밖으로 가져가려면 그 구조를 **그때 만들어야** 한다.

- `core/src/ops/library_export.rs` — 고른 것(문서 하나 / 폴더 하나 / 전체)을 폴더 구조 그대로
  펼친다. 파일 이름은 **제목**(관리번호로 내보내면 탐색기에서 뭔지 모른다), 못 쓰는 글자는
  바꾸고 겹치면 번호를 붙인다(덮지 않는다). 원문은 frontmatter 까지 그대로 — 되돌려 넣을 때
  필요한 것이 거기 있다. 첨부는 `문서이름.attachments/` 로 함께 나간다.
- `openguild library export <폴더> [--folder X | --id BOOK-NNN]` — 에이전트·스크립트도 쓴다.
- 앱: 문서 상세와 아이콘 뷰의 현재 폴더에 **[복사] [내보내기]**.
  - 내보내기 = 폴더를 골라 그곳에 펼친다.
  - 복사 = 임시 폴더에 펼친 뒤 **클립보드에 파일로** 올린다 → 탐색기에서 붙여넣기.
    웹 클립보드 API 로는 파일을 못 올려서(글자·그림뿐) OS 도구를 쓴다 —
    macOS `osascript`, Windows `Set-Clipboard`, 리눅스 `wl-copy`/`xclip`.
    **하나만 올린다**(macOS 는 목록을 파일로 안 붙여 준다) — 전체를 복사하면 길드 이름의
    폴더로 한 번 감싼다.

확인: 씨앗 길드를 CLI 로 내보내 폴더·첨부까지 그대로 나오는 것, macOS 에서 `osascript` 가
`«class furl»` 로 클립보드에 올라가는 것(여러 개를 한 번에 올리면 목록이라 안 된다는 것도).

## 남은 것 — 들어오는 쪽 (탐색기 → 도서관)

되돌려 넣는 쪽은 **아직 정하지 않았다.** 정해야 할 것:

- 붙여넣은 `.md` 가 도서관 문서가 되나, 첨부가 되나? (frontmatter 가 있으면 그 문서로 되돌리기?)
- `.md` 가 아닌 파일은? (이미지·PDF → 첨부로?)
- 같은 관리번호가 이미 있으면 — 덮기 / 새 번호 / 거절?
- 폴더째 넣으면 그 구조가 도서관 폴더가 되나?

## 정할 것 (처음 적어 둔 것)

- **반대 방향**(탐색기 → 도서관)도 할지. 하면 붙여넣은 파일이 도서관 문서가 되는지, 첨부가 되는지,
  `.md` 가 아닌 파일은 어떻게 되는지를 먼저 정해야 한다.
- 문서 하나를 복사할 때 나가는 것이 `.md` 원문인지, frontmatter 를 뗀 본문인지.
- 첨부가 딸린 문서는 첨부까지 함께 나가는지.
- 운영체제마다 다른 클립보드 파일 형식을 어디까지 맞출지(macOS / Windows).

## 테스트 방법

- 폴더를 복사해 탐색기에 붙여넣으면 하위 구조 그대로 나온다.
- 문서 하나만 복사해도 된다.

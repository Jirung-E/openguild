## 구현 (2026-07-05)
- **`repo/library.rs`** 신규: BookFile(+++ TOML frontmatter + 본문, auto 블록
  없음 — 관계 개념 없음), book_slug/parse_book_slug("BOOK" prefix 하드코딩 —
  admin 결정), LibraryCounter(.counter.toml, 경고 헤더), allocate_number 는
  counter 와 실존 파일 max 중 큰 쪽 +1 (git 충돌로 counter 후퇴해도 ID 중복
  방지 — quest counter 검증 철학).
- **`ops/library.rs`** 신규: list/get/create/update/delete(soft) — journal
  append + 파일 atomic write + library_docs 캐시 sync. LibraryDocRow 반환.
- **migration 0021**: library_docs (number UNIQUE, title, body, created_at,
  updated_at, deleted_at).
- **reindex**: library_docs wipe 후 파일에서 재구축 (soft-deleted 포함,
  deleted_at 채움). ReindexReport.library_loaded + summary 라인.
- **snapshot**: SOURCE_SUBDIRS 에 "library" 추가 (BUG-108 의 history 누락
  교훈 — 분리 디렉토리는 등록 필수).

  (len 만) 이라 rules 와 동일하게 fail-loud.

gui 의 Quest List 화면에 검색 UI 노출. URL `?search=` 매핑.
'제목에서만' 옵션 토글 추가 (백엔드 `ListQuery` 에 `title_only` 신설).

## 구현 (2026-05-21)

### Backend
- `core::models::ListQuery` 에 `title_only: bool` 추가 (default false).
- `core::services::quests::list`:
  - `title_only=true` → 토큰마다 `LIKE q.title` 한 번만 검사 (description 제외).
  - false → 기존 `(title OR description)` 동작.
- `cli`: `--title-only` 플래그, querystring `&title_only=true` 전파.

### Frontend (gui)
- `gui/frontend/src/lib/utils/quest-list.ts::filterQuests`: `search`, `titleOnly`
  파라미터 추가. 공백 split AND, 대소문자 무시, description null 안전.
- `QuestListFilter.svelte`: 검색 input + 제목만 체크박스 + 지우기 버튼.
- `QuestList.svelte`:
  - `search` / `titleOnly` state, `QuestListFilter` 와 양방향 바인딩.
  - URL `?search=` / `?title_only=` 양방향 동기화 (onMount 에서 URL→state,
    `$effect` 로 state→URL, `replaceState: true` history 폭증 방지).
  - 빈 결과 시 검색어 인용 메시지.

### 자동 테스트
- server +4 (`title_only` description 제외, default false, 다중 토큰 AND, no-match).
- cli +1 (querystring `title_only` 전파).
- frontend +9 (filterQuests search: title / description / 대소문자 /
  AND / null safe / titleOnly true / titleOnly description-only / search+type).

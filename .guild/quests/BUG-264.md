## 증상 (admin 보고, 모바일)

1. 도서관 상세가 **끝까지 안 내려간다.** 첨부가 있는 문서에서 최대로 내려도
   첨부 섹션 절반쯤부터 잘린다.
2. 아래로 스크롤해도 **주소창이 안 접힌다.**
3. 최상단에서 위로 당겨도 **새로고침이 안 된다.**

## 셋은 한 뿌리다

[[BUG-257]] 이 문서 스크롤을 잠갔다. macOS(WKWebView)의 rubber-band 가 커스텀
타이틀바를 끌어내리는 것을 막으려고, 문서를 고정하고 `main` 이 스크롤하게 했다.

```css
html, body { height: 100%; overflow: hidden; }        /* global.css */
main { height: calc(100vh - nav - titlebar);
       overflow-y: auto; overscroll-behavior: contain; }
```

모바일 브라우저가 주소창을 접거나 당겨서 새로고침하는 것은 **문서(root)
스크롤을 볼 때만** 하는 동작이다. 문서가 안 움직이니 브라우저 입장에서는
스크롤이 일어난 적이 없다(증상 2·3). `overscroll-behavior: contain` 은
pull-to-refresh 를 **명시적으로 끄는** 선언이라 3번을 한 번 더 못 박는다.

증상 1도 같은 잠금 때문이다. `100%` 와 `100vh` 가 모바일에서 다른 값을
가리킨다 — `100%` 는 주소창이 보이는 높이(ICB/small viewport), `100vh` 는
주소창이 접힌 높이(large viewport). `main` 이 `body` 보다 주소창 높이만큼
크고, `body` 가 `overflow: hidden` 이라 **넘친 만큼 잘린다.** 잘리는 양은
컨텐츠와 무관하게 일정하고, 도서관 상세는 첨부가 맨 아래라 하필 그 절반에서
잘린 것으로 보였다. 첨부가 스크롤에 기여하지 않는 것은 아니다.

데스크톱은 `100vh == 100%` 라 증상이 없어 BUG-257 때 안 걸렸다.

## 그래서 `dvh` 로는 부족하다

`dvh` 로 바꾸면 **1번만** 낫고 2·3번은 그대로 죽어 있다. 증상만 덮는 것이라
택하지 않는다.

## 고치는 법 — 잠금을 필요한 곳에만

BUG-257 이 막으려던 것은 **커스텀 타이틀바가 딸려 내려오는 것**이다. 모바일
브라우저에는 커스텀 타이틀바가 없다 — 거기서는 잠글 이유가 처음부터 없다.

판정은 `(pointer: coarse)` 로 한다. 화면 폭이 아니라 **포인터 종류**로 나누는
것은 이 저장소의 기존 판정과 같다(`hasCoarsePointer` — 데스크탑 창을 좁혔을
때 잘못 걸리지 않게). Tauri 데스크톱은 절대 coarse 가 아니므로 BUG-257 의
수정은 **그대로 남는다.**

- `(pointer: coarse)` 에서 `html/body` 잠금 해제 → **문서가 다시 스크롤**한다.
- 같은 조건에서 `main` 은 고정 높이·자체 스크롤을 놓는다.
- `pageScrollEl()` 도 그 조건에서 `null` 을 돌려주고, `page-scroll.ts` 에
  **처음부터 있던 문서 폴백**을 탄다.

셋이 한 번에 낫는다 — 문서가 스크롤하니 주소창도 접히고, pull-to-refresh 도
살아나고, `main` 에 고정 높이가 필요 없어져 `vh`/`%` 불일치가 사라진다.

## 남는 `vh` 들

같은 공식이 세 곳 더 있다. 이들은 내부 스크롤 영역이라 이번 범위가 아니지만,
모바일에서 잘리는 것은 막아야 하므로 `dvh` 폴백 쌍으로 바꾼다:

```
lib/components/QuestList.svelte    .quest-list  height
lib/components/QuestBoard.svelte   .board-wrap  height
lib/components/QuestBoard.svelte                max-height
```

**후속 과제**: 퀘스트 목록은 `.list` 가 자체 스크롤 컨테이너라(자체
sessionStorage 복원까지 있다) 모바일에서 여전히 주소창이 안 접힌다. 문서
스크롤로 옮기는 것은 복원 로직까지 건드리는 별도 작업이다.

## 재발 방지

`check:viewport` — 높이 계열 속성에 `vh` 를 쓰면서 바로 뒤에 `dvh` 폴백이
없으면 실패. 기존 가드 5종과 같은 자리에 둔다.

## 테스트 방법

**모바일(실기)** — 이 항목들은 agent 가 확인할 수 없다:

1. 도서관 상세(첨부 있는 문서)를 끝까지 스크롤 — 첨부 마지막까지 보인다.
2. 아래로 스크롤하면 주소창이 접힌다.
3. 최상단에서 아래로 당기면 새로고침된다.
4. 주소창이 접힌 상태/펼친 상태 둘 다에서 1번을 확인.

**데스크톱(회귀)**:

5. macOS Tauri 에서 맨 위로 rubber-band 를 당겨도 타이틀바가 안 흔들린다
   (BUG-257 재발 없음).
6. 페이지 이동·뒤로가기 스크롤 복원이 그대로 동작한다.
7. 데스크톱 브라우저 모드에서 overlay 스크롤바가 그대로 보인다.

사용자 보고(2026-07-04) 2건 — 뿌리 동일: **선택된 규칙이 URL 에 반영되지 않음.**
1. 규칙 본문의 다른 규칙 [[링크]] 클릭해도 이동 안 됨 — /rules 가 ?slug= 를 onMount 에서만 읽는데 같은 라우트 내 이동은 onMount 재실행 안 됨.
2. 규칙에서 퀘스트/캠페인 링크 따라갔다 뒤로가기 → 1번째 규칙으로 초기화 — 선택이 컴포넌트 state 뿐이라 소실.

## 수정 (rules/+page.svelte) — URL 을 선택 상태의 진리원으로
- $page.url 반응형 $effect: ?slug= 변화 → select() (편집 중이면 기존 confirmDiscardSlug 가드 경유) — 규칙간 링크 클릭 해결.
- 규칙 선택 시 syncUrl: goto(?slug=, replaceState+keepFocus+noScroll) — history entry 안 쌓고 현재 URL 에 기록 → 떠났다 돌아오면 onMount 가 복원. applyPendingSelect(편집 파기 후 전환)에도 적용.

## 테스트 방법 (GUI 또는 브라우저 재빌드 후)
1. 규칙 A 본문에 [[규칙B]] 링크 → 클릭 → **규칙 B 로 전환**되는지 (원 증상).
2. 4번째 규칙 선택 → 본문의 퀘스트 링크 클릭 → 뒤로가기 → **4번째 규칙 그대로**인지 (원 증상 2).
3. 사이드바 선택마다 주소창 ?slug= 갱신 + 뒤로가기 한 번에 이전 페이지(규칙 선택 단계를 되밟지 않음 — replaceState).
4. 편집 중 다른 규칙 링크/선택 → 파기 확인 모달 동작 회귀.
5. 퀘스트 본문에서 /rules?slug= 딥링크 진입 회귀(DEV-173).
6. cd gui/frontend && npm run check — 0 errors.

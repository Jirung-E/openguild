#### SQL 테이블 (마이그레이션)
```sql
CREATE TABLE campaigns (
    id              INTEGER PRIMARY KEY,
    campaign_slug   TEXT NOT NULL UNIQUE,    -- 'C-001'
    title           TEXT NOT NULL,
    description     TEXT,                     -- 본문 markdown (체크리스트 제외하지 않음)
    status          TEXT NOT NULL DEFAULT 'active',  -- 'active' | 'done'
    started_at      TEXT,                     -- ISO date
    ended_at        TEXT,
    display_order   INTEGER NOT NULL DEFAULT 0,  -- 어드민 수동 정렬용
    created_at      TEXT NOT NULL,
    updated_at      TEXT NOT NULL,
    deleted_at      TEXT
);

CREATE TABLE campaign_checklists (
    id           INTEGER PRIMARY KEY,
    campaign_id  INTEGER NOT NULL REFERENCES campaigns(id) ON DELETE CASCADE,
    text         TEXT NOT NULL,
    checked      INTEGER NOT NULL DEFAULT 0,
    order_idx    INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE campaign_quests (
    campaign_id  INTEGER NOT NULL REFERENCES campaigns(id) ON DELETE CASCADE,
    quest_id     INTEGER NOT NULL REFERENCES quests(id) ON DELETE CASCADE,
    PRIMARY KEY (campaign_id, quest_id)
);

CREATE TABLE campaign_counters (
    id           INTEGER PRIMARY KEY CHECK (id = 1),
    last_number  INTEGER NOT NULL DEFAULT 0
);
```

- **Home 페이지**:
  - **진행 중 캠페인** (status='active' 전부) 가로 카드 슬라이드.
    각 카드: 제목 / 기간 (started_at ~ ended_at) / 체크리스트 완료율

  - 캠페인 카드 아래에 `[캠페인 목록]` / `[캠페인 추가]` 버튼.

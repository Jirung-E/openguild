윈도우 세션 보고(2026-10-26, DEV-327 '앱 데이터 삭제' 시험 중):

- 제거한 뒤 `%LOCALAPPDATA%\openguild` 에 파일 942개, 33MB 가 남았다 — `gui\frontend\build\_app\immutable\` 아래 chunks 726 · assets 102 · nodes 98 · entry 16(6~9월 빌드의 해시 붙은 파일), `docs\AGENTS_OPENGUILD_USAGE.md`(7월), `openguild\data\recents.json`(7월, 아주 옛 구조).
- 원인: `installer.nsi` 의 Copy resources 는 새 파일을 덮어쓰기만 하고 옛 파일을 안 지운다. 빌드마다 해시 이름이 바뀌어 **업데이트할 때마다 쌓인다.** Section Uninstall 은 이번 빌드의 파일 목록만 지우고 폴더는 비어 있을 때만 지워(`RMDir`), 옛 파일이 남은 폴더와 설치 폴더가 끝까지 남는다.
- 제안: 앱이 가진 리소스 폴더(`gui\frontend\build` · `skills` · `docs`)를 설치 직전(업데이트 포함)과 제거 때 통째로 지운다. 설치 폴더 자체를 `/r` 로 지우는 것은 사용자가 엉뚱한 폴더를 골랐을 때 위험하니 피한다.

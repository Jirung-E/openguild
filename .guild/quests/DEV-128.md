현재 댓글은 author + ts + body 만 표시. CLI (`quest comment list / show --id N`) 와 본문 (예: "댓글 #3 참조") 에서 참조하려면 번호 알아야 하는데 GUI 에선 안 보임.

요구사항: 각 댓글 head 에 `#N` 표시 (예: "#3  alice · 2026-06-09 10:15").

- 클릭 시 그 댓글로 anchor 점프 (`#comment-3` URL fragment) 가능하면 더 좋음.
- 답글의 경우 parent ↩ 표시도 같이 (예: `#4 ↩ #2`).
- entry_id 는 frontmatter 의 og-comment 마커에 이미 있음 (DEV-094 의 `<!-- og-comment id="N" -->`) — GUI 의 CommentEntry 타입에 이미 `id: number` 필드 있음.

작업 범위는 CSS / 표시 위주 — 데이터 흐름 변경 없음.

## 관련
- DEV-094 (댓글 시스템).
- DEV-107 (답글 단위 접기).

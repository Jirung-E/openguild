터치스크린에서 보드 핀치-투-줌 지원.

## 계측 결과 (2026-07-04, admin 실기)
WebView2 가 touch 이벤트를 JS 로 전달함 확인(touches=2 도달) — IsPinchZoomEnabled 네이티브 변경 불필요, frontend 만으로 구현.

## 구현 (QuestBoard.svelte)
- .board 에 touch-action: none — 네이티브(Page Scale) 줌/스크롤 차단.
- 커스텀 핀치 핸들러(touchstart/move passive:false + preventDefault, 두 손가락일 때만 개입): 두 손가락 거리비 = 줌 배율(중점 기준 cy.zoom), 중점 이동분 = cy.panBy(핀치하며 끌기). 핀치 중 cytoscape userPanningEnabled 잠시 off — 한 손가락 pan 과 충돌 방지, touchend/cancel 에서 복원.
- 한 손가락 pan/탭/노드 드래그는 cytoscape 기본 터치 처리 그대로(개입 안 함).

## 테스트 방법 (터치스크린 실기)
1. 두 손가락 핀치 아웃/인 → 줌 인/아웃, 줌 중심이 두 손가락 중점 근처인지.
2. 핀치한 채 두 손가락 이동 → 보드가 따라 pan 되는지.
3. 한 손가락 드래그 = pan, 탭 = 노드 선택/카드, 노드 드래그 정상(회귀).
4. 핀치 → 한 손가락만 떼기 → 남은 손가락 드래그가 pan 으로 자연 전환되는지.
5. 앱(페이지) 자체가 네이티브 줌으로 커지지 않는지(touch-action 확인).
6. 마우스 휠/트랙패드(BUG-090 동작) 회귀 없음.
7. cd gui/frontend && npm run check — 0 errors.

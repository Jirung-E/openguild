터치스크린에서 보드 핀치-투-줌이 동작해야 함. 현재 안 됨.

## 현재 상태 (막는 층 2개)

1. cytoscape 층: `QuestBoard.svelte` 의 `userZoomingEnabled: false` 가 휠 줌뿐 아니라 cytoscape 내장 터치 핀치 줌까지 끔(같은 마스터 플래그, 분리 불가). BUG-090 에서 트랙패드 휠 처리 때문에 끈 것.
2. WebView2 층: `IsPinchZoomEnabled`(기본 true) 가 터치스크린 핀치를 네이티브 Page Scale 줌으로 자체 처리 → touch 이벤트가 JS 로 안 올 가능성(트랙패드 핀치가 wheel 로 안 왔던 것과 같은 계열의 한계).

## 접근

- ① cytoscape 는 그대로 userZoomingEnabled=false 유지(휠 커스텀 핸들러 보존)하고, 커스텀 터치 핀치 핸들러 추가: touchstart/touchmove 에서 두 손가락 거리비 → cy.zoom(center), midpoint 이동분 → cy.panBy. `.board` 에 touch-action: none 부여(브라우저 제스처 가로채기 차단).
- ② 위가 동작하려면 WebView2 가 touch 이벤트를 JS 로 줘야 함. 안 주면 Rust 에서 IsPinchZoomEnabled=false 네이티브 설정(with_webview + COM, Windows 전용) 필요. 디버그 빌드로 touch 이벤트(touchstart 2-finger)가 실제로 오는지 먼저 계측해 확인.

## 미해결 질문 (답변 요청)

- 테스트할 터치스크린 기기 보유 여부? (②는 실기 검증 필수 — 추측 금지)
- 우선순위/범위.

관련: BUG-090(트랙패드 줌, Ctrl+스크롤로 해결). 트랙패드 핀치는 WebView2 가 wheel 로도 안 줘서 불가였음 — 터치스크린은 경로가 달라 가능성 있음.

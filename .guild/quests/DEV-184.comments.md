## 설계 확정 (2026-07-03, admin 승인)

- **명칭**: 도서관(Library). **관리번호 prefix: `BOOK` (BOOK-001…)** — quest 와 별개 자체 카운터.
- **저장**: `.guild/library/{BOOK-NNN}.md` — quests 와 동일한 파일 진리원 패턴(`+++` TOML frontmatter: book_id/title/created_at/updated_at/deleted + markdown 본문). 카운터는 `.guild/library/.counter.toml`(단조 증가, 번호 재사용 금지). index.db 캐시(`library_docs`) + journal op + snapshot(SOURCE_SUBDIRS 에 `library`) 포함.
- **참조**: `BOOK-NNN` 은 XXX-NNN 형식이라 기존 cross-link(DEV-140) 정규식에 그대로 잡힘 — `[[BOOK-001]]` + bare 인식 + 편집기 자동완성 모두 재사용, refHref 만 `/library?id=` 분기 추가. (DEV-173 규칙 확장과 동일 패턴.)
- **GUI**: `/library` — rules 페이지 패턴(좌측 목록 + 우측 뷰/편집). Nav 링크. 첨부 지원 — DEV-097 '글로벌 첨부'는 도서관 문서 링크로 대체(기존 결정 유지).
- **CLI/HTTP**: `openguild library new/list/show/update/delete` + `/api/library` CRUD (invoke 와 1:1 — DEV-193 교훈).

`justfile`에 `build-debug` recipe만 추가했다.

- 먼저 기존 `build-frontend` dependency로 정적 frontend 자산을 생성한다.
- 이어서 `cargo build --workspace`로 Rust workspace를 debug profile로 빌드한다.
- `cargo tauri build`나 `.app`/installer 패키징은 포함하지 않는다.

저장소 규칙에 따라 실제 build/test는 자동 실행하지 않았다.

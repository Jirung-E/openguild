고침(Testing) — 브라우저가 그려 주는 구석 손잡이(CSS `resize`)가 남은 곳을 전부 찾았다. 세 곳이었다.
- 새 퀘스트 창의 설명 입력칸
- 새 캠페인 창의 본문 입력칸
- 설정 → 프리셋 가져오기(JSON) 입력칸

셋 다 브라우저 손잡이를 끄고 SizeGrip(댓글 · 메모와 같은 손잡이 — Shift 로 2배, 휴대폰 손가락, 화살표 키)을 아래에 뒀다. 나머지 입력칸(댓글 · 답글 · 메모 · 마크다운 편집기 · 작업 기록)은 이미 SizeGrip 이다. 검색 팔레트의 미리보기 경계선은 창을 나누는 막대라 손잡이와는 다른 것이라 그대로 뒀다.

다시 생기지 않게 시험으로 묶었다(SizeGrip.test.ts): CSS 로 `resize` 를 켜는 곳이 없어야 하고, textarea 가 있는 화면은 `resize: none` 과 SizeGrip 을 함께 둬야 한다. 고치기 전 코드에서는 실패한다.

확인: 시험 서버(웹, WebKit) — 새 퀘스트 창에 손잡이 1개, 입력칸 resize: none, 손잡이를 80px 끌면 높이 116 → 192.

테스트 방법: 새 퀘스트 · 새 캠페인 창의 입력칸 아래 손잡이를 끌어 본다. 구석의 빗금 손잡이가 없으면 정상.

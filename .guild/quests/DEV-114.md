DEV-074 의 dark/light/system 외에 사용자가 직접 토큰 색 (--bg / --text / --accent / --success / --btn-primary-* 등) 을 조정해 자신만의 테마를 만들고 저장 / 전환 가능하게 함.

작업 분해:
- 사용자 정의 테마는 `.guild/theme.toml` (또는 영속 store) 에 저장. 토큰 → hex 매핑 + 다크/라이트 기반.
- Settings 페이지에 '테마 편집기' 섹션: 토큰별 color picker + live preview (`<html>` 에 직접 적용).
- 프리셋 (이름 + 토큰 set) 다수 저장 + 선택. dark / light / system 옆에 사용자 프리셋 노출.
- 토큰 기본값 reset.
- export / import (JSON) — 프리셋 공유.
- CodeMirror oneDark 도 사용자 테마와 어울리는 inline EditorView.theme 으로 대체 (옵션).

의존:
- DEV-074 (테마 토큰 시스템) — 완료.
- Cytoscape stylesheet 도 사용자 토큰 따라 buildCyStyle 결과 갱신 (이미 theme 별 hex 명시).

확인 필요:
- 어디까지가 베타에 들어갈지. 단순 "버튼 색 1~2개 사용자 조정" vs "풀 토큰 에디터" — 사용자 답변 필요.

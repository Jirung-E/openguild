사용자 보고 묶음 — `openguild comments` 와 `openguild quest comment` 의
옵션셋/기본 동작 통일.

## 보고된 문제

1. `openguild comments` 를 옵션 없이 실행하면 길드의 **모든** 댓글을 출력 —
   기본값으로는 과함. 전체 출력은 명시 옵션(예: `--all`)으로 분리하고 기본은
   제한(최신 N개 등)으로.
2. `quest comment show` 도 마찬가지 — 옵션 없이 그 퀘스트의 전체 댓글 출력.
   동일하게 기본 제한 + `--all` 분리.
3. `quest comment` 에도 `comments` 가 가진 필터 옵션(--author/--since/
   --until/--grep/--discussion/--unresolved/--limit/--summary)이 필요.
4. 반대로 `comments` 에는 `quest comment show` 가 가진 tree 출력(--tree,
   --depth, --with-parents 계열)이 없음.

## 방향 (사용자 제안 그대로)

두 명령의 옵션셋을 통일하고 **같은 엔트리 포인트(공용 핸들러)** 로 실행 —
`quest comment` 는 해당 퀘스트의 댓글만 넘겨주는(스코프만 좁힌) 래퍼가
되는 구조. 현재 run_comment_cmd(CommentScope 로 quest/campaign 공용)가
이미 있으므로, comments 전역 검색 쪽 로직과 합쳐 옵션 파싱/렌더링(목록·
tree·요약)을 단일 구현으로.

## 주의

- 기본 출력 제한을 바꾸면 기존 스크립트/에이전트 워크플로가 영향받음 —
  CHANGELOG/docs(AGENTS_OPENGUILD_USAGE.md) 갱신 필수.
- --json 출력 스키마는 양쪽이 이미 다를 수 있음 — 통일 시 하위호환 검토.

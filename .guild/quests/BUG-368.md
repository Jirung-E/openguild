## 문제

퀘스트 목록(트리 보기)에서 자식 퀘스트를 접고 펴는 삼각형이 너무 작다(admin). 누르는 범위는 괜찮다.

## 원인

작은 삼각형 글자(`▸` `▾`)를 가장 작은 글자 크기(`--fs-xs`, 11.5px)로 그린다. 도서관 폴더 트리는 큰 삼각형(`▶` `▼`)을 쓴다.

## 고칠 것

도서관 폴더 트리와 같은 `▶` `▼` 로 바꾸고 한 단계 키운다. 누르는 범위(폭 1.25rem)는 그대로.

## 고친 것

`QuestListItem.svelte` — `▸` `▾` → `▶` `▼`(도서관 폴더 트리와 같게), 글자 `--fs-xs` → `--fs-sm`, 마우스를 올리면 강조색(도서관과 같게).

## 확인

웹 화면(시험용 길드 복사본, develop 서버) 스크린샷 전후 비교 — 삼각형이 또렷이 커졌다. 누르는 범위: 전 20×18.4px → 후 20×20.5px(폭 그대로, 조금 커짐).

## Test plan

- 퀘스트 목록 트리 보기에서 삼각형 크기가 알맞은지, 라이트 · 다크 테마에서 본다.

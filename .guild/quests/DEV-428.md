버튼을 **공통 부품 하나**로 바꾼다 — [[DEV-427]] 의 디자인 언어를 화면에 적용하는 첫 단계(admin).

버튼부터인 이유: 효과가 가장 크고 바로 눈에 보인다. 지금 버튼 클래스가 20종 넘고 `.btn-cancel` 이
8개 파일, `.btn-save` 가 6개 파일에 따로 정의돼 있다. 같은 "취소" 가 화면마다 조금씩 다르다.

## 할 일

- 종류를 정한다 — 주(저장·만들기) / 보조(취소) / 위험(삭제) / 조용한(텍스트형) / 아이콘 정도
- 부품 하나(또는 공통 클래스)로 만들고, 지금 클래스들을 옮긴다
- 크기·간격·모서리는 DEV-427 토큰만

## 하지 않는 것

버튼 말고 다른 부품(입력칸 · 팝업 · 알약)은 그 화면을 고칠 때 같이 옮긴다 — 한 번에 65개 화면을
갈아엎지 않는다.

## 한 것 (2026-10-11)

`global.css` 에 공통 버튼 `.btn` 하나를 두고, 화면마다 따로 정의돼 있던 버튼을 옮겼다. 종류는 **색으로만**
가르고 크기 · 모서리 · 여백은 같다. 값은 [[DEV-427]] 토큰만 쓴다.

| 클래스 | 예전 |
|---|---|
| `btn` | `.btn-cancel` · `.btn-no` · `.btn-edit` · `.btn-plain` · `.btn-link` · `.btn-reset` · `.btn-tpl` · `.btn-del-no` · 관리 화면 맨 `button` |
| `btn btn-primary` | `.btn-save` · `.btn-create` · `.btn-go` · `.btn-yes` · `.btn-pick` · 화면마다의 `.btn-primary` · `.btn.save` · `.btn.primary` |
| `btn btn-danger` | `.btn-delete` · `.btn-del-yes` · `.btn-overwrite` · `.btn-edit.danger` · `.btn-yes.danger` · `.btn.danger` · `.del-snap` |
| `btn btn-warning` | `.btn-update` · 백업 `.restore` |
| `btn btn-sm` | `.btn-new` · `.btn-check-upd` · `.btn-up` |
| `btn btn-quiet` | (새로) 테두리 없는 조용한 버튼 |

- 21개 파일에서 옛 정의를 지우고, 배치(margin · align-self)만 남겼다.
- 원칙에 맞춰 고친 것: 환영 화면의 "초기화하고 열기" 는 빨강 → 초록(되돌릴 수 없는 일이 아니다). 관리
  화면 상태 · 타입 만들기의 파랑 버튼 → 초록(주 동작 색은 하나). 환영 화면 폴더 고르기의 파랑 → 초록.
- `line-height` 는 일부러 안 정했다 — 본문(1.6)을 물려받던 예전 버튼과 높이를 맞춘다.
- **검사** `check:tokens` 에 규칙 추가 — 컴포넌트에서 `.btn*` 의 모양(배경 · 테두리 · 글자색 · 여백 ·
  글자 크기 · 모서리)을 다시 정하면 실패. 상단 바 아이콘 버튼(창 크롬)만 예외.
- 대상이 아닌 것: 상단 바 아이콘 버튼, 탭 · 세그먼트 · 타일 · 목록 줄, 보드 툴바 — 버튼 요소지만 다른
  부품이다. 입력칸 · 팝업도 이번엔 안 했다(이 퀘스트의 "하지 않는 것").
- 문서 [[BOOK-009]] 에 버튼 절, 규칙 `frontend-design-language` 에 한 줄.
- 태그 화면 시험이 저장 버튼을 `.btn.save` 로 찾고 있어 `.btn.btn-primary` 로 고쳤다.

확인: 14개 화면(홈 · 새 캠페인 · 퀘스트 상세 · 삭제 확인 창 · 댓글 · 도서관 · 아이콘 보기 · 규칙 · 태그 ·
관리 · 백업 · 설정 · 작업 기록 · 캠페인) × 다크 · 라이트, [[DEV-427]] 빌드와 나란히 — 같은 "취소" 가 어디서나
같은 모양이 됐고 깨진 곳 없음. `just test` 851 통과.

## 테스트 방법

1. 여러 화면의 저장 · 취소 · 삭제 버튼을 본다 — 크기 · 모서리 · 여백이 같다. 저장은 초록, 삭제는 빨강
   테두리, 나머지는 회색 테두리.
2. 마우스를 올리면 배경이 살짝 바뀌고, Tab 으로 오면 파란 링이 보인다.
3. 확인 창: 삭제처럼 위험한 일의 "예" 는 빨강, 아니면 초록.
4. 관리 → 백업: 복원은 노랑, 삭제는 빨강. 설정 → UI 크기를 바꾸면 버튼도 함께 커진다.

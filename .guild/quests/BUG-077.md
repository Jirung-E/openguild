admin reindex 에 문제(비정상 파일 등)가 있을 때, 무엇이 문제인지는 +layout 시동 스캔(list_problem_files 토스트) + admin loadProblemFiles(패널)에서 나오는데 이건 페이지 로드 때만 실행됨. reindex 핸들러가 문제 있을 때(skipped>0) 일부러 새로고침을 안 해서, 수동 Ctrl+R 전까지 상세가 안 보였음. 수정: reindex 후 항상 자동 새로고침 → 시동 스캔/패널이 다시 돌아 문제 자동 표시 + 데이터 stale 해소.

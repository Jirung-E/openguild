admin 요청:
- 도서관 검색이 무조건 전역 검색이 되는데, 현재 폴더와 하위 폴더만
  검색되도록 해야 함.
- 폴더 이름은 검색이 안 됨 — 폴더 이름도 검색 대상에 포함해야 함.

## 수정
- `library-tree.ts` 에 `searchLibrary(tree, books, query, scope)` 추가 —
  기존 `searchBooks`(제목/본문, 전역)는 유지하되, 폴더 이름 매칭 +
  `scope`(현재 폴더 경로, "" = 전체) 로 그 폴더 자신 + 하위만 필터링.
- explorer(아이콘) 모드는 `explorerPath` 를 scope 로 사용(탐색기의 "여기서
  찾기" 감각). tree 모드는 "현재 폴더" 개념 자체가 없어(트리 전체를 항상
  다 보여줌) 전역 유지 — 폴더 이름 매칭만 추가, 클릭하면 그 폴더를 펼쳐서
  보여줌(revealFolder).
- 단위 테스트 추가(scope 필터링, 폴더명 매칭, 하위 폴더 포함/조상 폴더
  제외 케이스).

## 테스트 방법
- `cd gui/frontend && npm test -- --run` (library-tree.test.ts 신규 케이스
  포함) + `npm run check` + `npm run check:no-hex`.
- 실기: 아이콘 뷰에서 하위 폴더로 들어간 뒤 검색 → 그 폴더 밖의 문서/폴더는
  결과에 안 나오는지. 폴더 이름으로 검색해도 매칭되는지.

## 증상

- `cargo build -p openguild-gui` (또는 `cargo run`) 만 실행하면 Tauri 가 embed
  하는 frontend (`gui/frontend/build/`) 가 **이전 빌드 결과** 그대로.
- frontend `.svelte` / `.ts` 를 수정한 뒤 `cargo build` 만 하면 변경 반영 안 됨.
- 사용자가 매번 수동으로 `cd gui/frontend && npm run build` 를 먼저 실행해야 함.

## 원인

- Tauri 의 `tauri.conf.json` 의 `build.beforeBuildCommand` 설정으로
  pre-build 명령을 줄 수 있음 — 현재 미설정 (또는 dev 모드 전용으로만).
- release 빌드도 동일 — `cargo build --release` 시에도 stale embed 가능.

## 작업

### A. `tauri.conf.json` 의 `beforeBuildCommand` 설정
```jsonc
{
  "build": {
    "beforeBuildCommand": "npm --prefix frontend run build",
    "frontendDist": "../gui/frontend/build"
  }
}
```
- `cargo tauri build` 가 자동으로 npm build 먼저 실행 → embed.
- `cargo build -p openguild-gui` 는 Tauri CLI 를 거치지 않으므로 여전히 stale
  가능 — 그래서 다음 B 추가.

### B. `build.rs` 에서 npm 빌드 트리거 (선택)
- `gui/build.rs` 에 frontend 파일 변경 감지 → `npm run build` 실행.
- 단 CI / docker 에서 npm 없는 환경 고려 — env 로 skip 옵션.

### C. 문서화
- README / AGENTS_OPENGUILD_USAGE 에 "frontend 변경 시 `npm run build` 필수" 명시.
- 가장 적은 코드로 즉시 해결.

## 권장 순서
1. **C** (즉시).
2. **A** (Tauri release 빌드 자동화).
3. **B** (cargo build 도 자동화 — 신중하게).

## 적용 (2026-06-03)

옵션 **A** 는 이미 `gui/tauri.conf.json` 에 `beforeBuildCommand: "npm run
build"` 로 설정되어 있었지만 `cargo build -p openguild-gui` 가 Tauri CLI 를
거치지 않아서 미적용이었음. → **B** (build.rs) 로 정착.

### `gui/build.rs` 변경
- `tauri_build::build()` 후 frontend src / 설정 변경 감지 →
  `npm run build` 직접 실행.
- `cargo:rerun-if-changed`: `frontend/src` `static` `package.json`
  `package-lock.json` `svelte.config.js` `vite.config.ts` `tsconfig.json`.
- 환경 안전망:
  - `OPENGUILD_SKIP_FRONTEND=1` 로 명시 skip (CI / docker / backend 만 iter 시).
  - npm 미설치 시 warning 만 (panic 안 함, 기존 `frontend/build/` 재사용).
- 실 build 실패 (`npm run build` exit != 0) 시 panic — embed 무결성.

### 검증
- frontend src 변경 후 `cargo build -p openguild-gui` →
  `warning: openguild-gui@0.1.0-beta: BUG-038 frontend rebuilt (npm run build)`.
- `OPENGUILD_SKIP_FRONTEND=1 cargo build -p openguild-gui` →
  `... OPENGUILD_SKIP_FRONTEND set — skipping frontend build ...`.
- `cargo test -p openguild-cli help_output_has_no_quest_id_leaks`: 통과
  (BUG-016 정책 — 본 fix 가 doc comment 안 건드림).

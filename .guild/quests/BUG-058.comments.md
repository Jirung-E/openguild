## 구현 (간단)

`global.css` 의 `[data-theme='light']` 에 `color-scheme: light;` 한 줄 추가.

이전엔 `:root` 의 `color-scheme: dark` 가 라이트 테마에도 상속되어 native date picker 의 달력 아이콘이 다크 모드 (밝은 색) 로 렌더링 → 흰 배경에 묻혀 안 보였음.

## 테스트 방법

1. Settings → 테마를 **라이트** 로 설정.
2. 새 quest 작성 화면 (또는 quest detail 의 due 편집) 의 `<input type="date">` 우측 달력 아이콘이 **회색** 으로 보여야 함 (이전엔 거의 안 보이는 흰색).
3. 달력 아이콘 클릭 시 native picker 가 라이트 스타일 (흰 배경 + 검정 글자) 로 떠야.
4. 테마를 **다크** 로 토글 → 같은 아이콘이 밝은 색으로 보이고 picker 는 다크 스타일.
5. 테마를 **system** 으로 토글 후 OS 테마 변경 → 자동 반영.

테스트 영역 — 날짜 입력 있는 모든 페이지: `/campaigns/new`, `/campaigns/[slug]` 편집, `/quests/[id]` 의 due 편집.

# [gui] 도서관 문서 이름이 옆 영역을 침범함

사용자 보고: 도서관에서 문서 이름이 옆 영역을 침범하는 현상.

## 원인 (재현 확인)

**아이콘 보기(타일 뷰)** 한정. `.tile` 이 `align-items: center` 인 column
flex 라 자식(`.tile-label`)이 stretch 되지 않고 content 폭을 그대로
가진다 — 긴 제목의 label 폭이 타일(92px)을 훨씬 넘어(재현 시 92px 타일에
265px 라벨) 옆 타일 영역 위로 겹쳐 그려졌다. `word-break: break-word` 는
있었지만 요소 자체 폭이 제한되지 않으면 줄바꿈이 일어나지 않는다.
(트리/리스트 뷰의 `.book-title` 은 ellipsis 로 이미 정상.)

## 수정

`.tile-label` 에 `max-width: 100%` 로 타일 폭 제한(이제 break-word 가
실제로 줄바꿈) + 과도하게 긴 제목은 `line-clamp: 3` 으로 3줄 말줄임.

## 테스트 방법 (1 실기 확인 완료)

1. 긴 한글 제목/공백 없는 긴 영문 제목의 문서를 만들어 아이콘 보기에서
   라벨이 타일 폭(92px) 안에서 줄바꿈되고 3줄 초과 시 말줄임되는지 —
   재현 스크립트로 침범 0 확인 완료.
2. `npx svelte-check` 클린.
3. (사용자 확인) 실제 GUI 아이콘 보기에서 시각 확인.

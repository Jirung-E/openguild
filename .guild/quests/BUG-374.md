윈도우 세션 보고(2026-10-25, DEV-327 시험 중):

- `just build-desktop`(= `cd gui && cargo tauri build`)만 하면 윈도우 설치본에 **옛 CLI** 가 실린다.
- `gui/nsis/installer.nsi` 는 `target\release\openguild.exe` · `openguild-server.exe` 를 그대로 싣는데(SecCli · SecServer), 이 둘은 tauri build 가 만들지 않는다. 그래서 그 자리에 남아 있던 예전 빌드(pull 전 12:41)가 실렸다.
- release.yml 은 그 앞에 `cargo build --release -p openguild-cli -p openguild-server` 를 돌려서 배포본에는 문제가 없다. 로컬 레시피만 순서가 빠졌다.

고칠 것: build-desktop 이 release.yml 과 같은 순서로 CLI · 서버를 먼저 빌드한다.

사용자 보고: 리눅스에서 UI 크기 조절만이 아니라 GUI 자체가 전반적으로
느림. 특히 보드에서 심하게 버벅임. "실제로 연산량이 많은 게 아니라 뭔가
이상한 것 같음" — 정확한 직감으로 보임.

## 유력 원인 가설 (Tauri/Linux 에서 매우 흔한 케이스)

WebKitGTK 의 DMABUF renderer 가 특정 GPU 드라이버(특히 NVIDIA, 일부
Mesa/가상머신) 조합에서 GPU 가속 합성이 깨지고, 소프트웨어 렌더링으로
떨어지면서 앱 전체가 버벅이는 문제. 캔버스 기반 화면(보드 = Cytoscape
canvas)이 가장 크게 체감됨 — "연산량 대비 비정상적으로 느림" 증상과 일치.
Tauri 커뮤니티 표준 완화책이 `WEBKIT_DISABLE_DMABUF_RENDERER=1`.

## 적용한 완화 (1차)

gui run() 최초 진입 시 Linux 한정으로 `WEBKIT_DISABLE_DMABUF_RENDERER=1`
설정(사용자가 이미 지정했으면 존중). 웹뷰 생성 전에 1회.

## 확인 요청 (Linux 실기)

1. 이 빌드로 보드 버벅임이 해소되는지.
2. 해소 안 되면 다음 진단 순서:
   - `WEBKIT_DISABLE_COMPOSITING_MODE=1 openguild-gui` 로 실행해 비교.
   - GPU/드라이버 정보(NVIDIA 여부, Wayland/X11) 공유.
   - 보드 외 화면(목록/상세)도 느린지, 스크롤/타이핑도 느린지 구분.
3. 환경 정보에 따라 2차 조치(조건부 env, 설정 노출, WebKitGTK 버전 가이드)
   결정.

## 배경

[[DEV-312]]의 macOS DMG는 GUI 앱을 Applications에 복사하는 디스크 이미지일 뿐, Windows NSIS처럼 GUI·CLI·Server 선택 설치와 PATH 등록을 수행하지 못한다. tar.gz 배포는 Cargo 의존을 제거하지만 설치·삭제·업데이트가 수동이라는 한계가 있다.

## 목표

macOS에서 Windows 설치본과 유사하게 하나의 `.pkg`로 GUI·CLI·Server를 설치할 수 있게 한다.

## 제안 구조

- GUI 앱 내부 `Contents/Resources/bin/`에 `openguild`와 `openguild-server`를 포함한다.
- `.pkg`가 `/Applications/openguild.app`을 설치하고 `/usr/local/bin/openguild`, `/usr/local/bin/openguild-server` 심볼릭 링크를 만든다.
- 가능하면 distribution package의 choices로 GUI/CLI/Server 선택 설치를 제공한다.
- CLI/Server를 앱 내부에 두어 Tauri `.app.tar.gz` 자동 업데이트가 세 바이너리를 함께 교체하게 한다. 외부 경로에 복사해 GUI만 갱신되는 macOS판 [[BUG-151]] 재발을 막는다.

## 고려사항

- 시스템 경로 설치 및 심볼릭 링크 생성에는 관리자 권한이 필요하다.
- Apple Developer 서명·공증이 없는 동안 `.pkg`에도 Gatekeeper 경고가 남는다.
- 새 설치, 구성요소 선택, 기존 버전 업데이트, 제거, GUI 자동 업데이트 후 CLI/Server 버전 동기화를 각각 검증해야 한다.
- Tauri 기본 번들 타깃에 `.pkg`가 없으므로 `pkgbuild`/`productbuild` 및 별도 CI 단계가 필요하다.
- 인앱 안내를 추가할 경우 [[no-native-dialogs]] 규칙을 따른다.

## 완료 조건

1. Apple Silicon `.pkg`가 CI와 태그 Release에서 생성된다.
2. GUI·CLI·Server가 선택된 구성대로 설치되고 PATH에서 실행된다.
3. GUI 자동 업데이트 후 CLI·Server도 같은 버전으로 유지된다.
4. 제거 시 설치한 앱·링크·영수증이 예측 가능하게 정리된다.
5. README/USAGE에 `.pkg` 설치와 미서명 Gatekeeper 절차가 반영된다.

관련: [[DEV-313]], [[DEV-315]], [[BUG-151]], [[release-process]].

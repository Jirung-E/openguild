## 기능
설치 디렉토리에 사용 설명서 자동 동봉.

## 변경
- `docs/USAGE.md` 신설 — 사용자 친화 빠른 시작 (길드 만들기 / 핵심 개념 / CLI / 백업 / 자동 업데이트 / 문제 해결).
- `gui/tauri.conf.json` 의 `bundle.resources` 에 README.md / USAGE.md 매핑.
  - 설치 후 위치: `<install_dir>/resources/docs/`.

## 테스트
1. `cargo tauri build --bundles nsis` 로 installer (`.exe`) 생성.
2. 생성된 setup 으로 설치.
3. 설치 디렉토리 (기본 `C:\Program Files\openguild\`) 안 `resources/docs/` 에 `README.md` / `USAGE.md` 가 있는지 확인.

## 한계 (별도 작업)
- LICENSE 파일 미존재로 동봉 안 됨. LICENSE 추가 후 본 매핑에 한 줄 추가.
- 시작 메뉴 shortcut 의 "사용 설명서" 미구현. `.md` 는 OS 기본 연결 X → PDF/HTML 변환 또는 in-app 도움말 통합 필요.

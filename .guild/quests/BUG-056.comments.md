## 구현 (간단)

Tauri WebView 의 native `window.confirm()` 이 silent return 되어 댓글 / 길드 규칙 / 캠페인 / 체크리스트 4건의 삭제가 확인 없이 진행되던 문제.

신규 `ConfirmDialog.svelte` 컴포넌트 (theme 토큰 + Esc/Enter 키보드 + 오버레이 클릭 cancel + `danger` 변형) 도입 후 4건 모두 state 기반 모달 흐름으로 교체.

## 테스트 방법

1. **댓글 삭제**: 임의 quest 의 detail 페이지 → 댓글 섹션의 본인 댓글 옆 "🗑 삭제" 클릭 → 모달 "이 댓글을 삭제할까요?" 표시 → "취소" 누르면 댓글 유지 / "삭제" 누르면 사라짐.
2. **규칙 삭제**: Rules 페이지 → 임의 규칙 선택 → "삭제" 버튼 → 모달 "'{slug}' 규칙을 삭제할까요?" → 동일 확인.
3. **캠페인 삭제**: 임의 캠페인 detail → "삭제" → 모달 "캠페인 '{title}' 을 삭제할까요?" → 확인.
4. **체크리스트 삭제**: 캠페인 detail 의 체크리스트 항목 옆 "×" → 모달 "체크리스트 항목 '{text}' 을 삭제할까요?" → 확인.
5. **공통 키보드**: 모달 떴을 때 `Esc` = 취소, `Enter` = 확인, 오버레이 (모달 밖 어두운 영역) 클릭 = 취소.
6. **다크/라이트 둘 다**: 테마 전환 후 1~5 반복. 모달 배경 / 글자 / 버튼 색이 각 테마에 맞게 나오는지.

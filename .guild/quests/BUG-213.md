admin 보고: 댓글 입력 박스에서 스크롤바가 안 보인다. 마크다운 편집기 모드로
바꾸면 보이는데 일반(textarea) 모드에서는 안 보인다.

## 원인

`OverlayScrollbar` 는 콘텐츠 높이 변화를 **MutationObserver(childList/subtree)**
로 감지한다. CodeMirror(마크다운 모드)는 줄마다 DOM 노드가 생겨 이게 걸리지만,
**textarea 의 내용은 자식 노드가 아니라 값**이라 타이핑해도 mutation 이 없다.
ResizeObserver 도 box 크기만 보므로 마찬가지.

그래서 `contentH`(scrollHeight)가 마운트 시점(빈 입력, scrollHeight ==
clientHeight) 값에 고정되고 `needed = contentH > viewportH` 가 계속 false —
스크롤이 실제로 생겨도 thumb 자체가 그려지지 않는다.

`onScroll` 도 `scrollTop` 만 갱신하고 재측정하지 않아 스크롤 중에도 복구되지
않는다. native 스크롤바는 `.body-input` 에서 CSS 로 숨겨져 있으므로(BUG-157)
결과적으로 **스크롤 표시가 아무것도 없는** 상태가 된다.

## 대상

`.body-input` 을 쓰는 모든 곳 — 새 댓글 / 답글 / 댓글 수정 (quest·campaign 공통).

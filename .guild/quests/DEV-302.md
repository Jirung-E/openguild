BUG-169 에서 **마크업(.svelte DOM)** 의 컬러 이모지 아이콘은 모두 SVG 로
교체했고 `check:no-emoji` 가드로 재발을 막았다. 남은 두 부류는 성질이 달라
별도로 다룬다.

## 1. JS 가 문자열로 조립하는 SVG 안의 이모지

- `lib/utils/quest-node-svg.ts` — `⛺ {날짜}`(캠페인 기한 우세 표시, 185행),
  `⏱ {날짜}`(246행)
- `lib/components/QuestBoard.svelte` — `💬 {개수}`(177행), `⛺`(207행),
  `⏱`(265행)

이들은 `<text>` 안에 그대로 들어가는 문자라 컴포넌트를 쓸 수 없다 — SVG
`<path>` 문자열을 만들어 좌표까지 맞춰야 하고, 노드 레이아웃(폭 계산)도 함께
손봐야 한다. 보드 노드 SVG 는 `pillTextWidth()` 등으로 폭을 계산하므로
아이콘을 path 로 바꾸면 그 계산도 바뀐다.

## 2. i18n 라벨 문자열의 이모지

`lib/stores/locale.ts`:

| 키 | 이모지 |
|---|---|
| `welcome.pickFolder` | 📁 |
| `worklogCard.title` / `worklogPage.title` | 🕘 |
| `board.selectBtn` | 🔘 |
| `worklogPage.notePre` / `notesInRangePre` | 📝 |
| `editor-links.ts` 의 `displayLabel` | 🏷️ 🔗 |

라벨 문자열에 아이콘이 섞여 있는 구조 자체가 문제다(번역 문구와 아이콘의
관심사 분리). 아이콘을 마크업으로 빼고 라벨은 텍스트만 남기는 리팩터가 맞다.
`editor-links.ts` 의 `displayLabel` 은 CodeMirror 자동완성이 문자열만 받으므로
렌더러 쪽(`QuestCommentsSection` 의 wiki-id 처럼)에서 아이콘을 붙여야 한다.

## 유지하는 것 (교체 대상 아님)

- 댓글 반응 `REACTION_SET = ['👍','✅','❓','❌']` — 반응 자체가 이모지다.
- 사용자가 입력한 본문/제목 안의 이모지.

## 배경

사용자 요청 — admin 에서 reindex 누르면 현재 화면이 자동 새로고침되도록.

이전 동작: `adminApi.reindex()` 성공 시 토스트만 띄우고 `drift = null` 로 reset. snapshots 등 admin 페이지 자체 데이터도 갱신 안 됨 + 사용자가 Board/List/Detail 로 이동해도 (SPA 라 onMount 재실행은 됨) 메모리에 캐시된 store 가 있다면 stale.

## 수정

`gui/frontend/src/routes/admin/+page.svelte` 의 `onReindex`:
- 성공 토스트 ("reindex 완료 — 데이터 새로고침") 후 `setTimeout(() => window.location.reload(), 600)`.
- 토스트가 600ms 짧게 보인 뒤 full reload — 모든 페이지/store 가 fresh.

대안 검토:
- `invalidateAll()` — load() 안 쓰는 이 프로젝트엔 효과 없음.
- 페이지별 refresh 함수 호출 — 모든 페이지 cross-cutting 변경 필요.
- 가장 확실한 = `window.location.reload()`.

confirm dialog 는 DEV-119 sweep 에서 사용자 지시로 제외했으므로 그대로 native `confirm()` 유지.

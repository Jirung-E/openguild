구현 — '연관 추가' 메뉴에 **부모 퀘스트** 줄 추가(기존 연결 / 새로 만들기 둘 다).

- `ComboMode` 에 `'parent'` 추가. 후보 조회는 기존 API 그대로
  (`candidates?relation=parent` — 사이클·자기 자신 등은 서버가 걸러준다).
- 선택 시 `changeParent(detail.id, { parent_quest_id: 고른퀘스트 })`.
  **서브퀘스트와 방향이 반대**라 분기를 따로 뒀다(서브는 상대의 부모를 이
  퀘스트로, 부모는 이 퀘스트의 부모를 상대로).
- 새로 만들기도 지원 — 생성된 퀘스트를 이 퀘스트의 부모로 연결.
- **부모가 이미 있으면 메뉴에서 이 줄을 숨긴다** — 부모는 하나뿐이고, 해제는
  부모 섹션에서 한다. 빈 섹션을 숨기고 추가는 메뉴로 몬 DEV-279 규칙과 동일.

## 검증 (테스트 길드, 실제 화면 조작)

```
부모 없음  → 메뉴: [부모 퀘스트] 서브퀘스트 선행 후속
'부모 퀘스트 → 기존 연결' → 모달 제목 "상위 퀘스트 지정", 후보 목록 정상
REQ-002 선택 후:
  DEV-002 의 부모      = REQ-002   ✅
  REQ-002 의 서브퀘스트 = [DEV-002] ✅  (반대 방향도 자동 성립)
  화면에 부모 섹션 표시  = true     ✅
부모 생긴 뒤 메뉴 → 서브퀘스트 선행 후속 (부모 줄 사라짐) ✅
```

검증용으로 건 관계는 `quest parent DEV-002 --detach` 로 원복했다.

## 왜 빠져 있었나

타입(`CandidateRelation`)·서버·Tauri 커맨드·`changeParent` API 는 전부 이미
있었다. DEV-278/279 에서 메뉴를 만들 때 sub/prereq/succ 세 가지만 넣었고,
부모는 "상대 퀘스트로 가서 서브퀘스트로 추가" 라는 우회로가 있어 드러나지
않았다.

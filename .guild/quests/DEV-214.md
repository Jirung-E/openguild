댓글이 접혀 있을 때 그 안의 토론(discussion)을 놓치는 문제 방지 — 접힘 3지점에 상태 글리프(✗ 미해결 / ✓ 해결, DEV-150 글리프·색 토큰 재사용).

## 구현 (2026-07-04, QuestCommentsSection.svelte 단일)
1. **스레드 접기(▶)**: '답글 N' 옆 — 자손 중 토론 있으면 글리프(미해결 하나라도 있으면 ✗ 우선). threadDiscState 파생 맵(자손만 — root 자신은 접혀도 보임).
2. **본문 접기(1줄 미리보기)**: 그 entry 자신이 토론이면 미리보기 앞에 글리프.
3. **섹션 전체 접기**: 헤더 카운트 옆 '✗ N' 뱃지 (미해결 있을 때만 — 완료 차단과 직결이라 최우선 노출).
색: --danger/--success 토큰. 전체 접기(DEV-190)도 동일 경로(스레드/본문 접기 상태) 커버.

## 테스트 방법 (재빌드 후)
1. 토론 답글 있는 스레드 접기(▶) → '답글 N' 옆 ✗(미해결)/✓(전부 해결) 표시, 펼치면 사라짐.
2. 토론 댓글 본문 접기(#id 클릭) → 미리보기 앞 글리프.
3. 섹션 접기 → 미해결 있으면 헤더에 '✗ N', resolve 후 재접기 → 사라짐.
4. 전체 접기(⊖) 상태에서도 1·2 표시.
5. cd gui/frontend && npm run check.

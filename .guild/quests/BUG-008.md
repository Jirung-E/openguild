## 증상

정렬 버튼을 빠르게 두 번 클릭하면 첫 번째 애니메이션 도중 두 번째 애니메이션이
시작되어 노드들이 움찔거림 (위치 점프).

## 원인

`arrangeNodes` / `arrangeNodesGrouped` 의 흐름:
```ts
arranging = true;
node.animate({ duration: 200, ... });   // 비동기 — 즉시 return
savePromises.push(updatePosition(...));
// ...
await Promise.all(savePromises);        // 로컬 SQL — 수 ms
arranging = false;                       // ← animate 완료 전에 해제됨
```

`cytoscape.animate({duration: 200})` 는 백그라운드로 진행하지만 가드는 **server
response 까지만** 보호 (수 ms). 즉 ~5~50ms 만에 `arranging = false` → animate
는 200ms 째 진행 중인데 가드 해제 → 두 번째 클릭이 들어오면 새 animate trigger
→ 첫 animate 가 중간에 새 위치로 jump.

BUG-006 (reactivity fix) 와 인접 영역 — `disabled={arranging}` 이 reactive 동작
은 정확하지만, 그 reactive 변수 자체가 너무 일찍 false 가 되어 disabled-off
짧은 구간에 새 클릭이 통과.

## 수정 (2026-05-20)

`arranging` 해제 시점을 **animate 완료 후** 로 옮김:

```diff
- await Promise.all(savePromises);
+ // animate 완료 + SQL 저장 둘 다 끝날 때까지 보호.
+ await Promise.all([
+     Promise.all(savePromises),
+     new Promise<void>((r) => setTimeout(r, ARRANGE_ANIM_MS))
+ ]);
  syncExpandedPos();
  arranging = false;
```

- `ARRANGE_ANIM_MS = 200` 상수 신설 — animate 의 `duration: 200` 과 동일 값.
- `arrangeNodes` / `arrangeNodesGrouped` 양쪽에 적용.
- 효과: animate 끝날 때까지 (~200ms) `arranging = true` 유지 → 그 사이 클릭은
  가드에서 차단.

## 회귀 / 부수 효과

- 정상 정렬 = 사용자 인지 지연 0 (이미 animate 200ms 기다리고 있으므로).
- 빠른 더블클릭 → 두 번째 무시 (사용자가 다시 누르려면 첫 animate 끝나야).
- `disabled={arranging}` 시각 피드백도 200ms 동안 유지 — BUG-006 의 "disabled
  너무 빨라 안 보임" 도 같이 개선.

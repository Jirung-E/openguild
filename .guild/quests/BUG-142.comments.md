## 테스트 방법 (보강)

⚠️ `target/release/openguild-gui` 직접 실행으론 검증 불가 — 리눅스 독바는 `.desktop` 등록이 있어야 앱을 인식함. 실제 패키지 설치로 확인해야 함:

```bash
cd gui && cargo tauri build --bundles deb
sudo dpkg -i ../target/release/bundle/deb/openguild_*.deb
openguild-gui   # 또는 앱 그리드에서 "openguild" 실행
```

- 독바/태스크바에 실제 openguild 로고(빨/초/파 겹친 사각형)가 뜨는지. 톱니바퀴 등 기본 아이콘이면 재현.
- 안 뜨면 GNOME Shell 캐시 가능성 → 로그아웃/재로그인(또는 X11 한정 `killall -SIGQUIT gnome-shell`) 후 재확인.

﻿BUG-200 에서 드러난 함정(미디어 쿼리를 기본 규칙보다 **앞**에 두면 같은 우선순위에서 순서로 진다)이 다른 곳에도 있는지 훑었다. admin 지적으로 도서관도 확인.

## 발견 (3건 중 2건이 실제 무효였다)
- `routes/rules/+page.svelte` `.sidebar` — 좁은 화면에서 우측 테두리·여백 제거가 **안 먹고 있었다**(DEV-257 작업의 일부가 무효).
- `routes/library/+page.svelte` `.sidebar` — 같은 문제. 처음 감사 스크립트가 놓쳤다(콤마 다중 셀렉터 + 블록 안 주석을 못 넘겨 두 번째 규칙을 파싱하지 못함). admin 이 "도서관도 같은 문제 아니냐"고 물어 재검사하며 발견.
- `routes/admin/+page.svelte` `th, td` — BUG-196 후속으로 넣은 셀 여백 축소가 죽어 있었다(백업 표가 들어맞은 건 `.snap-actions` 줄바꿈 덕이고, 여백 축소는 무효였다).
- `QuestList.svelte` `.tag-filter-chip` — 겹치는 속성이 없어 무해(그대로 둠).

## 조치
셋 다 미디어 블록을 기본 규칙 뒤(또는 스타일 끝)로 이동. 감사 스크립트도 고쳤다 — 주석 제거 후 콤마 분해까지.

## 검증(375px)
- 도서관 리스트뷰 사이드바: border-right 0px, padding-right 0px, border-bottom 1px, max-height 365px, 1열.
- 규칙 페이지 동일 구조.
- 어드민: 셀 여백 축소 반영.

## 교훈(규칙화 후보)
Svelte `<style>` 안에서 **미디어 쿼리 override 는 대상 규칙보다 뒤에** 둘 것. 특이성이 같으면 순서가 이긴다. 이번에 세 곳에서 조용히 죽어 있었다.

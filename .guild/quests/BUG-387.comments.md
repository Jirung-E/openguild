## 고침 — DOMPurify(A안, admin) + 목록 밖 태그는 글자로

1. **거르기**: `MarkdownView` 가 marked 결과를 `DOMPurify.sanitize` 로 거른 뒤 `{@html}`. 스크립트 · `on…` 속성 · `javascript:` 주소 · iframe · object · svg 등은 지운다. 더 막는 것: `style` 태그와 `style` 속성(스크립트 없이도 앱 화면을 덮어 꾸밀 수 있다), `form` · `button` · `textarea` · `select`. 의존성 `dompurify` 3.4.17(2026-10-12 출시) 고정.
2. **목록 밖 태그는 글자로**: 거르기 전에 marked 의 원문 HTML 토큰에서, 본문에 쓸 만한 태그 목록(a · b · br · code · details · summary · div · img · video · table … )에 없는 태그를 글자로 바꾼다. 실제 길드에서 원문 HTML 로 해석되는 47개가 **전부** 백틱 없이 쓴 자리표시(`<slug>` · `<String>` · `<ts>` …)나 태그 언급이었다 — 지금까지 화면에서 사라지고 있었고, `<style>` 은 뒤 문단을 CSS 로 삼켜 숨겼다(DEV-183 · DEV-131). 이제 글자로 보인다. 태그 찾기는 따옴표 속 `<` · `>` 를 넘어 읽는다(`srcdoc="<script>…"` 에서 끊기면 닫히지 않은 iframe 이 뒤를 삼켰다 — 시험이 잡음).

## 길드 확인(사본, 읽기만)
1,320 파일: 원문 HTML 토큰 47(전부 자리표시 · 언급), 일부러 쓴 HTML 0, 첨부 동영상 0. 코드블록 · 인라인 코드 속 HTML 모양 522 는 원래 글자 — 영향 없음.

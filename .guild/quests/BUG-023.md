1) Home 의 '진행 중 캠페인'에 현재 날짜가 시작일~종료일 안에 포함되는 캠페인만 (status=active 만으로는 부족 — 시작 전 / 종료 후 캠페인 노출됨). 2) 캠페인 detail 의 '퀘스트 연결' 입력이 datalist 인데 Quest Detail 의 + 기존 지정/추가 콤보 (QuestCombobox 컴포넌트) 와 모양 다름. 동일 컴포넌트로 통일.

## 구현 (2026-05-25)

### Part 1 — 진행 중 캠페인 기간 필터
`core/src/services/campaigns.rs::list_active_summaries` SQL 갱신:
```sql
WHERE deleted_at IS NULL
  AND status = 'active'
  AND (started_at IS NULL OR started_at = ''
       OR date(started_at) <= date('now', 'localtime'))
  AND (ended_at IS NULL OR ended_at = ''
       OR date(ended_at) >= date('now', 'localtime'))
```
- 시작일 비어있으면 "언제든 시작" → 오늘 포함.
- 종료일 비어있으면 "무기한 진행" → 오늘 포함.
- 둘 다 명시되면 그 범위에 오늘 포함될 때만.

영향: Home 의 "진행 중 캠페인" 카드 슬라이드. 시작 전 캠페인은 "곧 시작"
섹션에 이미 표시되고 종료된 active 는 어느 곳에도 안 보임 (캠페인 목록
페이지에서 확인). status 토글 (사용자가 end 누르기) 까지 사용자 책임.

### Part 2 — QuestCombobox 통일
`routes/campaigns/[slug]/+page.svelte`:
- `<input list="quest-options"> + <datalist>` 제거.
- `comboOpen` state 추가, "+ 퀘스트 연결" 버튼 → 모달 오픈.
- 모달 안에 `<QuestCombobox quests={linkableQuests} ... />` (Quest Detail
  과 동일 패턴).
- `linkableQuests` derived: `allQuests` 중 이미 연결된 quest 제외.
- `pickQuestToLink(questId)` → id 로 slug 찾아 `campaignsApi.linkQuest`.
- 모달 CSS (`.ov` / `.modal-sm` / `.modal-head` / `.x`) 도 Quest Detail
  과 동일 — Quest 검색 UX (↑↓ 이동, Enter 선택, Esc 닫기) 완전 통일.

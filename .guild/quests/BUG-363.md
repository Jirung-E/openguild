퀘스트 타입을 바꾸면(편집 → 타입 변경 → 확인) "저장하지 않은 변경 사항이 있습니다. 버리고 이동할까요?" 가 **한 번 더** 뜬다. BUG-359 확인 중 발견(웹 · 앱 공통 코드).

- 타입 변경 확인 창이 이미 "변경 즉시 새 슬러그 페이지로 이동 — 저장하지 않은 제목/설명 편집은 사라집니다" 라고 알렸다 → 두 번째 확인은 쓸모없다.
- 거기서 [취소] 를 누르면 **이미 없어진 옛 번호 화면**에 남는다(REQ-039 → DEV-444 로 바뀌었는데 주소는 REQ-039). 이 화면에서 저장하면 "quest REQ-039 not found".

원인: 미저장 가드(DEV-153)는 "편집 모드" 면 무조건 막는다. 타입 변경 뒤 새 주소로 갈 때 편집 모드를 안 끈다.

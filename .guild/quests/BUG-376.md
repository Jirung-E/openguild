윈도우 세션 보고(2026-10-26, DEV-327 '앱 데이터 삭제' 시험 중): 설정 → 앱 → 제거(GUI)로 지웠더니 **레지스트리 삭제만 셋 다 안 됐다.**

- 남은 키: `HKCU\…\Uninstall\openguild`(설정 앱 목록에 남을 수 있음), `HKCU\Software\Classes\.guild` + `openguild Guild File`(파일 연결), `HKCU\Software\openguild\openguild`(MANUPRODUCTKEY).
- 세 키의 마지막 수정 시각이 설치 때 그대로 — 지운 뒤 다시 쓰인 게 아니라 안 지워진 것. ACL 정상(User FullControl).
- 같은 '앱 데이터 삭제' 블록의 `RmDir /r $LOCALAPPDATA\io.openguild.desktop` 와 그 뒤 POSTUNINSTALL 훅은 실행됐고, 레지스트리 **읽기**(PathEnvSet → PATH 제거)도 됐다. 삭제만 전부 안 됨.
- 어제 시험 설치를 `uninstall.exe /S` 로 지웠을 때는 HKCU Uninstall 키가 제대로 지워졌다. 차이는 GUI 모드(설정 앱에서 실행, NSIS 가 임시 폴더로 자기를 복사해 다시 실행)뿐.
- 원인 모름. 재현할 때 각 삭제의 결과를 남기는 진단이 필요하다.

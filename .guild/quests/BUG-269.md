## 증상

퀘스트 상세 페이지에서 글자를 드래그해 선택하면, 선택 강조(파란 배경)가
**본문 영역 밖 창 양 끝까지** 뻗어나간다(admin 보고).

## 아는 것

- 이 프로젝트에는 `::selection` 규칙이 **하나도 없다**(전수 확인). 브라우저
  기본 선택 렌더링이다.
- 상세 페이지 본문은 폭이 제한돼 있다:
  - `.container { max-width: var(--content-max-width, 800px); margin: 0 auto; }`
  - 본문 카드 `.md` 는 배경·테두리·패딩을 가진 상자다.
- 그런데도 선택이 창 끝까지 칠해진다면, **선택 범위가 그 상자보다 넓은
  조상 블록까지 걸쳐 있다**는 뜻이다. 브라우저는 블록 경계를 넘는 선택에서
  줄상자(line box) 전체를 칠하고, 그 폭은 **담고 있는 블록**의 폭이다.

## 아직 모르는 것 — 확인 필요 (admin)

재현 조건을 좁혀야 고칠 수 있다:

1. **어디를 드래그했나** — 본문(마크다운) 안에서만? 아니면 제목·뱃지·첨부
   같은 다른 영역에서 시작하거나 끝났나?
2. **한 문단 안에서 드래그해도** 그런가, 아니면 **여러 문단/블록에 걸칠 때**
   만 그런가? (후자면 브라우저 기본 동작에 가깝고, 고칠 대상은 "선택이
   넘어가는 조상 블록의 폭"이다.)
3. 스크린샷 — 어디까지 칠해지는지가 원인을 거의 특정한다.
4. 데스크톱 앱인가 브라우저인가. 둘 다인가.

## 예상되는 방향

원인이 "조상 블록이 창 전체 폭"이라면, 본문을 감싸는 블록의 폭을 카드에
맞추거나 선택 가능한 영역을 상자 안으로 한정하는 쪽이 된다. `::selection`
색을 손보는 것은 증상만 가리므로 택하지 않는다.

## 테스트 방법

재현 조건이 잡힌 뒤 채운다.

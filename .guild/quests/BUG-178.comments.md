## 원인
`QuestCommentsSection.svelte` 의 접힘 판정이 `!discussionOnly && collapsedRoots.has(root.id)` 였다. '토론만'(DEV-213) 필터가 켜져 있으면 접힘 상태를 무조건 무시해서, 전체 접기(DEV-190)를 눌러도 답글이 펼쳐진 채였고 필터를 끄면 그때 접혀 있었다.

DEV-213 의 요구는 "토론이 아닌 댓글을 dim/숨김" 까지다. dim(필터의 표현)과 접기(사용자가 누른 동작)는 다른 축이라 필터가 접기를 덮어쓸 이유가 없다.

## 변경
`{@const isCollapsed = collapsedRoots.has(root.id)}` — 필터 게이트 제거(1줄).

- 일반 모드 전체 접기 (기존 동작 보호)
- '토론만' ON 상태에서 전체 접기 → 답글 0
- 접어둔 뒤 '토론만' 을 켜도 접힘 유지 (반대 방향)

수정 전 코드로 되돌려 실행하면 뒤 2건이 실제로 실패함을 확인(회귀 가치 검증).

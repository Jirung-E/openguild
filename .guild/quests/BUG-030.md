Quest Detail '+ 연결' 입력은 native datalist autocomplete. 다른 곳 (sub-quest / prereq 선택) 은 모달 + QuestCombobox 사용. 통일감 없어 보임. 캠페인용 콤보박스로 교체.

## 수정 (2026-05-27)

`CampaignCombobox.svelte` 신규 — `QuestCombobox` 와 동일 패턴 + 시각 톤.
캠페인 필드 (`campaign_slug`, `title`, `status: 'active'|'done'`) 에 맞게
배지 / 색만 조정. ↑/↓/Enter/Esc 키보드 지원 동일.

Quest Detail 페이지의 `Campaigns` 섹션 변경:
- 인라인 `<input list="campaign-options">` + native datalist 폐기.
- `+ 캠페인 연결` 버튼 (sub-quest / prereq `+ 추가` 와 동일 `.sec-add-btn`).
- 클릭 시 sub/prereq 와 같은 `.ov` + `.modal-sm` 오버레이 → `CampaignCombobox`.
- 후보 목록은 이미 연결된 캠페인 제외 (`campaignCandidates` derived).
- 모든 캠페인이 이미 연결된 경우 버튼 disabled + tooltip 안내.
- 에러는 alert 대신 모달 내 `combo-err` 표시 (sub/prereq 패턴).

## 아이디어

NSIS / MSI installer 로 openguild 를 설치할 때 설치 디렉토리에 실행 파일만
들어가고 사용 설명서가 없어, 첫 사용자가 어떻게 시작해야 하는지 모르는 문제.

설치 위치 (예: `C:\Program Files\openguild\`) 에 다음 문서를 함께 복사:
- `README.md` — 프로젝트 소개 / 빠른 시작.
- `docs/AGENTS_OPENGUILD_USAGE.md` (또는 일반 사용자용 별도 가이드) — CLI / 데스크탑
  앱 사용법.
- `docs/CHANGELOG.md` (있으면) 또는 release notes 텍스트.
- `LICENSE` (이미 들어갈 수도 — NSIS 의 LicensePage).

가능하면 시작 메뉴 / 바로가기에서도 "사용 설명서" shortcut 으로 열도록.

## 작업

### 1. Tauri 의 `bundle.resources` 또는 NSIS template 수정
- `gui/tauri.conf.json` 의 `bundle.resources` 배열 — 절대 / 상대 경로의 파일/
  디렉토리를 installer 페이로드에 포함. 설치 후엔 앱 디렉토리의 `resources/`
  하위에 위치.
- 또는 NSIS 의 `additionalFiles` 옵션 (`bundle.windows.nsis.additionalFiles`) —
  보다 명시적 / 설치 디렉토리 루트에 직접 배치 가능.

### 2. 문서 위치 선정
옵션 A — 앱 디렉토리 루트:
```
C:\Program Files\openguild\
├── openguild-gui.exe
├── README.md
├── USAGE.md
└── resources\
```
사용자가 즉시 발견 가능. 단 깔끔하지 않을 수 있음.

옵션 B — `docs/` 서브디렉토리:
```
C:\Program Files\openguild\
├── openguild-gui.exe
└── docs\
    ├── README.md
    └── USAGE.md
```
보다 정돈.

권장: **B (docs/)**.

### 3. 시작 메뉴 shortcut
- NSIS `Section` 에 `CreateShortCut` 추가 — "사용 설명서" 가 README 를 기본
  brower / markdown viewer 로 열도록 (또는 PDF 변환 후 PDF reader).
- 단 `.md` 는 OS 기본 연결이 없을 수 있어 PDF/HTML 변환 권장:
  - 빌드 단계 (`tauri-build` 또는 별도 script) 에서 `pandoc README.md -o
    docs/README.pdf` 같은 식.
  - 또는 단순 텍스트 (`README.txt`) 라도 추가.

### 4. 앱 안에서도 노출 (선택)
- "도움말" 메뉴 → 설치된 `docs/README.md` open. Tauri command 로 file path
  resolve 후 `tauri-plugin-shell::open`.

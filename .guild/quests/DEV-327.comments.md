## 정한 것 (2026-10-25, admin "DEV-327 해보자")

- **길드(`.guild` 가 든 폴더)는 어떤 경로로 지워도 안 건드린다**(본문의 핵심 결정). `~/.openguild` 안에는 길드가 없다(최근 목록은 경로만).
- `~/.openguild` 를 셋으로 나눴다:
  - **설치가 넣은 사본** — `skill-marketplace` · `docs`. 앱 파일이라 앱을 지우면 같이 지운다.
  - **이 기계의 설정** — `recents.json` · `locale.json` · `themes.json` · `plugin-consent.json` · `plugin-values.json`(토큰 같은 비밀값) · `plugin-sources.json` · `openguild-server.toml` · `panic.log` · `clipboard/`. 고를 때만 지운다(다시 깔 사람에게는 남아야 한다).
  - **남긴다** — `plugin-data/`: 플러그인이 남긴 기록(삭제 감사 로그 · 받은 편지함 등)은 사용자가 만든 자료다.

## 한 것

- **Windows** — NSIS 제거 프로그램은 이미 앱 · CLI · 서버 · 바로가기 · PATH 등록 · 레지스트리를 지운다(DEV-034). 빠진 것: `~/.openguild`. `hooks.nsh` 의 `NSIS_HOOK_POSTUNINSTALL`:
  - 업데이트(`/UPDATE`)가 아닐 때만 — 사본 둘을 지우고, **"앱 데이터 삭제"** 를 골랐으면 설정도 지우고(plugin-data 가 있으면 남겼다고 한 줄), `~/.openguild` 가 비었으면 그것도.
- **macOS** — `packaging/macos/uninstall.sh`, CLI · 서버 tar.gz 에 들어간다.
  - 기본: `/usr/local/bin` 의 `openguild` · `openguild-server` — 버전 줄이 openguild 인 것만(이름만 같은 다른 프로그램은 건너뜀).
  - `--app`: `/Applications/openguild.app` + 사본 둘. `--settings`: 설정 + `~/Library/{Application Support,Caches,WebKit}/io.openguild.desktop`.
  - 지울 것을 먼저 보여 주고 묻는다(`--yes` 면 안 묻는다). 쓰기 권한이 없는 곳만 sudo.
- **Linux** — 패키지 관리자(`apt remove` / `dnf remove`), AppImage 는 파일. 문서만.
- 문서: USAGE '지우기' 절, macOS tar.gz 의 README(영 · 한).

## 확인

- `hooks.nsh` — 실제 템플릿과 같은 변수(`$UpdateMode` · `$DeleteAppDataCheckboxState`)를 두고 Uninstall 에 매크로를 넣은 시험 스크립트를 makensis 로 컴파일 — 오류 없음. **실제 윈도우 설치 · 제거는 아직** — 윈도우 PC 의 설치본을 바꾸게 되므로 admin 에게 묻는다.
- `uninstall.sh` — 가짜 설치(임시 폴더의 bin · Applications · Library · ~/.openguild)로: 취소(n) → 아무것도 안 지움 · exit 1 / 기본 → CLI · 서버만 / `--app --settings` → 앱 · 사본 · 설정 · 앱 데이터, **plugin-data 와 모르는 파일(my-notes.txt)은 남음** / 다시 → "지울 것이 없습니다" / 이름만 같은 다른 프로그램 → 건너뜀.
- `package-macos-cli-server.sh` 로 만든 tar.gz 에 `uninstall.sh`(실행 권한) · README 가 들어간다.

## 테스트 방법

- Windows: 설치본에서 제거 — "앱 데이터 삭제" 를 끄면 `%USERPROFILE%\.openguild` 에 설정이 남고 skill-marketplace · docs 만 없어진다. 켜면 plugin-data 만 남는다. 길드 폴더는 그대로.
- macOS: tar.gz 를 풀고 `./uninstall.sh` — 목록을 보여 주고 묻는다.

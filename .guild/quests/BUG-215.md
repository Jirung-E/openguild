admin 보고: 모바일에서 마크다운 편집기의 글자를 꾹 눌러 선택하는 게 안 된다.

## 원인

편집기가 CodeMirror 6 의 `basicSetup` 을 그대로 쓰는데, 여기엔
**`drawSelection()`** 이 들어 있다. 이 확장은 네이티브 선택/캐럿을 숨기고
자체 레이어로 그린다 — 실측(375px)에서 확인:

```
.cm-content  caret-color : rgba(0, 0, 0, 0)   ← 투명(네이티브 캐럿 숨김)
.cm-selectionLayer 존재
```

데스크톱에서는 마우스 드래그로 선택하니 문제가 없지만, 모바일의 길게 누르기
선택은 **OS 가 네이티브 선택 위에 핸들·확대경을 띄우는 방식**이라 네이티브
선택이 숨겨지면 동작할 수단이 사라진다.

`drawSelection` 은 `EditorView.nativeSelectionHidden` 팩싯을 true 로 넣는데,
이 팩싯의 combine 이 `values.some(x => x)` 라 **나중에 false 로 덮을 수 없다**.
즉 확장을 끼운 뒤 되돌리는 방법은 없고, 터치 환경에서는 처음부터 빼야 한다.

## 방향

터치 기기(`pointer: coarse`)에서는 basicSetup 대신 drawSelection 과 마우스
전용 확장(rectangularSelection / crosshairCursor / dropCursor)을 뺀 구성을
쓴다. 데스크톱은 지금 그대로 둔다(위험 없음).

macOS 는 titleBarStyle:Overlay 로 네이티브 traffic light(빨/노/초) 가 이미
좌측에 있는데, 커스텀 타이틀바의 장식용 앱 아이콘(tb-appicon)이 그 옆에 또
붙어 중복돼 보임(사용자 지적, 2026-08-01 macOS 실기).

## 수정
`TitleBar.svelte` 에서 `isMac` 일 때 `tb-appicon` 렌더 안 함
(`{#if !isMac}`).

## 테스트 방법
1. macOS 앱 실행 → 타이틀바 좌측(native traffic light 옆)에 별도 앱
   아이콘이 안 보이는지 확인(traffic light 만 있으면 정상).
2. Windows/Linux 빌드에선 기존처럼 앱 아이콘이 보이는지(회귀 확인) —
   실기 없으면 코드 리뷰로: `{#if !isMac}` 조건이 macOS 만 걸러내는지.

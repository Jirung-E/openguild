admin 지적 2건.

## 1. `quest show` 기본 출력이 과하다

지금은 제목·상태·긴급도·생성/수정 시각·본문·관계·태그·기한까지 전부 쏟아낸다.
목록에서 하나 찍어볼 때 대부분은 필요 없고 가독성도 떨어진다.

- 기본: `id / title / status / urgency` 정도의 요약.
- 지금과 같은 전체 출력은 별도 옵션(예: `--full`)으로 분리.
- `docs` 명령이 DEV-274 에서 "기본 목차 / `--full` 전체" 로 정리된 것과 같은 결.

## 2. `--field` 가 빈약하다

현재: **한 번에 하나만**, 목록도 `id/title/status/status_slug/urgency/
description/type/parent/created_at/updated_at` 뿐이다.

- 관계 필드가 `parent` 하나뿐 — 서브퀘스트/선행/후속이 없다.
- 여러 필드를 한 번에 못 뽑는다. `--field title status description parent`
  처럼 여러 개를 넘길 수 있어야 한다.

## DEV-032 와의 관계 (admin 질문)

**직접적인 관계는 없다.** DEV-032 는 `.guild/index.db` 에 raw SQL SELECT 를
날리는 별도 명령이고(JOIN·GROUP BY·집계용, 도입 여부 자체가 보류 상태,
urgency 4), 이 건은 `quest show` 의 **출력 형태**를 다듬는 것이다.

굳이 엮자면 "스크립트에서 원하는 값만 뽑기" 라는 목적이 겹치지만, 그건
`--field` 로 충분하고 DEV-032 는 훨씬 큰 도구다. 이 퀘스트는 DEV-032 의
도입 여부와 무관하게 진행할 수 있다.

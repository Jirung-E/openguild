## 정렬 기준 확인 (2026-06-08)

현재 동작 (소스 확인 결과):
- `core::recents::add()` 가 호출되는 시점 = **GUI 가 길드를 open 하는 시점**.
- 호출 시 `last_opened: now` 로 갱신되고 list 최상단으로 이동 (LRU).
- 즉 정렬 기준은 이미 **'GUI 로 길드를 연 시간'** 입니다.

오해 가능 지점:
- Welcome 페이지의 라벨이 `"최근 작업한 길드"` 로 되어 있어서 "최근 작업 시간 (quest 의 updated_at 같은) 으로 정렬되는 줄" 알게 함.

제안:
1. 라벨 `"최근 작업한 길드"` → `"최근 연 길드"` 또는 `"최근 사용한 길드"` 로 변경 (이미 정렬은 그렇게 되고 있으므로 표기만 일치).
2. 만약 의도가 **"GUI 가 열려있는 동안의 모든 활동 (quest 생성 / 수정 등) 도 last_opened 를 touch 하게 해야 한다"** 라면 별도 quest. 현재는 open 시점 한 번만 touch.

어느 쪽이 의도였는지 알려주면:
- 라벨만 수정 → 가벼운 1-line PR.
- 활동 시점도 touch → DEV-006 후속 quest 등록 + 구현 (mutation hook 에서 recents::touch_current_guild() 호출).

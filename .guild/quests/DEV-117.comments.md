## 구현 (간단)

원인: `cli/src/main.rs::Backend::open_local()` 가 모든 CLI 호출마다 `core::recents::add()` → 다른 프로세스 (예: claude 의 `openguild quest comment add ...`) 가 길드 root 에서 CLI 돌릴 때마다 그 길드가 사용자 Welcome 의 '최근 연 길드' 최상단으로 올라가던 문제.

수정: CLI 의 `recents::add` 호출 제거. recents 의미를 "GUI 로 사용자가 직접 연 길드" 로 한정 (`gui/src/lib.rs` 호출만 유지). Welcome 라벨 ('최근 작업한 길드') 은 그대로 — 의미와 일치.

## 테스트 방법

### A. 기본 동작 (직접 GUI open 만 잡힘)

1. 길드 A 의 GUI 종료.
2. 길드 B 의 GUI open → Welcome 의 최근 목록에 B 가 최상단.
3. B 사용 + 종료.
4. 길드 A 의 GUI open → A 가 최상단, B 가 두 번째.

### B. CLI 가 오염 안 함 (회귀 검증)

1. 길드 A 의 GUI open (= recents 최상단 = A).
2. GUI 켜둔 상태에서 별도 터미널에서 길드 B 의 root 로 이동해 CLI 명령 실행:
   ```
   cd /path/to/guild-B
   openguild quest list
   openguild quest show {SLUG}
   openguild quest comment add {SLUG} --author test --body 'x'
   ```
3. GUI 종료 후 재시작 → Welcome 의 최근 목록 최상단이 여전히 **A** 여야 (B 가 위로 안 올라옴).
4. (이전: B 가 CLI 활동으로 최상단.)

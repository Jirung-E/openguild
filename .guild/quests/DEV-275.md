# [gui] 컨텐츠 폭 상한 확대 — 와이드 모니터에서 더 넓게

사용자 요청: GUI 컨텐츠 폭을 더 넓힐 수 있도록.

## 원인

`contentWidth` 상한이 1800px 로 하드코딩돼 있었다(DEV-101 fix2). 1080p~
1440p 기준이라 울트라와이드(3440)/4K(3840)에서는 슬라이더를 끝까지 밀어도
양옆에 여백이 크게 남았다.

## 수정

- **상한 1800 → 3200.**
- **최대값 = "화면 전체"(폭 제한 해제)** — 특정 픽셀값을 또 올려야 하는
  일이 없도록, 슬라이더 끝은 `--content-max-width: none` 을 발급해 각
  페이지의 `max-width: var(--content-max-width, …)` 가 창을 그대로 쓰게
  한다. 순수 함수 `isFullWidth()` / `contentWidthCss()` 로 분리(테스트
  가능 + 레이아웃/설정 양쪽에서 동일 판정).
- 설정 UI: 최대값일 때 숫자 입력칸 대신 "전체" 라벨을 보여주고(px 숫자가
  의미를 잃으므로), 힌트에 "맨 오른쪽은 전체" 문구 추가. 라벨은 숫자
  입력칸과 같은 자리/폭을 차지해 슬라이더가 밀리지 않게 했다.

`--popup-scale`(BUG-064: 팝업 크기 비례)은 기존대로 0.9~1.3 clamp 라
전체 폭에서도 팝업이 과하게 커지지 않는다.

## 하위호환

기존에 1800 으로 저장돼 있던 값은 그대로 유효(새 상한 아래라 고정 폭으로
동작) — 회귀 테스트로 고정.

## 테스트 방법

1. `contentWidth.test.ts` 6건 — 상한/clamp/isFullWidth/contentWidthCss/
   예전 값 하위호환/reset. 통과 확인.
2. `npx svelte-check`, `npm run test`(297), `npm run build` 클린.
3. (사용자 확인) 설정 → 컨텐츠 폭 슬라이더를 끝까지 밀어 "전체" 표시 +
   실제로 창 전체를 쓰는지, 중간 값에서 px 입력이 정상인지 확인.

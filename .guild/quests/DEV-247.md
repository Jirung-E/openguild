에이전트가 설치 폴더(%LOCALAPPDATA%\openguild\docs)의 문서를 읽을 때 샌드박스/권한 문제가 발생하는 경우가 있음(admin 보고). 홈 도트폴더(~/.cargo, ~/.ssh 관례)는 에이전트 도구들이 통상 허용하므로 사용자 데이터를 `~/.openguild/` 로 이전한다.

## 작업
- `~/.openguild/docs/` — 번들 문서(README/USAGE/AGENTS_OPENGUILD_USAGE/CHANGELOG)를 설치 시(NSIS) 또는 첫 실행 시 복사. 설치 디렉토리(exe 위치)는 NSIS 관례대로 유지 — 데이터만 분리.
- `~/.openguild/recents.json` — recents 를 directories 크레이트 경로(%LOCALAPPDATA%\openguild\openguild\data\recents.json, 사람이 찾기 어려운 3중 중첩)에서 이전. 구 경로에 파일 있으면 1회 마이그레이션(읽어서 새 위치에 쓰고, 구 파일은 남겨둠 — 다운그레이드 안전).
- 경로 헬퍼를 core 에 단일화(openguild_home()) — 이후 설정류가 같은 위치를 쓰도록.
- 문서에 새 경로 반영.

## 비고
- 설치본/사용자 데이터가 한 폴더에 섞인 현 구조는 언인스톨/업그레이드 시 데이터 유실 위험도 있음 — 이 분리로 해소.
- GUI 프론트 설정(localStorage)은 본 퀘스트 범위 아님 — 커스텀 테마 파일화는 별도 퀘스트.

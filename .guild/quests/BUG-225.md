DEV-317 DOM/SVG 보드 전환 후 실제 사용에서 확인된 저배율 표시·성능 회귀를
한 범위로 수정한다.

## 증상

- 접힌 레인에도 grid snap 점이 계속 보인다.
- snap 점과 저배율 노드가 흐리고 지나치게 작다.
- snap 점이 일정 높이 위·아래에서는 그려지지 않는다.
- 보드를 깊게 축소하면 제스처가 버벅인다.
- 실제 Tauri/Safari에서 rAF/표시 주사율이 60Hz인지 120Hz인지 앱 안에서 확인할
  수단이 없다.

## 방향

- snap 시각 레이어를 거대한 world 배경에서 분리해 현재 viewport만 덮는 반복
  타일로 만들고, pan은 transform/phase만 갱신한다.
- collapsed/hidden lane에는 snap 시각 레이어를 표시하지 않는다.
- 점 크기는 screen-space 최소 크기를 보장하고 세로 범위는 viewport 전체에서
  무한 반복되게 한다.
- 깊은 축소에서는 상세 카드 paint를 줄이는 저배율 LOD를 적용하되 hit-test와
  위치·edge 정합은 유지한다.
- rAF 간격, p95, 누락 프레임, board viewport transform 갱신 수를 표시하는
  성능 HUD를 추가해 60/120Hz와 실제 드롭을 구분한다.

관련 기록: [[DEV-317]], [[BUG-180]], [[BOOK-002]].

## 테스트 방법

1. snap on 상태에서 레인 접기/펼치기 시 해당 레인의 점이 함께 사라지고 복원된다.
2. 위·아래로 멀리 pan해도 현재 viewport 전체에 snap 점이 이어진다.
3. 최소 zoom에서도 점이 식별 가능하고, 노드는 가벼운 overview 표현으로 보인다.
4. 최소 zoom에서 연속 pan/zoom의 frame interval과 Layers/CPU를 기존 구현과 비교한다.
5. 성능 HUD가 실제 rAF Hz, median/p95, dropped frame, viewport update 수를 표시한다.

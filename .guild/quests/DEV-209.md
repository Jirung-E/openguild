목록을 출력하는 명령이 대부분 <명령> list 패턴(quest list / campaign list / backup list ...)인데, 상태·타입 목록은 top-level statuses / types 로 비일관.

전수조사 (퀘스트 생성만 — 구현은 후속):
1. 모든 목록 출력 명령의 네이밍 패턴 정리 — statuses/types 를 status list / type list(또는 statuses list) 로 통일 검토. 하위호환 alias 유지 여부 결정.
2. slug 표시 누락: statuses 사람용 출력은 name_en/name_ko 만 보이고 실제 slug(open/in_progress/testing…)가 안 보임. 명령 인자로 쓰는 값은 slug 라 사용자가 뭘 입력할지 모름(현재 --json 에만 노출). types 도 동일 점검. 사람용 출력에도 slug/식별자 표시.

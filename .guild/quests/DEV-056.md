현재 Done에 너무 많은 노드가 쌓여있다. 이것들을 숨길 수 있게 하고싶다.
이후 Done 뿐만 아니라 다른 상태에서도 숨기고 싶을 수 있고, 상태 자체를 숨기고 싶을수도 있다.

- - -

아래에서 사용할 용어 정리
- 연관관계: 부모자식관계 또는 선행후행 관계 등
- 그룹: 한 노드의 연관관계를 따라가면 만날 수 있는 모든 노드의 집합
- 그룹 멤버 노드: 그룹에 속한 노드. 다른 노드와 어떠한 연관관계로 이어져있다.
- 단독 노드: 그룹에 속하지 않은 노드. 다른 어느 노드와도 연관관계에 있지 않은 노드.

- - -

### 노드 숨기기
각 레인에서 어떤 종류의 노드를 숨길지 선택할 수 있어야 한다.
- 그룹 숨김: 그룹에 속한 모든 멤버 노드가 현재 레인에 있을때(같은 상태일때) 숨김. 
    - 하나의 그룹이 여러 레인에 걸쳐있으면 그 그룹은 어느 레인에서도 숨겨지지 않는다.
- 단독 노드 숨김: 그룹을 제외한 모든 단독 노드를 숨김

### 레인 숨기기
레인 자체를 숨길 수 있어야한다. 해당 레인에 있는 모든 노드가 숨겨지고 레인도 표시되지 않는다.

### 숨김처리시
숨겨진 노드는 퀘스트보드에서 다음과 같이 처리되어야 한다.
- 숨겨진 노드는 퀘스트보드에서 표시하지 않는다.
- 숨겨진 노드와 숨겨지지 않은 노드의 연관관계는 표시하지 않는다. (연관이 해제되지는 않는다)
- 숨겨지지 않은 노드를 선택하고 연관노드 하이라이팅 기능을 사용할때, 숨겨진 노드는 표시하지 않는다. 대신 '몇개의 숨겨진 노드가 추가로 존재한다'는 사실을 출력해야한다.

### 퀘스트보드 '숨김설정' UI
퀘스트보드 상단에 '숨김설정' 버튼 추가(정렬 버튼과 같은 레이어)
- 숨김설정 버튼을 누르면 팝업 윈도우

UI 예시:
```
 -------------------------------------------------
| 숨김 설정                                      x |
|                                                 |
| [ ] Open        | [ ] 그룹 숨김 [ ] 단독 노드 숨김 |
| [ ] In Progress | [ ] 그룹 숨김 [ ] 단독 노드 숨김 |
| [ ] Done        | [ ] 그룹 숨김 [ ] 단독 노드 숨김 |
| ...                                             |
 -------------------------------------------------
```
- 각 상태의 체크박스는 레인을 표시할지 여부(true면 표시, false면 숨김)
    - 체크되지 않으면 흐리게 표시해서 표시되지 않음을 나타낸다.
    - 그룹 숨김과 단독 노드 숨김은 레인이 표시될때만 활성화된다. 레인이 숨겨지면 이 옵션들은 의미가 없어진다.
- 오른쪽 두개의 체크박스는 숨길지 여부(true면 숨김, false면 표시)

## 구현 (2026-05-25)

### Data model
- `HideSetting { laneHidden, hideGroup, hideSolo }` per status slug.
- localStorage `openguild.hideSettings` (BUG-009 의 lane cols 패턴).

### 그룹 계산
- `computeGroups(quests, deps)` — parent/child + prereq/dependent 양방향
  인접 후 BFS → connected component. `groupOf: Map<questId, Set<questId>>`.

### 적용
- `computeHiddenIds()` — 각 quest 가 hidden 인지 결정:
  - `laneHidden` → hidden.
  - group size 1 + `hideSolo` → hidden.
  - group size > 1 + `hideGroup` + **모든 멤버가 같은 lane** → hidden.
- `applyHideSettings()` — `cy.batch` 안에서 `n.style('display', 'none')`.
  연결 edge 는 cytoscape 가 자동 숨김.
- `applyLaneVisibility()` — `laneHidden` lane 의 col / header DIV
  `display: none`.

### UI
- 툴바에 **"👁 숨김"** 버튼 (정렬 버튼 옆) — 활성 설정 있으면 `tb-on`.
- 모달: status 별 row 3 체크박스 (표시 / 그룹 숨김 / 단독 숨김). 표시 off 면
  나머지 disabled + lane 이름 strikethrough. 백드롭 / × 닫기.

### 트리거
- init 끝: groupOf 계산 + applyHideSettings.
- `applyStatusChange` 끝: status 변경에 따라 그룹 분포 / hideGroup 평가
  달라지므로 즉시 재적용.

## 테스트

### 1차
정상적으로 숨겨지는것은 확인 완료. 하지만 생각했던것과 다르게 동작하는 기능 존재
1. 레인 숨기기
   - 레인을 숨기면 해당 레인이 안보이긴 하지만, 그 자리가 빈 채로 있다. 뒤에 있는 레인들을 땅겨와야함
2. 노드 숨기기
   - 노드를 숨기면 해당 노드가 안보이긴 하지만, 자리는 계속 차지하고 있는걸로 보인다. 정렬 버튼을 눌렀을때 숨겨진 노드를 제외하고 보여지고 있는 노드만 정렬해야함

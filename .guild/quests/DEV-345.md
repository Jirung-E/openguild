Tauri 데스크톱 앱에서 Cmd+R(새로고침)이 아무 동작도 안 함 — 브라우저와 달리 페이지 새로고침 단축키가 아예 바인딩돼있지 않았음(재색인 버튼과는 별개 요청 — 전체 페이지 새로고침을 원함).

## 수정

`+layout.svelte` 에 Tauri 환경(`detectEnvironment() === 'tauri'`)에서만
Mod+R(Cmd+R macOS / Ctrl+R Windows·Linux) 를 가로채 `window.location.reload()`
호출하는 keydown 리스너 추가. 브라우저 모드는 건드리지 않음(이미 네이티브로
동작).

데스크톱 첫 화면에 최근 길드 표시. 저장은 OS 별 user data dir
(`directories` crate 사용).

## 구현 (2026-05-19)

### Backend (`core::recents`)
- `core/src/recents.rs` 신설:
  - `Recent { path, name, last_opened }` struct.
  - `recents_path()` — OS 별 경로 (Linux `~/.local/share/openguild/recents.json`,
    macOS `~/Library/Application Support/openguild/recents.json`,
    Windows `%APPDATA%\openguild\openguild\data\recents.json`).
    test 시 `OPENGUILD_RECENTS_DIR` env override.
  - `list()` / `write()` / `add()` / `clear()`.
  - LRU: `add()` 가 기존 path 면 최상단 이동, 새 path 면 prepend, MAX_RECENTS (10) 초과
    truncate. atomic write (tmp → rename).
  - 길드 이름: `*.guild` 파일 stem 우선, 없으면 디렉토리명.

### 자동 등록
- CLI (`Backend::Local::open_or`): `Store::open` 직후 `recents::add(path)` 호출.
  실패 시 warn 만 (ops 자체엔 영향 X).
- gui (`lib.rs::run`): 동일.

### Tauri invoke 핸들러
- `gui/src/commands.rs`:
  - `list_recents() -> Vec<Recent>`.
  - `clear_recents() -> ()`.
- `gui/src/lib.rs::generate_handler!` 매크로에 둘 다 등록.

### Frontend
- `gui/frontend/src/lib/api/recents.ts` — Tauri 환경에서만 invoke 호출.
  HTTP 모드는 빈 list (`recents.json` 은 사용자 PC local 파일이라 server 무관).
- `gui/frontend/src/routes/welcome/+page.svelte` — recent 목록 표시 + "전체 비우기"
  버튼. URL `/welcome` 으로 직접 접근.

## 회귀

- 기존 길드 open path 자체엔 변경 없음 — `recents::add` 는 부수 효과만.
- `recents::add` 실패해도 main 작업 안 막힘 (warn log 만).
- HTTP server / 브라우저 모드는 `recents.json` 안 봄.

DEV-027 MVP 후속. 자유 키워드 검색.

## 제안 옵션

- `--search <keyword>` — title / description 에서 부분 일치 검색.
- 대소문자 무시 (`LOWER` 비교).

```bash
openguild quest list --search "Tauri"
openguild quest list --search "invoke handler" --type DEV
openguild quest list --search "BUG-003"  # description 안 다른 quest ID 멘션
```

## 설계 결정 (구현 전 확정)

- **검색 범위**: title only / title+description / + auto-block (현재안: title+desc).
- **다중 키워드**: 공백 split → AND. 또는 인용부 한 토큰 (`"a b"`).
- **언어 처리**: 단순 `LIKE '%foo%'` 가 기본. NFC 정규화는 한글 깨짐 발생 시 도입.
- **인덱스**: quest 33개 — 없어도 충분. FTS (sqlite FTS5) 도입은 quest 1000+ 시점.
- **출력 강조**: matched span 색상 하이라이트? CLI 색이라 가능하지만 생략 권장.

## 영향 범위

- `core/src/models/quest.rs::ListQuery::search: Option<String>`.
- `core/src/services/quests.rs::list` — `(LOWER(q.title) LIKE LOWER(?) OR
  LOWER(q.description) LIKE LOWER(?))` (bind 시 `%foo%` wildcard 추가).
- `cli::QuestCmd::List --search`.
- 자동 테스트 ~6건 (단일 / 다중 / 대소문자 / 한글 / 매칭 없음 / desc 매칭).

## 우선순위 사유

## 구현 (2026-05-20)

- `ListQuery::search: Option<String>`.
- `services::quests::list`:
  - 공백 split → AND token. 각 토큰마다
    `(LOWER(q.title) LIKE LOWER(?) OR LOWER(COALESCE(q.description, '')) LIKE LOWER(?))`.
  - bind 시 `%token%` wildcard.
- `cli QuestCmd::List`: `--search <keyword>`.
- querystring 빌더 + test fixture 갱신.

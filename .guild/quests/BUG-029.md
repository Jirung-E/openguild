BUG-028 후속 — 진행중 캠페인 carousel 이 여전히 자동 회전 안 함. 원인: Home 의 currentActive 가 now 매초로 재derive 되어 summaries prop 참조 매초 변경 → $effect 가 매초 cleanup+재등록 → 3초 setInterval 절대 만료 안 함.

## 수정 (2026-05-27)

`$effect` 가 `summaries.length` 를 의존성으로 잡아 prop 참조 변경마다
재실행되는 게 근본 원인. `onMount` 로 setInterval 을 1회만 등록하고,
콜백 안에서 `summaries.length` / `hoverPause` / `userPaused` 를 fire
시점에 평가하도록 변경. 참조 안정성 무관.

```ts
let rotateHandle: ReturnType<typeof setInterval> | null = null;
onMount(() => {
    rotateHandle = setInterval(() => {
        if (hoverPause || userPaused) return;
        const count = summaries.length;
        if (count < 2) return;
        idx = (idx + 1) % count;
    }, autoRotateMs);
});
onDestroy(() => {
    if (rotateHandle) { clearInterval(rotateHandle); rotateHandle = null; }
});
```

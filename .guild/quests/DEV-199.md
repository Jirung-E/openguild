GUI/HTTP 는 댓글 이모지 반응을 지원하지만 CLI 에는 명령이 없었음.

## 구현 (2026-07-04)
- `openguild quest comment react <SLUG> <ID> <EMOJI> --author <NAME>` — 토글 시맨틱(GUI 와 동일 core 함수 재사용: ops::comments::toggle_comment_reaction). campaign comment react 동일(ops::campaign_comments::toggle_reaction). --author 필수(반응은 author 단위 토글). 다른 댓글 mutation 과 동일하게 Local 전용.
- 출력: '✓ #id 👍 추가|제거 (현재: 👍2 ✅1)' — 토글 후 집계. --json 은 on/reactions 원본.
- `comment list` 요약줄 끝에 반응 집계 `[👍2 ✅1]` 표시(반응 없으면 생략).
- 이모지 임의 문자열 허용(core 검증 재사용 — ,":| 금지) — DEV-132 커스텀 이모지와 정합.
- USAGE §2.9 갱신.

## 테스트 방법 (재빌드 후, 이 길드)
1. `openguild quest comment react DEV-199 1 👍 --author admin` → '추가' + 집계.
2. 같은 명령 재실행 → '제거'(토글).
3. `openguild quest comment list DEV-199` → 반응 있는 entry 에 [👍1] 표시.
4. campaign: `openguild campaign comment react C-003 <id> ✅ --author admin` 동일.
5. GUI 에서 해당 댓글 열어 반응 pill 동기화 확인.
6. cargo test -p openguild-cli 통과.

더블클릭 → gui 앱 열림. Windows/macOS/Linux 각각 설정.

## 변경 사항

### Rust (`gui/src/lib.rs`)
- `arg_to_guild_path(arg)` — argv path 해석:
  - `.guild` 확장자 파일 → 부모 디렉토리.
  - 디렉토리 → 그대로.
  - 다른 파일 / 존재 안 함 → `None`.
- `resolve_guild_path_inner(args, env, cwd_search, cwd) -> Result<PathBuf, String>`:
  - 환경 의존성을 closure 주입으로 명시 (테스트 가능).
  - 우선순위: argv → env → cwd 상위 탐색 → cwd fallback.
  - **argv 가 명시되었는데 해석 실패 → `Err`**. cwd 로 조용히 폴백하지 않음
    (1차 dogfood 피드백 — 사용자가 잘못된 경로 줬을 때 침묵 fallback 은 혼란
    유발). `--` 로 시작하는 플래그는 무시.
- `resolve_guild_path() -> Result<PathBuf, String>` — 실제 env / cwd 호출.
- `run()` 에서 Err 면 stderr 메시지 + `exit(2)`.
- 단위 테스트 12건 (argv path 처리 4 + 우선순위 / fallback 6 + 에러 케이스 2).

### Tauri (`gui/tauri.conf.json`)
- `bundle.fileAssociations` 신설:
  - ext `guild`, name "OpenGuild Guild File".
  - role "Editor", mimeType `application/x-openguild`.
- 배포 빌드 (`cargo tauri build`) 시 OS 별 설치 패키지에 자동 포함:
  - Windows: `.msi` / `.exe` → 레지스트리 등록.
  - macOS: `.app` 의 `Info.plist` CFBundleDocumentTypes.
  - Linux: `.deb` / `.AppImage` 의 `.desktop` 엔트리 MimeType.

### 문서 (`gui/README.md`)
- 실행 예시 4가지 (cwd 자동 / 디렉토리 지정 / `.guild` 파일 지정 / env).
- guild 경로 우선순위 표.
- OS 별 개발 중 수동 등록 (registry / xdg-mime) 방법.

## 동작

```bash
# cwd 의 .guild 자동 탐색
cargo run -p openguild-gui

# 디렉토리 명시
cargo run -p openguild-gui /path/to/my-project

# .guild 파일 직접 (더블클릭 시뮬레이션)
cargo run -p openguild-gui /path/to/my-project/foo.guild
```

OS 가 `.guild` 더블클릭 → `openguild-gui.exe "C:\path\to\foo.guild"` 호출 →
argv[1] = 파일 경로 → `arg_to_guild_path` 가 부모 디렉토리 반환 → 그 길드 오픈.

### 사용자 검증 필요 (수동)

**A. argv 동작 (~1분)**

```bash
# 1) 디렉토리 명시
cargo run -p openguild-gui D:\workspace\develop\openguild
# → 콘솔에 [openguild-gui] guild path: ...openguild 출력, 창에 27 quest 표시.

# 2) .guild 파일 명시 (더블클릭 시뮬)
cargo run -p openguild-gui D:\workspace\develop\openguild\openguild.guild
# → 동일 결과.

# 3) 잘못된 경로 → 에러 후 종료 (cwd 폴백 안 함)
cargo run -p openguild-gui C:\does\not\exist
# → stderr 에 "[openguild-gui] error: 'C:\\does\\not\\exist' 는 올바른 guild
#    경로가 아닙니다." 출력 후 exit code 2.

# 4) 비-guild 파일 → 마찬가지 에러
cargo run -p openguild-gui README.md
# → 동일한 에러 메시지.
```

**B. Windows 더블클릭 (선택, ~5분)**

`gui/README.md` 의 PowerShell registry 등록 스크립트 실행 후:
1. 파일 탐색기에서 `openguild.guild` 더블클릭.
2. OpenGuild 창이 뜨고, dogfood 의 27 quest 가 표시.
3. (정리) 같은 README 의 `Remove-Item` 명령으로 등록 해제.

배포 빌드 (`cargo tauri build`) 시점엔 installer 가 자동 등록 — 위 수동
절차는 개발 중에만 필요.

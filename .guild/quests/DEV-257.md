모바일 UI 도입 — 현재 GUI(Svelte 5 + SvelteKit, Tauri v2 데스크탑 셸)를
모바일 화면/입력(터치)에 맞춰 쓸 수 있게.

## 배경

- 현재 전제: 데스크탑 전용. 커스텀 타이틀바(`TitleBar.svelte`)는 Windows
  Tauri 에서만 렌더되고, 나머지(Nav.svelte 등)는 마우스/키보드 입력·넓은
  화면 폭을 전제로 설계됨.
- DEV-255(검색 팔레트 열기 방식 선택) 작업 시 이미 향후 확장을 염두에 둔
  지점이 있음:
  - `gui/frontend/src/lib/utils/open-item.ts` 의 `OpenMode` 타입이
    `'preview' | 'window' | 'page'` — 사용자가 "이후 모바일 UI 도입시
    모바일UI로 열기 같은게 가능해지면 좋을듯" 이라 언급, `'mobile'` 값 추가로
    확장 가능하게 설계해둠.

## 범위 (착수 시 구체화 필요 — 아직 미확정)

이 퀘스트는 등록 시점에 구체적 설계가 없는 상태 — 착수 전에 결정 필요:
- 반응형(같은 코드베이스, 뷰포트 기준 CSS breakpoint) vs 별도 모바일 전용
  라우트/레이아웃 중 방향 선택.
- 대상 플랫폼: Tauri 모바일(iOS/Android) 빌드까지 갈지, 아니면 브라우저
  모바일 뷰(HTTP 모드로 원격 접속 시 반응형)만 우선할지.
- 터치 인터랙션 전환이 필요한 기존 마우스 전용 UI 목록화 필요 (예: 드래그
  리사이즈 핸들 — SearchPalette 미리보기 세로 크기 조절, QuestBoard 드래그
  등 / hover 전용 UI — 크로스링크 미리보기(DEV-256), row-action 아이콘
  상시노출 패턴 등).
- 좁은 화면에서 타이틀바/Nav/사이드바 등 현재 고정폭 레이아웃 재검토.

착수 시 먼저 AskUserQuestion 등으로 범위/우선순위를 좁히고 시작할 것 —
현재는 백로그 등록 목적.

## 증상

사용자가 GUI 로 lab 길드를 열어 작업 중이었는데, Welcome 의 '최근 연 길드' 목록 최상단에 openguild 가 있었다. 사용자가 직접 열지 않았음에도.

## 원인

`cli/src/main.rs:1000` 의 `Backend::open_local()` 가 **모든 CLI 호출마다** `core::recents::add(&guild_path)` 를 호출. 즉 다른 프로세스 (예: claude 가 `openguild quest comment add ...` 같은 CLI 를 돌릴 때) 가 길드 경로로 CLI 를 실행하면 그 길드가 recents 최상단으로 올라감.

recents 의 의미는 **'사용자가 GUI 로 직접 연 길드'** 인데, CLI 활동까지 포함되고 있던 것.

## 수정

- `cli/src/main.rs` 의 `recents::add` 호출 제거. GUI 의 `gui/src/lib.rs` 호출만 유지.
- 라벨 '최근 작업한 길드' 는 그대로 — 정렬 의미와 일치 (GUI 로 길드 연 시점).

## 증상

markup 이 쓰는데 **어디에도 규칙이 없는** class 가 9개 파일 16건 있다. 스타일이
조용히 안 먹는다.

확인한 예: `QuestBoard.svelte` 의 토론 댓글 뱃지는
`<span class="pill xs discussion-count unresolved">` 와
`<span class="pill xs discussion-count resolved">` 두 가지인데, 스타일은
`.discussion-count.unresolved` 만 있다. **`.resolved` 는 아무 데도 없다** — 해결된
쪽만 색 구분이 없다.

## 목록

```
lib/components/QuestBoard.svelte                    resolved
lib/components/QuestListFilter.svelte               chips-toggle
lib/components/TagFilterRow.svelte                  open
lib/components/admin/AdminStatusesSection.svelte    dim, done-mark
routes/campaigns/[slug]/+page.svelte                meta, meta-item, status, type
routes/quests/[id]/+page.svelte                     status, urgency
routes/settings/+page.svelte                        hint, theme-row
routes/welcome/+page.svelte                         active
routes/worklog/+page.svelte                         open, viewmode
```

## 왜 지금 등록하나

[[DEV-382]] 에서 `check:classes` 가드를 만들 때 전수 조사로 나온 목록이다. 그때는
**가드를 통과시키려고 ALLOW 에 넣어 두었다** — 하나씩 확인할 범위가 아니었다.
ALLOW 는 "이유를 적은 예외" 를 담는 자리인데 이건 이유가 아니라 부채다.

각각 셋 중 하나다: (1) 진짜 죽은 이름 — 지운다, (2) 스타일을 붙일 생각이었는데
빠뜨림 — 붙인다, (3) 부모가 `:global()` 로 칠함 — ALLOW 에 그 이유를 적는다.

## 테스트 방법

- 확인이 끝난 항목은 `check-undefined-classes.mjs` 의 ALLOW 에서 뺀다.
- `npm run check:classes` 가 계속 통과한다.
- ALLOW 에 남는 것은 이유 주석이 붙어 있다.

임박 임계값이 너무 엄격해 사용자 테스트 퀘스트 (medium urgency, 19일 후) 가 표시 안 됨. lenient (Critical 30/High 14/Medium 7/Low 3) 로. 퀘스트 보드 노드 SVG 우하단에 required_due 표시 (⏱ YYYY-MM-DD). 캠페인 편집은 BUG-033 에서 이미 통합 — 빌드 캐시 가능성.

## 수정 (2026-05-27)

### 1) 마감 임박 퀘스트 표시 안 됨
원인: urgency 별 임박 임계값이 너무 엄격 (Medium=1일).
사용자 테스트 데이터로 `quest due DEV-001 --required 2026-06-15` 했을 때
오늘 (2026-05-27) 기준 19일 후 → Medium urgency 면 임계값 1일이라
표시 안 됨. 의도와 다른 결과.

해결: lenient 한 임계값으로 변경.
| urgency | 이전 | 현재 |
| ------- | ---- | ---- |
| Critical | 7일  | **30일** |
| High     | 4일  | **14일** |
| Medium   | 1일  | **7일** |
| Low      | 1일  | **3일** |

장기 critical 일정도 항상 노출 + medium 도 한 주 내 마감은 항상 표시.

### 2) 노드에 required_due 표시
Quest Board 의 cytoscape SVG 노드 + Home conveyor 의 동일 SVG 양쪽에
required_due 가 있으면 우하단에 `⏱ YYYY-MM-DD` 표시. 색 강조:
- 마감 지남: 빨강 (#f85149)
- ≤ 7일: 주황 (#f0883e)
- 그 외: 회색 (#8b949e)

desired_due 는 표시 X (정보성).

수정:
- `lib/utils/quest-node-svg.ts::makeQuestNodeSvgUrl`
- `lib/components/QuestBoard.svelte::makeSvgUrl` (의도적 duplicate)

### 3) 캠페인 편집창 재발

완료. 사용자 측 frontend dev 서버 / Tauri rebuild 누락 가능성. 본 빌드

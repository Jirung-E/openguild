댓글 상단 고정(pin) 또는 하이라이팅 기능 요청 (admin, 2026-07-06).

긴 댓글 목록에서 중요한 댓글(결정사항, 최신 지시 등)이 스크롤에 묻힘.

## 설계 검토 필요
- **고정(pin)**: root 댓글을 목록 최상단에 고정. 저장은 comments.md 의
  entry attr (`pinned="true"`) — discussion/resolved 와 같은 패턴이면
  파일 진리원 + DB 캐시 + GUI 토글로 일관 구현 가능. 여러 개 허용 여부,
  정렬(고정끼리는 원래 순서?) 결정 필요.
- **하이라이팅**: 색/스타일 강조만 하고 위치는 유지하는 대안 — pin 보다
  가볍고 흐름이 안 깨짐. 둘 다 갈지 하나만 갈지 결정 필요.
- CLI/HTTP 파리티: comment pin/unpin 명령 + 라우트 (DEV-193 원칙).
- comments 전역 검색(--pinned 필터?) 확장 검토.

## 설계 결정 (admin, 2026-07-07)
1. pin = 서버 저장(discussion/resolved 와 동일한 파일 attr + DB 캐시 +
   CLI/HTTP 파리티 패턴). localStorage 전용은 안 감 — CLI/다른 사람과
   공유되어야 함.
2. 하이라이팅은 별도 모드로 안 감 — pin 자체에 시각 강조(테두리)를 함께
   줘서 위치 이동 + 강조를 한 기능으로 처리.
3. quest 전용 게이트 없음 — discussion 과 달리 campaign 댓글도 지원.
4. --pinned 검색 필터는 이번 범위 밖 (후속 고려).

## 구현 (2026-07-07)
- **core::repo::comments**: `CommentEntry.pinned: bool` — discussion/resolved
  와 동일한 attr 패턴(`pinned="true"`, 기본 false 는 attr 생략). quest/
  campaign 댓글이 같은 `CommentEntry`/`parse_entries`/`serialize_entries`
  를 공유해 양쪽 다 자동 적용.
- **migration 0023**: `quest_comments`/`campaign_comments` 캐시 테이블에
  `pinned` 컬럼(discussion 과 달리 campaign 에도 추가 — quest 전용 게이트
  없음).
- **core::ops**: `comments::toggle_comment_pinned` /
  `campaign_comments::toggle_pinned` — discussion 과 동일한
  journal+file+DB캐시 흐름, resolve 같은 전제조건 게이트 없음(아무 댓글이나
  토글 가능 — root 제한은 GUI 가 pin 버튼 노출로 담당).
- **reindex/replay**: 두 캐시 재구축 INSERT 문에 pinned 컬럼 추가,
  `toggle_comment_pinned`/`toggle_campaign_comment_pinned` 는 id 만으로
  replayable.
- **server**: `POST /api/quests/by/{slug}/comments/{id}/pinned`,
  `POST /api/campaigns/{slug}/comments/{id}/pinned`.
- **cli**: `quest comment pinned <slug> <id>` (campaign comment 서브트리도
  공유 — CommentScope 로 분기, discussion/resolved 와 달리 게이트 없이
  quest/campaign 둘 다 허용). Local 전용(다른 댓글 mutation 과 동일 —
  React/Discussion/Resolved 도 원격 미지원).
- **gui**: Tauri 커맨드 `toggle_comment_pinned`/
  `toggle_campaign_comment_pinned` + `lib/api/comments.ts` 의
  `togglePinned`(quest/campaign 공용 factory) + `transport.ts` 라우팅.
  `QuestCommentsSection.svelte`: pin 버튼은 root 댓글에만(📌, 답글엔 노출
  안 함), `orderedRoots` derived 가 pinned 항목을 맨 위로(stable sort —
  고정끼리/일반끼리는 원래 순서 유지), 고정된 카드는 테두리 강조도 함께
  (하이라이팅을 별도 모드로 만들지 않고 pin 에 포함).

  고정된 것들끼리는 원래(시간) 순서 유지되는지. 다시 클릭하면 해제되고
  원래 위치로 돌아가는지.

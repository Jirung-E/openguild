고쳤습니다 — `installer.nsi` 에 `ClearOwnedResources` 를 두고 **설치 직전(업데이트 포함)과 제거 때** 부릅니다.

- 통째로 지우는 것은 이름이 우리 것인 경로만: `gui\frontend\build`, `skills\openguild-plugin`. 빌드마다 해시 이름이 바뀌는 파일(`_app\immutable\…`)이 여기 쌓였습니다.
- `docs` 처럼 흔한 이름은 사용자가 고른 설치 폴더의 다른 것일 수 있어 `/r` 로 지우지 않고, 옛 버전이 남긴 파일(`docs\AGENTS_OPENGUILD_USAGE.md`, DEV-264 에서 없앤 것)만 이름으로 지웁니다. 지금 버전의 docs 파일은 원래 목록대로 지워집니다.
- '앱 데이터 삭제' 를 고르면 아주 옛 버전이 설치 폴더에 두던 `openguild\data\recents.json` 도 지우고 빈 폴더 · 설치 폴더를 지웁니다.
- 설치 폴더 자체는 `/r` 로 지우지 않습니다(그대로 `RMDir` — 비었을 때만).

확인: 맥의 makensis 로 같은 매크로를 설치 · 제거 구역에 넣은 시험 스크립트가 컴파일됨. 실제 동작(업데이트 뒤 옛 해시 파일 0개, 지운 뒤 설치 폴더 없음)은 윈도우에서 확인해야 합니다.

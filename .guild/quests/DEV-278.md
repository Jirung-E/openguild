서브퀘스트만 '신규 생성'으로 추가할 수 있고, 선행/후속은 **이미 있는 퀘스트
연결**만 가능했다. 아직 없는 선행을 만들려면 목록으로 나가 만들고 다시
돌아와 연결해야 했다.

## 구현 (2026-07-29)

- 상태를 `showNewSubQuest: boolean` → `newRelMode: 'sub'|'prereq'|'succ'|null`
  로 바꿔 `NewQuestModal` 을 세 종류가 공용한다.
- 서브퀘스트만 모달에 `parentQuestId` 를 넘겨 생성 시점에 부모가 잡히고,
  선행/후속은 생성 후 의존 관계를 건다. **방향 주의**:
  - 선행 = `addPrerequisite(이 퀘스트, 새 퀘스트)`
  - 후속 = `addPrerequisite(새 퀘스트, 이 퀘스트)`
- 진입점은 [[DEV-279]] 의 '연관 추가' 메뉴 — 종류마다 '기존 연결'/'새로 만들기'.

## 실기에서 잡은 버그 (중요)

첫 시도에서 **퀘스트는 생성됐는데 연관이 안 걸렸다.** 원인은
`NewQuestModal` 이 `onclose()` 를 부른 **뒤에** `oncreated()` 를 부르는 순서:
`onclose` 가 `newRelMode` 를 null 로 만들어, 콜백에서 종류를 읽으면 이미
비어 있었다. 모달을 열 때의 종류를 `pendingRelMode` 로 따로 붙잡아 해결.

브라우저로 끝까지 돌려보지 않았으면 "구현 완료"로 넘어갔을 지점이다.

## 검증

- 브라우저에서 '후속 > 새로 만들기' → 퀘스트 생성 → **후속 퀘스트 섹션이
  새로 나타나며 연결됨**을 확인. CLI 로도 `quest show DEV-296 --field
  successors` = 생성된 퀘스트로 교차 확인.
- 검증용 임시 퀘스트 2건 삭제, `check counters` 0(file)+0(SQL).
- `svelte-check` 0 errors / 0 warnings.

## Test plan

2. 방향이 맞는지 — 선행으로 만든 퀘스트의 상세에서 이 퀘스트가 **후속**으로
   보이는지(그 반대도).
3. 생성 취소(모달 ×/Esc) 시 아무 연관도 안 생기는지.
4. 서브퀘스트는 여전히 생성 시점에 부모가 잡히는지(모달 제목이 '새 서브퀘스트').
5. 연관 생성 실패 시(권한/검증 오류) 토스트가 뜨는지.

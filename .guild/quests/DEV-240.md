admin 요청: 도서관(Library) 백업이 잘 되는지 확인.

## 조사 결과
- `core/src/snapshot.rs` 의 `SOURCE_SUBDIRS` 에 "library"(DEV-215)와
  "attachments"(DEV-069)가 이미 포함돼 있어, 도서관 문서(.md) + 폴더
  레지스트리(folders.toml) + 첨부 sidecar(.attachments.json) + 첨부
  실제 bytes 모두 스냅샷에 포함되고 있었음 — 코드 버그 없음.
- 다만 이 경로를 직접 검증하는 테스트가 없었음(quest/댓글/메모/history
  사이드카는 각각 회귀 테스트가 있었는데 도서관만 없었음) — 실제로 깨져도
  못 잡을 뻔했음.

## 조치
- `snapshot_preserves_library_docs_folders_and_attachments` 테스트 추가:
  폴더 안 문서 생성 + 첨부 등록 → snapshot → DB 캐시(library_docs/
  library_folders) 삭제 → restore → 문서/폴더 소속/첨부 목록/첨부 bytes
  전부 정상 복원 확인. 최초 실행부터 통과(회귀 없음, 안전망으로 추가).

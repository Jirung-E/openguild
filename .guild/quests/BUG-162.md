BUG-161(.gitignore 한글/퀘스트번호 leak)의 후속. `openguild init` 이 사용자
길드에 기록하는 파일 중 아래도 관리자 언어(한글)를 담고 있어, openguild 를
도구로 쓰는 **다른 프로젝트** 사용자에게 무의미한 한글이 새어 나갔다.

## 고친 것
- `core/src/repo/type_def.rs` `TYPE_FILE_HEADER` — types/*.toml 상단 경고 주석 → ASCII 영어.
- `core/src/repo/library.rs` `COUNTER_HEADER` — library `.counter.toml` 경고 주석 → ASCII 영어.
- `core/src/repo/seed.rs` 기본 타입 description 3개
  ("일반 개발 작업"/"버그 보고"/"기능 요청") → "Development work"/"Bug report"/"Feature request".

statuses/*.toml 의 `name_ko` 는 설계상 name_en 과 짝을 이루는 이중언어 데이터
필드(GUI 한글 로케일용)라 leak 이 아니며 그대로 둔다.

## 테스트 방법
- `cargo test -p openguild-core seeded_type_files_have_no_quest_ids_or_non_ascii` — 새 회귀 테스트 통과.
- 임시 폴더에서 `openguild init` → `.guild/types/DEV.toml`(및 BUG/REQ) 열어
  주석·description 이 모두 영어인지, 한글이 없는지 확인.

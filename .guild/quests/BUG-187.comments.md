## 후속: TitleBar.svelte(데스크탑) 동일 패턴 선제 수정

사용자 확인 후 진행: TitleBar.svelte 의 `.tb-add-wrap`/`.tb-recent-wrap`
에도 Nav.svelte 와 동일한 `min(21vw, 134px)` 근사 버그가 있었음. 지금은
모든 `tauri.*.conf.json` 의 `minWidth: 800` 제약 때문에 실제 발현 임계값
(약 638px)에 못 미쳐 드러나지 않지만, 나중에 최소폭 제약이 바뀌면 동일하게
터질 수 있어 선제적으로 같은 방식(pill 실측 + `--pill-half-w` CSS 변수)
으로 고침.

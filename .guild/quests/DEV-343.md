`just test`(vitest run) 실행 시 마지막에 아래 같은 콘솔 경고가 뜬다 — 테스트 자체는 통과하지만 노이즈:

```
[questIndex] quests 적재 실패 — 재시도 예정 [TypeError: Failed to parse URL from /api/quests?slim=true] {
  [cause]: TypeError: Invalid URL
      at new URL (node:internal/url:840:25)
      ...
}
```

원인: `QuestCommentsSection.svelte` / `MarkdownEditor.svelte` 가 컴포넌트 스크립트 최상단에서 무조건 `loadQuestIndex()` 를 호출한다(DEV-171/DEV-172). 이 함수는 `questsApi.list()` 등에서 상대경로(`/api/quests?slim=true`)로 `fetch` 를 호출하는데, 브라우저에서는 현재 페이지 origin 을 기준으로 상대경로가 resolve 되지만 vitest(Node 환경, `location` 없음)에서는 `new URL('/api/...')` 자체가 `Invalid URL` 로 실패한다. `loadQuestIndex()` 내부는 BUG-173 패턴으로 각 소스를 개별 `catch` 해서 `console.warn` 만 찍고 넘어가므로 테스트는 깨지지 않는다 — 하지만 `just test` 출력이 지저분해진다.

수정 방향(제안, 미확정): 이 컴포넌트들을 마운트하는 테스트에서 `$lib/api/*` 를 mock 하거나, `loadQuestIndex` 호출부를 `$effect`(브라우저에서만 실행) 로 옮기거나, vitest 쪽에 fetch base URL/전역 mock 을 추가.

# [gui] 규칙 slug 에 띄어쓰기가 있으면 cross-link 로 참조 불가

사용자 보고: 규칙 제목에 띄어쓰기가 있으면 cross-link 로 못 씀.

## 원인

cross-link 패턴이 **공백을 통째로 배제**하고 있었다:

- 렌더러 `MarkdownView.svelte`: `/\[\[([^[\]\s]{1,64})\]\]/g`
- 본문 편집기 자동완성 `editor-links.ts`: `/\[\[([^[\]\s]*)$/`
- 댓글 자동완성 `textarea-wikilink.ts`: 같은 패턴

퀘스트/캠페인/도서관 ID(`DEV-001`/`C-001`/`BOOK-001`)는 공백이 없어
문제가 없었지만, **규칙 slug 는 파일명(`.guild/rules/{slug}.md`)이라
공백을 포함할 수 있다**(CLI 로 `rule new "코딩 규칙"` 생성 가능 — 실기
확인). 그래서 `[[코딩 규칙]]` 은 링크가 안 걸리고, 편집기에서 `[[코딩 `
까지 타이핑하는 순간 자동완성도 끊겼다.

## 수정

3곳 모두 **줄바꿈만 배제**하도록 문자 클래스 변경(`[^[\]\n\r]`):

- 렌더러: `/\[\[([^[\]\n\r]{1,64})\]\]/g` + 매칭 토큰 `trim()` —
  `[[ 코딩 규칙 ]]` 처럼 여백을 준 표기도 같은 대상으로 해석(내부 공백은
  slug 의 일부라 보존). `[[   ]]` 같은 빈 토큰은 링크로 만들지 않고 원문
  유지.
- 자동완성 2곳: 공백 허용 + **64자 상한** — `[[` 를 닫지 않고 계속
  타이핑할 때 팝업이 문단 끝까지 따라붙지 않도록(렌더러 토큰 상한과 동일).

줄바꿈을 남겨둔 이유: 문단을 가로질러 `[[` … `]]` 가 엮이는 오탐 방지.

## 테스트 방법 (1·2 실기 확인 완료)

1. 스크래치 길드에 `rule new "코딩 규칙"` 생성 후 퀘스트 본문에
   `[[코딩 규칙]]` 과 `[[ 코딩 규칙 ]]` 작성 → GUI 에서 둘 다 정상 링크
   (`missing` 아님, title="규칙: 코딩 규칙", href=`/rules?slug=코딩%20규칙`)
   로 렌더되는 것 확인 완료.
2. `textarea-wikilink.test.ts` 에 회귀 테스트 추가 — `[[코딩 규` 까지만
   타이핑해도 매칭이 이어지고 삽입값이 `rules:코딩 규칙` 인지. 12건 통과.
3. (사용자 확인) 본문 편집기(CodeMirror)에서 `[[코딩 ` 타이핑 시 자동완성
   후보가 유지되는지 실기 확인.

Welcome 페이지에 "폴더 열기" 버튼 — OS 파일 탐색기로 디렉토리 선택 후
- 마커 있는 길드 → 그 보드로 진입.
- 마커 없는 위치 → "초기화할까요?" prompt 활성화.

## 배경

현재 Welcome 에서 길드 여는 방법:
- 최근 길드 목록 클릭 (Recent 에 있어야).
- 또는 터미널에서 `openguild-gui <path>` 직접 실행.

CLI 없이도 임의 위치로 이동할 수 있어야 함 (Recent 에 없는 길드 / 처음
여는 길드 / 새 폴더 초기화).

## 구현 스케치

### Backend (gui)
- `tauri-plugin-dialog` 추가 (`Cargo.toml` + `tauri.conf.json` permissions).
- 또는 dialog 는 frontend-only API 만 쓰고 별도 command 불필요.

### Frontend
- Welcome 헤더 또는 Recent 목록 위에 `[📁 폴더에서 열기]` 버튼.
- 클릭 → `import { open } from '@tauri-apps/plugin-dialog'`
  → `open({ directory: true, title: '길드 폴더 선택' })`.
- 선택 결과 path 로:
  - 그대로 `open_guild_in_current_window(path)` 호출 → 마커 없으면
    DEV-052 5회차에서 추가한 에러 반환 → 그 path 를 `uninitPath` 로 세팅
    + initName 채우고 uninit prompt 활성화.
  - 또는 별도 `check_guild_marker(path)` command 신설 후 분기 (호출 1회
    절약).

### UX
- 사용자가 dialog 취소 시 아무 일도 일어나지 않음 (null return).
- 마커 없는 폴더 선택 → 기존 uninit prompt 가 활성화 → 이름 input + 초기화.

## 검증

- 마커 있는 디렉토리 선택 → 보드.
- 마커 없는 디렉토리 선택 → uninit prompt + 이름 input (기본값 = 폴더명).
- Dialog 취소 → no-op.
- HTTP / 브라우저 모드에선 버튼 hide 또는 disabled (env !== 'tauri').

## 후속 아이디어 (이 quest 범위 외)

- 마지막 사용 디렉토리 기억 (`localStorage`) 으로 dialog 초기 경로.

## 구현 (2026-05-23)

### Backend
- `gui/Cargo.toml`: `tauri-plugin-dialog = "2"` 추가.
- `gui/src/lib.rs::run()`: `.plugin(tauri_plugin_dialog::init())` 등록.
- `gui/capabilities/default.json`: `"dialog:default"` permission 추가.
- `commands::inspect_guild_path(path) -> GuildPathInspect { exists,
  is_dir, has_marker, resolved_path }`:
  - `*.guild` 파일이 선택되면 parent 디렉토리로 resolve.
  - `recents::normalize_abs` 로 절대화 + Windows `\\?\` 제거.
  - `has_guild_marker` 결과를 그대로 노출.

### Frontend
- `gui/frontend/package.json`: `@tauri-apps/plugin-dialog ^2` 추가.
- `routes/welcome/+page.svelte`:
  - 새 `<section class="picker">` — 파란색 `📁 폴더에서 열기` 버튼 +
    힌트 텍스트. Tauri 모드 (`env === 'tauri'`) 일 때만 렌더.
  - `pickFolder()`: `open({ directory: true, multiple: false, title: '길드
    폴더 선택' })` → 취소면 no-op → `inspect_guild_path` 호출 →
    - `has_marker` → `open_guild_in_current_window` + `goto('/')`.
    - 아니면 `uninitPath` / `initName` 세팅 → 기존 uninit prompt 활성화.
  - `pickErr` 별도 표시 (uninit / open 에러와 격리).

### 분기 결정 — `inspect_guild_path` vs. `open_guild_in_current_window`
DEV-052 5회차에서 후자는 마커 없으면 에러를 던지지만, 그 에러 string 을
match 해서 uninit 으로 분기하는 건 fragile + `resolved_path` (절대화 결과)
가 backend 만 안다. 명시적 inspect command 가 깨끗.

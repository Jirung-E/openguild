## 영향

키보드 / 스크린리더 사용자에게 label 클릭으로 input focus 안 되고, autofocus 가
페이지 진입 시 컨텍스트 강제 점프. WCAG 2.1 Level A 위반.

## 수정 방향

### Label 7건
두 가지 패턴 중 하나:

```svelte
<!-- A. 명시적 id ↔ for -->
<label for="quest-title">제목</label>
<input id="quest-title" type="text" bind:value={title} />

<!-- B. label 안에 input 포함 (implicit) -->
<label>
  제목
  <input type="text" bind:value={title} />
</label>
```

`NewQuestModal.svelte` 와 `quests/[id]/+page.svelte` 의 해당 label 들 동일 패턴 적용.

### autofocus 1건 (`NewQuestModal.svelte:120`)
모달이 열릴 때 첫 입력에 focus 가 자연스러운 UX 인데 `autofocus` 속성은
스크린리더 사용자에게 갑작스러운 컨텍스트 이동을 강제. 대안:

```svelte
<script>
  let titleInput: HTMLInputElement;
  onMount(() => titleInput?.focus());
</script>

<input bind:this={titleInput} type="text" />
```

`onMount` + 명시적 `.focus()` 는 같은 UX 면서 a11y 경고 없음.

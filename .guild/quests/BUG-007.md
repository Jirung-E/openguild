## 증상

Quest 가 없는 lane (예: REQ 가 아직 없으면 REQ lane, 또는 비어있는 status lane)
의 lane 별 정렬 버튼 (`⊟` + `group` mode) 을 누르면 그 lane 만 정렬되어야 하는데
**전체 보드의 모든 노드** 가 재배치됨.

## 원인

`gui/frontend/src/lib/components/QuestBoard.svelte::arrangeNodesGrouped` 의 fallback:
```ts
const allNodes =
    nodesToArrange.length > 0
        ? nodesToArrange
        : (cy!.nodes('[questId]').toArray() as NodeSingular[]);  // ← 빈 배열 → 전체
```

호출자가 빈 배열 (`laneNodes` 가 0개) 을 넘기면 fallback 으로 모든 노드 사용.
toolbar 의 "전체 그룹 정렬" 같은 경우를 의도한 것으로 보이지만, 그 호출자는
이미 명시적으로 모든 노드 전달 (line 1664). fallback 은 실수 / 모호한 의미로
남음.

호출자 검토:
- `arrangeHighlightedGroup` (line 792): 사전에 `if (ids.size === 0) return;` 차단.
- toolbar 전체 그룹 정렬 (line 1664): 명시적 모든 노드 전달.
- **lane 별 group 정렬 버튼 (line 1099)**: `laneNodes` 가 빈 lane 에서 `[]` →
  fallback trigger.

## 수정 (2026-05-20)

`arrangeNodesGrouped` 초입에 `if (nodesToArrange.length === 0) return;` 추가.
fallback 제거 — `allNodes = nodesToArrange` 직접.

```diff
- const allNodes =
-     nodesToArrange.length > 0
-         ? nodesToArrange
-         : (cy!.nodes('[questId]').toArray() as NodeSingular[]);
- if (allNodes.length === 0) return;
+ // 빈 배열 시 no-op — 빈 lane 의 정렬 버튼이 전체 정렬을 trigger 하지 않도록.
+ if (nodesToArrange.length === 0) return;
+ const allNodes = nodesToArrange;
```

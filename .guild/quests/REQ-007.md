## 요청

문서 상세 페이지의 **'변경이력' 섹션에 접기 버튼**을 추가한다.
**기본 상태를 '접힘'** 으로 두고 필요할 때 펼치는 방식이 좋아 보인다.

## 배경

변경이력은 항상 필요한 정보가 아닌데 상세 페이지 하단을 길게 차지한다.
기본 접힘으로 두면 본문과 댓글에 집중할 수 있다.

## 대상

퀘스트/캠페인/사이드카 상세의 변경이력 패널 3종:

- `gui/frontend/src/lib/components/QuestHistory.svelte`
- `gui/frontend/src/lib/components/CampaignHistory.svelte`
- `gui/frontend/src/lib/components/SidecarHistory.svelte`

## 참고

기본 접힘으로 바꾸면 **접힌 동안에는 이력을 아예 fetch 하지 않는** 선택도
가능하다(초기 로드 비용 절감). 다만 이 3개 컴포넌트는 [[REQ-004]] 에서
stale-async 가드 누락이 지적된 바로 그 컴포넌트들이므로, 로딩 시점을 바꾸면
그 레이스 조건과 상호작용한다. 두 작업의 선후를 정하고 진행할 것.

## 수정 내용 (2026-08-20)

변경이력 패널 3종에 접기 토글 추가, **기본 접힘**.

- `QuestHistory.svelte` / `CampaignHistory.svelte` / `SidecarHistory.svelte`
- `locale.ts` 에 `history.expand` / `history.collapse` 키 추가

`QuestNoteSection`(DEV-107)의 토글 패턴을 그대로 따랐다 — 같은 상세 페이지의
형제 섹션이라 조작감이 달라지면 안 된다. 마크업(`.section-toggle` +
`.toggle-icon`), CSS, `aria-expanded`, 회전 아이콘까지 동일하다.
접기 상태는 **영속화하지 않는다**(메모 섹션과 같은 정책).

### REQ-004 와의 상호작용 — 의도적으로 피했다

접힘은 **표시만** 토글하고 fetch 타이밍은 건드리지 않았다. 접힌 동안 fetch 를
미루면 초기 로드는 아끼지만, 이 3개 컴포넌트는 [[REQ-004]] 에서 stale-async
가드 누락이 지적된 바로 그 파일들이라 로딩 시점을 바꾸면 그 레이스와 얽힌다.
lazy fetch 는 REQ-004 수정 이후로 미룬다.

## 검증 (브라우저 실측, /quests/DEV-359)

`svelte-check` 0 errors (경고 2건은 기존 `dynamic-range-limit`, 무관).

| 상태 | aria-expanded | 아이콘 | 목록 | 항목 | 섹션 높이 |
|------|---------------|--------|------|------|-----------|
| 초기(접힘) | false | -90° | 미렌더 | 0 | 20px |
| 펼침 | true | 회전없음 | 렌더 | 5 | 969px |
| 다시 접힘 | false | -90° | 미렌더 | 0 | 20px |

접힌 동안 목록이 **DOM 에 아예 없다**(`{#if !collapsed}`) — 숨김이 아니라
미렌더라 초기 렌더 비용도 준다.

### 검증 환경 주의사항 (실사고 기록)

Claude 브라우저 패널이 hidden 이면 문서가 `visibilityState: hidden` 이라
`requestAnimationFrame` 이 돌지 않는다. 그래서 CSS transition 이
`playState: "running"` 인 채 끝나지 않고, 아이콘 회전이 중간값(-90°)에
고착된 것처럼 보인다. **이걸 결함으로 오인해 [[DEV-362]] 본문에 잘못된
"기존 결함 발견" 을 적었다가 정정했다.**

최종 상태를 확인하려면 전이를 끄고 측정할 것:

```js
document.head.appendChild(Object.assign(document.createElement('style'),
  {textContent:'*{transition:none !important;animation:none !important}'}));
```

## 테스트 방법

퀘스트/캠페인/도서관 상세 페이지에서:

1. 변경 이력 섹션이 **처음부터 접혀** 있는지
2. 제목을 클릭하면 펼쳐지고 아이콘(▼)이 회전하는지
3. 다시 클릭하면 접히는지
4. 다른 문서로 이동하면 다시 접힌 상태로 시작하는지 (영속화 안 함)

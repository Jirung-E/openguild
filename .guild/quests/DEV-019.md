## 테스트 방법

### 자동 (완료)
- 모든 명령의 CLI 파싱 / clap 테스트 통과 (`cargo test --workspace`).
- 내부 함수 (reindex, snapshot, etc.) 단위 테스트 통과.

### 사용자 검증 필요 (수동)
임시 guild 에서 전체 cycle 확인:
1. `openguild init --name test /tmp/test-guild`
2. 임의 quest 생성, status 변경.
3. `openguild-server snapshot` → `.guild/backups/snapshots/{ts}.db` 생성, journal truncate.
4. `openguild-server restore --list` → 방금 만든 snapshot 표시.
5. 추가 quest 생성 → `restore --to <ts>` → 이전 상태로 돌아감 (`.pre-restore.db` 백업 생성).
6. `.guild/quests/` 의 .md 파일 직접 편집 → `check-drift` → 보고. `--resync` 로 reindex.
7. `check-counters` → drift 없음. (DEV-019 dogfood 테스트 중 `--fix` 가 두번째 호출
   에서 보고만 하고 실제로 UPDATE 안 되는 버그 발견 — 별도 BUG 로 추적할 것.)
8. `openguild-server info` → quest / 백업 / DB 통계 표시.

### 알려진 이슈

- **`check-counters --fix` 결함** — 첫 호출 시 "보정됨" 로그를 찍지만
  `quest_counters.last_number` UPDATE 가 실제로 안 됨. 두번째 호출은
  "발견 이슈: 0" 보고. (dogfood guild 에서 재현됨, 2026-05-17.) → BUG-003 신설 예정.

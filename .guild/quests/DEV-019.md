backup list / backup restore <ts> / audit tail / db migrate / db check / db vacuum / db stats 등 관리 명령 추가. 본 quest 에선 snapshot / restore / reindex / migrate-to-files / check-counters / check-drift 구현. audit tail / db vacuum / db check 등은 DEV-023 으로 분리.

## 테스트 방법

- `openguild-server snapshot` → `.guild/backups/snapshots/{ts}.db` 생성, journal truncate
- `openguild-server restore --list` → 사용 가능 snapshot 목록 표시
- `openguild-server restore [--to TS]` → 복원 + 직전 상태가 `.pre-restore.db` 로 백업
- `openguild-server reindex` → `.guild/quests/*.md` → `index.db` 재구축. statuses=6, types=3, quests 카운트 일치
- `openguild-server migrate-to-files` → legacy `guild.db` 가 있으면 `.guild/quests/` 로 이전 (현 repo 엔 이미 적용됨)
- `openguild-server check-counters [--fix]` → type 의 `last_number` 가 max quest 번호 ≥ 검증
- `openguild-server check-drift [--resync]` → 외부 편집 시 fresh/missing/stale 보고. `--resync` 면 자동 reindex
- 회귀: `openguild-server info` / `host` / `backup` (snapshot alias) 도 정상 동작

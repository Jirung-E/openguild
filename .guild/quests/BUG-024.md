BUG-023 SQL 필터를 frontend 로 이전 + 매초 시계로 실시간 분류 / 카운트다운. 곧 시작 카드는 slug/진행률 제거 (날짜만). 진행 중 카드는 종료 임박 시 '(x일 남음)' 빨강 추가. 일/시간/분/초 단위 자동 전환.

## 구현 (2026-05-26)

### 설계 — backend 단순화 + frontend 매초 갱신
BUG-023 의 SQL 기간 필터 제거 (모든 active 캠페인 반환). 분류 (시작 전 /
진행 중 / 종료 후) 와 카운트다운 표시는 frontend 가 매초 시계 보고 처리.
페이지 보고 있는 동안 카드 자동 이동 + 단위 자동 전환 (사용자 reload 없이).

### `core/src/services/campaigns.rs::list_active_summaries`
SQL 필터 (started_at ≤ now ≤ ended_at) 제거. 단순 `status='active'` alive
모두 반환. Home 이 클라이언트에서 분류.

### `gui/frontend/src/lib/utils/datetime.ts::formatRemaining`
신규 헬퍼. ISO date(`YYYY-MM-DD`) 또는 datetime 입력 → 단위 자동:
- 1일 ≤ : `n일 남음`
- 1시간 ~ 1일 : `n시간 남음`
- 1분 ~ 1시간 : `n분 남음`
- 1분 미만 : `n초 남음`
- 이미 지남 : 빈 문자열

`mode: 'until-start' | 'until-end'` — date-only 입력일 때 그 날 00:00:00
(시작 시점) 또는 23:59:59 (종료 시점) 으로 해석.

### `lib/components/CampaignCardSlider.svelte`
- `size` prop → `mode: 'active' | 'upcoming'` 로 변경.
- `now: number` prop 추가 (부모가 매초 갱신).
- **active 모드**: 슬러그 + 제목 + 기간 + (종료 임박 시 `(x일 남음)`
  빨강 `#f85149`) + 진행률.
- **upcoming 모드**: 슬러그 / 진행률 제거. 제목 + `<X일 남음> (YYYY-MM-DD)`
  형식 (남은 시간은 accent 파랑 `#58a6ff`).

### `lib/components/Home.svelte`
- `allActive` state — 한 번 fetch (모든 active summary).
- `setInterval(1000)` 으로 `now` state 갱신, `onDestroy` 에서 clear.
- `currentActive = $derived` — `now` 시점에 기간 안에 있는 것만 (시작일
  비어있으면 "언제든 시작", 종료일 비어있으면 "무기한").
- `upcomingSummaries = $derived` — 1주일 이내 시작 예정, 없으면 가장
  가까운 미래 시작 1개 (BUG-023 의 fallback 동작 유지).
- 두 슬라이더에 `currentActive` / `upcomingSummaries` + `mode` + `{now}`
  전달.
- backend 호출은 한 번 — 부담 적음. status 토글 / 새 캠페인 추가는
  페이지 reload 시점에 반영.

### 자동 이동 동작
- 캠페인 기간 시작 (`started_at` 도달) → upcoming 에서 사라지고 active 에
  추가됨 (다음 tick / 1초 이내).
- 캠페인 기간 종료 (`ended_at` 지남) → active 에서 사라짐. 시작 전 캠페인이
  1주 윈도우에 새로 들어오면 upcoming 에 추가됨.
- 모든 변환은 `now` derived 의 재계산으로 svelte 가 자동 reactive.

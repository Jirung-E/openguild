## 메모 — Status name 입력 UX (DEV-014 후속, 2026-05-24)

DEV-014 의 Admin Quest Statuses 섹션에서 현재 `name_en` 만 필수, `name_ko`
는 선택. 이 기본 언어 선택 기능이 만들어지면:
- **기본 언어 = 영어**: `name_ko` 입력 필드 자체를 숨김 (또는 "+ 다른 언어
  추가" 아코디언). 영어권 사용자에겐 한국어 input 이 시각 잡음.
- **기본 언어 = 한국어**: `name_ko` 노출 (현재 동작). 단 여전히 선택 — 한국어
  사용자라도 짧은 status 는 영어 그대로 두고 싶을 수 있음.
- 적용 위치:
  - `lib/components/admin/AdminStatusesSection.svelte` 의 추가 모달 + inline
    수정 input.
  - `name_ko` 비어있을 때의 표 표시 "—" 도 기본 언어 = 영어면 column 자체
    숨김 검토.
- 표시 사이트 (board / detail / list / combobox status badge) 가 현재
  `name_en` 고정 — 기본 언어 정책에 따라 `name_ko` 우선 fallback 도입 필요.
  fallback 순서: 사용자 기본 언어 → name_en (영원한 fallback).
- DB schema 변경 없음 — UI 정책만 바뀜.

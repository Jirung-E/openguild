## 한 것 (2026-10-25, admin "DEV-187 해보자")

- `openguild check update` — 앱의 updater 와 **같은** `latest.json`(GitHub Releases 최신)을 받아 지금 버전과 비교해 안내만 한다. 설치는 안 한다(돌고 있는 실행 파일을 바꾸는 건 설치 프로그램 · 앱의 몫).
  - 이름: 기존 진단 묶음 `check drift|counters|sidecars` 에 붙였다(단수형 + sub 필수 규칙). 길드가 필요 없어 길드 밖에서도 돈다.
  - 새 버전: "새 버전이 있습니다: 0.6.1-beta (2026-11-02) — 지금 0.6.0-beta / 받기: <릴리스 페이지>". 아니면 "최신입니다 — 지금 X (나온 것 중 최신 Y)". `--json` 은 `current` · `latest` · `update_available` · `pub_date` · `release_url`.
  - 실패: 404 → "아직 릴리스가 없거나 주소가 잘못됐습니다", 연결 실패 → "네트워크 연결을 확인하세요", 깨진 파일 → "latest.json 을 읽지 못했습니다" — 모두 종료 코드 1. 시한 10초.
  - 주소는 `OPENGUILD_UPDATE_URL` 로 바꿀 수 있다(미러 · 시험).
- 버전 비교는 semver 규칙 — 숫자 셋, 그다음 pre-release 없는 쪽이 새것, `beta.2 < beta.10`, 앞의 `v` 무시.
- 서버: 따로 만들지 않았다 — CLI 와 서버는 늘 같은 버전으로 함께 나가 이 명령 하나로 둘 다 본다(본문의 "server 도 검토").
- 문서: USAGE '자동 업데이트' 절, 스킬 reference/meta-and-maintenance.

Quest Board의 도구 버튼이 상태에 따라 서로 다른 투명도로 보이고, 버튼 배경이
레인 배경과 같아 도구 모음과 보드 콘텐츠의 경계가 불분명하다.

## 원인

- undo/redo 비활성 상태는 버튼 전체 `opacity: 0.35`를 사용한다.
- 접기 버튼은 별도로 `opacity: 0.7`을 사용한다.
- 활성 토글(`tb-on`) 배경은 강조색을 `transparent`와 혼합한다.
- toolbar 컨테이너 자체에는 표면·테두리·그림자가 없다.
- 일반 버튼과 lane 배경이 모두 `--bg-elevated`라 같은 면처럼 보인다.

## 구현 방향

- toolbar를 콘텐츠 크기만큼 차지하는 불투명 `--bg-elevated` 패널로 만들고
  `--border`, 작은 그림자, padding/radius를 적용한다.
- 좁은 화면에서는 기존처럼 최대 폭 안에서 줄바꿈하되, 화면 전체를 덮는 투명
  클릭 영역을 다시 만들지 않는다.
- 일반 버튼과 select는 `--bg-subtle` 표면으로 통일한다.
- 사용 가능한 버튼은 모두 `opacity: 1`로 통일한다. 접기 버튼의 별도 opacity를
  제거한다.
- 비활성 버튼은 전체 opacity 대신 흐린 글자·테두리·배경으로 상태를 표시한다.
- 활성 버튼의 배경·테두리는 `transparent`가 아니라 테마 표면 토큰과 강조색을
  혼합해 완전히 불투명하게 만든다.
- 새 퀘스트 primary 버튼은 기존 초록색 강조를 유지한다.
- `backdrop-filter`는 사용하지 않는다. 대비에 불필요하고 WebKit 합성 비용만
  늘릴 수 있다.

## 테스트 방법

1. 라이트/다크 테마에서 툴바가 레인 배경과 구분되는 패널로 보이는지 확인한다.
2. 일반 버튼·select·접기 버튼이 동일한 불투명 표면으로 보이는지 확인한다.
3. undo/redo 활성·비활성 상태가 구분되지만 버튼 자체가 사라진 듯 흐려지지 않는지
   확인한다.
4. 가로 행·스냅·보드 설정 활성 상태가 불투명한 강조 배경으로 표시되는지 확인한다.
5. 툴바를 접고 펼친 뒤 패널 크기가 실제 버튼 크기에 맞게 줄어드는지 확인한다.
6. 좁은 화면에서 버튼이 패널 안에서 줄바꿈되고 화면 밖으로 나가지 않는지 확인한다.
7. 툴바 바깥의 빈 보드 영역에서 노드 클릭과 pan이 기존처럼 동작하는지 확인한다.

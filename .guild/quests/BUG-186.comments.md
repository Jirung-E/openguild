## 테스트 방법
1. 웹 모드(`just dev-frontend` + `just dev-server`)에서 창을 넓게 열고
   확인 — 캠페인 목록/작업기록/태그 목록이 메뉴바에 안 나오고 항상
   ☰(접힌 메뉴) 안에만 있는지.
2. ☰ 버튼이 header 맨 왼쪽에 있는지, 클릭 시 팝업이 화면 안쪽(오른쪽)
   으로 정상 펼쳐지는지(화면 밖으로 안 나가는지).
3. 창을 서서히 좁혀서 홈/보드/목록/관리/규칙/도서관 링크가 안 들어갈
   때만 오른쪽부터 ☰ 로 접히는지 — 접힐 때 캠페인/작업기록/태그와 같은
   메뉴 안에 같이 보이는지.
4. 창을 다시 넓히면 접혔던 항목이 메뉴바로 복귀하는지(캠페인 등은
   여전히 ☰ 안에 남아있는지).
5. 데스크탑 앱은 회귀 없는지(원래 동작 그대로 — 캠페인 항상 ☰, 나머지
   응답형, ☰ 위치 안 바뀜).

## 간격 수정 (2026-08-01, 사용자 보고: "접힌 메뉴 버튼과 다른 버튼 사이
간격이 너무 넓음")

원인: `<header>` 가 자식 전체에 균일한 `gap: 2rem` 을 쓰는데, ☰ 버튼을
왼쪽으로 옮기면서 header 의 직접 자식이 됐음 — nav 링크와의 간격도
"다음 섹션과의 간격"용 2rem 을 그대로 물려받아 버튼-링크 사이가 과하게
벌어짐.

수정: `.more-wrap` + `<nav>` 를 `.nav-group` wrapper 로 묶어 자체 좁은
gap(0.5rem) 사용 — header 의 2rem 은 이제 nav-group 과 그 다음 섹션
(검색 pill 등) 사이에만 적용됨. header 안에서의 flex-grow 몫도 nav
개별이 아니라 nav-group 이 가져가도록 조정.

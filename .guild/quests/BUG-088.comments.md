추가 진단(admin 제보): 작업표시줄/타이틀바/인스톨러뿐 아니라 **파일탐색기에서 원본 이미지를 봐도 투명 부분이 검정**.

→ Windows 캐시/빌드 문제가 아니라 **소스 이미지 자체가 투명이 아님**. 32x32.png 가 color type 6(RGBA)이긴 하나, 배경 픽셀의 alpha 가 0 이 아니라 불투명 검정(alpha=255)으로 저장된 것으로 보임. (RGBA 채널 존재 ≠ 실제 투명)

해결: 디자인 소스를 **진짜 투명 배경으로 재export**(편집기에서 배경 레이어 제거 / 알파 0 확인) 후 `cargo tauri icon <source.png>` 로 .ico/.png 세트 재생성. 로고에 순수 검정(#000)이 안 쓰였다면 임시로 black→transparent 변환도 가능하지만, 정석은 소스 재export. (코드/빌드 수정으로는 못 고침 — 에셋 문제.)

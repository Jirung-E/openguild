Quest Detail 창에서 퀘스트 내용 편집창은 늘어나는 크기에 한계가 있어서 내용이 많더라도 너무 좁은 영역만 보여진다.  
영역의 최대 크기를 늘려야하고, 또한 퀘스트 추가시의 편집창에서처럼 수동으로 크기를 조절할수도 있어야 한다.

## 구현 (2026-05-25)

### Frontend (`gui/frontend/src/routes/quests/[id]/+page.svelte`)
- `.editor-wrap` CSS:
  - `resize: vertical` (HTML5 native handle).
  - `min-height: 200px`, `max-height: 90vh` (이전 480px 하드 한계 제거).
- `initEditor()`:
  - `editorContainer.style.height = loadEditorHeight()` 적용 (저장된 값
    또는 480 기본).
  - CodeMirror theme 변경: `cm-editor { height: 100% }` /
    `cm-scroller { overflow: auto }` — parent height 따라 fill. 이전엔
    `cm-scroller maxHeight: 480px` 가 고정 한계라 parent resize 의미 없었음.
  - `ResizeObserver` 가 사용자 drag resize 감지 → `scheduleEditorHeightSave`
    (debounce 250ms) → localStorage `openguild.questEditorHeight`.
- `exitEditMode()`: observer disconnect.

### 검증
- `npm run check` → 0 error.

- `npm run build` → ✔.

### 라이브
- Quest Detail → 설명 편집 모드 → 편집창 우하단 drag handle → 크기 조절.
- 다른 quest detail / 페이지 갔다 와도 마지막 크기 유지.

사용자 보고: "gui를 처음 켰을때도 웰컴페이지에서 뒤로가기 단축키(마우스
버튼 또는 Ctrl+왼쪽화살표)가 동작한다. 가장 최근에 연 길드로 돌아가려고
하는거같다."

## 원인

`routes/+page.svelte` 의 `launch_mode === 'welcome'` bounce
guard(DEV-052)가 `goto('/welcome')` 를 기본(push) 옵션으로 호출했다.
콜드 스타트 시 webview 가 최초 로드하는 URL 이 `/` 이므로, history 가
`["/", "/welcome"]` 두 entry 로 쌓인다. `/` 자체는 길드 컨텍스트 없이도
`<QuestBoard>`/`<Home>` 을 렌더하려 시도(Tauri 가 항상 관리하는 placeholder
Store 기준) — 뒤로가기를 누르면 이 `/` 가 잠깐 다시 마운트되어 board/home
UI 가 보였다가, onMount guard 가 다시 `/welcome` 으로 bounce 한다. 이게
"다른(최근) 길드로 가려다 막히는" 것처럼 보였던 것.

## 수정

`goto('/welcome', { replaceState: true })` 로 변경 — 콜드 스타트의 `/`
history entry 자체를 남기지 않고 교체. 뒤로가기를 눌러도 더 이상 갈 곳이
없어(또는 앱 진입 이전 단계로) 의도치 않은 board flash 가 사라짐.

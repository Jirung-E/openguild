DEV-266 이 노출하는 콘솔 트리거 `window.__ogNotify` 가 실제 빌드에서
`__ogNotify is not defined` 로 실패(사용자 보고).

## 원인
훅 노출이 `import.meta.env.DEV` 로만 게이트돼 있었다 — 이 값은 vite dev /
tauri dev 에서만 true 라, `just build` 로 만든 릴리스 exe 에는 훅이 아예
번들되지 않는다. 알림 스택은 실기 빌드에서 확인해야 의미가 있는데 테스트
경로가 dev 서버뿐이었던 셈.

## 수정
릴리스 빌드에서도 **사용자가 명시적으로 켰을 때만** 노출하도록 opt-in 추가:
- `window.__ogEnableDebug()` — 항상 존재(플래그만 세팅 + reload).
- localStorage `openguild.debugHooks === '1'` 이면 `__ogNotify` 노출.
- dev 서버는 종전대로 항상 노출.
기본값은 꺼짐이라 일반 사용자 콘솔은 그대로 깨끗하다. update 카드 렌더
게이트도 같은 조건으로 맞춤(브라우저에서 update 트리거 검증 가능).

## 테스트 방법
릴리스 빌드 콘솔에서:
1. `__ogEnableDebug()` → 자동 새로고침.
2. `__ogNotify.toast('e','error',0); __ogNotify.schema(); __ogNotify.update('available');`
3. `for (let i=0;i<8;i++) __ogNotify.toast('m'+i,'info',0);`
   → 5개 + "+N개 더 보기" 칩, error/지속형 유지, 칩 클릭 시 전체 펼침,
   `__ogNotify.toast('m1','info',0)` 재호출 시 ×2 뱃지.
4. 끄기: `__ogEnableDebug(false)`.

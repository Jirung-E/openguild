## 원인
Campaign Detail 페이지의 `toggleChecklist` / `removeChecklist` / `addChecklist` 가 모두 `load()` 전체 reload 호출 → `detail` 객체 swap → `{#each detail.checklists as item, idx (item.id)}` 의 모든 item 이 새 참조 → Svelte 가 DOM 전체 재생성 → 브라우저가 scroll anchor 잃고 페이지 최상단으로 fallback.

## 수정 (옵션 A — optimistic update)
`load()` 안 호출, 단일 array row 만 변경:

| 함수 | 변경 |
|------|------|
| `toggleChecklist` | `target.checked = next` (Svelte 5 deep reactivity). 실패 시 `target.checked = currentlyChecked` 로 원복. |
| `removeChecklist` | `detail.checklists.splice(idx, 1)`. 실패 시 같은 위치 재삽입. |
| `addChecklist` | API 응답 row 를 `detail.checklists.push(added)` — load() 안 함. |

같은 array 안 단일 row 변경이라 다른 item 의 `(item.id)` key 가 stable → DOM 재사용 + scroll 보존.

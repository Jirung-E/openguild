## 문제

도서관에서 문서를 편집하다가 뒤로 가기(이전 문서로)를 누르면 확인 창이 두 번 뜬다 — 먼저 "편집 중 이동 / 저장하지 않은 변경 사항이 있습니다", "버리고 이동" 을 누르면 다시 "편집중 이동 / 편집 중인 변경 사항이 있습니다".

## 원인

- 앱 전체 가드(`+layout.svelte` 의 `beforeNavigate`)가 먼저 묻고, 확정하면 미저장 표시만 지운 뒤 이동한다 — 도서관의 편집 모드는 그대로다.
- 도서관은 주소의 `?id=` 가 바뀌면 `select(id)` 를 부르는데, 이것은 **클릭으로 고를 때** 쓰는 길이라 편집 중이면 또 묻는다.

## 재현

1. 도서관에서 문서 A → 문서 B 를 연다.
2. B 에서 편집을 누른다.
3. 뒤로 가기 → 확인 창 → "버리고 이동" → 두 번째 확인 창.

## 고칠 것

주소가 바뀐 것은 이미 앱 전체 가드를 지났다 — 주소가 진실이므로 편집을 접고 그 문서를 바로 연다. 목록으로 돌아가는 경우(`?id=` 없음)도 편집을 접는다.

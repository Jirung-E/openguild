사용자 요청(재보고): 커스텀 타이틀바의 최소화/최대화/닫기 버튼이 모든
플랫폼에서 '윈도우 모양'으로 고정 — 원하는 것은 실행 중인 OS 의 시스템
모양. 이전에 "OS에 따라 스타일 맞출 수 없는지" 질문했을 때 macOS/Linux 는
네이티브라 문제없다고 답변받았으나, BUG-140 이후 Linux 도 커스텀 타이틀바를
쓰므로 그 답은 무효 — Linux 에서 윈도우식 버튼이 그대로 노출된다.

요구:
- 창 컨트롤 버튼(최소화/최대화(복원)/닫기)의 시각 스타일을 플랫폼별로:
  - Windows: 현행(가는 선 글리프 + 사각 호버, 닫기 빨강) 유지.
  - Linux: 데스크탑 환경 관례에 맞는 모양(예: GNOME/Adwaita — 원형 호버
    배경 + 글리프, 버튼 간격/정렬). DE 별 완전 일치는 불가능하므로 대표
    스타일 1종(GNOME 기준) 근사로 시작, 필요시 설정으로 변형.
- decorations:false 상태에선 진짜 네이티브 버튼을 그릴 수 없음(웹 레이어
  렌더) — "시스템 모양"은 근사 구현임을 전제. usesCustomTitlebar() 판별
  재사용, 플랫폼별 클래스 분기.

## 변경
`routes/+layout.svelte` — 환경별로 창 닫기와 무관한 수단만 쓴다.
- **브라우저/서버 모드**: `beforeunload` + `preventDefault` 재도입. Tauri 창 닫기와 무관해 BUG-075 와 충돌하지 않는다.
- **Tauri**: `beforeunload` / `onCloseRequested` 는 그대로 두고(= 창 닫기는 절대 안 막는다), 새로고침 단축키만 keydown **capture** 단계에서 가로채 기존 공용 모달을 띄운다. '버리고 진행' 을 누르면 `clearUnsaved()` 후 `location.reload()`.

판정은 `lib/utils/reload-shortcut.ts` 로 분리했다 — 데스크탑에서는 이 판정이 미저장 경고의 유일한 트리거라 조합 하나만 새도 내용이 날아간다.

## 테스트
- `reload-shortcut.test.ts` 3건: F5 / Ctrl+R / Cmd+R / Ctrl+Shift+R = true, 일반 타이핑·Ctrl+S·F6 = false, Alt 조합(창 관리 단축키) = false.

## 검증 (서버 모드 실측)
같은 페이지에서 `beforeunload` 를 cancelable 로 발생시켜 `defaultPrevented` 관측:
- 편집 전: false (경고 없음 — 정상)
- 편집 중: **true** (경고 걸림)
- 편집 취소 후: false (해제됨)

frontend 334 테스트 통과, `svelte-check` 0 error.

## 미검증
Tauri 경로(F5 가로채기 → 공용 모달)는 데스크탑 앱을 띄워야 확인 가능해 검증하지 못했다. 확인 절차:
1. GUI 실행 → 아무 퀘스트 본문 '편집' 진입 → 몇 글자 입력
2. F5 (그리고 Ctrl+R, Ctrl+Shift+R) → **미저장 확인 모달**이 떠야 하고 화면이 새로고침되지 않아야 함
3. '계속 편집' → 그대로 유지 / '버리고 진행' → 그때 새로고침
4. 편집 중이 아닐 때 F5 → 모달 없이 바로 새로고침
5. **BUG-075 회귀 확인**: 편집 중이든 아니든 창 X 버튼은 즉시 닫혀야 함

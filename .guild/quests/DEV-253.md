admin 요청([[DEV-201]] 후속 논의): 네이티브 타이틀바 테마 동기화가 가끔 안 맞는 문제 — vscode 처럼 아예 커스텀 타이틀바로 전환해 원천 해소.

## 배경
DEV-201 은 Tauri `setTheme()` 으로 네이티브 타이틀바(Windows immersive dark mode)를 앱 테마에 맞추지만, OS/WebView2 타이밍 이슈로 간헐적으로 어긋남(admin 보고). 커스텀 타이틀바는 HTML/CSS 라 테마 토큰을 그대로 따르고, 커스텀 테마([[DEV-114]]) 색도 타이틀바에 적용됨.

## 작업
- `tauri.conf.json` `decorations: false` + HTML 타이틀바 컴포넌트(`data-tauri-drag-region` 드래그 영역).
- 창 컨트롤 직접 구현: 최소화/최대화(복원 토글)/닫기 — `getCurrentWindow()` API. 더블클릭 최대화 토글.
- **Windows 11 Snap Layouts**: decorations:false 면 최대화 버튼 호버 스냅 팝업이 사라짐 — tauri-plugin-decorum 류 플러그인 또는 Win32(WM_NCHITTEST) 트릭으로 복원 검토. 복원이 과하면 1차 릴리즈에서 명시적 트레이드오프로 문서화.
- 리사이즈 보더/엣지 동작 확인(Tauri 가 resizable 처리하지만 drag 영역과의 간섭 검증).
- 타이틀바에 기존 Nav 정보 통합 검토(길드 이름/원격 배지 등) — vscode 의 메뉴+타이틀 통합 패턴.
- macOS/Linux 는 각자 관례가 달라(traffic lights 등) — 1차는 Windows 만, 타 OS 는 decorations 유지 분기.

## 검증
- 다크/라이트/커스텀 테마 전환 시 타이틀바 색 즉시 반영(재현되던 어긋남 소멸).
- 최소화/최대화/복원/닫기/더블클릭/드래그/스냅(Win+화살표) 동작.
- DEV-201 의 setTheme 경로는 커스텀 타이틀바 도입 시 불필요해지는지 확인 후 정리.

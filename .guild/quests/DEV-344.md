퀘스트 생성 팝업(`NewQuestModal.svelte`)의 설명(description) 입력창에서 cross-link 자동완성(`[[` 자동완성)이 작동 안 함.

## 조사 내용

DEV-172 회귀가 아님 — `NewQuestModal.svelte` 의 description 필드는 애초에
일반 `<textarea>`(`tabInsert` 액션만 붙음)이고, `wikiMatch`/`MarkdownEditor`
등 cross-link 자동완성 관련 코드가 전혀 연결돼 있지 않았음(git history 상으로도
이 파일에 wiki/자동완성 관련 커밋이 없었음). 즉 원래부터 없던 기능 — 퀘스트
상세(수정 모드)/규칙/메모/댓글엔 있는데 생성 모달에만 빠져 있던 불일치였음.

## 수정

댓글(textarea 기반, DEV-171/172 이후 공용화된 `wiki-popup-place.ts` +
`WikiAutocompletePopup.svelte`)과 동일한 방식으로 연결. 새 로직 없이 기존
프레임워크 무관 유틸(`wikiMatch`/`applyWikiLink`/`applyWikiPrefix`/`caretXY`
— textarea-wikilink.ts, `computeWikiPlace`/`clampWikiLeft`/
`isWikiCaretVisible` — wiki-popup-place.ts)만 재사용해 배선.

## 테스트 방법

1. "퀘스트 추가" 모달 열고 설명란에 `[[` 입력 → 댓글/본문과 동일한 팝업 뜨는지.
2. ↑/↓/Enter/Tab/Esc 동작, 네임스페이스 접두(`[[q` 등) 선택 시 이어지는지.

(Playwright 로 자동 검증 완료 — 실제 생성 없이 팝업/삽입 동작만 확인, 모달은 저장 없이 닫음.)

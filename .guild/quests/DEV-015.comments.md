언어를 바꿀때, '언어 선택 창' 에 표시되는 언어는 번역되어서는 안된다.

### 현재
한국어 선택시
```
한국어 <<<
English
```

영어 선택시
```
Korean
English <<<
```

### 원하는 동작
한국어 선택시
```
한국어 <<<
English
```

영어 선택시
```
한국어
English <<<
```

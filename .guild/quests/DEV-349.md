## 배경

[[DEV-312]]에서 macOS Apple Silicon용 GUI DMG 배포는 추가했지만, CLI(`openguild`)와 HTTP 서버(`openguild-server`)는 DMG 및 GitHub Release에 포함되지 않는다. 현재 문서는 사용자가 Rust/Cargo로 직접 빌드하도록 안내해 일반 배포물로서 불완전하다.

## 목표

- macos-26 release 잡에서 Apple Silicon용 CLI와 Server를 release profile로 빌드한다.
- 두 실행 파일과 설치 안내를 하나의 `openguild_<version>_macos_arm64_cli-server.tar.gz`로 묶는다.
- `workflow_dispatch` artifact와 실제 태그 GitHub Release에 tar.gz를 첨부한다.
- 사용자는 Rust/Cargo 없이 압축 해제 후 `/usr/local/bin`에 설치할 수 있어야 한다.
- README 영문/국문과 `docs/USAGE.md`를 실제 배포 방식에 맞게 갱신하고, Windows 설치 안내와 macOS 안내가 섞인 문구를 바로잡는다.

## 범위 밖

- GUI·CLI·Server를 한 화면에서 선택 설치하는 macOS `.pkg` 설치 프로그램은 별도 후속 퀘스트에서 다룬다.
- Apple Developer 서명·공증은 [[DEV-312]] 결정대로 이번 범위에 포함하지 않는다.

## 구현 원칙

- 아카이브에는 사전 빌드된 `openguild`, `openguild-server`, 설치용 README를 포함한다.
- 바이너리 실행 권한을 보존한다.
- 기존 `openguild-macos-arm64-packages` artifact와 태그 Release에 함께 첨부한다.
- 파일명에는 crate 버전을 포함해 다운로드한 파일만으로 버전을 식별할 수 있게 한다.
- 설치 후 `openguild --version`, `openguild-server --version`으로 검증할 수 있게 안내한다.

## 테스트 방법

1. `Release` workflow를 `workflow_dispatch`로 실행한다.
2. `openguild-macos-arm64-packages` artifact에 기존 DMG/app updater 파일과 함께 `openguild_<version>_macos_arm64_cli-server.tar.gz`가 있는지 확인한다.
3. tar.gz를 풀어 `openguild`, `openguild-server`, `README.md`가 있고 두 바이너리에 실행 권한이 있는지 확인한다.
4. Rust/Cargo가 없는 사용자 환경을 가정해 README 절차대로 `/usr/local/bin`에 설치한다.
5. `openguild --version`과 `openguild-server --version`이 실행되는지 확인한다.
6. 폐기 가능한 테스트 길드에서 `openguild quest list`와 `openguild-server host`가 정상 동작하는지 확인한다.

관련: [[DEV-313]], [[DEV-315]], [[release-process]].

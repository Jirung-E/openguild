## 구현 (2026-05-18, MVP)

### 옵션
- `--type <PREFIX>` — 대소문자 무시.
- `--status <slug-or-name>` — 'Open' / 'open' / 'in_progress' / 'in-progress' /
  'In Progress' 모두 같은 매칭 (SQL `LOWER` + `REPLACE`).
- `--sort id` (기본) / `--sort urgency`.
- `--limit N` (음수 → BadRequest, 0 OK 빈 결과).

후속 (별도 quest 또는 추후): `--parent`, `--reverse`, `--offset`, multi-value,
urgency range, search.

### 변경 파일
- `core/src/models/quest.rs` — `ListQuery { type, status, sort, limit }` struct.
- `core/src/services/quests.rs::list(pool, &query)` — 시그니처 변경.
  SQL 안에서 fuzzy match (UPPER / LOWER REPLACE).
- `server/src/routes/quests.rs::list_quests` — `Query<ListQuery>` extractor.
- `cli/src/main.rs`:
  - `QuestCmd::List` 에 옵션 4개 추가.
  - `Backend::list_quests(&q)` + Http 측 `list_query_to_querystring` + 직접
    구현 `urlencode` 헬퍼.
- `gui/src/commands.rs::list_quests(query: Option<ListQuery>)` — backward compat
  (`None` 이면 기존 전체 동작).

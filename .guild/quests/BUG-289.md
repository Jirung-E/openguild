## 증상

`~/.openguild/plugin-data/` 에 시험이 남긴 폴더가 **126개** 쌓였다.

```
og-deliver-fail-1788968100317185000-4184…/p
og-deliver-nostdin-…/p
og-deliver-nocmd-…/p
og-deliver-runenv-missing-…/p
test-guild-2faa14ae017ff65c/      ← 이것만 진짜
```

`just test` 한 번에 4개씩 생긴다. CI 는 매번 새 머신이라 안 드러나고 개발자 기계에만 쌓인다.

## 원인

[[BUG-279]] 가 `run` 의 작업 디렉터리를 플러그인 폴더에서 **데이터 폴더**
(`~/.openguild/plugin-data/{길드}/{플러그인}/`)로 옮겼다. 데이터 폴더는 실행할 때 없으면
만든다.

`core/src/plugins/delivery.rs` 의 `run` 시험 가운데 넷이 `OPENGUILD_HOME` 을 격리하지 않았다
— 같은 파일의 `RunLab` 이 바로 이걸 막으려고 있는데 안 썼다.

| 시험 | 임시 길드 이름 |
|---|---|
| `a_failing_process_is_reported` | `og-deliver-fail-*` |
| `a_missing_command_is_reported` | `og-deliver-nocmd-*` |
| `a_child_that_never_reads_stdin_does_not_wedge_the_thread` | `og-deliver-nostdin-*` |
| `run_with_a_missing_env_var_fails_loudly` | `og-deliver-runenv-missing-*` |

## 왜 문제인가

시험이 **사용자의 실제 홈을 건드리면 안 된다.** 같은 홈에 동의 파일과 설정값
(`plugin-values.json` — 봇 토큰 같은 비밀값)이 있다. 지금은 폴더만 만들지만, 시험이 그
파일들을 건드리는 쪽으로 바뀌어도 막는 장치가 없다. 시험마다 격리를 **기억해야** 하는
구조라 한 번 빠뜨리면 이렇게 된다.

## 수정

1. 네 시험을 `RunLab`(임시 홈)으로 옮긴다.
2. **구조적으로 막는다** — core 의 시험 빌드에서는 `OPENGUILD_HOME` 이 없으면 실제 홈 대신
   프로세스 전용 임시 홈을 쓴다. 다음에 누가 격리를 빠뜨려도 실제 홈에는 못 닿는다.
3. 쌓인 126개를 지운다(`test-guild-*` 는 남긴다).

## 확인한 것

- 재현: 네 시험만 돌렸더니 `plugin-data` 가 126 → 130.
- 수정 뒤 플러그인·user_dirs 시험 전체: 130 → 130. 쌓인 129개(`og-deliver-*`)를 지운 뒤
  `just test` 전체: 1 → 1 (`test-guild-*` 만).
- `a_test_without_openguild_home_never_reaches_the_real_home` — 시험 빌드의 기본 홈을 실제
  홈으로 되돌리면 실패한다.
- 네 시험을 `RunLab` 으로 옮긴 것과 기본 홈 폴백은 **각각** 막는다 — 앞은 이번 누수를,
  뒤는 다음에 격리를 빠뜨린 시험을.

## 테스트 방법

- `just test` 전후로 `~/.openguild/plugin-data` 의 항목 수가 같다.
- core 시험 빌드에서 `OPENGUILD_HOME` 없이 `openguild_home()` 이 실제 홈이 아니다.

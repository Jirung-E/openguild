DEV-265 이번 세션 2차 작업으로 실제 해결됐습니다.

1차(전에 재오픈 때 반영한 것)는 리눅스를 GNOME/Adwaita "근사" CSS로
흉내만 낸 것이었는데, 이번 2차에서는:

- 실행 중인 시스템의 실제 GTK 아이콘 테마(`gtk::IconTheme`)에서
  `window-minimize-symbolic`/`window-maximize-symbolic`/
  `window-close-symbolic` 를 그대로 조회해서 그림 — Adwaita 뿐 아니라
  Yaru(Ubuntu)/Breeze(KDE)/Pop 등 어떤 테마든 그 테마의 실제 아이콘이
  나옵니다.
- 버튼 순서도 `gsettings get org.gnome.desktop.wm.preferences
  button-layout` 을 그대로 반영(하드코딩 안 함).
- 조회 실패 시(비-GNOME 세션 등)에만 기존 근사 CSS로 폴백.

개발 환경이 Windows라 이 부분은 로컬에서 직접 실행 검증은 못 했습니다 —
실제 리눅스에서 새 빌드로 확인 부탁드립니다. 특히:
- 아이콘 모양이 실제 시스템 테마와 일치하는지
- 버튼 순서가 시스템 설정과 맞는지
- (조회 실패 케이스라면) 최소한 기존 근사 스타일로는 뜨는지

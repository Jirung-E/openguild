## 무엇

도서관에서 **여러 항목을 골라 한 번에** 옮기거나 지우고 싶다.

지금은 한 번 누르면 바로 열린다. 파일 탐색기처럼 **누르면 선택, 두 번 누르면 열기**로 바꾼다.

## 한 것 (2026-09-20)

**아이콘 뷰**에 다중 선택을 넣었다. 트리 뷰는 그대로 뒀다 — 그쪽은 옮겨 다니는 길잡이라
한 번 눌러 여는 편이 맞다.

- 누르면 고르고, **두 번 누르면 연다**(폴더는 들어가고, 문서는 상세로).
- `⌘/Ctrl` 토글, `Shift` 범위(화면에 보이는 순서 기준, 기준점은 그대로 둬서 늘렸다 줄일 수
  있다). 규칙은 `utils/multi-select.ts` 에 두고 시험 8개로 고정했다.
- 고른 것이 있으면 줄이 하나 뜬다 — **몇 개인지** 먼저 말하고 [폴더 이동] [삭제] [선택 해제].
- 폴더와 문서를 **섞어** 고를 수 있다. 옮기기는 둘 다 되고, 삭제는 폴더의 경우 비어 있을
  때만 된다(코어가 막고 그 말을 그대로 보여 준다).
- 목록이 바뀌면 사라진 것을 선택에서 떨군다 — 없는 것을 고른 채 "3개 옮기기" 라고 하지 않게.

웹으로 확인: 한 번 누르면 선택(안 열림)·Shift 로 3개·두 번 누르면 폴더 진입과 문서 상세,
문서 둘을 골라 `보관` 으로 한꺼번에 이동.

## 남은 것

- 빈 곳 드래그로 사각형 선택, `⌘/Ctrl+A`, 방향키 이동은 아직. (`multi-select.ts` 에
  `all()` 은 준비해 뒀다.)
- 고른 것을 [[REQ-028]] 의 복사·내보내기 대상으로 삼는 것.

## 정할 것

- 고르기: 누르면 하나, `Shift` 로 범위, `⌘/Ctrl` 로 더하기·빼기, 빈 곳 드래그로 사각형 선택,
  `⌘/Ctrl+A` 로 전부.
- 폴더와 문서를 **섞어** 고를 수 있나(옮기기는 되고 열기는 안 된다).
- 고른 뒤 할 수 있는 일: 옮기기(폴더 고르기 / 끌어다 놓기), 지우기, 내보내기·복사([[REQ-028]]).
- 트리 뷰도 같은 규칙으로 갈지, 아이콘 뷰만 바꿀지.
- 키보드: 방향키 이동, `Enter` 로 열기, `Delete` 로 지우기.

## 곁들여 볼 것

- 지금 한 번 누르면 열리는 동작에 익숙한 사람에게는 바뀌는 조작이다 — 바꾸는 김에 빈 곳을
  눌렀을 때 선택 해제, 선택 개수 표시 같은 것도 함께.
- [[REQ-028]] 의 복사·내보내기가 "고른 것" 을 대상으로 돌면 자연스럽다.

## 테스트 방법

- 여러 개를 골라 한 번에 옮긴다 / 지운다.
- 두 번 눌러야 열린다. 한 번 누르면 선택만 된다.
- 선택한 채로 폴더를 옮겨도 선택이 흐트러지지 않는다.

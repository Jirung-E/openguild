`openguild campaign` 에 제목/본문을 수정하는 명령이 없다. `campaign --help` 의
서브커맨드는 new/list/show/history/start/end/link/unlink/delete/checklist/
comment/attach/memo 뿐이고, `update_campaign` 을 호출하는 CLI 경로는
`campaign_set_status`(start/end 전용) 하나다.

반면 core `ops::campaigns::update_campaign` 은 title/description/status/
start_date/end_date 를 모두 받고, 서버는 `PATCH /api/campaigns/{slug}`,
GUI 는 `update_campaign` 커맨드로 이미 노출한다 — **CLI 만 빠져 있다**
(quest 는 `quest update --title/--description-file` 이 있어 비대칭).

## 왜 문제인가

`.guild` 프론트매터는 CLI 로만 수정한다는 규칙([[openguild reads via CLI not
files]] 계열) 때문에, GUI 없이 캠페인 이름을 고칠 방법이 아예 없다. 실제로
C-005 제목이 초기 범위("DB 투영 불변식")에 묶여 있어 고쳐야 하는데 CLI 로는
불가능했다.

## 수정 방향

`campaign update <slug>` 추가 — `--title`, `--description-file <PATH>`,
`--start`, `--end`(날짜)까지. quest update 의 옵션 규약을 그대로 따른다
(비ASCII 본문은 파일로만 — [[openguild-cli-help-no-quest-ids]] 와 동일 이유로
stdin 인코딩 문제 회피). Backend::Http 는 이미 있는 `campaign_update` 를 재사용.

창 폭이 좁아져 메뉴바(Nav)의 항목이 화면을 벗어나면(잘리면), 넘치는 항목을
타이틀바의 ☰ 메뉴 안으로 이동시켜 항상 접근 가능하게 유지. 창이 다시
넓어지면 메뉴바로 복귀 — 브라우저 툴바의 overflow menu(priority+
navigation) 패턴.

## 현재 구조 (등록 시점 확인)

- 메뉴바 = `Nav.svelte`: 홈 / 퀘스트 보드 / 퀘스트 목록 / 관리 / 규칙 /
  도서관 (+ 우측 Reindex·설정 버튼).
- 타이틀바 ☰ 메뉴 = `TitleBar.svelte`: 메뉴바에 없는 페이지 모음
  (캠페인 목록 / 작업기록 / 태그 목록). Windows/Linux 커스텀 타이틀바
  플랫폼에서만 존재(BUG-140 이후, `usesCustomTitlebar()`).

## 동작 요구

1. Nav 항목이 가로로 안 들어가면 오른쪽(우선순위 낮은) 항목부터 숨기고,
   숨긴 항목을 ☰ 드롭다운에 추가(기존 캠페인/작업기록/태그 항목과 구분선
   등으로 구획 권장).
2. 창이 넓어지면 역순으로 메뉴바로 복귀. ResizeObserver 기반 측정 필요 —
   창 폭뿐 아니라 UI 크기(uiScale)·언어(라벨 길이) 변화에도 반응해야 함.
3. 현재 활성 페이지 하이라이트는 ☰ 안으로 이동해도 유지.

## 열린 질문 (착수 전 확인)

- Nav 우측의 Reindex/설정 버튼도 overflow 대상인가, 아니면 페이지 링크만?
  (일단 페이지 링크만으로 가정)
- 커스텀 타이틀바가 없는 환경(macOS/브라우저 HTTP 모드)엔 ☰ 가 없음 —
  Nav 자체에 "…" overflow 버튼을 두는 fallback 이 필요한지, 해당 환경은
  범위 밖인지.

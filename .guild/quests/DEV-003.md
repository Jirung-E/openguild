Tauri v2 데스크탑 crate 신설. gui/Cargo.toml, gui/src/{lib,main}.rs, gui/tauri.conf.json,
gui/build.rs, gui/capabilities/default.json. workspace members 에 `gui` 추가.

## 변경 사항

- `gui/Cargo.toml` — Tauri v2 deps (tauri / tauri-build / serde / serde_json / anyhow / openguild-core).
- `gui/src/lib.rs` — `run()` + 임시 `ping` invoke 핸들러 (DEV-004 에서 확장).
- `gui/src/main.rs` — `windows_subsystem = "windows"` (release), `openguild_gui_lib::run()` 호출.
- `gui/build.rs` — `tauri_build::build()`.
- `gui/tauri.conf.json` — productName "OpenGuild", identifier "io.openguild.desktop",
  frontendDist `./frontend/build`, devUrl `http://localhost:5173`, 1280×800 main window.
- `gui/capabilities/default.json` — v2 capability (메인 윈도우 + `core:default`).
- `gui/icons/` — placeholder (PowerShell 생성, 32×32 단색).
- `gui/frontend/svelte.config.js` — `@sveltejs/adapter-static` 로 전환 (build/ 출력, SPA fallback).
- `gui/frontend/package.json` — adapter-auto 제거, adapter-static 추가.
- 루트 `Cargo.toml` workspace.members 에 `"gui"` 추가.
- 루트 `.gitignore` — `gui/gen/` 무시 (tauri-build 자동 생성).
- `gui/README.md` — 부트스트랩 안내 (`npm run build` 후 `cargo check`).

## 테스트 방법

### 자동 (완료)
- `cargo check --workspace` → 0 errors (gui crate 포함 5 crate 컴파일).
- `cargo test --workspace` → 191 통과 (core 110 + cli 25 + server 56, gui/ 테스트 없음).
- `cd gui/frontend && npm run build` → adapter-static 으로 `build/` 디렉토리 생성, SPA fallback 동작.
- `cd gui/frontend && npm test -- --run` → 51 통과 (기존 frontend 회귀).
- `cd gui/frontend && npm run check` → 0 errors (기존 a11y warning 만 잔존).
- `gui/icons/` 에 32×32 / 128×128 / 128×128@2x / icon.ico 파일 존재.
- `gui/gen/` 은 gitignore (tauri-build 가 capabilities 컴파일 시 schemas 생성).

### 사용자 검증 필요 (수동)
- **실제 Tauri 창이 뜨는지** — `cargo run -p openguild-gui` 실행 시:
  - 1280×800 윈도우가 뜨고 타이틀 "OpenGuild"
  - frontend 가 webview 에 로딩 (현재는 SvelteKit 기본 화면)
  - Windows 작업표시줄 아이콘 placeholder 표시
  - 콘솔 panic / 에러 없음
- **`ping` invoke 핸들러 호출 가능** — devtools 콘솔에서:
  ```js
  await window.__TAURI__.core.invoke('ping')  // → 'pong'
  ```
- 종료 시 process 가 깨끗하게 끝나는지 (좀비 안 남는지)

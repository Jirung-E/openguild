댓글을 마크다운 모드(CodeMirror, `MarkdownEditor.svelte`)로 작성해서 등록하면 입력창이 안 비워짐 — textarea 모드는 정상.

## 원인

`QuestCommentsSection.svelte`의 `add()`(등록 성공 후 `newBody = ''`)는 바인딩된
`value` 를 리셋하지만, `MarkdownEditor.svelte` 는 `value` prop 이 **초기
마운트 시 1회만** CM 문서에 반영되고(`doc: untrack(() => value)`), 이후로는
CM → `value` 단방향(`updateListener`)으로만 동기화된다. 즉 부모가 `value` 를
외부에서 다시 대입해도 CM 내부 문서엔 반영되는 경로가 없음 — 댓글뿐 아니라
`MarkdownEditor` 를 쓰는 어떤 화면이든 부모가 `value` 를 외부 리셋하면 동일하게
재현될 구조적 문제였음.

## 수정

`MarkdownEditor.svelte` 에 `value` 를 감시하는 `$effect` 추가 — 현재 CM
문서 내용과 다르면 `view.dispatch()` 로 전체 치환. `updateListener` 가 이미
매 타이핑마다 `value` 를 CM 과 동일하게 맞춰두므로 무한 루프 없음(비교 후
같으면 skip).

## 테스트 방법

1. 댓글 입력창을 마크다운 모드(M↓ 토글)로 전환, 내용 입력 후 등록.
2. 입력창이 빈 상태로 초기화되는지 확인 (기존엔 방금 쓴 내용이 그대로 남아있었음).
3. 같은 편집기에서 `[[` cross-link 자동완성(DEV-172)이 여전히 정상 동작하는지도 함께 확인.

(1~3 Playwright 로 자동 검증 완료 — 실제 화면에서 육안 확인도 부탁드립니다.)

구현 완료. 정렬 키: 번호/이름/수정 + 방향 토글(↑↓), localStorage 영속(openguild.librarySort). 기본은 기존 동작과 동일한 이름순.

- buildLibraryTree 에 preserveDocOrder 옵션 — 페이지가 정렬한 books 순서를 내부 title 재정렬이 덮지 않게(기본값은 기존 title 정렬 유지, 타 호출처/테스트 호환).
- tree 모드 사이드바 / explorer 툴바 양쪽에 검색창 옆 sort-group(quest list 와 동일 패턴) 배치. 검색 결과와 explorer 그리드도 같은 정렬을 따름(sortedBooks 단일 소스).
- 폴더 자체는 현행 이름순 유지. vitest 1건 추가.

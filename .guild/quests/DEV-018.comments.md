## 기능
`openguild-server info` 의 두 가지 추가 모드 — 1줄 요약 + 진단.

## 사용

### `--brief` — 1 줄 요약 (스크립트 / status bar 친화)
```
$ openguild-server info --brief
guild=my-project quests=12/13 schema=0011 quest_comments_memos snapshots=3 journal=15
```
형식: `guild=X quests=alive/total schema=V snapshots=N journal=M`.

### `--detailed` — 정기 점검 / 디버깅용
기본 출력에 추가:
- `=== migrations (history) ===` — 모든 마이그레이션 + success mark.
- `=== integrity_check ===` — `PRAGMA integrity_check` 결과.
- `=== drift ===` — `detect_drift` 의 fresh files / siblings / missing / stale.

### 상호배타
`--brief --detailed` 동시 지정 시 clap `ArgumentConflict` 에러.

## 테스트
1. 길드 폴더에서 `openguild-server info --brief` → 1 줄.
2. `--detailed` → migrations / integrity_check / drift 3 섹션 추가.
3. `--brief --detailed` → "argument conflict" 에러.

## 자동 검증
- `cargo test parse_info_with_brief_and_detailed_flags`
- `cargo test run_info_succeeds_on_fresh_guild` (3 모드 모두).

업데이트(updateState) 상태 메시지가 여러 컴포넌트에서 서로 다른 위치로 렌더되고 일부 상태는 중복 표시됨. 예: welcome 에서 자동 감지는 상단 전역 배너, 수동 확인은 하단 토스트. 전수조사 결과와 통일 방안은 토론 댓글 참조.

## 해결 — 옵션 A (전역 단일 토스트) 채택

`UpdateBanner.svelte` 를 상단 배너(actionable 만, 레이아웃 밀어냄)에서
**우하단 floating toast 하나**로 전면 재작성 — idle 이 아닌 모든 상태
(checking/available/downloading/ready/uptodate/error)를 같은 위치에서
처리. `welcome/+page.svelte` / `settings/+page.svelte` 의 중복
toast(`.upd-toast`) 와 그 표시 상태(`updateRequested`) 는 제거 — 두
페이지는 이제 "업데이트 확인" 버튼이 `checkForUpdate()` 만 호출하고,
결과 표시는 전역 컴포넌트가 전부 담당. `+layout.svelte` 의 mount 위치는
그대로(한 번만, 모든 라우트 공통).

효과: 같은 메시지가 항상 같은 위치/스타일로 뜨고, 수동 확인 시
전역+페이지 이중 표시가 사라졌으며, checking/uptodate/error 도 어떤
라우트에서든 보임(이전엔 페이지 토스트가 없는 라우트에선 안 보였음).

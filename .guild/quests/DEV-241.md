admin 요청: CLI 로 댓글 출력할 때 부모/자식(답글) 댓글을 어디까지 출력할지
지정하는 옵션이 필요.

## 현재 상태(조사)
`quest comment show <slug> --id N` 이 그 entry 하나만 출력 — 부모/답글은
전혀 안 보임. 전체를 보려면 `comment list` 로 다시 다 훑어야 했음.

## 구현
- `CommentCmd::Show` 에 `--depth <N>`(기본 0 = 대상만) / `--with-parents`
  플래그 추가.
- `depth` 는 답글을 BFS 로 그만큼 단계 따라감(레벨마다 ts 순 정렬).
  `with-parents` 는 root 까지의 조상 체인을 앞에 붙임(오래된 순).
  GUI(DEV-200)는 시각적으로 2단까지만 보여주지만 실제 parent_id 체인은
  임의 깊이라 CLI 는 제한 없이 그대로 노출.
- quest/campaign 공용(`run_comment_cmd` 하나로 처리 — scope 무관).

## 테스트 방법
- `cargo test -p openguild-cli select_thread` (선택 로직 단위 테스트 —
  depth/with_parents 조합, 존재 안 하는 id).
- `cargo test -p openguild-cli comment_show` (파싱 테스트).
- 실기: `openguild quest comment show <slug> --id N` (기존과 동일, 대상만).
  `--depth 2` 로 답글 2단까지, `--with-parents` 로 조상 체인까지 같이
  나오는지 확인.

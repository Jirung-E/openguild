**결정: `run` 훅은 길드 폴더에서 돈다. 다른 위치는 받지 않는다**(admin, REQ-035 를 대신한다).

고를 수 있게 하지 않는다. 고르게 하면 "왜 AI 가 아무것도 모르나" 를 사람이 한 번은 겪어야
알게 되고, 설정 칸만 하나 늘어난다.

## 지금

훅은 **플러그인의 데이터 폴더**에서 돈다.

```
~/.openguild/plugin-data/<길드>-<해시>/<플러그인>/
```

`delivery.rs` 의 `.current_dir(&workdir)`, `workdir` 은 `plugin.data_dir()`.

## 왜 바꾸나

AI 를 부르는 훅에서는 작업 폴더가 곧 **AI 가 보는 세상**이다. `claude -p` 를 데이터 폴더에서
띄우면 길드도 코드도 못 보고 댓글 한 줄만 들고 답한다. 정작 묻고 싶은 것은 대개 "이 퀘스트에
대해" 인데 그걸 볼 수가 없다(admin). 지금은 명령 앞에 `cd "$OPENGUILD_GUILD_DIR" &&` 를
붙여서 피하고 있다 — 기본값이 틀렸다는 뜻이다.

## 조심할 것 — BUG-279 를 되돌리면 안 된다

작업 폴더를 **플러그인 폴더**로 두면 안 되는 이유는 그대로다. 동의 지문이 플러그인 폴더의
모든 파일을 보므로, 훅이 출력을 옆에 쓰는 순간 자기 동의를 깨고 한 번 돌고 멈춘다. 길드
폴더는 지문 대상이 아니라 그 덫은 없다.

대신 새로 생기는 것:

| | |
|---|---|
| 훅이 길드 안에 파일을 흘린다 | 데이터 폴더는 그대로 두고(`OPENGUILD_PLUGIN_DATA_DIR`) 거기 쓰라고 안내한다. 예제의 `delivered.log` 는 **절대경로로** 쓰게 고쳐야 한다 — 지금은 상대경로라 길드 루트에 떨어진다 |
| `.guild` 직접 쓰기 | 규칙대로 ops 를 거쳐야 한다. 훅이 `.guild` 를 직접 건드리면 캐시가 어긋난다 — 문서에 못 박는다 |
| 길드가 git 저장소다 | 훅이 만든 파일이 `git status` 에 뜬다. 최소한 예제들은 길드 안에 아무것도 안 남겨야 한다 |

## 할 일

1. `delivery::run` 의 `current_dir` 을 `plugin.guild_root` 로
2. 예제들의 상대경로 출력을 `$OPENGUILD_PLUGIN_DATA_DIR` 기준 절대경로로 (`delivered.log`,
   `inbox.md`, `deleted.log`)
3. 문서 — USAGE.md · reference/plugins.md · 제작 스킬의 "작업 폴더" 설명 전부
4. 시험 — 훅이 길드에서 돈다는 것, 그리고 **BUG-279 가 안 돌아왔다는 것**(훅이 출력을 써도
   동의가 안 깨진다)

## 한 것 (2026-10-22)

- `delivery::run` — `current_dir` 을 **길드 루트**(`plugin.guild_root`, `OPENGUILD_GUILD_DIR` 와 같은 값)로. 데이터 폴더는 그대로 미리 만들고 `OPENGUILD_PLUGIN_DATA_DIR` 로 알린다.
- 이름: 허용 화면(CLI) · 앱 · README 의 '작업 폴더' → **'데이터 폴더'**(en: data folder). 훅이 도는 자리가 아니게 됐으므로 틀린 말이 됐고, 셋이 같은 이름이어야 찾는다(BUG-329).
- 예제 출력을 데이터 폴더 **절대경로**로: discussion-to-ai(`delivered.log` · `inbox.md`, sh · ps1), deleted-audit(`deleted.log`, sh · powershell), desktop-notify(`notify.log`). backup-archive 는 상대 경로로 쓰는 것이 없어 설명만.
- 문서: USAGE(작업 폴더 · 데이터 폴더 · `.guild` 직접 쓰기 금지), reference/plugins.md, 제작 스킬(openguild-plugins) 두 곳, 예제 README. 처방의 `--guild "$OPENGUILD_GUILD_DIR"` 는 남겼다(admin 댓글 #1).

## 시험

- 새 시험 `run_starts_in_the_guild_root_and_is_told_its_data_folder` — 훅의 `pwd` 가 길드 루트, 데이터 폴더는 길드 밖, 길드 루트에 아무것도 안 남음.
- **BUG-279 가 안 돌아왔다:** `a_hook_that_writes_files_keeps_its_consent` — 훅이 상대 경로(이제 길드 루트)에 두 번 써도 동의가 유지되고 코드 폴더는 그대로.
- 상대 경로로 쓰던 delivery 시험 8개는 길드 루트에서 찾게, CLI `plugin_sources` 시험의 훅은 권장대로 `$OPENGUILD_PLUGIN_DATA_DIR` 에 쓰게.
- 실제 프로그램(시험용 길드 사본을 git 저장소로 만들어): discussion-to-ai 받은 편지함 · 명령 실행, deleted-audit 삭제 → 기록 4개 모두 데이터 폴더, 훅의 `pwd` = 길드, `.guild` 보임, 길드의 `git status` 에 `.guild` 밖 변화 없음.
- `just test` 통과.

## 테스트 방법

1. 앱의 관리 → 플러그인에 '데이터 폴더' 가 보인다(예전 '작업 폴더').
2. discussion-to-ai 를 명령 실행 + claude(또는 codex) 로 두고 토론 댓글 → AI 가 그 퀘스트를 읽고 답한다.
3. 길드가 git 저장소면 `git status` 에 훅이 만든 파일이 안 뜬다.

admin 질문 (BUG-131 후속): 이모지 팝업이 화면 밖으로 완전히 벗어났을 때
팝업을 닫는 처리는?

BUG-131 은 스크롤에 팝업이 "따라오도록" 만들었지만, 트리거 버튼이
스크롤로 화면 밖으로 완전히 나가버린 경우(예: 위쪽 스크롤 컨테이너
경계 밖) 팝업이 clamp 된 위치에 허공에 떠서 남아있는 문제가 그대로
있었음 — wiki 팝업(placeWiki)은 caret 이 보이는 영역 밖이면 `null` 을
반환해 팝업 자체를 숨기는데, 이모지 팝업엔 그 케이스가 없었음.

## 수정
`computeReactionPickerPos`(scroll/resize 마다 호출)에서 트리거 버튼의
rect 가 뷰포트를 완전히 벗어났으면(bottom<=0 / top>=innerHeight /
right<=0 / left>=innerWidth) 위치 재계산 대신 팝업을 닫음.

## 테스트 방법
- `cd gui/frontend && npm run check && npm run check:no-hex && npm test -- --run`.
- 실기: 댓글 목록이 스크롤되는 상황에서 이모지 팝업을 연 채로 그 댓글이
  화면 밖으로 완전히 나가도록 스크롤 → 팝업이 자동으로 닫히는지.

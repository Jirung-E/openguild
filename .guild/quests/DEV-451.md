[[REQ-039]] 의 나머지 — 퀘스트 목록에만 있던 쿼리(`키:값`, [[DEV-446]])를 **캠페인 · 도서관**에도. admin(2026-10-24): "나머지도 쿼리 쓸 수 있도록 해라".

문법은 그대로다(쉼표 = 또는, 띄어 씀 = 그리고, `-` = 아닌 것, 키 없는 낱말 = 검색, 모르는 키는 오류). **키만 대상마다 다르다** — 캠페인에 `urgency` 를 쓰면 "쓸 수 있는 키: …" 로 알려 준다.

## 키

| 대상 | 키 | 값 |
|---|---|---|
| 캠페인 | `status` | `active` · `done` |
| | `start` · `end` | 날짜 · `<=날짜` · `>=날짜` · `none`. `end:overdue` = 끝 날이 지났는데 진행 중 |
| | `quest` | 퀘스트 번호(`DEV-012`) — 그 퀘스트가 연결된 캠페인 |
| | (낱말) | 제목 · 설명 · 번호 |
| 도서관 | `tag` | 태그 이름 |
| | `folder` | 폴더 — 하위 폴더까지. `none` = 최상위만 |
| | `updated` | 날짜 · `<=날짜` · `>=날짜` (고친 날) |
| | (낱말) | 제목 · 본문 · 번호 |

## 할 것

- 코어 `query` — 대상(퀘스트 · 캠페인 · 도서관)마다 키 묶음과 SQL. 해석기는 하나.
- CLI `campaign list -q` · `library list -q`, 서버 `GET /api/campaigns?q=` · `GET /api/library?q=`, 앱 명령도 같은 값. 기존 옵션(`--status` · `--folder` · `--tag`)과 **그리고**.
- 문서: USAGE, 스킬.

화면(보드 · 캠페인 · 도서관의 쿼리 칸)은 [[DEV-452]].

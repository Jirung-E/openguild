수정 — `ops::rules::history` / `ops::library::history` 가 이력을 읽기 **전에**
대상 존재를 확인하고, 없으면 `NotFound`.

- 규칙: `repo::read_rule_entry` 가 None 이면 NotFound.
- 도서관: `paths.book_path(book_id)` 파일이 없으면 NotFound.

사이드카(`.jsonl`)만 읽던 구조라 파일이 없으면 그냥 빈 목록이 됐고, 그래서
"이력이 없는 문서" 와 "없는 문서" 가 같은 결과로 보였다.

## 검증 (CLI 실측)

수정 전:
```
$ openguild rule history 없는규칙xyz     → (no history)   exit 0
$ openguild library history BOOK-999     → (no history)   exit 0
```

수정 후:
```
$ openguild rule history 없는규칙xyz     → error: rule not found: 없는규칙xyz      exit 1
$ openguild library history BOOK-999     → error: document not found: BOOK-999     exit 1
$ openguild rule history fasdasdgdf      → (no history)   exit 0   # 실존, 이력 없음
$ openguild library history BOOK-001     → (no history)   exit 0
```

이력이 없는 실존 문서는 예전 그대로다 — 바뀐 건 없는 대상뿐.

테스트 2건 추가(core): 없는 규칙/BOOK 은 NotFound, 실존 대상은 Ok(대조군).

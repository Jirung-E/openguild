agent dogfood 피드백(2026-07-04, 사용자 확인): '최근 댓글 확인'이 핵심 반복 작업인데 comment list 가 퀘스트 단위라 전역 검색 불가 — .comments.md grep 우회 중이었음.

## 구현 (2026-07-04)
1. **`openguild comments` 전역 명령** (로컬 전용 — index.db 의 quest_comments + campaign_comments UNION, 원격 HTTP 파리티는 후속):
   - 필터: --author(대소문자 무시) / --since / --until / --grep / --discussion / --unresolved(상호배타) / --limit(기본 20). 기본 최신순(ts DESC).
   - 출력: `<슬러그> #id ts author [●미해결|✓해결] 요약1줄`, --json 은 전체 필드(scope/slug/entry_id/ts/author/body/discussion/resolved).
   - campaign 댓글엔 discussion 개념이 없어 --discussion/--unresolved 시 자연 제외.
2. **per-quest `comment list --reverse --limit N`** (campaign 동일) — 기본은 오래된 순(대화 흐름) 유지, 최신순 옵트인.
3. 문서: AGENTS_OPENGUILD_USAGE §2.9 + openguild-workflow 스킬의 세션 시작 루틴을 grep 우회 → 새 명령으로 교체.

## 테스트 방법
- `cargo test -p openguild-cli` — 파싱 테스트(reverse/limit 필드) 포함.
- 실기(이 길드에서):
  1. `openguild comments --limit 5` → 최근 5개(quest+campaign 섞여 최신순).
  2. `openguild comments --author admin` → admin 작성분만.
  3. `openguild comments --unresolved` → 미해결 토론만(● 배지).
  4. `openguild comments --grep 도서관` → 본문 매칭.
  5. `openguild quest comment list DEV-184 --reverse --limit 2` → 최근 2개.
  6. --json 출력 필드 확인.

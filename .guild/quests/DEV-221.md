agent dogfood 피드백(2026-07-04, 사용자 확인): '최근 댓글 확인'이 핵심 반복 작업인데 comment list 가 퀘스트 단위라 전역 검색 불가 — 매번 .comments.md 파일을 grep 으로 우회 중.

제안: openguild comments [옵션] — quest+campaign 전체 댓글 횡단 조회.
- 필터: --author, --since/--until, --grep, --discussion, --unresolved, --limit N (기본 최신순 20)
- 출력: <소속슬러그> #id ts author 요약1줄 (--json 은 전체 필드)
- 구현: 캐시(quest_comments/campaign_comments)가 이미 index.db 에 있어 단일 쿼리로 가능 — 파일 스캔 불필요.
- 활용: agent 가 세션 시작 시 'openguild comments --author admin --since <지난확인>' 한 방으로 피드백 수집. --unresolved 는 미해결 토론 전체 파악.

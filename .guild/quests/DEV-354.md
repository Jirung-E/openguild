## 배경

현재 새 퀘스트 생성 팝업에서는 타입·긴급도·제목·설명·템플릿을 설정할 수 있지만, 일반 생성 흐름에서는 연관관계를 지정할 수 없다. 생성 후 상세 화면에 들어가 상위/하위/선행/후속 관계를 별도로 추가해야 한다.

## 목표

- 새 퀘스트 생성 팝업에서 기존 퀘스트를 검색해 상위·하위·선행·후속 관계를 미리 선택할 수 있게 한다.
- 상위는 하나, 하위·선행·후속은 여러 개를 선택할 수 있게 한다.
- 생성 성공 직후 기존 관계 API로 선택 관계를 연결한다.
- 같은 대상을 상충하는 방향으로 동시에 선택하지 않도록 UI에서 방지한다.
- 관계를 지정하지 않는 기존 생성 흐름은 그대로 유지한다.

## 테스트 방법

1. 일반 새 퀘스트 팝업에서 상위·하위·선행·후속 후보를 각각 선택해 생성한다.
2. 생성된 퀘스트 상세에서 네 관계가 올바른 방향으로 표시되는지 확인한다.
3. 여러 하위/선행/후속을 추가·제거한 뒤 생성해 모두 반영되는지 확인한다.
4. 관계를 선택하지 않고 생성했을 때 기존과 동일하게 생성되는지 확인한다.

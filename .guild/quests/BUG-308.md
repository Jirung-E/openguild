## 무엇이 잘못됐나

`deleted-audit` 예제가 윈도우에서 안 돈다(admin). 기록 동작이 `sh` 를 띄우는데 윈도우에는
`sh` 가 없다.

```toml
[actions.log.run]
    command = "sh"
    args    = ["-c", "cat >> deleted.log; echo >> deleted.log"]
```

## 왜 남았나

BUG-294 에서 `backup-archive` 와 `desktop-notify` 에 윈도우용 갈래
(`[actions.*.run.windows]`)를 붙였는데, 이 예제는 **스크립트 파일이 아니라 한 줄짜리
`sh -c`** 라 눈에 안 띄어 빠졌다.

## 고칠 방향

같은 방식으로 윈도우 갈래를 붙인다. 하는 일은 "들어온 것을 `deleted.log` 뒤에 붙이고 빈 줄
하나" 뿐이라 파워셸 한 줄로 된다.

## 테스트 방법

- `openguild plugin check examples/plugins/deleted-audit` 가 통과한다.
- 윈도우에서 퀘스트를 지우면 `deleted.log` 에 쌓인다.
- `keep` 태그가 붙은 퀘스트는 여전히 안 지워진다.

## 무엇이 잘못됐나

`discussion-to-ai` 를 **어떻게 쓰는지 감이 안 잡힌다**(admin).

> 받은 편지함은 뭔소리고, 프로그램에 넘기기를 할때 제대로 넘어갔는지도 모르겠음.

둘 다 맞는 지적이다.

**"받은 편지함" 이 무슨 말인지 모른다.** 내가 지은 말이고, 설명이 "정해 둔 파일 뒤에
붙입니다" 뿐이다. **그 파일이 어디 있는지**를 안 알려 준다 — 비워 두면 플러그인 데이터
폴더에 생기는데, 그 폴더가 어딘지는 화면 어디에도 없다. 쓰라고 만든 것을 찾을 수가 없다.

**넘어갔는지 알 길이 없다.** '프로그램에 넘기기' 는 명령을 띄우고 끝이다. 그 프로그램의
출력은 버려지고, 실패해도 조용하다. 사용자가 확인할 수 있는 것이 아무것도 없다.

## 고칠 방향

**1. 어디로 가는지 화면에 적는다.** 설정 칸을 비웠을 때 실제로 쓰일 경로를 자리표시(또는
도움말)에 **그대로** 보여 준다. 플러그인 데이터 폴더는 이미 허용 화면에 나오니 같은 값이다.

**2. 이름을 바꾼다.** '받은 편지함' 대신 **'파일에 쌓기'** — 무엇을 하는지가 이름에 있다.
나머지 둘도 같은 결로: '명령 실행', 'tmux 창에 넣기'.

**3. 잘 갔는지 보이게 한다.** 가장 싼 길은 마지막 전달 결과를 남기는 것이다. 이미
"최근 전달 실패" 를 모으는 자리가 있으니, 성공도 한 줄 남기면 화면에서 보인다.

**4. 예제 README 에 실제로 해 보는 절차를 넣는다** — 파일에 쌓기로 한 번, 명령으로 한 번.
지금 README 는 무엇을 고를 수 있는지만 적고 **처음부터 끝까지 해 보는 길**이 없다.

## 테스트 방법

- 설정 화면만 보고도 **파일이 어디 생기는지** 알 수 있다.
- '명령 실행' 으로 바꾸고 토론 댓글을 달면, 성공했는지 화면에서 확인된다.
- 명령이 실패하면 그 사실이 보인다.
- README 를 따라 하면 한 번에 된다.

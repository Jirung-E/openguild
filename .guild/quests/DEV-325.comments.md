## 툴팁(`use:titlePopup`)이 쓰이는 곳 전부

| # | 위치 | 성격 | 가림 문제 | 높이 확장이 맞나 |
|---|------|------|----------|----------------|
| 1 | `SearchPalette.svelte:404` 결과 행 | 목록(키보드 ↑/↓ + 마우스 호버) | **있음** — 위/아래 행을 덮는다 | **예** — 행 높이만 늘리면 됨 |
| 2 | `QuestCommentsSection.svelte:1499` 댓글의 cross-link 자동완성 항목 | 목록(가상 포커스 — DOM focus 는 textarea 에 남음) | **있음** | **예** — 단 팝업 max-height 안에서 스크롤 보정 필요 |
| 3 | `library/+page.svelte` 탐색기 타일 라벨 ×4 (목록/검색 결과 각각 폴더·문서) | 그리드 | 있음(아래 타일) | **조건부** — 그리드는 한 칸이 늘면 그 **행 전체**가 늘어난다. 출렁임이 커서 별도 판단 필요 |
| 4 | `SearchPalette.svelte:444` 미리보기 패널 제목 | 단일 요소 | **없음**(가릴 항목이 없다) | 아니오 — 그냥 두거나 줄바꿈 허용이면 충분 |

(참고: 본문 편집기의 cross-link 자동완성은 CodeMirror 자체 팝업이라 이 액션을 안 쓴다 — DEV-172 로 caret 팝업 통일이 예정돼 있고, 통일되면 2번과 같은 처리를 받는다.)

## 동작 규칙 (제안)
- **마우스 호버** → 지금 그대로 툴팁.
- **키보드 선택** → 툴팁을 띄우지 않고 그 항목만 높이를 늘려 전체 제목을 제자리에 보여준다. 데코레이션·버튼은 그대로 보인다(가려지지 않는다).
- 선택이 다른 항목으로 옮겨가면 이전 항목은 한 줄로 되돌아간다 — 목록 전체가 늘어나 있지 않다.
- 높이가 바뀐 뒤 한 번 더 `scrollIntoView({block:'nearest'})` — 늘어난 항목이 화면 밖으로 밀리지 않게.

## 샘플 (검색 팔레트)

지금:
```svelte
<div class="row" class:sel={i === selIndex} onmouseenter={() => (selIndex = i)}>
  <button class="row-main" use:titlePopup={fullText(it)}>
    <span class="ptype {it.kind}">{kindLabel(it.kind)}</span>
    <span class="ptitle">{displayName(it)}</span>
```
```css
.ptitle { flex: 1; overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
```

바뀐 뒤:
```svelte
<!-- DEV-325: 키보드로 선택된 행은 툴팁 대신 제자리에서 펼친다. 마우스 호버는
     기존 툴팁 그대로 — 호버는 목록을 훑는 동작이라 행 높이가 계속 바뀌면
     오히려 어지럽다. -->
<div
  class="row"
  class:sel={i === selIndex}
  class:expanded={i === selIndex && navMode === 'keyboard'}
  onmouseenter={() => { navMode = 'mouse'; selIndex = i; }}
>
  <button
    class="row-main"
    use:titlePopup={navMode === 'keyboard' ? null : fullText(it)}
  >
```
```css
/* 펼침 = 말줄임 해제. 행 높이는 내용만큼만 늘어난다. */
.row.expanded .ptitle {
  white-space: normal;
  overflow: visible;
  text-overflow: clip;
  overflow-wrap: anywhere;
}
/* 늘어난 행에서도 우측 버튼이 첫 줄에 머물도록 */
.row.expanded { align-items: flex-start; }
```
```ts
// 기존 selFromKeyboard(1회성 플래그) → 지속 상태로 승격.
let navMode = $state<'keyboard' | 'mouse'>('mouse');
// ↑/↓ 핸들러에서 navMode = 'keyboard'
$effect(() => {
  void selIndex;
  if (preview || !rowsEl || navMode !== 'keyboard') return;
  const el = rowsEl.children[selIndex] as HTMLElement | undefined;
  // 높이가 바뀐 뒤 위치를 재계산해야 하므로 다음 프레임에.
  requestAnimationFrame(() => el?.scrollIntoView({ block: 'nearest' }));
});
```

`titlePopup` 액션은 `null` 을 넘기면 아무것도 안 뜬다(이미 그렇게 동작한다) — 액션 자체는 손대지 않아도 된다.

## 확인이 필요한 선택지
1. **3번(도서관 타일)도 포함할지.** 그리드라 한 칸이 늘면 그 행 전체 높이가 늘어난다. 대안: 타일은 그대로 두고 툴팁만 유지 / 또는 선택 시 제목 clamp 를 2줄 → 4줄로만 늘리기(행 출렁임 최소).
2. **마우스 호버도 펼침으로 통일할지.** 지금 제안은 호버=툴팁 유지인데(훑을 때 레이아웃이 계속 흔들리는 걸 피하려고), 일관성을 원하면 호버도 펼침으로 바꿀 수 있다.

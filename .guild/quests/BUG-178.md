'토론만' 필터가 켜진 상태에서 '전체접기'를 눌러도 **토론이 아닌 답글이 접히지
않는다.**

## 원인

`QuestCommentsSection.svelte` 의 스레드 접힘 판정이 토론 모드에서 무력화된다:

```svelte
{@const isCollapsed = !discussionOnly && collapsedRoots.has(root.id)}
```

`discussionOnly` 가 true 면 `isCollapsed` 가 **무조건 false** 가 되어, 사용자가
전체접기로 세운 `collapsedRoots` 가 완전히 무시된다. 그래서 답글이 다 펼쳐진
채로 남는다.

DEV-213 의 의도("토론만 보기에서 비토론 entry 는 숨기지 않고 dim — 문맥 유지")와
접기는 **다른 축**이다. dim 은 필터의 표현이고, 접기는 사용자가 명시적으로 누른
동작이다. 필터가 접기를 덮어쓸 이유가 없다.

## 수정

접힘 판정에서 `discussionOnly` 게이트를 제거 — 두 모드 모두 `collapsedRoots` 를
그대로 따른다.

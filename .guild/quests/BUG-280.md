## 증상

`just test` 가 간헐적으로 실패한다.

```
guild_file::tests::load_parses_valid_guild_file
  left: "X"   right: "모니터"
```

REQ-021 작업 중 실제로 밟았다. 바로 다시 돌리면 3회 연속 통과한다 — 그래서
"어쩌다 그런 것" 으로 넘어가기 쉽다.

## 원인 — 임시 디렉터리 이름이 시계뿐이다

`guild_file.rs` 의 시험 헬퍼:

```rust
let id = SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_nanos();
let path = base.join(format!("openguild-test-{id}"));
```

이 헬퍼를 **18개 시험이 함께 쓴다.** 병렬로 도는 두 시험이 같은 나노초를 받으면
**한 디렉터리를 공유한다.** 실제 잔재가 268ns 차이로 만들어진 것을 확인했다 —
충돌은 시간 문제였다.

그러면 이렇게 된다.

| 시험 | 쓰는 파일 |
|---|---|
| `load_finds_guild_file_regardless_of_name` | `anything.guild` (name = "X") |
| `load_parses_valid_guild_file` | `monitor.guild` (name = "모니터") |

`load()` 는 `read_dir` 이 주는 **첫 번째** `*.guild` 를 집는다. `anything` 이
먼저 오므로 "모니터" 를 기대한 쪽이 "X" 를 받는다. 관측된 실패와 정확히 같다.

덤으로 한쪽이 끝나며 `remove_dir_all` 로 **다른 쪽 디렉터리를 지운다.**

## 수정

이름에 단조 증가 카운터를 붙인다. 시계 해상도와 무관하게 한 프로세스 안에서
겹치지 않는다.

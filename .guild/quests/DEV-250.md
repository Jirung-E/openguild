admin 보고 묶음 — CLI 댓글 출력(quest/campaign `comment list`/`comment show` + 횡단 `comments`)의 표시 누락/기능 부재:

1. **이모지 반응**: list 에만 표시(DEV-199) — show / comments 횡단에는 안 보임.
2. **pin 여부**: 어디에도 안 보임.
3. **토론(discussion)/해결 여부**: 어디에도 안 보임.
4. **트리 표시**: 답글 구조를 들여쓰기 트리로 볼 방법이 없음 — `comment list --tree`.
5. **show --depth 무제한**: DEV-241 의 --depth 는 숫자만 — `--depth all` 허용.
6. **미존재 slug**: `comment list/show` 에 존재하지 않는 퀘스트 슬러그를 줘도 "(댓글 없음)" — 명시적 에러로(오타를 침묵 통과시키면 agent 가 잘못된 slug 로 계속 진행).

## 작업
- 메타 배지 공통 포맷: `📌`(pin), `● 미해결 토론`/`✓ 해결됨`(discussion/resolved), `[👍2 ✅1]`(reactions) — list 한 줄/show 헤더/comments 횡단 모두 동일 규칙.
- `comment list --tree`: parent_id 기반 들여쓰기(print_quest_tree 패턴). 필터와 조합 시 매칭된 entry 의 조상 포함 여부는 quest list 의 DEV-040 정책 참고.
- `comment show --depth all`: value parser 를 "u32 또는 'all'" 로.
- slug 존재 검증: list/show 진입 시 quest/campaign 조회 — 없으면 에러 exit.
- 검증: list/show/comments 3 출력 모두에서 pin/discussion/reactions 확인(admin 지적: 세 곳 모두).

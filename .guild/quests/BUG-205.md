모바일에서 브라우저 자체 스크롤 인디케이터와 앱의 커스텀 스크롤바가 **둘 다** 보인다(admin 보고).

페이지 전체용 커스텀 스크롤바는 outes/+layout.svelte 의 <OverlayScrollbar />(target 없음) 하나뿐이고, 나머지 15개는 컨테이너용(검색 팔레트·자동완성 팝업·목록·편집기 등)이다. 컨테이너 쪽은 브라우저가 대신 그려주지 않으므로 그대로 두고, **페이지 전체용 하나만** 숨긴다.

판정은 화면 폭이 아니라 (pointer: coarse) — 폭으로 나누면 데스크탑 창을 좁혔을 때도 우리 것이 사라지는데 브라우저 기본 스크롤바는 global.css 가 이미 숨겨 놔서 **아무 스크롤바도 없는** 상태가 된다. 회전/입력장치 변경에 따라오도록 matchMedia 를 구독한다.

검증: 데스크탑(pointer: fine)에서는 그대로 표시됨을 확인. **터치 기기에서 숨겨지는지는 admin 확인 필요**(이 PC 는 coarse 포인터가 없어 실기 검증 불가).

CLI 에도 넣었습니다. 퀘스트·도서관 둘 다입니다.

```
openguild quest   list --tag gui
openguild library list --tag 회고 --tag 2026
```

여러 개를 주면 **모두 가진 것만** 나옵니다(AND). `--tag a,b` 로 한 번에 써도 되고
`--tag a --tag b` 로 나눠 써도 됩니다.

퀘스트 쪽은 SQL 에서 거릅니다(태그마다 `EXISTS` 하나 — 개수 제한 없이 AND 가 걸립니다).
도서관 쪽은 목록을 받아 거릅니다. 화면의 태그 필터와 같은 규칙입니다.

## 증상

Quest Board 노드의 제목이 2줄 (36자 초과) 일 때 두번째 줄이:
- 회색 (`#8b949e`) 로 표시 — 1줄과 색이 달라 가독성 떨어짐.
- 추가로 close tag 오타 가능성 (아래 참조) 로 일부 환경에서 렌더링 깨질 수 있음.

## 원인

`gui/frontend/src/lib/components/QuestBoard.svelte` 의 `makeSvgUrl()` (line ~40-60):

```js
const titleY = line2 ? 44 : 52;
const svg = `<svg ...>
  ...
  <text x="10" y="${titleY}" fill="#c9d1d9" font-size="12">${x(line1)}</text>
  ${line2 ? `<text x="10" y="${titleY + 16}" fill="#8b949e" font-size="11"
    font-family="...">${x(line2)}<\text>` : ''}
</svg>`;
```

두 가지 결함:

1. **2번째 줄 fill 색이 회색** — `fill="#8b949e"` 가 1줄의 `#c9d1d9` 보다 어두움.
   디자인 의도일 수 있으나 사용자 피드백상 일관된 색이 더 명확.
2. **close tag 오타 `<\text>`** — JavaScript 템플릿 리터럴에서 `\t` 는 TAB 이스케이프.
   결과 문자열은 `< ext>` (TAB 포함). SVG 파서가 정상 닫힘 처리 못 함:
   - 일부 브라우저: forgiving 파서 — 첫 줄만 보이고 2번째 줄 무시 / 깨짐.
   - WebView2 (Tauri): 동작 확실치 않음 — 수동 확인 필요.

또한 `font-size="11"` 도 1줄 (`12`) 보다 작아 시각적 위계가 강조됨 (디자인 의도).

## 수정 방향

1. **fill 통일** — 2번째 줄도 `#c9d1d9` 로. (또는 사용자 선호에 따라 적정 명도).
2. **close tag 수정** — `<\text>` → `</text>`.
3. (선택) font-size 도 12 로 통일 또는 11 유지 — 디자인 선택.

## 우선순위

`urgency = 3`. 가독성 영향 — 1줄 안에 들어가는 제목은 영향 없음. 긴 제목 (36자
초과) 만 해당.

## 재현 절차

1. `cargo run -p openguild-gui` 또는 브라우저 dev.
2. 보드에서 제목이 36자 넘는 quest 노드 찾기 (예: BUG-001
   "openguild quest update --description multi-line 시 첫 줄만 저장됨").
3. 2번째 줄 색 확인 (`#8b949e` 회색).
4. DevTools → Inspect SVG element → 두번째 `<text>` 의 close tag 살펴보기.

## 임시 회피

제목을 짧게 (36자 이내) 유지.

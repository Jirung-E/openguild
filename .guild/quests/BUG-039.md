## 증상

- Quest description / 댓글 / 메모 등 markdown 본문 안에 긴 URL 이 있으면
  본문 컨테이너 너비를 벗어나 가로 스크롤 발생.
- 모바일 / 좁은 윈도우에서 특히 거슬림.

## 원인

- `MarkdownView.svelte` 또는 base.css 에 `a` / `code` 의 `overflow-wrap` /
  `word-break` 미설정.
- 기본 inline link 는 break 되지 않아 컨테이너 overflow.

## 작업

### MarkdownView CSS 패치
```css
.markdown-view a,
.markdown-view code {
  overflow-wrap: anywhere;
  word-break: break-word;
}
.markdown-view {
  max-width: 100%;
}
```
- 모든 마크다운 렌더링 위치 일괄 해결.

### 추가 확인 위치
- Quest Detail description (`MarkdownView`).
- 댓글 entry body (`QuestCommentsSection` 이 MarkdownView 사용).
- 메모 (`QuestNoteSection` MarkdownView).
- Rules 페이지 (`MarkdownView`).
- 캠페인 description.

## 적용 (2026-06-03)

`gui/frontend/src/lib/components/MarkdownView.svelte` 의 CSS:

```css
.md {
    /* 자식 (긴 링크 / inline code) 이 컨테이너 폭 못 넘게. */
    max-width: 100%;
    overflow-wrap: anywhere;
}
.md :global(a) {
    color: #58a6ff;
    overflow-wrap: anywhere;
    word-break: break-word;
}
```

`MarkdownView` 가 quest description / 댓글 / 메모 / rules / campaign 본문 등
모든 markdown 렌더링 위치에 사용되므로 단일 fix 로 일괄 해결.

`pre` (code block) 은 기존에 `overflow-x: auto` 라 코드는 가로 스크롤 그대로
유지 — 의도.

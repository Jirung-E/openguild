## 증상

- Quest description / 댓글 / 메모 등 markdown 본문 안에 긴 URL 이 있으면
  본문 컨테이너 너비를 벗어나 가로 스크롤 발생.
- 모바일 / 좁은 윈도우에서 특히 거슬림.

## 원인

- `MarkdownView.svelte` 또는 base.css 에 `a` / `code` 의 `overflow-wrap` /
  `word-break` 미설정.
- 기본 inline link 는 break 되지 않아 컨테이너 overflow.

## 작업

### MarkdownView CSS 패치
```css
.markdown-view a,
.markdown-view code {
  overflow-wrap: anywhere;
  word-break: break-word;
}
.markdown-view {
  max-width: 100%;
}
```
- 모든 마크다운 렌더링 위치 일괄 해결.

### 추가 확인 위치
- Quest Detail description (`MarkdownView`).
- 댓글 entry body (`QuestCommentsSection` 이 MarkdownView 사용).
- 메모 (`QuestNoteSection` MarkdownView).
- Rules 페이지 (`MarkdownView`).
- 캠페인 description.

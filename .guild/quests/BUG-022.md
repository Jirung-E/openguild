현재 Nav 의 '+ New Quest' 버튼이 모든 페이지에서 보임. Quest Board / Quest List 컨텍스트에서만 보이도록 조건 추가.

## 구현 (2026-05-25)

`gui/frontend/src/lib/components/Nav.svelte`:
- `showNewQuestButton = $derived(onRootPath && (currentView === 'board' || currentView === 'list'))`
- `<button class="btn-new">` 를 `{#if showNewQuestButton}` 안으로.

결과:
- Quest Board / Quest List 에서 표시.
- Home / Admin / Campaigns (목록/상세/신규) / Quest Detail / Welcome 에서 숨김.

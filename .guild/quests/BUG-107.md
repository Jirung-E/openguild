justfile 의 `build: build-rust build-frontend` 의존성 순서가 반대였음.
gui crate 의 tauri.conf.json bundle.resources 가 frontend/build 를
요구하는데, `just build` 를 실행하면 build-rust 가 build-frontend 보다
먼저 실행되어 fresh clone 에서 항상 실패 (frontend\build 없음).

사용자가 프로젝트를 C: 드라이브로 옮기고 `just build` 를 실행했을 때
겪은 바로 그 에러:
  error: failed to run custom build command for `openguild-gui`
  resource path `frontend\build` doesn't exist

수정: `build: build-frontend build-rust` 로 순서 변경.
확인: `just --dry-run build` 로 build-frontend 가 먼저 실행됨을 확인.
DEV-224 (문서화) 와 연관 — 근본 원인은 문서 부재가 아니라 justfile
버그였음.

## markdown 본문 로컬 이미지 표시 (DEV-087 논의에서 합류, 2026-06-12)

현재 quest/campaign 본문의 `![](로컬경로)` 는 안 뜸 — WebView 의 frontend origin (`http://tauri.localhost`) 에서 `file://` 로드가 cross-origin 차단되기 때문. 웹 URL (`https://...`) 만 동작.

해결 = 본 quest 범위에 포함:
1. Tauri **asset protocol** 활성화 (DEV-087 배너와 인프라 공유) — `convertFileSrc(absPath)` 로 `asset://` URL 생성.
2. `MarkdownView` 렌더 후처리 hook — `<img src>` 가 웹 URL 이 아니면 `.guild/` 기준 상대 경로로 해석해 asset URL 로 변환.
3. 권장 reference 형식: `![alt](attachments/foo.png)` — `.guild/attachments/` 기준.

백업 관련 (본문의 "백업시 db 저장" 요구에 대한 제안): 첨부를 DB blob 으로 넣는 대신 `.guild/attachments/` 를 **git tracked** 디렉토리로 두는 것을 권장 — 댓글 파일과 동일한 보장 수준, snapshot (index.db copy) 범위 밖이지만 git 으로 복원 가능. DB blob 은 index.db 비대화 + reindex 비용 문제. 이견 있으면 회신.

업로드 UI / drag-drop / 로컬(quest 별) 첨부 / 승격은 후속 DEV-097 에서.

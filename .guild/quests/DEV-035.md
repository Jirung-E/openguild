`gui/icons/*` 의 placeholder (PowerShell 으로 생성한 32×32 단색 + "OG" 글자) 를
실제 디자인 아이콘으로 교체.

## 필요 산출물

| 파일 | 크기 | 용도 |
|---|---|---|
| `gui/icons/icon.png` | 1024×1024 | source (Tauri CLI 가 다른 크기로 생성) |
| `gui/icons/32x32.png` | 32×32 | small |
| `gui/icons/128x128.png` | 128×128 | medium |
| `gui/icons/128x128@2x.png` | 256×256 | retina |
| `gui/icons/icon.ico` | multi-size | Windows |
| `gui/icons/icon.icns` | multi-size | macOS |

생성 도구: `cargo tauri icon ./gui/icons/icon.png` — 1024 source 한 장에서 나머지
모든 크기 / 형식 자동 생성.

## 디자인 방향 (제안)

- 테마: 길드 / 모험 / RPG 풍 (`OpenGuild` 의 RPG 메타포 반영).
- 컨셉 후보:
  - 깃발 / 문장 (heraldic crest)
  - 두루마리 (quest scroll)
  - 검 + 방패
  - "OG" 모노그램 (모던 미니멀)
- 색 팔레트: type color 시드와 일관 (DEV 파랑 `#4A90D9` / BUG 빨강 `#E94F4F` /
  REQ 초록 `#7BB87F`) — 또는 단색 / accent 1-2.

## 작업 단계

1. 컨셉 스케치 (사용자 선호 결정).
2. 1024×1024 source 파일 (`.png` 또는 `.svg`).
3. `cargo tauri icon` 으로 자동 변환.
4. `gui/tauri.conf.json::bundle.icon` 확인 — 모든 파일 참조 OK.
5. DEV-034 (installer) 빌드 시 새 아이콘 반영.

## 구현 (2026-05-25)

### Source
- `D:\workspace\resources\openguild-logo\openguild-icon-2_object-only.png`
  (1254×1254, 8-bit RGB).
- `gui/icons/source.png` 로 복사.

### 생성
```
cargo install tauri-cli --version "^2" --locked   # v2.11.2
cd gui && cargo tauri icon ./icons/source.png
```

자동 생성된 파일 (모두 RGBA):
- `icon.ico` — MS Windows multi-size (6 sizes, 32×32 PNG payload).
  이전엔 766 B 16-color placeholder → 52,866 B 정상.
- `icon.icns` — macOS multi-size, 1,145,834 B. 이전엔 0 B placeholder.
- `32x32.png` / `64x64.png` (신규) / `128x128.png` / `128x128@2x.png`.
- `icon.png` — 512×512 master.
- `Square{30,44,71,89,107,142,150,284,310}x*Logo.png`,
  `StoreLogo.png` — Windows Store 자산.
- `android/`, `ios/` — 모바일 자산 (현재 빌드 대상 아니지만 자동 생성됨).

### tauri.conf.json
`bundle.icon` 배열 기존 5개 (`32x32.png`, `128x128.png`, `128x128@2x.png`,
`icon.icns`, `icon.ico`) 모두 새 파일로 자동 교체됨 — 설정 변경 불필요.

### 검증
- `file gui/icons/icon.ico` → MS Windows icon resource, 6 icons.
- `file gui/icons/icon.icns` → Mac OS X icon, 1,145,834 bytes.
- 모든 PNG `file` 확인 → 8-bit/color RGBA.

`gui/icons/*` 가 placeholder (PowerShell 으로 생성한 32×32 단색 + "OG" 글자).
placeholder 아이콘 (PowerShell 생성 단색 + "OG" 글자) 을 실제 디자인 아이콘으로
교체.

## 필요 산출물

| 파일 | 크기 | 용도 |
|---|---|---|
| `gui/icons/icon.png` | 1024×1024 | source (Tauri CLI 가 다른 크기로 생성) |
| `gui/icons/32x32.png` | 32×32 | small |
| `gui/icons/128x128.png` | 128×128 | medium |
| `gui/icons/128x128@2x.png` | 256×256 | retina |
| `gui/icons/icon.ico` | multi-size | Windows |
| `gui/icons/icon.icns` | multi-size | macOS |

생성 도구: `cargo tauri icon ./gui/icons/icon.png` — 1024 source 한 장에서 나머지
모든 크기 / 형식 자동 생성.

## 디자인 방향 (제안)

- 테마: 길드 / 모험 / RPG 풍 (`OpenGuild` 의 RPG 메타포 반영).
- 컨셉 후보:
  - 깃발 / 문장 (heraldic crest)
  - 두루마리 (quest scroll)
  - 검 + 방패
  - "OG" 모노그램 (모던 미니멀)
- 색 팔레트: type color 시드와 일관 (DEV 파랑 `#4A90D9` / BUG 빨강 `#E94F4F` /
  REQ 초록 `#7BB87F`) — 또는 단색 / accent 1-2.

## 작업 단계

1. 컨셉 스케치 (사용자 선호 결정).
2. 1024×1024 source 파일 (`.png` 또는 `.svg`).
3. `cargo tauri icon` 으로 자동 변환.
4. `gui/tauri.conf.json::bundle.icon` 확인 — 모든 파일 참조 OK.
5. DEV-034 (installer) 빌드 시 새 아이콘 반영.

## 우선순위 사유

`urgency = 4`. 기능 영향 없음. 디자인 결정 (사용자
취향) 이 가장 큰 부분. 작업량 자체는 1024 source 만 있으면 5분.

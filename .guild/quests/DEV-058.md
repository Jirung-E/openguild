gui를 다시시작하거나 다른곳으로 이동했다가 퀘스트 보드로 돌아왔을때 이전에 보고있던 위치가 아니라 전체가 보이는 상태가 된다.

이전에 보고있던 위치 및 확대율을 유지해야한다.

## 구현 (2026-05-25)

### Frontend (`gui/frontend/src/lib/components/QuestBoard.svelte`)
- localStorage key `openguild.boardViewport` 에 `{ pan: {x,y}, zoom }` 저장.
  BUG-009 lane cols / DEV-056 hide settings 와 동일 패턴.
- `loadViewport()` — null-safe 파싱 + 형식 검증.
- `scheduleViewportSave()` — debounce 250ms (연속 pan/zoom 시 폭주 방지).
- `cy.on('pan zoom')` 핸들러에 `scheduleViewportSave()` 추가.
- `init()` 끝의 `cy.fit()` 전에 저장된 viewport 있으면 `cy.viewport({pan,zoom})`
  복원, 없으면 기존 fit (첫 진입).

### 검증
- `npm run check` → 0 error.
- `npm test` → 116.
- `npm run build` → ✔.

### 라이브
- Board → pan / zoom → 다른 라우트 (List / Detail) 이동 → 다시 Board →
  **마지막 viewport 그대로**.
- 앱 재시작 → 같은 길드 다시 열기 → 마지막 viewport 복원.

### Trade-off / 후속
- 길드 전환 시 다른 길드의 viewport 가 적용 (localStorage 가 origin 단위).
  심각하지 않지만, 길드별 분리 (recents.path 같은 키 prefix) 가 필요하면
  별도 작업.

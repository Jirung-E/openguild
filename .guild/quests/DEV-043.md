CLI 에서 퀘스트 개별 필드 (제목 / 상태 / 중요도 / 본문 / 생성일 / 변경일) 를
단독 출력하는 명령이 없음. 5 개 별도 명령 대신 `quest show --field <name>`
단일 옵션으로 집약. 또한 기본 `show` 출력에 생성일 / 변경일 표시 추가
(GUI Detail 에는 있지만 CLI 에는 누락).

## 구현 (2026-05-22)

### CLI
- `QuestCmd::Show` 에 `--field <FIELD>` 옵션 (Option<String>).
- 새 helper `quest_field_value(d, field)` — Quest 의 필드를 raw 값으로 반환.
  지원 이름 (alias 포함):
  - `id` / `slug` → quest_id ("DEV-007")
  - `title`
  - `status` / `status_name_en` → name_en ("Open")
  - `status_ko` / `status_name_ko`
  - `status_slug` → 자체 도출 (LOWER + space/hyphen → underscore)
  - `urgency` (숫자 문자열)
  - `description` / `body`
  - `type` / `type_prefix`
  - `parent` (id 또는 빈 문자열)
  - `created_at` / `created`
  - `updated_at` / `updated`
- 모르는 필드명 → 사용 가능 필드 목록 포함한 err 반환.
- `--field` 미지정 시 기본 멀티라인 형식 (변경 없음 + `created` / `updated`
  두 줄 추가).
- `--json` + `--field` 조합: JSON-encoded string (escape 처리).

### 기본 출력 추가
- `print_quest_detail` 에 `created` / `updated` 두 줄 추가.

## 자동 테스트 +12 (cli)
- 각 필드 매핑 (id / slug / title / status / status_slug / status_ko / urgency /
  description / type / parent / created_at / updated_at).
- multi-word status → snake_case slug 도출 (`"In Progress"` → `"in_progress"`).
- description None → 빈 문자열.
- parent None → 빈 문자열, Some → id 문자열.
- 모르는 필드명 → err 메시지에 "unknown field" 포함.

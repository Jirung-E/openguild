admin(2026-10-25): 아이콘이 글자인지 SVG 인지 물음 → 글자 아이콘을 SVG 로 진행.

## 지금 (2026-10-25)

- **SVG**: 공용 `Icon` 부품(BUG-169, `utils/icon-paths.ts`) — folder · doc · comment · memo · trash · image · clock · pin · globe · up · select 11종.
- **글자 기호**가 나머지 대부분 — ☰ ⚙ ⟲ ✎ × ▼ ▶ ◀ ↑ ↓ ✓ ↗ ⤢ ★ ▦ 등(× 26개 파일, ↑↓ 약 20, ▼ 11). 글꼴이 그리므로 OS · 글꼴마다 모양 · 크기 · 높이가 다르다.
- **컬러 이모지**: 도서관 아이콘 보기의 📁 📄 — admin 결정(DEV-326)으로 유지. 이번 대상 아님.

## 할 것

- UI 크롬(버튼 · 메뉴 · 도구줄)의 글자 아이콘을 `Icon` SVG 로. 도형은 `icon-paths.ts` 한 곳.
- 크기 · 색은 지금과 같게(글자색을 따른다, UI 배율 따라감) — 모양만 OS 와 상관없이 같아진다.
- 대상 아님: 사용자가 쓴 본문 · 댓글 반응 이모지 · 문장 안의 화살표(설명 글).
- 다시 글자 아이콘이 들어오지 않게 가드(check:no-emoji 처럼).

## 시험

- 바꾼 화면을 바꾸기 전 빌드와 나란히(라이트 · 다크) — 크기 · 자리가 같다.

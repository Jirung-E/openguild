## 색 사용 원칙 (재발 방지)

원인 패턴:
- 컴포넌트 CSS 에 hex 직접 사용 (`color: #79c0ff`) → 테마 무관 고정.

1. 모든 색은 `global.css` 의 토큰 (`var(--xxx)`) 으로. dark / light 양쪽 동시 정의 필수.
2. JS 가 색을 필요로 하는 경우 (Cytoscape canvas / SVG data URL — CSS var 컴퓨팅 못 함) `lib/stores/theme.ts` 의 `themePalette(eff)` 단일 source 사용.
3. 컴포넌트 안에서 `eff === 'light' ? '#x' : '#y'` 분기 작성 금지.

새 fix 또는 신규 컴포넌트 추가 시 위 규칙 준수. 위반 시 PR 반려 (단일 사용자라 self-review).

## 증상

mermaid 다이어그램 렌더링 시 **노드 안 글자가 잘려 보이는** 현상이 발생한다.
노드 박스 크기가 텍스트를 다 담지 못하는 것으로 보인다.

## 재현 예시

아래 다이어그램에서 실제로 발생했다(사용자 제보).

```mermaid
flowchart LR
    BO[backoffice] --> R
    R["rusty-wvsapi<br/>(오케스트레이터·maintenance ID 발급)"]
    GA[("GA DB<br/>MaintenanceID 카운터<br/>MaintenanceState")]
    R -- "SP: GetNextMaintenanceID" --> GA
    R -- "gRPC 4종<br/>(센터별 팬아웃)" --> C0["Center #0<br/>CMaintenanceMan"]
    R -- " " --> C1["Center #1 ..."]
    C0 -- "점검상태 저장/복원" --> GA
    C0 -- "CSP_SetMaintenanceStateRequest" --> L[로그인서버]
    C0 -- "CSP_UpdateMaintenanceStates" --> G[게임서버]
    C0 -- "CSP_MaintenanceKickRequest" --> G
    C0 -- "CSP_Set.../Kick..." --> H[허브서버]
    C1 -.-> H
```

## 조사 포인트

- `<br/>` 로 줄바꿈된 다중 라인 노드에서 특히 발생하는지
- 한글 + 괄호 조합에서 폭 계산이 틀리는지 (폰트 메트릭 문제 가능성)
- `[(...)]` 실린더 노드처럼 특수 형태에서 더 심한지
- 다이어그램 렌더 시점의 폰트 로딩 타이밍 — 웹폰트가 늦게 적용되면 mermaid 가
  fallback 폰트 기준으로 폭을 계산한 뒤 다시 안 재는 문제가 흔하다. 이 경우
  폰트 로드 완료 후 재렌더가 필요하다.

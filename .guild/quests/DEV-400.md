## 무엇

[[DEV-399]] 로 생긴 **소스·사용 중** 개념을 데스크톱 관리 → 플러그인 화면에 올린다.

## 할 것

- **[+ 플러그인 추가]** — 폴더를 고르면 소스로 등록하고, 그 소스가 내놓는 플러그인 중 고른
  것을 이 길드에서 쓴다. 고른 직후 **무엇에 동의하는지 보여주고** 허용까지 한자리에서.
- 목록 항목에 **출처** 표시(길드 / 소스 이름). 소스에서 온 것에는 `쓰지 않기`.
- 소스 관리 — 등록된 소스 목록, 경로, 제거. 경로가 사라진 소스는 이유와 함께.
- 로컬 데스크톱에서만. 웹은 조회만(링크는 그 기계의 것이라 원격에서 더할 수 없다 — 동의와 같은 이유).

## 테스트 방법

- 폴더를 골라 추가하면 목록에 뜨고, 허용하면 돈다.
- 출처가 보이고, 소스에서 온 것만 `쓰지 않기` 가 있다.
- 경로가 사라진 소스가 이유와 함께 보인다.
- 웹에서는 추가 버튼이 없다.

## 구현 / 확인한 것

- 코어 `plugins::sources` 에 화면용 셋: `status(guild)`(소스 + 플러그인 + 이 길드에서 쓰는지), `add_folder(guild, dir)`
  (하나면 바로 쓰고 `Used{name}`, 여럿이면 `Registered{plugins}`), `stop_using_entry(guild, source, folder)`(짝으로 뺀다 —
  이름은 소스마다 겹칠 수 있다). CLI `plugin add <폴더>` 도 `add_folder` 를 쓰게 바꿨다(판단이 두 곳에 갈리지 않게).
  여럿일 때 `--json` 이 아무것도 안 찍던 것도 함께(`added: null`).
- 데스크톱 명령: `plugin_sources` / `plugin_add_folder` / `plugin_use` / `plugin_stop_using` / `plugin_source_remove`.
  길드를 안 연 상태에서는 거절, 바뀌면 곧바로 다시 꽂는다.
- 화면(관리 → 플러그인, **로컬 데스크톱에서만**)
  - **+ 플러그인 추가** → 폴더 고르기. 하나짜리는 그 항목으로 스크롤 + 강조 + **스크립트 펼침** + 허용 버튼에 포커스
    — 더한 자리에서 읽고 허용한다. 여럿이면 소스 목록으로 데려간다(아무것도 켜지 않음).
  - 항목마다 **출처**(이 길드 / 소스 이름 — 경로). 소스 것에만 **이 길드에서 빼기**.
  - **소스 (이 기계)** — 경로, 사라진 폴더의 이유, 플러그인별 쓰기/빼기, **소스 해제**(확인 대화상자 — 모든 길드에서 빠진다).
  - 웹·원격 길드에서는 추가·다시 읽기·소스 목록이 없고 소스를 묻지도 않는다. 출처는 조회라 보인다.
  - 안내 문구를 "이 길드의 플러그인은 … 길드 밖 폴더도 더할 수 있다" 로 고쳤다.
- 시험: 코어 `adding_a_folder_uses_a_lone_plugin_and_lets_you_pick_from_many`, CLI 실제 바이너리
  `a_folder_with_several_plugins_is_only_registered`, 프런트 경계(`plugins.test.ts` — 새 호출도 로컬 데스크톱에서만),
  화면 7건(출처·빼기 짝, 소스 목록·사라진 폴더, 하나짜리 추가 시 펼침 — 펼침을 빼면 실패함을 확인, 여럿은 등록만,
  고르기 취소, 다시 읽기, 웹에서는 없음).
- 브라우저(빌드한 프런트 + Tauri 브리지를 흉내 낸 Playwright): 1280px·400px 에서 가로 넘침 없음, 추가 후 강조·펼침 확인.
  영어 UI 400px 도 같음.
- 실제 IPC(tauri mock 런타임, 창 없이 — 실제 앱 창은 이 환경에서 화면 캡처·조작 권한이 없어 못 띄웠다):
  `plugin_source_commands_work_over_ipc` — 명령 이름·인자 이름(`path`/`source`/`folder`/`name`)·반환 모양을 실제
  직렬화로. 추가 → 동의 대기(안 꽂힘) → 허용 → 꽂힘, 여럿은 등록만, 쓰기/빼기, 없는 것 빼기는 오류, 정의를 지워도
  다시 읽기 전에는 그대로(자동 감지 없음) → 다시 읽기 뒤 빠짐, 소스 해제. `without_an_open_guild_nothing_is_recorded`.
  `every_command_the_frontend_invokes_is_registered` — 프런트가 부르는 명령 150개가 전부 등록됐는지(등록을 빼면
  실패함을 확인). 다시 읽기에서 재적재를 빼면 IPC 시험이 실패함도 확인.
  **실제 데스크톱 앱 창에서는 확인하지 않았다** — 앱을 빌드·설치하지 않았다.

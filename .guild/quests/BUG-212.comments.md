**이 퀘스트의 측정은 무효다. 결론을 내리기 전에 재측정이 필요하다.**

## 무엇이 잘못됐나

누수 판정에 쓴 브라우저 pane 이 **숨겨진 상태**였다:

```
document.hidden       : true
document.visibilityState : "hidden"
requestAnimationFrame  : 1.5초 동안 0회 발화
```

숨겨진 문서에서는 rAF 콜백이 아예 실행되지 않는다. cytoscape 는 렌더 루프를
rAF 로 도는데(`startRenderLoop`, "exit if destroy() called ... in between
frames"), **예약된 rAF 콜백이 영원히 실행되지 않으면 그 클로저가 renderer 를
계속 붙잡는다**. renderer 는 `r.data.canvases`(3) + `r.data.bufferCanvases`(3)
+ `labelCalcCanvas`(1) = **정확히 관측된 방문당 7개** 를 쥐고 있다.

즉 "방문당 canvas 7개가 GC 를 견디고 살아남는다" 는 관측은 **누수의 증거가
아니라 pane 이 숨겨져 렌더 루프가 멈춘 결과일 수 있다**. 보이는 창에서는
다음 프레임(약 16ms)에 콜백이 실행되고 `r.destroyed` 를 보고 빠져나가면서
참조가 풀린다.

이 가설은 관측된 비대칭도 설명한다 — rAF 루프를 도는 페이지는 보드뿐이라
`/rules ↔ /library`, `/?view=list ↔ /rules` 에서는 누수가 0 이었다.

## 시도했다가 되돌린 것

`onDestroy` 에서 cy/컨테이너/캐시 참조를 직접 끊는 방어적 teardown 을
넣어봤지만 canvas 순증은 그대로 35개였다(5회 방문). 원인이 우리 참조가
아니라는 뜻이고, 위 가설과 일치한다. **근거 없는 수정이 되므로 되돌렸다.**

1. 보드 5회 방문 → 강제 GC → alive canvas 수와 힙 바닥값

**오탐 확정. 누수 없음. 코드 변경 없음.**

pane 을 띄울 수단이 없어(브라우저 확장도 미연결) 아티팩트를 직접 무력화했다:

```js
window.requestAnimationFrame = (fn) => setTimeout(() => fn(performance.now()), 16);
```

cytoscape 의 `raf` 래퍼는 호출 시점에 `_window.requestAnimationFrame` 을
조회하므로(dist 1342~1370행), 이렇게 갈아끼우면 **숨겨진 문서에서도 렌더
루프가 계속 돈다** — 보이는 창과 같은 조건이 된다.

## 결과 (rAF shim 적용)

| | canvas alive | 정착 바닥값 |
|---|---|---|
| shim 없음, 보드 5회 방문 | 35 / 35 (전부 생존) | +27.6MB |
| shim 적용, 보드 5회 방문 | **7 / 35** | — |
| shim 적용, 보드 6회 추가 + GC 반복 | **0 / 77** | 82.3 → 41.0MB |
| shim 적용, 보드 6회 더 (정착 바닥값 비교) | 14 (직후 잔여) | 41.1 → **29.0MB** |

마지막 줄이 결정적이다. 보드를 6번 더 방문했는데 **정착 바닥값이 오히려
12.1MB 내려갔다**(41.1 → 29.0). 누적이 전혀 없다는 뜻이다. 방문 직후 남아
있는 canvas 도 GC 를 몇 번 더 돌리면 0 이 된다.

## 정리

- 원래 관측한 "GC 를 견디는 canvas 방문당 7개" 는 **숨겨진 pane 에서 렌더
  루프가 멈춰 예약된 rAF 클로저가 renderer 를 고정한 결과**였다.
- 실제 사용 환경(보이는 창, 데스크톱 앱)에서는 발생하지 않는다.
- 그래서 이 퀘스트는 취소한다. 방어적 teardown 도 되돌린 채로 둔다 —
  효과가 없었고(가설과 일치) 근거 없는 코드가 된다.

## 남는 교훈

숨겨진 pane 에서 잰 메모리/애니메이션 관련 수치는 신뢰할 수 없다. 앞으로
같은 종류를 측정할 땐 `document.hidden` 과 rAF 발화를 **먼저** 확인하고,
불가피하면 위 shim 을 깔고 잰다.

**다시 엶 — 칠하기 · 지우기 더함** (admin, 2026-10-23: "읽기만 되는거임? 쓰기는 왜안됨?" → 진행. "사용자가 '칠해줘'라고 하기 전에는 ai가 자율적으로 칠하지는 않게" — 난잡해지는 것 방지)

**구현:**
- `quest|campaign|rule|library highlight add <ID> "<글>" [--part body|memo|comment:N] [--nth N]` · `highlight remove <ID> <형광펜 id>`. 로컬 · `--remote` 둘 다.
- 칠할 글은 **읽기 화면에 보이는 글자**로 받는다 — 화면(`findQuote`)이 그 글자로 자리를 다시 찾기 때문. core `highlight_text`(새 의존성 `pulldown-cmark`, 기능 없이)가 원문에서 화면 글자를 만든다: 마크다운 기호 빼기, `[[dev-1]]` → `DEV-1`(화면과 같은 규칙, 코드 · 링크 안은 그대로), 문단 안 줄바꿈은 글자로 남김(marked 와 같음), mermaid · 이미지는 글자 없음.
- 공백 · 줄바꿈 차이는 무시하고 찾고, 저장은 화면 글자 그대로 + 앞뒤 32자(화면과 같은 수).
- 막는 것: 화면에 없는 글(원문 기호째 등), 여러 문단에 걸친 글, 여러 번 나오는데 `--nth` 없음(몇 번인지 알려 줌), 없는 댓글 · 빈 메모, 규칙 · 도서관의 memo/comment. 같은 자리를 또 칠하면 늘리지 않고 있는 것을 돌려줌. 없는 id 지우기는 오류(종료 1).
- AI 규칙: `add` 도움말 첫 줄과 스킬(SKILL.md · reference/comments.md)에 "사용자가 칠해 달라고 할 때만 — 스스로 칠하지 않는다, 지우기도 시킨 것만".

**구현:**
- CLI `quest highlight list <ID>` · `campaign highlight list <C-NNN>` · `rule highlight list <slug>` · `library highlight list <BOOK-NNN>` — 메모처럼 대상 명령 아래. 읽기만(칠하기 · 지우기는 화면 몫).
- 이름은 다른 명령처럼 찾아서 앱이 적는 표기로 바꾼다(`dev-443` → `quest:DEV-443`, `BOOK-1` → `library:BOOK-001`). 없는 대상은 오류(종료 코드 1) — 빈 목록으로 답하지 않는다.
- 출력: `본문 · 메모 · 댓글 #N`, 칠한 때, id, 그 아래 칠한 글(여러 줄 그대로). 없으면 `(형광펜 없음)`. `--json` 은 서버 `GET /api/highlights` 와 같은 배열(prefix/suffix 포함).
- 로컬 · `--remote` 둘 다.
- 문서: USAGE, 스킬 SKILL.md("Highlights — what the user marked": 사용자가 중요하다고 본 곳이니 읽을 때 같이 본다) · reference/comments.md.

**확인(시험용 길드 복사본, develop 빌드):**
- 로컬: 퀘스트(본문 · 댓글 #1 · 메모, 여러 줄) · 캠페인 · 규칙 · 도서관(`BOOK-1`) 다 나옴. 소문자 `dev-443` 도 찾음. 형광펜 없는 퀘스트 → `(형광펜 없음)`.
- 없는 대상 4종(DEV-999 · C-999 · 규칙 · BOOK-999) → 오류, 종료 코드 1.
- 원격(서버 띄워 `--remote`): 같은 결과, `--json` 은 로컬과 글자 하나까지 같음. 영어 locale 라벨(`body` · `comment #1` · `(no highlights)`).
- 시험 `highlights_are_found_by_the_name_the_app_wrote`(소문자 · 짧은 BOOK 번호로 찾기, 없는 대상 4종 오류). just test 통과.

현재 보드는 상태(status) 레인이 **세로 열**로만 배치된다(LANE_W 948px 고정,
X축으로 LANE_STRIDE 만큼 나열). 레인을 **가로 행**으로 눕히는 모드를 추가해
사용자가 전환할 수 있게 한다.

## 왜
- 상태 수가 많으면 가로로 계속 길어져 좌우 스크롤이 심하다.
- 와이드 모니터에서는 세로 열보다 가로 행이 화면을 더 잘 쓴다(퀘스트가
  가로로 여러 개 늘어서고 상태끼리는 위아래로 비교).

## 범위(설계 시 확인할 것)
- 레인 기하: LANE_W/LANE_STRIDE/LANE_TOP/LANE_PAD_X 가 X축 전제 — 축을
  파라미터화하거나 orientation 별 분기.
- snapToGrid / arrangeNodes / arrangeNodesGrouped / laneCols(열 수) 의
  의미가 가로 모드에서 뒤바뀜(열 ↔ 행).
- visibleLaneLeftOfStatus / visualToAbsX 등 X 기준 헬퍼 대응.
- 레인 접기(LANE_COLLAPSED_W), 레인 헤더, grid snap dot SVG 배경.
- 저장된 위치(quest_positions x/y)와의 호환 — 모드 전환 시 좌표 해석.
- 툴바에 모드 토글 + localStorage 영속(gridSnap/laneCols 와 동일 패턴).

우선 설계 결정(좌표를 모드마다 따로 저장할지, 하나를 회전해 쓸지)이 필요.

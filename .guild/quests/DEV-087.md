캠페인에 배너 이미지 추가. Home 의 진행중 캠페인 carousel 카드 배경으로 이미지를 꽉 차게 표시. 글자(제목/기간/진행률)가 있는 좌측은 불투명, 이미지쪽(우측)으로 갈수록 투명해지는 fade 그라데이션으로 가독성 확보. 저장: 캠페인 image_path 필드 추가 (DB migration + 파일 frontmatter + core/server/gui). 이미지 경로 지정 / 업로드 UI.

## 설계 확정 (2026-06-11, 사용자 '맘대로' 위임)

1. **이미지 저장**: `.guild/assets/` 에 복사 보관 — 길드 폴더 이동/공유 시 이미지가 같이 감. `GuildPaths::assets_dir()` 신설. 파일명 = `{campaign_slug}-banner.{ext}` (덮어쓰기 정책 — 캠페인당 1장).
2. **frontmatter**: `CampaignFrontmatter.image` (Option<String>, `.guild/` 상대 경로 — 예 `assets/C-001-banner.png`). 파일 진리원.
3. **DB**: migration 0016 `campaigns.image_path TEXT NULL`. reindex / 캠페인 mutation 경로에서 sync.
4. **지정 UX**: Tauri 파일 picker (`tauri_plugin_dialog` 의 file open — 이미 의존성 있음). campaign detail 의 편집 영역에 "배너 이미지" 버튼. 제거 버튼도.
5. **표시 (수정 2026-06-12)**: WebView 는 raw `file://` 로드를 차단 (frontend origin 이 `http://tauri.localhost` — cross-origin) — **Tauri asset protocol** 사용. `tauri.conf.json` `assetProtocol.enable` + 시작 시 `asset_protocol_scope().allow_directory(guild_dir)` (길드 경로가 동적이라 런타임 allow). frontend 는 `convertFileSrc(absPath)`. data URL 안 (base64 오버헤드) 은 폐기. HTTP 모드는 정적 서빙 (`GET /api/campaigns/{slug}/image`). 본문 markdown 로컬 이미지 (DEV-069) 와 인프라 공유.
6. **fade**: Home carousel 카드 — `background-image` + `linear-gradient(90deg, var(--bg-elevated) 0%, var(--bg-elevated) 35%, transparent 75%)` overlay. 라이트/다크 토큰으로.

## 작업 단계

1. migration 0016 + CampaignFrontmatter.image + reindex sync.
2. GuildPaths::assets_dir + ops::campaigns::set_banner_image (copy + frontmatter + DB) / clear_banner_image.
3. Tauri: pick file (dialog) → set_banner_image / get_campaign_image (data URL).
4. server: POST /api/campaigns/{slug}/image (multipart 또는 base64 body) + GET (bytes).
5. GUI: campaign detail 버튼 + Home carousel fade 표시.

CLI(openguild)에 가벼운 update-check 추가. 현재 업데이트 확인은 GUI(Tauri updater) 전용이라 CLI/server 단독 사용자는 새 버전을 알 길이 없음. openguild update-check (또는 --check-update): tauri.conf 의 updater endpoint(releases/latest/download/latest.json)를 GET → latest.json 의 version 과 자기 CARGO_PKG_VERSION 비교 → 새 버전이면 버전 + release URL 안내, 아니면 최신. CLI 는 실행 중 exe 교체가 까다로우므로 자동 설치 X(안내만; 설치는 GUI/installer). 네트워크/404 는 GUI humanizeUpdaterError 와 유사하게 친화적 메시지. server 도 동일 적용 검토. 우선순위 낮음(백로그).

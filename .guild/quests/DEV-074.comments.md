## 현황 (step 1 — 토큰 + store + 토글)

본 quest 의 spec ("다크/라이트/시스템 선택") 의 backbone 만:

1. CSS variable 토큰 (--bg / --text / --accent 등) 의 dark / light 정의.
2. `<html data-theme="dark|light">` 로 swap.
3. theme store (writable + localStorage 영속).
4. Settings 의 표시 섹션에 [다크 | 라이트 | 시스템] 세그멘티드.
5. OS 의 `prefers-color-scheme` 변경 listener (system 모드만 자동 반영).
6. `color-scheme` CSS property 토큰화 → native input (date picker 등) 도 테마 일관.

## 사용
- Settings → 표시 → 테마 토글.
- 즉시 반영 + 자동 저장 (`openguild.theme`).
- "시스템" 선택 시 OS 의 다크/라이트 설정에 따라 자동.

## 한계 / 향후 (별도 sub-quest 권장)

global.css 의 html / body 만 var() 화. 점진 마이그레이션 필요:

- Nav / Home / QuestBoard / QuestList / QuestDetail / Campaign* / Settings 의 hardcoded color → var() 로.
- input / button / badge / modal 의 색 토큰화.
- light 테마에서 시각적 일관성 검증.

→ DEV-074 의 sub-quest 들로 분할 권장. 각 component 단위.

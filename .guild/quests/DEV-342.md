사용자 요청: 퀘스트 보드의 레인(lane) 폭을 줄이는 토글 — 노드 1개 폭까지
줄일 수 있게.

## 현재 상태 (조사)

`QuestBoard.svelte` 의 `LANE_W` 가 전 레인 공통 고정 상수다:

```
const LANE_W = NODE_W * 3 + NODE_GAP * 2 + LANE_PAD_X * 2; // 948px
```

레인별 "열 수"(`laneCols`/`globalCols`, 1~3열) 설정은 이미 있지만, 그건
레인 *안에서* 노드를 몇 열로 배치할지만 바꾸고 레인 자체의 렌더 폭
(`laneWidth()` → `LANE_W`, `collapsedLanes` 이면 `LANE_COLLAPSED_W`=40)에는
영향을 안 준다 — 1열로 설정해도 레인 폭은 그대로라 좌우로 빈 공간이 남는다.

코드에 이미 이 한계가 명시돼 있다(line ~740):
> "lane 접기 — collapsed 시 그 lane 의 노드 hide + label 90도 회전. **lane 폭
> 자체 축소는 미지원 (LANE_W 상수 retrofit 필요 — 별도)**."

즉 지금의 "접기"(collapsed)는 폭을 40px 로 줄이되 노드 자체를 안 보이게
하는 다른 기능 — 사용자가 원하는 건 노드는 보이는 채로 레인 폭만 노드
1개 폭(`NODE_W + LANE_PAD_X*2` 정도)까지 줄이는 것.

## 범위 제안 (조사만, 미확정)

- 레인별(또는 전역) "폭" 설정을 열 수(1/2/3)와 별개로 두거나, 열 수 = 1일 때
  자동으로 좁은 폭을 쓰는 옵션을 토글로 노출.
- `laneWidth(slug)` 가 `LANE_COLLAPSED_W` / 좁은 폭(1노드) / `LANE_W`(기본)
  3단을 반환하도록 확장.
- 노드 배치(`arrangeNodes`)·엣지 좌표·드래그 드롭 판정 등 `LANE_W` 를 참조하는
  다른 지점들(node-layer 클램프, drag-target 판정 등)도 같이 갱신 필요 —
  상수 하나가 아니라 여러 곳에서 `LANE_W` 를 직접 참조 중이라 실제 구현 시
  전수 조사 필요.

## 한 것 (2026-10-24)

- `render_table` 의 폭 계산 · 채우기 · 가로줄을 **터미널 칸 수**(`unicode-width`, BUG-326 의 `pad_to_width` · `max_width`)로. 오른쪽 맞춤(숫자)도 칸 수로 앞에 공백. 러스트 폭 지정자(`{:<w$}`)는 안 쓴다.
- 몸통을 `table_lines` 로 떼어 시험할 수 있게 했다. 이 함수를 쓰는 표 8곳(quest · type · tag · status · rule · library · campaign · plugin 쪽)이 모두 고쳐진다.
- 지금 이 길드의 표는 한글이 마지막 컬럼(제목 · 설명)에만 있어 안 보였다. 앞 컬럼에 한글이 오는 경우 — 한글 태그 이름, 상태 이름을 한글로 바꾼 길드 — 에서 어긋났다.

## 확인

- 시험 `table_columns_line_up_with_korean_in_front_columns` — 앞 컬럼에 `테스트 중` · `진행 중` 이 섞여도 마지막 컬럼이 같은 칸에서 시작, 숫자 오른쪽 맞춤, 가로줄 길이.
- 길드 사본에 태그 `wip` · `긴급` · `디자인검토`:

## 테스트 방법

`openguild tag list --table` 에 한글 태그가 있으면 색 컬럼이 한 줄로 선다. 윈도우 터미널에서도 같은지(글꼴에 따라 한글 폭이 다를 수 있음).

**윈도우 11 확인 (2026-10-24, 윈도우 세션, 969fa1c8) — 칸 수로는 맞음, 눈으로 보는 확인은 사용자 몫.**

`tag list --table` 출력의 COLOR 열이 머리줄과 한글 태그 줄 모두 12칸째에서 시작한다(한글 2칸으로 셈). Windows Terminal · 기본 콘솔 화면은 보지 않았다.

참고: 구분선 `─`(U+2500)는 동아시아 '애매한 폭' 글자라, 한국어 코드페이지 기본 콘솔에서는 2칸으로 그려져 선이 두 배로 길어 보일 수 있다 — 열 맞춤과는 따로 볼 거리.

사용자 보고 (2026-08-01, admin 실기, macOS). 원인: +layout.svelte 의
trackRecentDoc() 이 `$page.url.pathname + search` 를 그대로 recentDocs
href 로 저장하는데, 퀘스트 네비게이션(Board/List/Nav/Home 등)만
`?from=board` 류 추적 쿼리를 붙인다. SearchPalette 의 recent 모드는 전역
검색 인덱스(all, 쿼리 없는 href)와 recentDocs 의 href 를 문자열로
매칭하는데, 퀘스트만 쿼리가 섞여 있어 매칭이 항상 실패 — 퀘스트만 최근
목록에서 누락됐다. 캠페인/규칙/도서관은 네비게이션에 추적 쿼리가 안 붙어
정상 동작했음.

## 수정
kind/label 로 canonical href(쿼리 없는 정규 경로)를 만드는
`canonicalDocHref()` 를 `recentDocs.ts` 에 추가하고, `trackRecentDoc()`
이 원본 URL 대신 이를 저장하도록 변경.

## 테스트 방법
1. 데스크탑 앱에서 퀘스트 상세를 보드/목록/Nav 검색 등 여러 경로로 열어본다.
2. 타이틀바의 "최근"(시계 아이콘) 버튼을 눌러 방금 본 퀘스트가 목록에
   보이는지 확인.
3. 캠페인/규칙/도서관 문서도 여전히 최근 목록에 잘 잡히는지(회귀 확인).
4. `cd gui/frontend && npm run check && npm test -- --run` — 0 errors.

사용자 보고 (2026-08-01, 웹 모드): 화면 좌우폭이 좁을 때 검색 팔레트
양옆의 '퀘스트 추가'/'최근 문서' 버튼이 검색 팔레트와 너무 가까워지다
못해 팔레트 영역 안으로 들어가기까지 함.

## 원인
버튼 위치를 `translateX(min(21vw, 134px))` 로 계산 — 검색 pill 의 실제
절반 폭 근사치였는데, pill 은 `min-width: 260px`(절반 130px)라 좁은
뷰포트에서도 그 밑으로 안 줄어드는 반면, `21vw` 는 뷰포트가 638px
미만이면 130px 밑으로 계속 줄어듦. 그래서 버튼이 pill 의 실제 가장자리
보다 안쪽으로 파고듦.

## 수정
`pillEl` 을 ResizeObserver 로 실측해 절반 폭을 CSS 변수(`--pill-half-w`)
로 흘려보내고, 버튼 위치 계산이 그 실측값을 쓰도록 변경.

## 참고
`TitleBar.svelte`(데스크탑)에도 동일한 `min(21vw, 134px)` 패턴이 있으나,
창 최소 폭이 800px(이 버그 임계값 638px 보다 큼)로 강제돼 있어 실제로는
발현 안 됨 — 잠재 버그로만 남겨둠, 이번엔 안 고침.

## 테스트 방법
1. 웹 모드에서 창을 638px 미만으로 좁혀보고 버튼이 pill 바깥에 정상적으로
   유지되는지(안으로 안 들어가는지).
2. 창을 다시 넓혔을 때도 정상 배치인지, 언어 전환(길드명 길이 변화) 시에도
   버튼 위치가 pill 을 따라가는지.

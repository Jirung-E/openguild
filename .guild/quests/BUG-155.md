# [gui] 타이틀바 ☰ 메뉴가 열린 상태에서 타이틀바 클릭으로 닫히지 않음

사용자 보고: 타이틀바의 메뉴 버튼(☰)을 눌러 메뉴 리스트가 떠 있을 때,
타이틀바(빈 영역)를 눌러서 이 메뉴를 닫는 게 안 됨.

## 원인

TitleBar 의 바깥-클릭 감지가 `<svelte:window onclick>`(버블) 이었다.
그런데 Tauri 가 주입하는 drag-region 스크립트가 타이틀바
(`data-tauri-drag-region`) 위 **mousedown** 에서
`stopImmediatePropagation()` 을 호출하고 창 드래그를 시작한다 — 이벤트가
window 버블 리스너까지 오지 않고, 드래그가 시작되면 click 자체가 발생하지
않기도 한다. 검색 팔레트가 DEV-255 4차에서 정확히 같은 원인("타이틀바
클릭으로 안 닫힘")을 겪고 capture-phase mousedown 으로 고쳤는데, ☰ 메뉴
쪽은 그대로 남아 있었다.

## 수정

window `mousedown` 을 **capture 단계**로 등록(onMount, cleanup 포함) —
capture 는 window→document→target 순서라 drag 스크립트(document 버블)보다
먼저 실행되고 stopImmediatePropagation 의 영향도 받지 않는다.
`.tb-menu-wrap` 내부(버튼/메뉴 항목) mousedown 은 닫지 않으므로 토글/항목
클릭 동작은 그대로.

## 테스트 방법

브라우저(웹)에는 drag-region 스크립트가 없어 재현 불가 — 데스크탑 앱
실기 확인 필요:
1. ☰ 메뉴 열기 → 타이틀바 빈 영역 클릭 → 메뉴가 닫히는지.
2. ☰ 버튼 재클릭 토글, 메뉴 항목 클릭 이동(afterNavigate 닫힘), 본문
   영역 클릭 닫힘 등 기존 동작 회귀 없는지.
3. 타이틀바 드래그로 창 이동도 여전히 정상인지(capture 리스너는 이벤트를
   소비하지 않음 — preventDefault/stopPropagation 안 함).

svelte-check / vitest(281) / build 클린 확인 완료.

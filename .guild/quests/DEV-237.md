도서관(BOOK-NNN) 문서에 이미지/동영상 외 임의 파일 첨부 지원. DEV-097(취소됨, 도서관으로
대체 결정)이 원했던 "일반 파일 첨부"를 도서관에서 채워야 함.

## 현재 상태 (조사 완료)
- `gui/frontend/src/routes/library/+page.svelte` 가
  `attachmentExtension(onError, undefined, { mediaOnly: true })` 로 호출 —
  rules 페이지와 동일하게 이미지/동영상만 허용(`editor-attach.ts` 의
  `IMAGE_EXTS`/`VIDEO_EXTS` 화이트리스트).
- quests/campaigns 는 `mediaOnly` 없이 호출하고 대신 별도 "첨부 섹션" UI
  (attachToSection 콜백)로 비-미디어 파일을 올림 — dead link 방지(BUG-083).
- 백엔드 `save_attachment` 는 이미 파일타입 화이트리스트 없음 — 프런트만 고치면 됨.

## 방향
- Library 에도 quests/campaigns 와 동일한 "첨부 섹션" 패턴 추가 후 `mediaOnly` 제거.
  (단순히 mediaOnly:false 만 하면 다운로드 링크가 갈 곳 없는 dead link 가 됨.)

## 선행
- 없음 (독립).

## 구현 (2026-07-07)
- **core**: `GuildPaths::book_attachments_meta_path` 추가 —
  `.guild/library/{BOOK-NNN}.attachments.json` sidecar. `ops::attachments`
  에 `list_book_attachments`/`add_book_attachment`/`remove_book_attachment`
  — 기존 `add_attachment`/`remove_attachment` 제네릭 헬퍼(quest/campaign
  과 공유) 재사용. `attachment_referenced`(GC 판정)에 도서관 sidecar
  디렉토리 + `library_docs.body` LIKE 스캔 추가 — 도서관에서만 쓰는
  첨부를 다른 쪽에서 안 쓴다고 오판해 GC 하지 않도록.
- **server**: `BookResponse` 에 `attachments` 필드 추가(get_book 에서만
  채움, list_books 는 빈 배열 — quest/campaign 과 동일). `POST/DELETE
  /api/library/{book_id}/attachments`.
- **gui**: Tauri 커맨드 `add_book_attachment`/`remove_book_attachment` +
  `get_book` 이 attachments 채움. `transport.ts` — book_id 뒤에 sub-path
  가 붙는 첫 케이스라, 일반 `/api/library/{bookId}` 블록보다 먼저
  `attachments` 를 검사하도록 순서 조정(안 그러면 GET 등이 sub-path 를
  무시하고 get_book 으로 잘못 매칭됨) + 일반 블록에 `!parts[3]` 가드 추가.
- **gui/frontend**: `AttachmentSection.svelte` 의 `scope` 를
  `'quest'|'campaign'|'library'` 로 확장(첨부 endpoint 분기만 추가).
  `library/+page.svelte`: 편집기를 `mediaOnly: true` 대신 quests/campaigns
  와 동일한 `attachToSection` 콜백으로 전환(비미디어 paste/drop 이 첨부
  섹션에 등록, 본문엔 dead link 안 남음) — 단, 여기는
  `libraryApi.addAttachment`(api.post, transport 경유)를 써서 브라우저
  모드에서도 동작(quests/campaigns 의 attachToSection 은 Tauri invoke
  직접 호출이라 브라우저 모드 미지원인 기존 한계가 있음 — 도서관은 이번에
  더 낫게 감).

## 테스트 방법
- `cargo test -p openguild-core book_attachment` /
  `cargo test -p openguild-server library_attachment` (sidecar CRUD,
  교차 참조 GC 가드, HTTP 등록/삭제).
- `cd gui/frontend && npm run check && npm run check:no-hex && npm test --
  --run` (transport 라우팅 신규 케이스 — sub-path 우선순위 포함).
- 실기 (GUI): 도서관 문서 편집기에서 이미지가 아닌 파일(zip/pdf 등)을
  드래그&드랍 또는 붙여넣기 → 본문에 인라인되지 않고 아래 "첨부파일" 섹션에
  등록되는지. 이미지/동영상은 기존처럼 본문에 인라인되는지. 첨부 제거 후
  다른 곳에서도 안 쓰면 실제 파일도 삭제되는지(다른 quest 가 같은 파일을
  참조 중이면 유지).

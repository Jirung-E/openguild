admin 보고 (DEV-234 후속 — 이모지/고정 버튼 위치를 옮긴 뒤 나타난 문제):
- 이모지 버튼이 왼쪽으로 이동했는데, 버튼을 눌렀을 때 나오는 팝업이
  여전히 왼쪽으로 펼쳐지면서 화면 밖으로 나감. 오른쪽으로 펼쳐지게 해야
  하고, '자동완성 팝업' 이랑 같은 방식으로 화면 밖으로 나가지 않도록
  해야 함.
- 이모지 버튼은 왼쪽으로 옮겨졌지만 반응 이모지 pill 들은 여전히
  오른쪽정렬되어 달리고 있음. 왼쪽정렬되어 달리도록 해야 함.

## 원인
- 팝업 방향: `.reaction-picker` 가 `position: absolute; right: 0;` 로
  `.picker-wrap` 기준 오른쪽 정렬 + 왼쪽으로 펼치는 CSS 였음 — 버튼이
  foot-right(카드 오른쪽 끝)에 있을 때는 자연히 화면 안에 들어왔지만,
  foot-left(카드 왼쪽 시작부)로 옮긴 뒤에도 같은 CSS 를 써 왼쪽으로
  펼치다 화면 밖으로 나감.
- pill 정렬: `.entry-foot` 가 `justify-content: space-between` 이라
  foot-left/foot-right 사이 남는 공간을 전부 벌려, foot-right(반응 pill +
  고정 버튼)가 통째로 카드 오른쪽 끝에 붙어있었음 — 이모지 추가 버튼만
  foot-left 로 옮겼을 뿐 반응 pill 들의 컨테이너 자체는 안 옮겨졌으니
  여전히 오른쪽에 몰려 보임.

## 수정
- `.reaction-picker` 를 `position: fixed` 로 바꾸고, 버튼 클릭 시
  `getBoundingClientRect()` 로 위치를 계산해 인라인 style 로 지정 — 자동
  완성 팝업(`placeWiki`)과 동일하게 뷰포트 좌우/상하 경계를 벗어나지
  않도록 clamp(왼쪽 clamp + 위쪽 공간 부족하면 아래로 flip).
- `.entry-foot` 의 `justify-content: space-between` 제거, `.foot-right` 에
  `flex: 1` 을 줘 foot-left 바로 옆에서 시작(반응 pill 왼쪽 정렬)하게 하고,
  `.pin-btn` 에만 `margin-left: auto` 를 줘 고정 버튼만 카드 오른쪽 끝으로.

## 테스트 방법
- `cd gui/frontend && npm run check && npm run check:no-hex && npm test -- --run`.
- 실기: 창 폭을 좁혀 카드가 화면 왼쪽에 가깝게 뜨는 상태에서 이모지 버튼
  클릭 → 팝업이 오른쪽으로 펼쳐지고 화면 밖으로 안 나가는지. 반응을 여러
  개 남긴 댓글에서 pill 들이 답글쓰기/이모지 버튼 바로 옆(왼쪽)부터
  배치되고, 고정 버튼은 카드 오른쪽 끝에 남아있는지.

**윈도우에서 `clippy -D warnings` 가 CLI 에서 실패해 `just test` 가 시험 전에 멈춘다**(2026-10-03, 윈도우 세션 보고 —
깨끗한 4c02c7b1 에서도).

- `cli/src/main.rs` 의 `enum Backend { Http(HttpClient) /*48B*/, Local(LocalBackend) /*256B*/ }` 가 `clippy::large_enum_variant`.
  리눅스 · 맥에서는 `LocalBackend` 가 문턱 아래라 통과했다(DEV-431 때 `Store` 를 줄여 맞춘 적이 있다). 윈도우에서는 더 크다 —
  tokio 런타임 · 잠금 · 경로 같은 OS 별 크기 차로 보인다.
- `justfile` 의 `test-rust` 는 clippy 를 먼저 돌리므로 **윈도우에서 `just test` 는 시험까지 못 간다** — 윈도우에서만 깨지는
  시험들(BUG-347 · 348)을 손으로 못 잡은 이유 중 하나다. CI 윈도우 잡은 clippy 를 안 돌려 안 보였다.

## 고칠 것

- `Local(Box<LocalBackend>)` — 큰 쪽을 상자에 넣는다(CLI 는 백엔드를 한 번 만든다, 비용 없음).
- CI 윈도우 잡에 clippy 를 더해 다시 갈라지지 않게.
- 윈도우 세션: 윈도우에서 `cargo clippy --workspace --all-targets -- -D warnings`(gui 포함)와 `just test` 전체가 끝까지 도는지.

## 윈도우 세션 상세 확인 (2026-10-03, 8197ee45)

- 크기: 윈도우 `PathBuf` 32B(유닉스 24B) — `LocalBackend` 안에 둘(GuildPaths · guild_path)이라 256 − 48 = 208 > 200(문턱).
  윈도우 전용 clippy 경고는 이것 하나.
- `just test` 를 끝까지 막던 것이 셋 더: ① **gui 시험 실행 파일이 윈도우에서 아예 못 뜸**(0xc0000139 — Common Controls v6
  매니페스트가 시험 실행 파일에 없음, tauri 는 앱에만 넣는다) ② `check:classes` 가 `\` 경로로 ALLOW 를 못 맞춤(오탐 16)
  ③ 새 체크아웃(`frontend/build` 없음)에서 tauri-build 의 자원 검사가 BUG-038 의 프런트 빌드보다 먼저라 멈춤.
- 매니페스트를 고치자 gui 시험이 윈도우에서 **처음으로** 떴고, 그래서 처음 드러난 시험 셋: 앱 출처(`tauri://localhost` 는 윈도우에서
  `http://tauri.localhost`) 2개, `file://C:\…` 모양 주소 1개.
- `just` 는 cmd.exe 로 돌고 npm 스크립트는 node 라 Git Bash 없이 돈다.

## 고침

1. cli `Backend::Local(Box<LocalBackend>)`.
2. gui/build.rs — 프런트를 **먼저** 만들고(`build_frontend`), tauri 매니페스트를 끄고 같은 내용(`gui/windows-app-manifest.xml`)을
   링커로 모든 대상에(`/MANIFEST:EMBED /MANIFESTINPUT`, msvc 만).
3. check-undefined-classes.mjs — 경로를 `/` 로 맞춰 비교.
4. gui 시험: 앱 출처를 OS 별로(`APP_ORIGIN`), `file_url_to_path` 가 `file:///C:/…` 를 드라이브 경로로(시험 추가), 시험이 OS 에 맞는 주소를 만든다.
5. CI 윈도우 잡: 프런트 빌드 + 워크스페이스 전체 clippy + 시험(gui 포함).

## 시험

- 맥: `just test` 통과, gui 시험 34(새 1), 프런트를 치운 채 `cargo build -p openguild-gui` 가 다시 만들고 통과.
- 윈도우 세션: 새 체크아웃 + `npm ci` 만으로 `just test` 가 clippy(우회 없이 0) → cli · core 통과 → gui 30/33 에서 멈춤(위 3개, 이번에 고침).
  남은 확인(사용량 한도로 멈춤): 3개 고친 뒤 끝까지, 릴리스 빌드 링크 · exe 매니페스트 하나 · 아이콘.
- CI 윈도우 잡(gui 포함)이 초록이면 1차 확인.

## 테스트 방법

윈도우에서 새로 받은 저장소로 `cd gui/frontend && npm ci` 뒤 저장소 루트에서 `just test` → 끝까지 통과하면 정상.
앱을 빌드해(`just build-desktop` 또는 `cargo build -p openguild-gui --release`) 띄웠을 때 창이 뜨고 아이콘이 그대로면 정상.

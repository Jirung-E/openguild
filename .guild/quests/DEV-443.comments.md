**구현:**
- core: `.guild/highlights/highlights.json` (폴더 안 `.gitignore` 가 `*` — 이미 있는 길드의 `.gitignore` 를 안 고쳐도 git 에서 빠진다). 백업(스냅샷) 대상에 `highlights` 추가. 대상 키 `quest:` · `campaign:` · `rule:` · `library:BOOK-NNN`, 부분 `body` · `memo` · `comment:N`. 칠한 글 + 앞뒤 최대 64자 저장(화면은 32자를 보낸다). 퀘스트 타입 변경 · 타입 접두어 이름 변경 · 규칙 이름 변경 때 키를 옮긴다. 도서관은 문서 번호라 폴더를 옮겨도 그대로. 플러그인 이벤트는 내보내지 않는다(메모처럼 개인 표시 — 카탈로그에 Excluded).
- 서버 `GET/POST /api/highlights?target=` · `DELETE /api/highlights/{id}?target=`, 앱 명령 `list/add/remove_highlight`(transport 배선).
- 화면: MarkdownView 에 `hlTarget` · `hlPart` — 여섯 곳(퀘스트 본문 · 댓글 · 메모 · 캠페인 본문 · 규칙 · 도서관). 칠하기는 찾기(Ctrl+F)와 같은 CSS Custom Highlight API 라 DOM 을 안 바꾼다. 색은 검색 발췌의 노랑(`--search-hit-*`)을 그대로. 찾기와 겹치면 찾기가 위.
- 글을 고르면 [형광펜], 칠한 곳을 누르면 [형광펜 지우기](링크는 그대로 이동). 못 찾은 형광펜은 "형광펜 N개를 찾지 못했습니다 [지우기]".

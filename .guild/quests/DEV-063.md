tauri-plugin-updater 도입 + 시작 시 + 메뉴에서 수동 체크. 새 버전 있으면 다운로드 + 사용자 확인 후 재시작.

## 배경

DEV-034 가 installer 자체를 만든다면 본 quest 는 그 이후 — 사용자가 새
버전이 나왔을 때 알아채는 / 받는 메커니즘. installer 매번 새로 받기 불편.

## 구현 스케치

### Backend (gui)
- `tauri-plugin-updater = "2"` 추가.
- `lib.rs::run()` 에 `.plugin(tauri_plugin_updater::Builder::new().build())`.
- `tauri.conf.json::plugins.updater`:
  - `endpoints`: GitHub Release 의 `latest.json` URL (호스팅).
  - `pubkey`: 서명 검증용 (CI 가 signing key 로 release artifact 서명).
- capability 추가: `updater:default` (capabilities/default.json).

### Frontend
- 시작 시 자동 체크 (background, 비차단): onMount 에서
  `check()` → 새 버전이면 toast / 헤더 배지.
- 사용자 액션:
  - Welcome 또는 Admin 페이지 메뉴에 "업데이트 확인" 버튼.
  - 새 버전 있으면 release notes (latest.json 의 `notes`) 표시 + "다운로드 + 재시작" / "나중에" 선택.
- 진행 표시: 다운로드 % progress bar.

### 서명 (release 측, DEV-034 보완)
- Tauri 의 `tauri signer generate` 로 key pair 생성. private key 는
  GitHub secret, public key 는 tauri.conf.json.
- release CI 가 빌드 결과를 sign → latest.json 에 signature 포함.

## 검증
- 로컬 두 버전 빌드 → 한쪽에서 다른쪽으로 업데이트 확인.
- 서명 검증 실패 시 거부.
- "나중에" 누른 뒤 재시작해도 강제 안 됨.

## 후속 (이 quest 범위 외)
- Stable / beta 채널 분리 (endpoint 다르게).
- Delta 업데이트 (diff 만 다운로드).

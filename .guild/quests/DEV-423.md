## 무엇을 하나

README 의 답글 예시가 `claude -p` 하나뿐이다. 이 플러그인의 취지는 **밖으로 안 나가는
것**이므로 로컬 모델(ollama) 예시가 더 어울린다 — 그리고 실제로 더 빠르다.

## 재 본 것

`gemma4:e4b` 로 한 바퀴 돌려 답글까지 확인했다.

```
#1  admin ●미해결   파일을 진리원으로 두고 index.db 를 캐시로 쓰는 구조, 이대로 가도 될까요?
#2  gemma ↩ #1      네, 파일을 진리원(Source of Truth)으로 두고 `index.db`를 캐시로 …
```

| | claude -p | ollama gemma4:e4b |
|---|---|---|
| 걸린 시간 | 15초쯤 | **1초** |

## 깃발 셋을 꼭 적어야 한다

`ollama run` 을 그냥 부르면 **반드시 깨진다.** 그 이유를 안 적으면 예제가 없느니만 못하다.

- `--think=false` — 사고 모델은 답 앞에 영어 추론을 통째로 붙인다. 그게 댓글로 달린다.
- `--nowordwrap` — 줄바꿈을 다시 그리느라 `ESC[K` 가 **본문 한가운데** 섞인다.
- `2>/dev/null` — 스피너가 stderr 로 나온다.

## 테스트 방법

- README 의 ollama 예시를 그대로 따라 하면 답글이 달린다.
- 답글에 추론이나 escape 문자가 안 섞인다.

CLI: openguild library new/list/show/update/delete (quest 명령과 동일 관례 — new/list/show/update/delete, --json, delete 는 --yes). server: /api/library CRUD 라우트 (Tauri invoke 와 1:1 — DEV-193 교훈: GUI 가 쓰는 모든 invoke 에 대응 HTTP 필수). 선행: core 저장 구조.

## 구현 (2026-07-05)
- **server**: `routes/library.rs` — GET/POST `/api/library`, GET/PATCH/DELETE
  `/api/library/{id}`. 응답 BookResponse = book_id + flatten row. 404(soft
  delete 후 조회)/400(잘못된 id 형식) 매핑.
- **CLI**: `library list/show/new/update/delete` — 단수형+sub 필수 규칙 준수.
  본문은 `--file`(UTF-8) 로만 받아 stdin 인코딩 함정 회피. delete 는 `--yes`
  없으면 확인 프롬프트. rules 와 달리 **원격 모드(--remote)도 지원** —
  BookDto 가 서버 응답과 동일 형태라 Local/Http 공용.
- docs/AGENTS_OPENGUILD_USAGE.md 에 library 명령 카탈로그 추가.

## 테스트 방법
- 자동: `cargo test -p openguild-cli cli_library` (파싱),
  `cargo test -p openguild-server test_library` (HTTP CRUD + 번호 단조),
  전체 회귀 cli 90 / server 172 통과 확인.
- 실기(재빌드 후):
  1. `openguild library new --title "테스트 문서" --file <utf8.md>` → BOOK-001.
  2. `openguild library list` / `show BOOK-001` — 한글 본문 무결.
  3. `openguild library update BOOK-001 --title "수정"` → 제목만 변경.
  4. `openguild library delete BOOK-001 --yes` → list 에서 사라짐,
     `.guild/library/BOOK-001.md` 는 deleted=true 로 잔존.
  5. `openguild library new --title 둘째` → BOOK-002 (번호 재사용 안 됨).
  6. (원격) `openguild-server host` 띄우고 `--remote http://localhost:PORT`
     로 1~5 반복.

사용자 지적에 따라 snap 열별 DOM을 제거했다.

- `.lane-grid-col` 아래 만들던 `.lane-dot-column` 자식 1~3개를 모두 삭제했다.
- 이미 존재하는 레인 컨테이너 자체에 CSS `radial-gradient` layer를 1/2/3개
  적용하고, 각 layer의 X 위치를 명시한 뒤 `repeat-y`만 사용한다.
- 레인 컨테이너가 위치·폭·클리핑·점 paint를 모두 담당한다. 스냅 점과 열 때문에
  추가되는 DOM은 0개다.
- 열별 transform/크기/위치 style write도 제거하고 레인당 background size/position
  한 번으로 합쳤다. 이전에 필요했던 viewport overscan용 자식 크기 계산도 삭제했다.

워크플로 규칙에 따라 build/test는 자동 실행하지 않았다. 수동 확인은 기존 테스트
방법대로 1/2/3열 전환, 상하 pan, 접힌 레인 숨김을 보면 된다.

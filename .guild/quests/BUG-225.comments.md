구현 및 자동·브라우저 검증 결과.

- grid snap을 world SVG data URI에서 viewport-space CSS radial-gradient로 교체했다. visible/non-collapsed lane만 화면 높이+2행 overscan을 만들고 pan은 phase transform으로 추적한다.
- 점 반지름은 화면 px 기준 0.9~2.25px로 유지한다. 고정 worldHeight 의존이 없어 상하 pan 범위 제한도 사라졌다.
- zoom LOD를 detail(>=0.55), compact(>=0.16), overview(<0.16)로 나눴다. overview에서도 외곽 node hit area는 유지하고 내부 pill/icon/text DOM만 제거한다.
- 도구바에 `Hz 성능` HUD를 추가했다. rAF Hz, median/p95, 12.5ms 초과 비율, viewport update/s, zoom, LOD를 1초 단위로 표시하며 꺼진 동안 측정 loop는 없다.

실제 self guild 브라우저 검증:

1. snap on에서 `게시됨` lane 접기 후 첫 grid column이 `display:none`, 펼치면 복원.
2. panY 297→-273 이동 뒤에도 dot rect top 29.35 / bottom 808.61, board viewport top 52 / bottom 720으로 위·아래 전체 overscan 확인.
3. 375×720 fit zoom 0.0253429에서 dot radius 0.9px, overview LOD, node 560개/내부 자식 0개(중간 LOD에서는 1,120개).
4. 최소 zoom 41-point drag 중 HUD: 120Hz, median 8.3ms, p95 9.7ms, >12.5ms 0%, viewport 40/s.

검증 통과: viewport helper 4 tests, frontend 39 files/399 tests, svelte-check 0 errors(기존 dynamic-range-limit 경고 2), production build, release openguild-gui build, git diff --check.

인앱 브라우저의 120Hz는 확인했다. macOS Tauri는 WebKit 자체 cap 여부가 별개이므로 release 앱에서 같은 HUD로 실제 값을 확인해야 한다. 60Hz라면 약 16.7ms/60Hz, 정상 120Hz라면 약 8.3ms/120Hz가 표시된다.

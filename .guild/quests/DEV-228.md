길드 전체에 존재하는 tag 목록을 출력하는 CLI 명령이 없음.

현재:
- `quest tag list <slug>` — 한 퀘스트에 붙은 tag 만.
- `.guild/tags/{slug}.toml` (DEV-068 tag defs — color/description 정의)
  는 GUI/HTTP 로만 접근 가능, CLI 명령 자체가 없음.

## 제안
DEV-227 의 단수형 규칙(top-level 단수 + sub 필수)을 따라 새 그룹:
- `openguild tag list` — 정의된 tag 카탈로그(.guild/tags/*.toml, color/
  description) 목록. + 실사용 중인 quest_tags 의 distinct 값도 함께
  보여줄지 결정 필요(정의 안 된 채 quest 에만 쓰인 ad-hoc 태그가 있을
  수 있음 — quest_tag_defs 테이블이 있으니 union 고려).
- `openguild tag add/update/delete` — tag def CRUD (지금 GUI 전용인
  기능을 CLI 로).

## 우선순위 판단 필요
GUI 에서 이미 tag 관리가 되므로 CLI 는 "확인용" 목적이 큼 — list 만
우선 구현하고 CRUD 는 후순위로 나눠도 됨.

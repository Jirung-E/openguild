사용자 보고: "웰컴페이지에서 설정창으로 바로 들어갔을때, '원격 서버' 탭이
있는데, 아직 아무 길드에도 들어가지 않았으므로 이건 잘못된 정보일것이다."

## 원인

설정 페이지의 "원격 서버" 탭 "현재 모드"가 `$remoteServerUrl` 존재
여부만으로 로컬/원격을 표시했다. Welcome 에서 아직 아무 길드도 열지
않은 상태(`$remoteServerUrl` 이 null)에서도 "로컬 (이 PC 의 길드 파일
직접 사용)"이라고 표시되어, 실제로는 아무것도 안 열려있는데 마치 로컬
길드를 보고 있는 것처럼 잘못 안내했다.

## 수정

"현재 모드"를 3단계로 분기:
1. **아직 길드를 열지 않음** — 로컬도 원격도 활성 아님(`anyGuildOpen`
   false). `anyGuildOpen` 은 로컬(`launch_mode === 'guild'`, Rust invoke)
   **또는** 원격 활성(`remoteServerUrl` && `isRemoteSessionActive()` —
   BUG-095 에서 만든 "이번 세션에 실제로 연결했는지" 판별과 동일 기준)
   중 하나라도 참이면 true. 원격 연결 중엔 Rust 의 `launch_mode` 가 안
   바뀌므로(원격은 Rust 를 거치지 않음) 로컬 기준만으로는 부족 — 두
   조건을 OR 로 합쳐야 정확함.
2. **원격** — `isRemoteActive` true.
3. **로컬** — 나머지(`anyGuildOpen` true, `isRemoteActive` false).

브라우저 모드는 서버가 항상 어떤 길드든 호스팅 중이므로 `anyGuildOpen`
이 always true(이 탭 자체가 Tauri 전용이라 실제로는 도달 안 하지만
방어적으로 처리).

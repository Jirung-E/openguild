현재 캠페인 progress = checklist 만. 추가로 '링크된 퀘스트 중 완료된 비율' 도 계산·표시. '완료' 의 정의는 길드 사용자가 status 별로 결정 (예: done 만 / done+cancelled 둘 다 / testing 까지 등). 베타 1.0.0 필수.

## 배경

현재 (DEV-011 시점) 캠페인 진행률은 본문 GFM 체크리스트만 사용. 그런데 사용자
운영에서는 캠페인에 quest 를 N개 링크하면 "체크리스트 진행도" 와 별개로
"N 개 quest 중 몇 개가 done 인가" 도 알고 싶음. **둘 다 의미가 다른
progress** 라 같은 카드에 두 가지로 보여줘야 함.

추가 요구: **"완료" 의 정의가 길드마다 다름**. 어떤 팀은 `done` 만, 어떤
팀은 `done + cancelled`, 어떤 팀은 `testing` 까지 완료로 보기도 함. 길드
운영자가 status 별로 "이 상태는 완료로 카운트한다" 를 켤 수 있어야 한다.

## 스펙

### 데이터 모델

**status 정의에 `counts_as_done: bool` 필드 추가**.

- 파일 `.guild/statuses/{order}-{slug}.toml`:
  ```toml
  sort_order = 3
  name_en = "Done"
  name_ko = "완료"
  color = "#7BB87F"
  counts_as_done = true
  ```
- DB: `quest_statuses` 테이블에 `counts_as_done BOOLEAN NOT NULL DEFAULT 0`.
- migration `0010_status_counts_as_done.sql`.
- seed 갱신: `done` 과 `cancelled` 의 기본값 = true.
- 기존 길드: migration 적용 시 done / cancelled slug 자동 true 로 backfill.

### 진행도 계산

`CampaignSummary` / `CampaignDetail` 에 새 필드:
- `checklist_progress: f64` (= `checklist_checked / checklist_total`, 기존
  `progress` 와 동일 의미. rename 또는 별칭).
- `quest_total: i64` (= linked quest 개수, soft-delete 제외).
- `quest_done: i64` (= 위 중 `status.counts_as_done = true` 인 것).
- `quest_progress: f64` (= `quest_done / quest_total`).

SQL: `services::campaigns::summarize` 에 LEFT JOIN 추가.

### UI

- **Home active 캠페인 carousel 카드**: progress bar 2개 (체크리스트 / 퀘스트).
  - 안 1: 두 줄 progress bar.
  - 안 2: 한 progress bar + "체크리스트 X/Y · 퀘스트 A/B" 라벨.
  - 안 1 권장 — 시각적으로 명확.
- **Campaign Detail**: 위 두 진행률 + 각 카운트 표시.
- **status 의 `counts_as_done` 토글 UI**: Admin → Statuses 에 체크박스 추가.

### Backend / API

- `services::statuses::update(slug, ...)` 가 `counts_as_done` 도 받음.
- server route `PATCH /api/admin/statuses/:slug` 필드 추가.
- Tauri command `admin_update_status` 동일.
- 새 컬럼이 `CampaignSummary` SQL 응답에 포함되도록 service 갱신.

### CLI (선택)

- `openguild statuses update <slug> --counts-as-done true|false` 도입 검토.

### 검증

- migration apply OK + 기존 길드 reindex 시 done/cancelled 자동 true.
- Campaign Summary API 에 quest_progress / quest_done / quest_total 등장.
- Home 카드에 두 progress 표시.
- status 정의 페이지에서 토글 → 즉시 캠페인 진행률 변화.

### 후속

- 베타 1.0.0 캠페인 (C-001) 에 링크.
- 베타 캠페인 체크리스트는 quest 와 1:1 — 둘 다 100% 일 때 진정한 완료.

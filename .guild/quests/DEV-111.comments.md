## 테스트용 다이어그램

### Flowchart

```mermaid
flowchart LR
    A[사용자] --> B{quest 작성}
    B -->|backend OK| C[file 저장]
    B -->|backend Err| D[error toast]
    C --> E[DB 인덱스]
    E --> F[UI 갱신]
```

### Sequence

```mermaid
sequenceDiagram
    participant U as User
    participant GUI as Tauri GUI
    participant Core as openguild-core
    participant FS as .guild/

    U->>GUI: 새 quest 작성
    GUI->>Core: create_quest()
    Core->>FS: write .guild/quests/DEV-NNN.md
    Core->>Core: INSERT INTO quests
    Core-->>GUI: QuestDetail
    GUI-->>U: 상세 페이지로 이동
```

### State

```mermaid
stateDiagram-v2
    [*] --> Open
    Open --> InProgress: start
    InProgress --> Testing: done (자동)
    Testing --> Done: 사용자 확인
    Testing --> Returned: 사용자 반려
    Returned --> InProgress: 재작업
    Done --> [*]
```

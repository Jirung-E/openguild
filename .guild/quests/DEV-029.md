DEV-027 MVP 후속. quest 간 관계 (선행 / 서브) 유무로 필터.

## 제안 옵션

| 옵션 | 의미 |
|---|---|
| `--has-prereq` | 선행 quest 가 1개 이상 있는 quest 만 |
| `--no-prereq` | 선행 quest 가 없는 quest 만 |
| `--has-sub` | 서브 quest 가 1개 이상 있는 quest 만 |
| `--no-sub` | leaf quest (서브 없는) 만 |

각각 상호배타 페어 (`has-prereq` vs `no-prereq`).

## 사용 예

```bash
# 시작 가능한 작업만 (선행 없음 + open)
openguild quest list --no-prereq --status open

# Epic-style (큰 단위) — 서브 있는 것만
openguild quest list --has-sub

# 정리 대상 — 선행 / 서브 둘 다 없는 외톨이 quest
openguild quest list --no-prereq --no-sub
```

## 영향 범위

- `core/src/models/quest.rs::ListQuery` — bool flag 4개 추가.
- `core/src/services/quests.rs::list`:
  - prereq: `EXISTS (SELECT 1 FROM quest_dependencies WHERE quest_id = q.id)`.
  - sub: `EXISTS (SELECT 1 FROM quests s WHERE s.parent_quest_id = q.id AND s.deleted_at IS NULL)`.
- `cli::QuestCmd::List` — 4 flag + 상호배타 (`conflicts_with`).
- 자동 테스트 ~8건.

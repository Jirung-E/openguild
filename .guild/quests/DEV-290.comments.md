## 무엇을 한 퀘스트인가

**규칙·도서관(BOOK) 문서의 변경 이력을 열람**할 수 있게 만든 작업.
기록하는 쪽은 앞선 DEV-288 이 맡았다(고칠 때마다 사이드카 `.jsonl` 에 적음).
이 퀘스트는 그렇게 쌓인 것을 **읽어서 보여주는** 모든 계층이다.

## 커밋별 내용

### 1. `599c267` — core · server · GUI

- **core**: 이력 전용 테이블이 없으므로 사이드카(`.jsonl`)를 직접 읽는
  `ops::rules::history` / `ops::library::history` 추가 (최신 → 과거 순).
- **server**: `GET /api/rules/{slug}/history`, `GET /api/library/{id}/history`.
- **GUI(Rust)**: `rule_history` / `library_history` invoke 커맨드 + transport 라우팅.
- **GUI(프런트)**: `SidecarHistory.svelte` 재사용 컴포넌트를 만들어 규칙 상세와
  도서관 상세에 삽입.
- 로컬(invoke)·원격(HTTP) 양쪽 동일 동작.

### 2. `e053017` — CLI

`openguild rule history <name>` / `openguild library history <book-id>`.
`--json` 지원. `print_sidecar_history` 헬퍼로 `quest history` 와 출력 톤 통일
(rename 만 old→new 로 표시).

### 3. `6984349` — `rule history` 원격 지원

서버에 라우트가 있는데 CLI 의 `Backend::Http` 가 unsupported 를 반환하던 것을
수정. 이 과정에서 **rules CLI 전반이 원격 미지원**이라는 더 근본적인 문제를
발견해 **BUG-166** 으로 분리 등록했다.

## 교훈

본문·댓글이 비어 있으면 몇 달 뒤 "이게 무슨 작업이었나" 를 커밋 로그로만
복원해야 한다. 근거·범위·검증은 퀘스트에 남기는 편이 낫다.

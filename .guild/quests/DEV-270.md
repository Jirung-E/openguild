# [skill] SKILL.md/reference/library.md에 첨부파일 안내 추가

## 배경

사용자 요청: 배포용 스킬 문서에 첨부파일 관련 내용을 넣어달라 — 도서관을
만든 목적 중 하나가 용량 큰 첨부파일/기획문서 저장이었기 때문. 이 과정에서
CLI에 `library attach` 명령 자체가 없었던 걸 발견해 먼저 구현(BUG-150).

## 구현

- `reference/library.md`: `library attach list/add/remove` 사용법 추가.
  겸사겸사 이 파일에 있던 기존 플래그 표기 오류도 수정 — 실제 CLI는
  `library new --title "..." --file <PATH> --path "folder"` (positional
  `<name>`/`--folder` 아님), `show`/`update`/`delete` 는 `<book-id>`
  positional, `delete`/`folder delete` 는 `--yes` 필요.
- `SKILL.md`:
  - "Before you start" 절의 `library show <name>` → `<book-id>` 로 정정.
  - "What's worth recording" 의 Library 항목에 "코드로 유도 불가능한
    조사/설계 노트" 뿐 아니라 "큰/바이너리 자료(기획 문서, spec PDF,
    디자인 목업, 압축된 에셋)는 quest description 이나 본문에 붙여넣지
    말고 `library attach` 로" 라는 안내 추가.
  - "Full reference" 목록의 library.md 한 줄 설명에 attachments 언급 추가.

## 테스트 방법

`claude plugin validate ./skills/openguild-plugin` + quest-ID leak grep
로컬 검증 완료(순수 문서 변경).

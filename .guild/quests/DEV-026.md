## 수정 방향

### A. Route 별 dynamic import (Vite default + SvelteKit 활용)

SvelteKit 은 route 단위로 자동 code split. 그러나 cytoscape / codemirror 를
`+page.svelte` 의 `<script>` top-level 에 import 하면 같은 chunk 에 묶임.
top-level → `onMount` 내부 dynamic import 로 옮기면 분리.

```svelte
<!-- before: top-level -->
<script>
  import cytoscape from 'cytoscape';
</script>

<!-- after: onMount 내부 -->
<script>
  let cyLib: typeof import('cytoscape').default | null = $state(null);
  onMount(async () => {
    cyLib = (await import('cytoscape')).default;
  });
</script>
```

cytoscape 가 별도 chunk 로 분리. 첫 로드는 stub, board route 진입 시 추가 fetch.

### B. manualChunks (rolldown / vite 설정)

`vite.config.ts` 에 `build.rollupOptions.output.manualChunks` 로 명시 분리:

```ts
build: {
  rollupOptions: {
    output: {
      manualChunks: {
        cytoscape: ['cytoscape'],
        codemirror: ['codemirror', '@codemirror/lang-markdown', '@codemirror/theme-one-dark'],
        marked: ['marked']
      }
    }
  }
}
```

각 라이브러리가 별도 chunk → 첫 페이지 (홈) 는 그것들 없이 로드, 필요한 route 에서만 fetch.

### C. 둘 다 + chunkSizeWarningLimit 상향

빠른 임시 대응: `build.chunkSizeWarningLimit: 800` 으로 늘려 경고 끄기.
근본 해결 X — 권장 안 함.

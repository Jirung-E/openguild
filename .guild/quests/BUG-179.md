본문/댓글/메모 등을 편집 중일 때 **새로고침(F5·Ctrl+R)** 하면 아무 경고 없이 편집 내용이 사라진다. 라우트 이동(링크·뒤로가기)에는 DEV-153 의 공용 확인 모달이 뜨는데, 새로고침 경로만 비어 있다.

## 경위
DEV-153 이 `beforeunload` 가드와 Tauri `onCloseRequested` 가드를 함께 넣었는데, BUG-075(창 X 가 안 닫힘 — WebView2에서 close 가로채기 오작동)로 **둘 다 제거**됐다. 그때 커밋 메시지에 "창닫기 시 미저장 경고는 안전한 방법 확보 후 재도입 — 별도" 라고 남겨둔 그 별도 항목에 해당한다.

## 방침
창 닫기를 다시 막는 일은 하지 않는다(BUG-075 는 심각도 1이었다). 새로고침만, 환경별로 안전한 수단으로 되살린다.

- **브라우저/서버 모드**: `beforeunload` + `preventDefault` — 브라우저 기본 "나가시겠습니까?" 경고. Tauri 창 닫기와 무관하므로 BUG-075 와 충돌하지 않는다.
- **Tauri(데스크탑)**: `beforeunload`/`onCloseRequested` 는 손대지 않는다. 대신 새로고침 단축키(F5 / Ctrl+R / Ctrl+Shift+R)를 keydown 단계에서 가로채, 미저장이면 기존 공용 모달을 띄우고 '버리고 진행' 시에만 reload 한다.

## 검증
- 단축키 판정 함수 단위 테스트(F5 / Ctrl+R / Cmd+R / Ctrl+Shift+R = true, 그 외 = false).
- 서버 모드에서 편집 중 새로고침 시도 → beforeunload 가 걸리는지 확인.
- 창 닫기(X)는 여전히 즉시 닫히는지 확인 — BUG-075 회귀 금지.

추가 증상(admin 보고, 2026-07-04): 규칙 본문의 퀘스트/캠페인 링크를 따라갔다가 **뒤로가기로 돌아오면 1번째 규칙으로 초기화** — 4번째 규칙을 보고 있었다는 정보가 복원 안 됨.

원인 — 본 퀘스트의 원 증상과 같은 뿌리: **선택된 규칙(selectedSlug)이 URL 에 반영되지 않음**. 컴포넌트 state 라 페이지를 떠나면 소실되고, 돌아올 때 URL 은 ?slug 없는 /rules 라 첫 규칙 자동 선택.

통합 수정 방향 — **URL 을 선택 상태의 진리원으로**:
1. 규칙 선택 시 `goto(`/rules?slug=...`, { replaceState: true, keepFocus: true, noScroll: true })` 로 URL 갱신.
2. $page.url.searchParams 반응형 구독으로 slug 변화 → selectedSlug 동기화 (원 증상인 규칙→규칙 링크 클릭도 이걸로 해결).
3. 뒤로가기 복귀 시 history 의 URL 에 slug 가 남아있어 자동 복원.
편집 중 전환은 기존 confirmDiscardSlug 가드 경유.

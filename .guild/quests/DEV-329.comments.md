admin 결정: 합산 하나가 아니라 **체크리스트/퀘스트를 따로** 표시.

카드(CampaignCard)와 같은 구성이 되어 두 화면을 같은 방식으로 읽는다. 각 줄에 라벨(체크/퀘스트) + 바 + `완료/전체`, 항목이 없는 쪽은 줄 자체를 만들지 않는다. 완료 색(초록)도 각 줄이 100%일 때 개별로 들어간다.

검증(375px): C-013 이 `체크 1/3 (33%)` / `퀘스트 0/2 (0%)` 두 줄로 표시, 가로 스크롤 0.

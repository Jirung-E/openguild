수정 — `.toolbar { pointer-events: none }` + `.toolbar > * { pointer-events: auto }`.

띠 자체는 클릭을 통과시키고 실제 컨트롤(버튼·셀렉트)만 받는다. BUG-193 의
줄바꿈 레이아웃(`left: 14px` + `flex-wrap`)은 그대로 유지된다.

## 검증 (실제 보드 페이지)

툴바 세로 중앙선에서 `document.elementFromPoint` 로 무엇이 잡히는지 측정:

| 지점 | 수정 후 |
|---|---|
| x=34 (띠 왼쪽 끝) | `DIV.board` — 캔버스로 통과 ✅ |
| x=164 | `DIV.board` ✅ |
| x=334 | `DIV.board` ✅ |
| x=640 (중앙) | `DIV.board` ✅ |
| 버튼 위 | `SPAN.icon` — 버튼은 그대로 동작 ✅ |

`getComputedStyle(.toolbar).pointerEvents === 'none'` 확인.
수정 전에는 이 지점들이 전부 `.toolbar` 로 잡혀 클릭이 캔버스에 닿지 않았다.

사용자 보고: "업데이트 확인 결과 팝업이 시간이 지나도 안사라진다."

## 원인

DEV-194 에서 업데이트 토스트(`UpdateBanner.svelte`)를 전역 단일 컴포넌트로
통합할 때, 닫기는 `×` 버튼(수동) 하나뿐이고 자동 닫힘 타이머가 전혀
없었다. `available`/`downloading`/`ready` 처럼 사용자 행동이 필요하거나
진행 중인 상태는 그대로 유지돼야 맞지만, `uptodate`("최신 버전입니다")
/`error`("확인 실패")는 정보성이라 일정 시간 후 사라지는 게 자연스러운데
그러지 않았다.

## 수정

`UpdateBanner.svelte` 에 `$effect` 추가 — `updateState.status` 가
`uptodate`/`error` 로 바뀌면 5초 후 `dismissUpdate()` 자동 호출(이전
타이머는 effect cleanup 으로 정리, 상태가 먼저 바뀌거나 사용자가 수동으로
닫으면 자동 닫힘 취소). `available`/`downloading`/`ready`/`checking`
은 그대로 유지(checking 은 보통 금방 다른 상태로 전이되므로 별도 타이머
불필요).

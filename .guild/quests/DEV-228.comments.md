구현 완료 — list 우선이 아니라 CRUD 까지 전부(백엔드 API 가 이미 있어 비용이 작았음).

- `openguild tag list [--used]` — 정의 카탈로그(slug 를 정의 색으로 colorize). --used 는 quest_tags + library_tags distinct UNION 으로 실사용 태그를 함께 표시하고, **정의 없이 쓰인 ad-hoc 태그를 별도 줄로 발견**(본문의 "union 고려" 채택). --used 는 로컬 전용(HTTP 라우트 없음 — comments 전역 검색과 동일 정책).
- `tag add`(있으면 에러) / `tag update`(지정 필드만 교체 — upsert 가 전체 교체라 기존값 merge) / `tag delete`(사용은 보존).
- DEV-227 규칙 준수: 단수형 top-level + sub 필수(bare `openguild tag` 는 에러) — 파싱 테스트로 고정.
- 원격(HTTP) 모드는 기존 /api/tag-defs 라우트 재사용 — list/add/update/delete 모두 동작.
- enum 이름은 TagDefCmd — quest 별 태그 부착용 TagCmd(quest tag ...)와 충돌 회피.
- AGENTS_OPENGUILD_USAGE §2.1 갱신.

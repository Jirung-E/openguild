macos-26(arm64) 러너에서 GUI를 빌드해 dmg / .app.tar.gz를 릴리스에 첨부한다. gui/tauri.macos.conf.json에 bundle.targets(app, dmg)를 넣어 로컬 cargo tauri build도 맥에서 그대로 동작하게 한다. check 워크플로에도 macOS 컴파일/테스트 잡을 추가해 플랫폼 분기 코드가 깨지는 것을 CI가 잡게 한다.

macOS 26.6.1 / SDK 26.5로 만든 로컬 앱과 macos-15 CI 배포 앱 사이에 네이티브 타이틀바 외형 차이가 확인되어, check/release 워크플로를 macos-26 ARM64로 통일한다.

## 테스트 방법

1. develop push 후 check 워크플로의 `cargo (macos-arm64)` 잡이 macos-26에서 통과하는지 확인한다.
2. release 워크플로를 `workflow_dispatch`로 실행한다. GitHub Release를 만들지 않고 `openguild-macos-arm64-packages` artifact에 `.dmg`, `.app.tar.gz`, `.app.tar.gz.sig`가 모두 있는지 확인한다.
3. `.dmg`를 열어 Applications로 복사한 뒤, 미서명 앱의 기존 Gatekeeper 우회 절차로 실행한다.
4. 다운로드한 앱과 로컬 macOS 26 빌드 앱의 신호등 버튼 크기 및 제목 표시줄 외형이 동일한지 비교한다.

macos-15(arm64) 러너에서 GUI를 빌드해 dmg / .app.tar.gz를 릴리스에 첨부한다. gui/tauri.macos.conf.json에 bundle.targets(app, dmg)를 넣어 로컬 cargo tauri build도 맥에서 그대로 동작하게 한다. check 워크플로에도 macOS 컴파일/테스트 잡을 추가해 플랫폼 분기 코드가 깨지는 것을 CI가 잡게 한다.

기존 macos-14 러너는 2026-11-02 지원 종료 예정이므로 0.5.0 릴리스 전에 check/release 워크플로를 macos-15 ARM64로 전환한다.

## 테스트 방법

1. develop push 후 check 워크플로의 `cargo (macos-arm64)` 잡이 macos-15에서 통과하는지 확인한다.
2. release 워크플로를 `workflow_dispatch`로 실행한다. GitHub Release를 만들지 않고 `openguild-macos-arm64-packages` artifact에 `.dmg`, `.app.tar.gz`, `.app.tar.gz.sig`가 모두 있는지 확인한다.
3. `.dmg`를 열어 Applications로 복사하고 Gatekeeper 안내에 따라 우클릭 → 열기로 앱이 실행되는지 확인한다.

admin 지적: 퀘스트 상세의 '연관 추가' 메뉴에 **상위(부모) 퀘스트가 없다**.
서브 / 선행 / 후속만 있다.

## 현황

- 타입에는 이미 있다: `CandidateRelation = 'parent' | 'sub' | 'prereq' | 'succ'`.
- 서버/Tauri 도 `GET /api/quests/{id}/candidates?relation=parent` 를 지원한다
  (사이클·자기 자신·이미 부모 있는 것 등을 걸러 후보를 준다).
- 부모를 바꾸는 API 도 있다 — `changeParent`. 실제로 코드 안에서 쓰이고 있다:
  서브퀘스트를 붙일 때(그 퀘스트의 부모를 이 퀘스트로), 그리고 부모 해제.

즉 **UI 메뉴에만 빠져 있다**. 지금 부모를 지정하려면 상대 퀘스트로 이동해서
'서브퀘스트 추가'로 반대 방향에서 걸어야 한다.

## 할 일

`연관 추가` 메뉴에 '상위 퀘스트' 줄 추가 — 기존 연결 / 새로 만들기 둘 다.
부모는 하나뿐이므로 **이미 부모가 있으면 줄을 숨긴다**(해제는 부모 섹션에서).
빈 섹션을 숨기고 추가는 메뉴로 몬 DEV-279 의 규칙과 같은 취급.

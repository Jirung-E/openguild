admin 보고 (BUG-128 후속): 도서관에서 폴더 안에 들어가 검색했을 때 그
폴더 자신의 이름도 검색 결과로 뜬다.

## 원인
`searchLibrary(tree, books, query, scope)` 의 폴더 이름 매칭이
`inScope(path)`(= scope 자신 + 하위)를 그대로 써서, scope 폴더 자체도
매칭 대상에 포함됐음 — 이미 그 폴더 안에서 검색 중인데 자기 자신이
결과로 나오는 건 무의미함.

## 수정
폴더 이름 매칭에만 `path !== scope` 조건을 추가(`inScopeDescendant`) —
scope 의 진짜 하위 폴더만 이름 매칭 대상. 문서(book) 검색은 그대로 scope
폴더 자신 소속 문서도 포함(변경 없음, 원래 의도).

## 테스트 방법
- `cd gui/frontend && npm test -- --run` (library-tree.test.ts 신규 케이스
  포함) + `npm run check` + `npm run check:no-hex`.
- 실기: 아이콘 뷰에서 하위 폴더로 들어간 뒤, 그 폴더 자신의 이름으로
  검색 → 결과에 자기 자신이 안 뜨는지(하위 폴더/문서는 정상 매칭되는지).

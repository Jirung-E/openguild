데스크톱(Tauri) 앱에서 길드가 열리지 않는다. admin 보고 에러:

```
invalid args `query` for command `list_quests`:
invalid type: string "true", expected a boolean
```

## 원인

`transport.ts` 의 Tauri 분기는 쿼리스트링을 `Record<string, string>` 으로
그대로 넘긴다(DEV-277). HTTP 경로는 `Query<ListQuery>` = serde_urlencoded 라
`"true"` → bool, `"10"` → i64 로 강제 변환해주지만, Tauri 경로의 args 는
**JSON 으로 역직렬화**되므로 타입이 정확해야 하고 문자열이면 즉시 실패한다.

BUG-210 에서 `slim=true` 를 모든 목록 호출에 붙이면서 처음 드러났지만,
`title_only` / `no_parent` / `reverse` / `has_prereq` 등 기존 bool 필터도
데스크톱에서는 똑같이 깨져 있었다(그동안 GUI 가 그 필터를 쿼리스트링으로
보내지 않아 안 드러났을 뿐). `limit` / `offset` 도 동일.

## 수정

`questListQueryToArgs()` 로 분리해 ListQuery 의 bool / 정수 필드를 실제
타입으로 복원. serde_urlencoded 가 받아주는 표기(`true`/`1`/빈값)를 맞춘다.

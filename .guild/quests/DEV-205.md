DEV-015(다국어 MVP, 1.0)의 후속 — GUI 전역 문자열 스윕. Svelte 컴포넌트의
한글 하드코딩 문자열을 locale.ts t() 사전으로 이전(기본 한글, 언어 토글로
영어 전환). 범위: 모듈1~5(Nav/공통 컴포넌트/Welcome, 홈/캠페인, Quest
List/Board, 퀘스트 상세, 설정/Admin/rules) — 전부 완료.

core/cli 의 println!/에러 메시지, server 응답 메시지 다국어화는 범위와
설계(CLI 명시적 선택 옵션, 서버 언어 전달 방식)가 크게 달라 **DEV-254 로
분리**했음.

- 모듈3: Quest List + 필터, Quest Board(툴바/레인설정/하이라이트/필터

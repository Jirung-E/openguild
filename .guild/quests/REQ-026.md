## 무엇

이벤트가 아니라 **시간이 되면** 조건에 맞는 문서 목록을 받아 스크립트 함수를 부른다. Bevy 의 "매 프레임 쿼리" 에 해당한다.

```json
{ "every": "1h", "query": { "quest": { "status": ["open", "in_progress"], "due": "overdue" } }, "call": "마감_알림" }
```
```rhai
fn 마감_알림(quests) { for q in quests { notify(q.id + " 마감 지남"); } }
```

받을 것이 없으면 함수를 부르지 않는다. 쓰임: 마감 알림, 오래 멈춘 퀘스트 찾기 등 — 지금 구조로는 불가능.

## 따로 둔 이유 (admin, 2026-09-18)

플러그인 스크립트 구조 논의(정의 파일에서 "언제 → 어떤 함수" 를 짝짓는 방식)에서 나왔다. 좋은 기능이지만 아래를 먼저 정해야 해서 별도 과제로 뺐다.

- **누가 시간을 재나** — 앱·서버는 계속 켜져 있어 되지만 CLI 는 명령이 끝나면 꺼진다.
- **두 번 도는 문제** — 같은 길드를 앱과 서버가 함께 열고 있으면 양쪽에서 돈다.
- 조회 문법(`query`)은 이벤트 핸들러의 `with`/`when` 과 맞춘다.

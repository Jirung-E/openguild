만들었습니다(admin 2026-10-27: "다 진행해라").

```toml
[[groups]]
    id   = "notify"
    with = ["subject"]
    [groups.when]
        "subject.tags" = "notify"

[[handlers]]
    group = "notify"
    post  = ["comment.added"]
    call  = "on_comment"     # fn on_comment(e, subject)
```

- 묶음 칸: `id` · `when` · `with` · `run_after` · `run_before`. 줄은 `group = "id"` 로 하나에 든다(`core/src/plugins/groups.rs`).
- **불러올 때 줄마다 합친다.** 묶음의 `when` · `with` 를 든 줄에 합치므로 실행기 · 검사 · `plugin test` 는 바뀌지 않았다. 허용 화면은 줄마다 합친 조건과 "묶음 notify" 를 보여 준다. 합치기는 여러 번 해도 같다(시험으로 확인).
- **부딪히면 오류:** 같은 조건 칸을 줄과 묶음이 다른 값으로 적은 것(둘 다 만족할 수 없어 영영 안 돈다), 없는 묶음, 이름이 줄 이름과 겹치는 묶음, 묶음 순서에 적은 없는 이름 · 자기 자신.
- **순서(DEV-414)와 함께:**
  - `run_after` / `run_before` 에 묶음 이름을 적으면 그 묶음의 줄 가운데 같은 자리에서 도는 줄들에 걸린다.
  - 묶음이 적은 순서는 든 줄마다 걸린다.
  - 자기가 든 묶음과의 순서는 오류.
- `plugin check` 경고: 줄이 하나도 안 든 묶음.
- 함수 인자 순서: 묶음의 `with` 가 줄의 것보다 앞.

확인
- 시험: 묶음 3개(합치기 · 다시 합쳐도 같음, 오류 넷, 빈 묶음 경고), 순서 1개(묶음 이름으로 적은 순서 · 묶음이 적은 순서 · 자기 묶음 오류).
- 시험 길드: 스킬 문서의 예제(댓글 줄 + 첨부 줄이 묶음 하나) — `plugin check` 에 두 줄 모두 "(조건: subject.tags = notify) · 읽음: subject · 묶음 notify". `notify` 태그가 붙은 퀘스트의 댓글에만 알림, 첨부도 그 퀘스트에서만 한 번 돎. 태그 없는 퀘스트는 조용.

## 테스트 방법

1. 위 예제처럼 묶음 하나에 줄 둘을 넣은 플러그인을 만들고 `openguild plugin check` → 두 줄에 묶음의 조건이 합쳐져 보인다.
2. 태그 `notify` 가 붙은 퀘스트와 안 붙은 퀘스트에 댓글을 단다 → 붙은 쪽에서만 돈다.
3. 줄에 같은 조건 칸을 다른 값으로 적으면 `plugin check` 가 오류를 낸다.

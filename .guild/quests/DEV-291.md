BUG-165 로 GUI 에는 반대방향 해제(자식→부모, 선행→후속) 버튼이 생겼고, CLI
에도 연산 자체는 있다:
- 부모 해제: `quest parent <자식> --detach`
- 후속 해제: `quest prereq remove <후속> <자기>` (= 후속의 선행에서 자기 제거)

문제: `quest show` 가 관계를 전혀 표시하지 않는다(`--field parent` 만 있음).
자식/선행/**후속** 을 CLI 로 볼 수 없어 무엇을 끊을지 찾을 수가 없다.
(후속은 auto-block 에도 없는 파생 전용이라 더더욱 안 보임.)

## 할 일
- `quest show` 기본 출력에 관계 섹션 추가: Parent / Sub-quests / Prerequisites
  / Successors(파생 조회). GUI 상세와 동일 정보.
- 선택: 후속 중심 별칭(`quest successor remove` 등)으로 반대방향 해제 가독성
  개선(현재는 prereq remove 를 반대로 써야 함).

## 구현 (2026-07-28)

`QuestDetail.successors` 는 이미 채워지고 있었고(DEV-070) **CLI 출력에만** 빠져
있었다 — 조회 로직 추가 없이 표시만 붙였다.

- `quest show` 기본 출력에 `successors (N):` 섹션 추가. 색은 선행(#a371f7 보라)과
  짝이 되도록 주황(#f0883e) — 방향이 반대임을 한눈에 구분.
- 섹션 끝에 반대방향 해제 힌트 한 줄:
  `(해제: openguild quest prereq remove <후속> <자기>)`.
  이 명령을 찾기 어렵다는 게 DEV-291 의 출발점이라 출력에 박아 뒀다.
- `--field successors` / `prerequisites`(`prereqs`) / `sub_quests`(`children`)
  추가 — slug 를 줄바꿈으로 출력해 스크립트로 일괄 해제가 가능하다.

Parent / Sub-quests / Prerequisites 는 이미 표시되고 있었으므로 그대로 뒀다.

## 실제 확인

```
$ openguild quest show BUG-035
  prerequisites (1):
    - BUG-034 [Done] ...
  successors (2):
    - BUG-036 [Done] ...
    - REQ-001 [Done] ...
    (detach: openguild quest prereq remove <successor> BUG-035)

$ openguild quest show BUG-035 --field successors
BUG-036
REQ-001
```

## Test plan

1. 후속이 있는 퀘스트에서 `quest show` — successors 섹션과 해제 힌트가 나오는지.
2. 후속이 없으면 섹션이 아예 안 나오는지(빈 섹션 노출 금지).
3. `--field successors|prerequisites|sub_quests` 가 slug 만 줄바꿈으로 주는지,
   관계가 없으면 빈 출력인지.
4. 힌트대로 `quest prereq remove <후속> <자기>` 를 실행하면 실제로 끊기는지.
5. `--remote` 에서도 동일하게 나오는지(서버 detail 응답에 successors 포함).
6. `--json` 출력에 successors 가 이전과 동일하게 들어있는지(회귀).

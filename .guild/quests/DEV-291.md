BUG-165 로 GUI 에는 반대방향 해제(자식→부모, 선행→후속) 버튼이 생겼고, CLI
에도 연산 자체는 있다:
- 부모 해제: `quest parent <자식> --detach`
- 후속 해제: `quest prereq remove <후속> <자기>` (= 후속의 선행에서 자기 제거)

문제: `quest show` 가 관계를 전혀 표시하지 않는다(`--field parent` 만 있음).
자식/선행/**후속** 을 CLI 로 볼 수 없어 무엇을 끊을지 찾을 수가 없다.
(후속은 auto-block 에도 없는 파생 전용이라 더더욱 안 보임.)

## 할 일
- `quest show` 기본 출력에 관계 섹션 추가: Parent / Sub-quests / Prerequisites
  / Successors(파생 조회). GUI 상세와 동일 정보.
- 선택: 후속 중심 별칭(`quest successor remove` 등)으로 반대방향 해제 가독성
  개선(현재는 prereq remove 를 반대로 써야 함).

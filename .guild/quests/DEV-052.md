- `openguild-gui` (인자 없음) → `/welcome` 페이지 진입.
- `openguild-gui <경로>` → 그 길드 보드.

DEV-006 본문의 "Welcome 자동 진입" 후속.

## 구현 (2026-05-23)

### Backend (gui crate)
- `gui/src/lib.rs::LaunchMode` enum: `Guild(PathBuf)` 또는 `Welcome`.
- `resolve_launch_mode(args, env)` — argv 우선, env 차순, 그 외엔 Welcome.
  - 이전 `cwd 자동 탐색` 폴백 제거 — 인자 없으면 명시적 환영 화면.
  - argv 가 잘못된 경로면 기존처럼 `Err` (silent fallback 금지).
- `run()`:
  - Guild 모드 → 그 path 로 Store::open + recents::add.
  - Welcome 모드 → OS temp 디렉토리에 빈 길드 부트스트랩 (Store / commands
    의 invariant 유지) + recents::add 건너뜀.
  - `LaunchInfo { mode: "guild" | "welcome" }` managed state 로 frontend
    에 노출.

### Tauri command (gui/src/commands.rs)
- `launch_mode() -> &'static str` 신설 — managed `LaunchInfo` 의 mode 반환.

### Frontend
- `routes/+page.svelte` (root): onMount 에서 Tauri 환경 + 첫 방문일 때
  `invoke('launch_mode')` 호출. `"welcome"` 이면 `goto('/welcome')`.
- `sessionStorage` 마커 (`og-launch-handled`) 로 중복 redirect 방지 —
  사용자가 `/welcome` 에서 다시 `/` 로 navigate 한 경우는 redirect 안 함.

## 자동 테스트 (gui +9)

기존 `resolve_guild_path_inner` 테스트 8개 → `resolve_launch_mode` 로
재작성 + 1개 추가 (총 9):
- argv dir → Guild.
- argv .guild 파일 → Guild (parent).
- argv 잘못된 경로 → Err.
- argv non-guild 파일 → Err.
- argv empty + env valid → Guild (env).
- argv empty + env invalid → Welcome.
- argv empty + no env → Welcome (이전 cwd fallback → 행동 변경).
- argv 가 모두 `--` 플래그 → Welcome.
- helper `is_guild` 분류.

## 회귀

  의 길드를 열었지만 이제는 Welcome 으로 진입. 의도된 변경.
- recents 자동 등록: Welcome 모드는 temp 부트스트랩이므로 등록 안 함 (recents

## 후속 fix (returned 2회차, 2026-05-23)

User testing 결과 4가지 UX 문제:

1. **Welcome 페이지에 상단 Nav 노출** — Board/List/Admin/+New Quest 가 의미
   없는 액션으로 보임.
2. **로고 클릭 → 빈 보드** — Nav 로고가 `/` 로 가는데 redirect 가 첫 회만
   동작 (sessionStorage 마커) 해서 빈 board 노출.
3. **Recent 클릭 → 미구현** — 본문에 "기능 미구현" 만 표시.
4. **"전체 비우기" → 브라우저 confirm()** — OS 스타일이라 어울리지 않음.

### 수정

1. `routes/+layout.svelte`: `$page.url.pathname === '/welcome'` 일 때
   `<Nav>` 자체를 mount 안 함. `main` 의 min-height 도 조정 (`100vh`).
2. `routes/+page.svelte`: sessionStorage 마커 제거. Welcome 모드면 `/` 진입
   할 때마다 `/welcome` 으로 redirect → 로고 클릭해도 빈 보드 안 나옴.
   (사용자는 그래도 새 창에서 직접 길드 path 로 열면 됨.)
3. **Recent 클릭 구현** — 새 Tauri command `open_guild_in_new_window(path)`:
   - `std::process::Command::new(current_exe).arg(path).spawn()` 으로 새
     openguild-gui 프로세스를 detached 실행.
   - 현재 welcome 창은 사용자가 닫게 둠 (자동 종료는 안 함 — 여러 길드 비교
     같은 use case 대비).
   - Welcome 페이지의 recent item 을 `<button>` 으로 바꿔 클릭 가능 +
     로딩 상태 "새 창에서 여는 중…" 표시.
   - 실패 시 (path 없음 / spawn 실패) `openErr` 에 메시지 노출.
4. 커스텀 confirm 모달 — `confirmOpen` $state + `.ov / .modal` (Quest Detail
   삭제 모달과 동일 톤). 비우기 / 취소 버튼.

## 후속 fix (returned 4회차, 2026-05-23)

User testing 결과 5가지 (한 회차에 묶음):

1. **`openguild-gui` 인자 없이 켰는데 Welcome 안 나옴** — root `+page.svelte`
   의 `invoke<string>('launch_mode')` 가 3회차에서 응답 구조를
   `{ mode, uninit_path }` 로 바꾼 뒤 업데이트 안 됨 → `mode === 'welcome'`
   비교가 영원히 false → redirect 무력화.
2. **Uninit prompt path 가 `.` 그대로 표시** — `openguild-gui .` 로 실행 시
   상대경로가 정규화 안 됨.
3. **Uninit 시 길드 이름 입력 못함** — 항상 `guild` 로 강제. 디렉토리명을
   기본값으로 한 input 이 필요.
4. **Recent 클릭 → Store::open 실패** — Windows `\\?\` extended-length
   prefix 가 sqlite URL 안에서 `?` 로 오인되어 query string 파서가 깨짐:
   `sqlite://?/C:/…/index.db?mode=rwc` → "unknown query parameter".
5. **로고 클릭 → 보드** — 길드 들어간 뒤 다른 길드 / Welcome 으로 돌아갈
   방법이 없음. Welcome 으로 가야 함.
6. **사라진 길드 처리 부재** — Recent 목록에 이미 삭제된 경로가 살아있고,
   클릭 시 그냥 에러.

### 수정

#### Backend
- `core::store::Store::open` — sqlite URL 빌더를 헬퍼 `sqlite_file_url`
  로 분리하면서 Windows `\\?\` prefix strip. (이전엔 `migrate.rs` 만 처리.)
- `core::recents::add` — 저장 전 `normalize_abs` (canonicalize + `\\?\`
  제거). 사용자 화면 표시도 깨끗해짐.
- `core::recents::remove(path)` 신설 + Tauri `remove_recent` command.
- `gui::resolve_launch_mode` — argv / env path 를 `absolutize` 로 절대화
  + `\\?\` 제거.
- `commands::list_recents` 응답 → `RecentDto { path, name, last_opened,
  missing }` — `Path::exists()` 체크.

#### Frontend
- `routes/+page.svelte` (root) — `invoke<{ mode, uninit_path }>` 로 시그니처
  맞춤. mode 'welcome' / 'uninit' 모두 `/welcome` 으로 redirect.
- `routes/welcome/+page.svelte`:
  - Uninit prompt 에 `<input bind:value={initName}>` — 기본값은 path 의
    마지막 component (split `[\\/]`). 빈 값이면 "길드 이름을 입력하세요"
    에러.
  - `init_and_open_guild` 호출 시 `name` 도 전달.
  - Recent list — `r.missing` 이면 `.recent-row.missing` 클래스 (opacity
    + cursor not-allowed) + "⚠ 경로를 찾을 수 없습니다" 라벨 + 옆에 `×`
    제거 버튼 (`removeRecent(path)` → `recentsApi.remove`).
- `lib/api/recents.ts` — `Recent` 인터페이스에 `missing`, `remove(path)`
  메서드 추가.
- `lib/components/Nav.svelte` — 로고 `href="/"` → `href="/welcome"`.

현재 댓글은 1-level 플랫 스레딩 — 답글의 답글이 root 로 flatten 됨. 답글에도 답글 작성이 되도록.

## 결정 (2026-07-03, admin)
**2단까지 들여쓰기** — root > level-1 답글 > level-2(답글의 답글). level-2 보다 깊은 체인은 가장 가까운 level-1 조상 밑에 flatten 하고 ↩ #id 링크가 실제 대상 표시. parent_id 체인은 데이터에 그대로 기록(서버 변경 없음).

## 구현 (frontend 전용 — QuestCommentsSection.svelte)
- groups 를 2단 트리로 확장: level1ByRoot + level2ByParent(가장 가까운 level-1 조상 밑 flatten) + rootIdOf/byId. 기존 childrenByRoot(전체 자손)는 답글 수/스레드 접기 기준으로 유지.
- 모든 entry(답글 포함)에 '답글 쓰기' 버튼 — parent_id 로 실제 대상 기록.
- 답글 폼은 대상이 level-1/2 여도 그 스레드(root 카드) 하단에 표시, placeholder 에 '↩ #id 작성자 에 답글…' 로 대상 명시. submitReply 가 replyingTo(실제 대상)로 저장.
- CSS .reply-list.l2 — level-2 한 단 더 들여쓰기.
- 캠페인 댓글도 동일 컴포넌트(scope prop) — 자동 적용.

## 테스트 방법
- cd gui/frontend && npm run check && npm test -- --run
- 수동:
  1. root 댓글에 답글 A 작성 → 1단 들여쓰기 (기존 동작).
  2. 답글 A 의 '답글 쓰기' → 폼 placeholder 가 '↩ #A ...' 인지 → 작성 → A 밑에 2단 들여쓰기로 표시 + ↩ #A 링크.
  3. 그 2단 답글에 다시 답글 → 같은 2단 레벨에 flatten + ↩ 링크가 실제 대상.
  4. 스레드 접기(▶)/전체 접기(DEV-190) 시 level-2 포함 전부 숨김, 답글 수 카운트에 포함.
  5. 답글 삭제 후 orphan 표시 회귀 확인.
  6. 캠페인 댓글에서 동일 동작.

## 구현 (간단)

`QuestCommentsSection.svelte::enterReply()` 를 async 로 — `await tick()` 후 mount 된 `.reply-form textarea.body-input` 을 `scrollIntoView({ block: 'center', behavior: 'smooth' })` + `focus({ preventScroll: true })`. `preventScroll: true` 로 focus 가 smooth scroll 을 부정하지 않게.

한 번에 한 답글 폼만 떠 있으므로 `document.querySelector` 로 단일 선택 충분.

## 테스트 방법

### A. 짧은 댓글

1. 임의 quest detail 의 댓글 섹션 → 짧은 댓글에 "↩ 답글" 클릭.
2. 답글 입력 폼이 그 댓글 바로 아래 나타나고 **textarea 에 자동 포커싱** (커서 깜빡임).

### B. 긴 댓글 (핵심 시나리오)

1. 본문이 매우 긴 댓글 (스크롤 한 화면 이상) 에 "↩ 답글" 클릭.
2. 폼이 화면 밖 아래쪽에 mount 되지만, **자동으로 스무스 스크롤** 되어 폼이 화면 중앙에 보여야.
3. textarea 가 포커싱되어 즉시 타이핑 가능.

### C. 다른 답글로 교체

1. 댓글 A 의 "↩ 답글" → 폼 A 위치로 스크롤 + 포커스.
2. 그 상태에서 댓글 B 의 "↩ 답글" → 폼 A 사라지고 폼 B 가 댓글 B 아래 mount + 스크롤 + 포커스.

### D. 취소

1. 폼 떴을 때 "취소" 클릭 → 폼 사라짐. 다시 "↩ 답글" 클릭 시 정상 mount + 포커스.

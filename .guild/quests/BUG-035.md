## 수정 (2026-05-27)

### 1) 임박 노드 날짜 중복
`QuestNodeConveyor.svelte` 가 SVG 노드 우하단 (BUG-034 에서 추가) + 별도
`.due-label` (DEV-076 초기) 둘 다 날짜를 렌더 → 두 개로 보임.

중복이라 단순화. SVG 한 곳만 단일 소스.

### 2) 임박 conveyor fade mask 조건부
BUG-032 에서 CampaignConveyor 만 `.conveyor.marquee` 조건부로 했고
QuestNodeConveyor 는 항상 fade mask 적용 상태였음. 동일 패턴 복제:
- `class:marquee={needsMarquee}` 추가.
- mask + grab cursor 는 `.conveyor.marquee` 에만.
- 임계값 5px 기반 setPointerCapture 지연 + suppressNextClick (드래그
  직후 click 차단) — CampaignConveyor 와 1:1.

### 3) 캠페인 편집 버튼 위치
이전: `.title-row` 안 (제목 옆) 에 편집 버튼. Quest Detail 은 top-bar
의 우측 `.top-actions` 에 묶음 — 일관성 부족.
변경: 캠페인도 동일하게 top-bar `.top-actions` 안에 편집 + 삭제 한 묶음.
`.title-row .btn-edit { margin-left: auto }` 제거.

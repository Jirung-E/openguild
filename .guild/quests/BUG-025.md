1) 캠페인 목록의 정렬 선택이 Home 카드 순서에도 반영 (localStorage 공유). 2) 체크리스트 100% 시 파랑 → 초록 + 체크 표시 (Home 카드 + 캠페인 상세). 3) Home 의 진행 중 캠페인은 컨텐츠 좌우 꽉 채우는 carousel (한 번에 1개씩 부드럽게 전환), 곧 시작 캠페인은 멈춤 없이 흐르는 컨베이어 벨트 효과.

## 구현 (2026-05-26)

### Part 1 — 정렬 sync (캠페인 목록 ↔ Home)
신규 `lib/utils/campaign-sort.ts`:
- `loadCampaignSort()` / `saveCampaignSort()` — `localStorage` 키
  `openguild.campaignListSort`.
- `sortCampaigns(arr, mode, now)` — 3가지 정렬 (recent / remaining /
  manual) 공통 함수.
- `recent`: created_at DESC.
- `remaining`: ended_at - now 가까운 순. 종료일 없으면 가장 뒤.
- `manual`: display_order ASC, tie-break created_at DESC.

캠페인 목록 (`routes/campaigns/+page.svelte`):
- sort state 초기값 `loadCampaignSort()`.
- `$effect` 로 변경마다 `saveCampaignSort`.
- 인라인 정렬 코드 → `sortCampaigns` 호출.

Home (`lib/components/Home.svelte`):
- mount 시 `sort = loadCampaignSort()` (목록 페이지에서 변경한 값 즉시 반영).
- `currentActive` derived 가 `sortCampaigns(filtered, sort, now)` 사용.
- upcoming 은 시작일 가까운 순 의미가 있어 자체 정렬 유지.

길드별 분리는 후속 (BUG-019 의 prefix 패턴 활용 가능 — 현재는 전역).

### Part 2 — 100% 달성 표시
신규 `lib/components/CampaignCard.svelte` (단일 카드 추출):
- `completed = $derived(total > 0 && checked === total)`.
- progress-fill: `class:done` → `#4a9eff` (파랑) → `#2ea043` (초록).
- progress-text: 100% 시 `color: #56d364 font-weight: 600`.
- 카드 head: `✓ 완료` 마크 (slug 오른쪽).
- 카드 자체: `completed` 시 border `#2ea043` + 미묘한 초록 그라데이션 배경.

캠페인 상세 페이지:
- 체크리스트 헤더에 `✓ 완료` 텍스트 + 헤더 색 `#56d364`.

### Part 3 — Home carousel + 컨베이어
신규 `lib/components/CampaignCarousel.svelte` (진행 중):
- viewport overflow hidden + track translateX transition.
- 한 번에 1개 표시 (좌우 꽉 채움 = 100% width).
- 좌/우 화살표 + dot pagination.
- 5초 간격 자동 회전 (`setInterval`). hover 시 일시정지
  (`onmouseenter`/`onmouseleave` → paused state).
- 카드 1개면 화살표/dots 숨김.

신규 `lib/components/CampaignConveyor.svelte` (곧 시작):
- 카드 < 4개: 단순 flex (모두 화면에 들어옴).
- 4개 이상: marquee 효과 — 카드 목록 두 번 복제 + `animation: scroll-x
  linear infinite`. translateX 0 → -50% (계산: gap 보정 포함).
- hover 시 `animation-play-state: paused`.
- duration = `summaries.length × secondsPerCard` (기본 6초/카드).
- 양쪽에 fade mask (`mask-image: linear-gradient`) 로 가장자리 자연.
- 두 번째 복제는 `aria-hidden` (a11y 중복 회피).

기존 `CampaignCardSlider.svelte` 제거 — 두 컴포넌트로 대체. Home 도
`<CampaignCarousel ... />` + `<CampaignConveyor ... />` 사용.

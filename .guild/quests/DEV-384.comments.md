## 예제 `desktop-notify` — CLI 에서도 뜨게, 댓글 알림 글 고침 (admin 요청, 2026-11-02)

- `scope` 에 `cli` 추가. AI 가 CLI 로 댓글을 달면 알림이 온다. 작성자로 거르지 않는다 — CLI 로 스무 개를 일괄 처리하면 스무 번 뜬다.
- 맥 · 리눅스 댓글 알림의 `? 본문` 고침. 댓글 이벤트에는 `quest` 가 없어 번호를 `target.id` 에서 읽는다. 윈도우는 번호가 빠져 있어 같이 고침.
  - 제목 `openguild - DEV-001`, 본문 `claude: 댓글` (작성자가 비면 본문만). 퀘스트 생성은 본문이 제목.

확인(맥, 임시 길드): CLI 로 `--author claude` 댓글 → 배너 `openguild - DEV-001` / `claude: AI 가 단 댓글 시험입니다`. 퀘스트 생성 + 댓글 두 명령 합계 0.26초, 대기 경고 없음.

**윈도우 재확인 필요:** `notify.ps1` 을 맥에서 돌려 보지 못함. CLI 는 훅을 2초까지 기다린다 — 토스트를 못 쓰면 쓰는 말풍선이 4초 머물러 대기 경고가 나올 수 있다.

- 작성자 빈 댓글 → 본문만. `quest new` → 본문이 퀘스트 제목.
- 시간: 토스트 경로 0.43~0.47초, 경고 없음.

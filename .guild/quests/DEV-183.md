본문 마크다운 코드펜스(`lang)에 언어를 지정해도 syntax highlighting 이 안 됨. 원인: MarkdownView 가 marked 만 사용하고 highlighter(highlight.js/shiki/prism)가 의존성에 없음 — language-xxx 클래스만 붙고 색칠 안 됨. 작업: highlight.js + marked-highlight(또는 shiki) 통합, `lang fence 의 언어로 하이라이트, 다크/라이트 테마. 설계 결정: hljs 테마 CSS 는 고정 hex 색을 쓰므로 컴포넌트 토큰 정책과 충돌 — 전역 import CSS(컴포넌트 <style> 밖, no-hex 검사 비대상)로 두거나 토큰 매핑 테마 작성. mermaid 처럼 language-mermaid 는 기존 렌더 유지.

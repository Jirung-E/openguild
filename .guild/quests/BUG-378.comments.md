고쳤습니다 — `installer.nsi` 에 자체 매크로 `OgAssociate` / `OgUnassociate` 를 두고 Tauri 의 `APP_ASSOCIATE` / `APP_UNASSOCIATE` 대신 부릅니다(`FileAssociation.nsh` include 는 그대로 — 다른 데서 쓸 수 있어서).

- 연결: `.guild` 의 지금 값이 비었거나 자기 클래스면 백업하지 않는다. 다른 앱의 것일 때만 `<클래스>_backup` 에 적는다.
- 풀기: `_backup` 값은 늘 지운다. `.guild` 가 **지금 우리 클래스를 가리킬 때만** 기본값을 손댄다 — 백업이 있고 자기 자신이 아니면 되돌리고, 아니면 기본값을 지운다. 그다음 `.guild` 키는 비었을 때만(`/ifempty`) 지우고, 클래스 키는 지운다.
- 비교(`==` · `!=`)는 NSIS 에서 대소문자를 안 가려 옛 철자 `OpenGuild Guild File` 도 자기 것으로 본다 — 이미 자기 자신이 백업된 기존 설치도 지울 때 깨끗해진다.

확인: 맥 makensis 3.12 로 같은 매크로를 설치 · 제거 구역에 넣은 시험 스크립트가 컴파일됨. 실제 레지스트리 동작(다시 깔고 지운 뒤 `.guild` 키가 없음 · 다른 앱 것이면 되돌림)은 윈도우에서 사용자가 연 PowerShell 로 봐야 합니다.

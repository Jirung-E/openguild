## 배경

[[BUG-176]]에서는 히스토리 항목에 길드 정보가 없고 길드 재오픈이 전체 재인덱싱을 유발해 무거웠기 때문에, 데스크탑 웰컴 페이지에서 뒤로가기/앞으로가기를 취소하도록 처리했다.

이후 증분 동기화가 확대됐다. 현재 `sync_on_open`은 일반적인 퀘스트·캠페인·도서관·댓글/메모의 신규·수정·삭제를 증분 처리하고, 타입/상태/태그 정의처럼 해석 구조가 바뀐 예외에만 전체 reindex 안전망을 사용한다. 이전 기록의 전체 reindex 실측은 warm 1.3초/cold 10.2초였지만, 일반 길드 전환은 이제 파일 stat + 변경분 반영이 중심이다.

## 목표

- 웰컴 페이지에서 뒤로가기/앞으로가기를 무조건 취소하는 제한을 제거한다.
- 히스토리 항목에 저장된 길드 식별자(local path / remote URL)가 현재 길드와 다르면 해당 길드를 자동으로 다시 연다.
- 전환 중 이전 길드 데이터가 한 프레임 보이거나 이전 Store로 API 요청이 나가지 않도록 전환 상태로 본문 렌더를 가린다.
- 길드 열기 실패 시 웰컴 페이지로 돌아가 오류를 안내한다.
- 브라우저 단일 길드 모드는 기존 탐색 동작을 유지한다.

## 테스트 방법

1. 데스크탑에서 A 길드의 상세 페이지 → Welcome → B 길드의 상세 페이지 순으로 이동한다.
2. 뒤로가기/앞으로가기를 반복해 A/B 길드와 각 경로가 히스토리 순서대로 복원되는지 확인한다.
3. 전환 중 다른 길드 화면이 깜빡이거나 잘못된 데이터 요청이 보이지 않는지 확인한다.
4. 원격 길드와 로컬 길드를 섞어 같은 과정을 확인한다.
5. 브라우저 서버 모드에서는 일반 뒤로가기/앞으로가기가 이전과 동일한지 확인한다.

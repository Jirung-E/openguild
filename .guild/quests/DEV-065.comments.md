## 기능
Quest List 뷰 모드 토글 — Tree (기본, 부모 들여쓰기) / List (모든 quest 평면).

## 사용
- Quest List 페이지 (`/?view=list`) 상단 필터 바로 아래 [Tree | List] 세그멘티드 토글.
- 클릭으로 즉시 전환.
- URL `?mode=list` 동기화 (Tree 는 기본이라 생략).
- localStorage (`openguild.questListMode`) 영속.

## 차이

| Tree | List |
|------|------|
| 부모 아래로 자식 들여쓰기 | 모든 quest 평면 |
| 검색 결과의 조상 자동 포함 + 펼침 | 매칭된 quest 만 |
| 폴드/펼치기 chevron | 단일 row |

## 테스트
1. `/?view=list` → Tree 모드 (기본).
2. List 클릭 → 모든 quest 평면. 부모/자식 구분 없음.
3. URL 에 `?mode=list` 추가됨.
4. 새로고침 → List 유지 (URL + localStorage).
5. `?view=list&mode=tree` 직접 입력 → Tree.
6. 검색 입력 → List 모드는 매칭된 것만, Tree 모드는 조상 자동.

## 한계 (향후)

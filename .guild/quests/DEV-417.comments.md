둘 다 반영했습니다.

검색 팔레트가 쓰던 버튼 셋(미리보기 / 새 창 / 페이지로 이동)을 한 군데로 빼서
(`DocRowActions`) 팔레트와 목록이 **같은 것을 나눠 씁니다** — 한쪽만 고쳐져 갈라질 일이
없습니다. 아이콘·설명·순서가 팔레트와 같습니다.

붙인 곳은 퀘스트 상세의 관계 목록(부모·하위·선행·후속·연결된 캠페인), 캠페인의 퀘스트
목록, 그리고 말씀하신 **연관 문서**(백링크)입니다.

버튼이 아닌 자리를 누르면 예전처럼 페이지 이동입니다.

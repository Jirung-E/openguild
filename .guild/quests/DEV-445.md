## 문제

퀘스트 타입(`DEV-001` 의 `DEV`)을 바꾸는 명령이 CLI 에 없다. 앱과 웹 화면(BUG-359 로 서버에도 생김)에서만 된다. AI · 스크립트는 타입을 잘못 만든 퀘스트를 고칠 방법이 없다(admin: "왜 없어").

core(`ops::change_quest_type`)와 서버(`PATCH /api/quests/{id}/type`)는 이미 있다 — 이름 · 댓글 · 메모 · 첨부 · 보드 위치 · 형광펜까지 따라간다. CLI 만 빠졌다.

## 할 것

```
openguild quest retype <slug> <PREFIX>
```

- 로컬 · 원격(`--remote`) 둘 다.
- 같은 타입이면 "변경 없음" 으로 끝낸다(`quest move` 와 같게).
- 출력은 옛 번호 → 새 번호. `--json` 은 바뀐 퀘스트.
- 스킬 · 도움말에 적는다.

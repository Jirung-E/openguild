## 문제

퀘스트 타입(`DEV-001` 의 `DEV`)을 바꾸는 명령이 CLI 에 없다. 앱과 웹 화면(BUG-359 로 서버에도 생김)에서만 된다. AI · 스크립트는 타입을 잘못 만든 퀘스트를 고칠 방법이 없다(admin: "왜 없어").

core(`ops::change_quest_type`)와 서버(`PATCH /api/quests/{id}/type`)는 이미 있다 — 이름 · 댓글 · 메모 · 첨부 · 보드 위치 · 형광펜까지 따라간다. CLI 만 빠졌다.

## 할 것

```
openguild quest retype <slug> <PREFIX>
```

- 로컬 · 원격(`--remote`) 둘 다.
- 같은 타입이면 "변경 없음" 으로 끝낸다(`quest move` 와 같게).
- 출력은 옛 번호 → 새 번호. `--json` 은 바뀐 퀘스트.
- 스킬 · 도움말에 적는다.

## 고친 것

- `openguild quest retype <slug> <PREFIX>` — 로컬은 `ops::change_quest_type`, 원격은 `PATCH /api/quests/{id}/type`. 출력은 `DEV-444 → BUG-365` 다음 바뀐 퀘스트 한 줄. 같은 타입이면 "(이미 DEV 타입입니다 — 변경 없음)".
- 스킬(SKILL.md 명령 목록, reference/quest.md "Changing the type"), docs/USAGE.md 에 적었다. 다른 문서에 적힌 `[[옛 번호]]` 는 바뀌지 않는다는 것도(직접 확인).

## 확인

- 시험용 길드 복사본: 로컬 DEV-444 → BUG, 댓글 따라감, 없는 타입은 `unknown type prefix`, `--json`. develop 서버를 띄워 `--remote` 로도 REQ → BUG 변경 · 같은 타입 noop.
- 파싱 시험 1개.

## Test plan

- `openguild quest retype <번호> <타입>` 으로 실제 퀘스트 하나를 바꿔 보고, 앱에서 댓글 · 메모 · 첨부 · 보드 위치가 따라왔는지 본다.

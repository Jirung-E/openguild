1) 진행중 캠페인 카드 세로 길이 늘림. 2) 진행중 carousel 3초 자동회전 + 정지 버튼. 3) 곧 시작은 다시 marquee (자동 흐름) + 마우스 드래그 (2초간 정지) + 첫↔끝 사이 시각적 gap.

## 구현 (2026-05-26)

### Part 1 — 진행중 카드 세로 길이
`CampaignCard.svelte` 의 `.card.active`:
- `min-height: 180px`, `padding: 1.1rem 1.4rem`, `gap: 0.85rem`.
- `.card.active .title` 도 `font-size: 1.1rem` (기본 0.95rem) 으로.

### Part 2 — 진행중 carousel 3초 + 정지 토글
`CampaignCarousel.svelte`:
- `autoRotateMs` default 5000 → 3000.
- `hoverPause` (hover) + `userPaused` (명시 토글) 둘 다 → `paused`
  derived = `hoverPause || userPaused`.
- controls 에 `▶ / ⏸` 토글 버튼 추가 (다음 화살표 우측).

### Part 3 — 곧 시작 marquee 재구현 + 드래그
BUG-026 의 finite carousel 폐기, marquee 복원. 단 BUG-026 의 문제점 해결:
- `requestAnimationFrame` 기반 scroll — CSS animation 대신 (드래그 / 정지
  로직 통합 위해). `pixelsPerSec = (200 + 12) / secondsPerCard`.
- `scrollX` 가 `seqWidth` (카드 N × 폭 + loop gap) 도달 시 0 으로 리셋.
- **첫 ↔ 끝 시각적 gap**: 마지막 카드 뒤에 `margin-right: 200px` (카드 1장 폭) —
  loop boundary 자연 인지.
- **마우스 드래그**: `pointerdown / move / up` 으로 `scrollX` 직접 조작.
  드래그 중 `cursor: grabbing`, slot pointer-events: none (실수 클릭 방지).
- **2초간 자동 정지**: `dragPauseUntil = now + 2000` — `paused()` 가 시각
  비교.
- **hover pause** 도 유지 (드래그 / 카드 클릭 편의).
- 카드 수 적어 화면에 다 들어가면 `needsMarquee=false` — marquee 없음
  (BUG-026 의 "적은 양에도 도는" 해결).

캠페인의 "링크 퀘스트 진행바"가 counts_as_done 비율 하나로 단일 색 채움 —
완료 40% 외의 나머지가 뭔지(미시작/진행 중/테스트 대기/보류) 안 보임.

## 제안 (admin, 2026-07-06)
진행바를 **상태별 누적(stacked) 세그먼트**로: 링크된 퀘스트들을 상태별로
집계해 각 상태의 색(quest_statuses.color — 보드 레인/뱃지와 동일 색)으로
분할 표시. 캠페인의 병목(예: done 40% + testing 30% = 검증만 남음)이
한눈에 보임.

## 설계 메모
- 정렬은 sort_order (open → ... → done) 고정 — 바가 안정적으로 읽히게.
- 상태 종류가 많으면 조각이 잘게 쪼개짐 → hover 툴팁에 "상태명 N개(%)".
- 완료된 캠페인의 기존 연출(초록 + ✓)과의 조화 검토 — 완료 시 단색 유지 고려.
- 체크리스트 진행바는 이분법이라 현행 유지, **퀘스트 진행바만** 변경.
- 데이터: 카드가 이미 링크 퀘스트 status_slug 를 받고 있어(완료 판정에
  사용 중) GUI 만으로 가능할 가능성 높음 — summary 응답에 상태별 카운트가
  없으면 server summary 확장 필요 여부 확인.
- 적용 위치: CampaignCard(홈 carousel + 캠페인 목록) + 캠페인 상세 페이지.

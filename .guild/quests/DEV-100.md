사용자: "캠페인에도 댓글/메모를 달 수 있게 하면 좋을듯".

DEV-012 (quest 단일 markdown 댓글/메모) + DEV-094 (entry 단위 + 답글 + DEV-099 의
CLI) 패턴을 그대로 Campaign 으로 확장.

## 설계

### 저장 경로 (Quest 와 평행)

```
.guild/campaigns/{slug}.md              ← 기존
.guild/campaigns/{slug}.comments.md     ← 공개 댓글 (git tracked, entry 단위)
.guild/campaigns/{slug}.memo.md         ← 비공개 메모 (gitignored)
```

`.guild/.gitignore` 의 `quests/*.memo.md` 옆에 `campaigns/*.memo.md` 추가.

### Backend (core)

옵션 A — **공용화** (권장): `repo::comments` 가 quest / campaign 둘 다 받도록
`paths.comments_path(slug)` 가 아니라 `(base_dir, slug)` 입력. 또는 enum
`CommentScope { Quest, Campaign }`. parser/serializer 자체는 동일 (HTML 주석
마커 + reply_to attr) 이라 file IO 만 추상화.

옵션 B — **복제**: `repo::campaign_comments` 별도 모듈. 코드 중복 있지만 진리
원이 명확. quest/campaign 의 메타 (frontmatter 등) 가 더 갈라지면 유리.

→ **A 권장** — parser/serializer 가 100% 동일.

구현:
- `GuildPaths::campaign_comments_path(slug)` / `campaign_memo_path(slug)`.
- `repo::comments::read_entries(paths, kind: CommentScope, slug)` 같은 시그.
  또는 더 단순 — `read_entries_at(path)` 로 path 만 받고 caller 가 path 선택.
- `services::comments::{list, add, update, delete}_campaign_entries`.
- `ops::comments::{*}_campaign_*` — journal 래퍼.

### HTTP / Tauri

Quest 와 같은 구조, slug prefix 만 다름:

```
GET    /api/campaigns/by/{slug}/comments                # entries 목록
POST   /api/campaigns/by/{slug}/comments                # 새 entry
PATCH  /api/campaigns/by/{slug}/comments/{id}           # body 교체
DELETE /api/campaigns/by/{slug}/comments/{id}           # 삭제
GET    /api/campaigns/by/{slug}/memo
PUT    /api/campaigns/by/{slug}/memo
```

Tauri commands: `list_campaign_comments / add_ / update_ / delete_ /
get_campaign_memo / set_`.

### Frontend

- `lib/api/comments.ts`: `campaignsApi` 대신 같은 `commentsApi` 의 generic
  쪽으로 (`commentsApi.list({ kind: 'quest', slug })`) 또는 별도 키 (`commentsApi.
  listCampaign(slug)`). DEV-094 의 `QuestCommentsSection` 의 prop 으로 `kind`
  추가하거나 `CampaignCommentsSection` 별도.
- Campaign Detail (`/campaigns/[slug]/+page.svelte`) 에 `QuestNoteSection mode=
  "memo"` 비슷한 패턴 + 댓글 entry 컴포넌트 mount.
- transport.ts 매핑 5 endpoint 추가.

### CLI (DEV-099 패턴)

```
openguild campaign comment list <slug>
openguild campaign comment show <slug> [--id N]
openguild campaign comment add <slug> [--author X] [--parent-id N] [--file PATH]
openguild campaign comment edit <slug> <id> [--file PATH]
openguild campaign comment rm <slug> <id> [--force]

openguild campaign memo show <slug>
openguild campaign memo set <slug> [--file PATH]
openguild campaign memo clear <slug>
```

`CampaignCmd` 에 `Comment` / `Memo` variant + `CommentCmd` / `MemoCmd` 의
공용화 (Quest 와 같은 enum 재사용 가능).

## 요청

규칙(rule) 문서에도 검색 기능을 추가한다.

## 현황

강화 검색(REQ-009)이 지원하는 대상은 quest / campaign / book 이고, `rule` 은
빠져 있다. 규칙 페이지 자체에도 검색 입력이 없어, 규칙이 늘어나면 원하는
문서를 찾기 어렵다.

관련: [[REQ-009]] 강화 검색, [[REQ-011]] 도서관 검색 옵션.

## 범위 (구현 전 확정할 것)

1. `openguild search` 의 대상에 rule 포함 — `SearchHit.kind` 에 `rule` 추가,
   `matched_in` 은 body / attachment / comment 중 규칙이 실제로 갖는 것만.
2. 규칙 페이지에 검색 입력 — 도서관(REQ-011)과 같은 UI 로 통일.
3. 검색 팔레트가 규칙을 이미 다루는지 확인하고, 강화 검색 토글(REQ-012)이
   붙을 때 규칙도 함께 걸리게 할지 결정.

## 확인 필요

- 규칙에 댓글/첨부 개념이 있는지 (없다면 body 만 대상)
- `rule` alias 정리(DEV-231 에서 `rules` alias 제거됨) 와 충돌 없는지

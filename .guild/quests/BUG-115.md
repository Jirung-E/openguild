증상: 본문(quest/campaign/rules/memo) 편집기의 cross-link 추천 목록이
전체가 표시되지 않고 몇 개만 보임 — 아래로 더 있어도 안 보임.

## 원인 (editor-links.ts)
CodeMirror 자동완성 후보(options)는 slice 없이 전부 넘겨지고 있었음 —
문제는 데이터가 아니라 렌더링 위치. 편집기를 감싼 `.editor-wrap`
(routes/quests/[id]/+page.svelte 등)이 리사이즈 핸들/모서리 때문에
`overflow: hidden` 인데, CodeMirror 툴팁 기본 위치 모드는 "fixed"라
보통 조상의 overflow 클리핑을 우회하지만, 공식 문서에 명시된 대로
"조상 중 하나가 transform 이 걸려있으면 라이브러리가 absolute 로
폴백"한다 — 그 경우 다시 `.editor-wrap` 의 overflow:hidden 에 잘려
추천 목록이 실제 후보 수와 무관하게 눈에 보이는 몇 줄만 남았음.

## 수정
`crossLinkAutocomplete()`(4개 페이지: quest/campaign/rules/memo 편집기
공용)에 `tooltips({ parent: document.body })` 확장 추가 — 툴팁을
document.body 에 직접 붙여 어떤 조상의 overflow/transform 과도 무관하게
안 잘리도록 함.

## 테스트 방법
1. 규칙/퀘스트/캠페인이 많은 길드에서 quest 본문 편집기에 `[[` 입력.
2. 추천 목록이 후보 수만큼 다 스크롤 가능하게 뜨는지 확인(이전엔 몇
   개만 보이고 잘렸음).
3. campaign/rules/memo 편집기에서도 동일 확인 (crossLinkAutocomplete
   공용 사용).
4. `cd gui/frontend && npm run check && npm test -- --run` 통과.

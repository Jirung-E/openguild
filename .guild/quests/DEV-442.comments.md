구현:
- 댓글 · 답글: [M↓] 바로 오른쪽에 팝업 버튼. 메모: 설명줄 오른쪽(메모에는 [M↓] 가 없다).
- 켜져 있으면 [M↓] 처럼 칠해진다. 앱 전체에 하나 — 한 곳에서 끄면 모든 입력창이 같이 꺼지고, 새로고침해도 남는다(localStorage `openguild.composeDock`). 기본은 켜짐.
- 팝업이 붙어 있을 때 넓게 펴면 버튼이 보인다 — 거기서 끄면 곧바로 제자리로 돌아간다(글은 남는다). 좁게 보기에서는 [M↓] 줄째 접혀 있어서 안 보인다.

확인(웹 빌드, WebKit 1280×800):
- 새 댓글 · 답글 · 메모 각각: 켜짐에서 위로 스크롤 → 붙음 / 붙은 채 끔 → 제자리 / 꺼진 채 포커스 + 스크롤 → 안 붙음 / 다시 켬 → 붙음.
- 메모에서 끄면 댓글 칸 버튼도 같이 꺼짐. 새로고침 뒤에도 꺼짐.
- 버튼 높이 [M↓] 와 같음(24px).

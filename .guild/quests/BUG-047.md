drift 검사가 .guild/quests/ 안 .md 전체를 quest 본문으로 봐서 sibling .comments.md / .memo.md 가 missing_in_index 로 잡힘. reindex 도 같은 list 로 로딩해서 매번 'frontmatter 없음' skip 경고. fix: drift / reindex 에서 .comments.md / .memo.md 패턴 제외.

## 적용 (2026-06-04)

원인 확인: `.guild/quests/*.md` 의 glob 이 quest 본문 (`DEV-001.md`) 뿐 아니라
sibling 인 `.comments.md` (DEV-012, 공개 댓글) / `.memo.md` (DEV-094 후속,
gitignored 메모) 도 포함. `core::drift::detect_drift` 가 그 sibling 의 stem
(`DEV-094.comments`) 으로 file_slugs 작성 → quests 테이블엔 `DEV-094` 만 있어
`missing_in_index` 에 sibling 들이 누적. `core::reindex::reindex` 도 같은 glob
사용 → sibling 을 `QuestFile::read` 로 파싱하다 frontmatter `+++` delimiter
없어 `⚠ skip 됨` 경고 매번 발생.

수정 — `core::repo::fs` 에 helper:

```rust
pub fn is_quest_body_file(path: &Path) -> bool {
    // .md 확장 + stem 에 `.` 없음 ("DEV-001" OK, "DEV-001.comments" 제외).
    ...
}

pub fn list_quest_body_files<P: AsRef<Path>>(dir: P) -> Result<Vec<PathBuf>>
```

`drift::detect_drift` 와 `reindex::reindex` 의 `list_with_extension(..., "md")`
호출을 `list_quest_body_files(...)` 로 교체.

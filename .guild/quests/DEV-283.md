DB 투영 불변식(BOOK-001) 구현 — 역류 경로 B1. BUG-145 의 근본 수정.

incremental 시동 sync 가 파일 mtime > cached 를 "외부 편집"으로 보고
frontmatter `updated_at` 을 되쓴다. git checkout/pull 이 내용 동일해도 mtime
을 바꾸므로, 무관한 퀘스트 updated_at 이 일괄 변조된다(BUG-145, 매 커밋
노이즈 필터의 원인). 내용-비교 가드가 있으나 불완전.

## 수정 방향

자체를 폐지하고 updated_at 진리원을 파일로만. BUG-145 와 통합 검토.

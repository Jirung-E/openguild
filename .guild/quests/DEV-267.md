사용자 요청(DEV-265 후속): 창모드(비최대화)일 때 창 모서리를 둥글게.

## 배경

Windows 는 DWM(Win11)이 자동으로 창 모서리를 둥글게 그려주지만, Tauri 의
리눅스 창은 `decorations:false` 라 각진 채로 뜬다. 커스텀 타이틀바(DEV-265)
를 쓰는 리눅스에서 모서리가 각져 이질감이 있음.

## 구현 방향 (조사됨)

가능함. 다만 리눅스는 공짜가 아니라 트레이드오프가 있음:

1. `gui/tauri.linux.conf.json` 에 `"transparent": true` 추가.
2. 앱 최외곽을 감싸는 컨테이너에 `border-radius` + `overflow:hidden`,
   그 바깥 영역은 투명.
3. 최대화 상태에선 라운드 제거(전체화면이므로 각지게).

## 트레이드오프 / 주의

- GNOME/Mutter 는 투명 무테 창에 **서버 그림자(drop shadow)를 안 그려줌**.
  → 그림자 없이 둥근 모서리만 두거나, CSS `box-shadow` 를 직접 그리되
    그림자가 보이도록 창 가장자리에 투명 여백을 둬야 함(그만큼 실제 창이
    살짝 작아 보임).
- 컴포지터가 꺼진 드문 환경에선 모서리가 검게 보일 수 있음.
- 투명 창은 리사이즈 엣지 히트테스트 / 클릭 영역에 영향 줄 수 있어 실기
  확인 필요.
- Windows/macOS 는 해당 없음(각 OS 가 알아서 처리) — 리눅스 한정 분기.

## 테스트 방법

리눅스에서 빌드/실행 → 창모드에서 네 모서리가 둥근지, 그림자가 자연스러운지,
최대화 시 각지게 돌아오는지, 리사이즈(가장자리 드래그)가 정상인지 확인.

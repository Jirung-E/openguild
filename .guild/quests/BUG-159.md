# BUG-159: 최근 본 문서 목록의 제목이 이상하게 표시됨

사용자 지적: 최근 본 문서 목록의 제목이 이상하게 표시됨.

## 원인

DEV-276 에서 제목을 화면의 `main h1` 에서 긁어 저장했는데, **페이지마다
h1 의 의미가 달랐다**:

- **도서관**: 첫 h1 이 페이지 제목("도서관") — `querySelector` 가 그걸
  집어 **모든 도서관 문서가 "도서관"으로 표시**됐다.
- **규칙**: h1 이 `# {slug}` 형식 — `#` 이 붙은 데다 라벨과 중복이라
  "규칙 | 코딩 규칙 | # 코딩 규칙" 처럼 보였다.
- 퀘스트/캠페인만 우연히 맞았다.

## 수정

DOM 스크래핑을 걷어내고 **cross-link 인덱스(`questIndexNs`)에서 조회**로
전환. 그 인덱스는 `[[..]]` 렌더/자동완성이 쓰는 것과 같은 캐시로 ID→제목
매핑을 이미 들고 있고 reindex 시 갱신되므로, 정확할 뿐 아니라 **문서
이름을 바꾸면 목록도 따라온다**(저장 방식은 이름 변경 시 옛 제목 고착).

- `recentDocTitle(doc, ns)` 순수 함수로 분리 — kind:ID 네임스페이스
  조회라 종류가 다른 같은 번호끼리 안 섞인다(DEV-219 규칙).
- 제목이 라벨과 같으면(규칙처럼 slug 가 곧 제목) 중복 표시 생략.
- 목록을 열 때 `loadQuestIndex()` 호출(이미 적재됐으면 memo 라 비용 0).
- 하위호환: 예전 세션이 저장한 title 은 인덱스 조회 실패 시 폴백.

## 검증

웹 실기 — 퀘스트/규칙/도서관을 차례로 방문 후 목록:
`도서관 BOOK-001 설계 결정 기록` / `규칙 코딩 규칙` / `퀘스트 DEV-001
퀘스트 제목 1` 로 정상 표시 확인(각각 예전엔 "도서관", "# 코딩 규칙"
중복이었음).

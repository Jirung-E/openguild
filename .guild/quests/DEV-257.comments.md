도서관/규칙/설정 페이지 등 왼쪽에 탭을 표시하는 페이지들이 모바일에서 제대로 표시되지 않음
- 탭 영역이 화면의 반 이상을 차지하며 컨텐츠 영역이 화면 밖으로 밀려남. 이렇게 되면 좌우로 스크롤이 가능해지면서 메뉴바가 잘려서 표시됨

## 원인

좌측 탭/목록이 있는 세 페이지가 **고정 폭 열**을 쓰고 있었다:

| 페이지 | 선언 | 375px 에서 |
|---|---|---|
| 도서관 | `grid-template-columns: 260px 1fr` | sidebar 가 69% |
| 규칙 | `grid-template-columns: 240px 1fr` | sidebar 가 64% |
| 설정 | `.side { flex: 0 0 160px }` | 탭이 43% |

남은 `1fr`/`flex:1` 열은 min-content 아래로 줄어들 수 없어 컨텐츠가 화면
밖으로 밀리고, 그래서 **페이지에 가로 스크롤이 생기면서 sticky 메뉴바가
잘려 보인** 것(보고 내용과 정확히 일치). `min-width: 0` 은 이미 걸려 있었고
원인은 고정 열 폭이었다.

## 수정

`@media (max-width: 640px)`(DEV-257 1차에서 쓴 것과 같은 브레이크포인트):

- 도서관/규칙: 한 열로 쌓고 sidebar 는 자체 스크롤(45vh/40vh)로 높이 제한 —
  목록이 길어도 컨텐츠가 화면 아래로 밀려나지 않게. 세로 구분선은
  border-bottom 으로 전환.
- 설정: 탭을 위로 올려 **가로 한 줄**(넘치면 그 줄만 스크롤, 스크롤바 숨김),
  본문이 전폭 사용.

같은 패턴을 전 페이지에서 재검색 — 이 셋이 전부였다(conveyor 의 200px
카드는 자체 가로 스크롤 컨테이너라 의도된 것).

## 검증 (375×812 실측)

빌드한 프론트를 `openguild-server host --frontend-dist` 로 띄우고 브라우저를
375×812 로 맞춰, 각 페이지에서 `documentElement.scrollWidth - clientWidth` 와
"화면 밖으로 나간 요소" 전수 측정:

| 경로 | 오버플로 | 넘친 요소 |
|---|---|---|
| `/library` | 0 | 0건 |
| `/rules` | 0 | 0건 |
| `/settings` | 0 | 0건 (탭 flex-direction=row, 전폭 343px) |

회귀 확인으로 `/`, `/?view=board`, `/?view=list`, `/campaigns`, `/worklog`,
`/tags`, `/admin` 도 함께 스캔 — 전부 오버플로 0.

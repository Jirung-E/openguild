## 재발 방지 규칙 (기록)

**팝업 / 모달 / 토스트 / dropdown 등 고정 폭 UI 는 px 대신 rem.**

- 이유: DEV-101 의 UI 크기 조절이 root font-size (rem) 스케일 방식 — 글자는 rem 으로 커지는데 상자가 px 고정이면 글자가 삐져나감. DEV-138 퀵메뉴에서 처음 발견 → 본 quest 에서 12곳 일반화.
- 변환 기준: px ÷ 16 = rem (기본 16px 가정). 큰 팝업엔 `max-width: calc(100vw - 2rem)` 안전망 권장.
- **예외**: 페이지 레이아웃의 max-width (예 campaigns/new 760px) — 텍스트가 wrap 되는 흐름 레이아웃은 px 여도 무해. 1px 보더 / 그림자 offset 같은 비텍스트 치수도 px 유지.

신규 컴포넌트 작성 시 체크: `width|max-width|min-width: NNNpx` 가 팝업류에 있으면 의심. 감사 명령:

```
grep -rnE "(max-|min-)?width:\s*[0-9]{3,4}px" src --include="*.svelte" | grep -vE "var\(|100%"
```

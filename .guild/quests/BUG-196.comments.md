﻿admin 재보고: 백업 섹션이 아직 삐져나옴(구분선이 삐져나온 걸로 봐서 영역 자체가 넘침).

1차 수정은 .section-header(제목+버튼) 만 줄바꿈 허용했는데, 실제 원인은 **스냅샷 표**였다. .snap-actions { white-space: nowrap } 이 Restore+Delete 를 한 줄에 묶어 그 칸만 180px 를 요구하고, 	able { width: 100%% } 는 내용 최소폭 아래로 못 줄어든다 → 표 321px vs 가용 285px → 섹션 밖으로 15px. 그때 tr 아래 테두리가 함께 나가 '구분선이 삐져나온' 모습이 된다.

수정(≤640px): .snap-actions nowrap 해제 + flex-wrap(버튼이 필요하면 세로로 쌓임), 셀 여백 축소.

검증(375px, 영어): 표 폭 321 → **285**, 섹션 scrollWidth == clientWidth(325) — 넘침 없음, 가로 스크롤 0.

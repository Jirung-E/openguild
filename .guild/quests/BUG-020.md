레인당 그룹정렬시 다른 레인에 있는 노드와 연결되어있는 노드도 단독노드로 취급해서 그룹으로 분리되지 않는 문제가 있다.

## 적용 (2026-06-03)

원인: `gui/frontend/src/lib/components/QuestBoard.svelte` 의 `arrangeNodesGrouped`
가 lane 한정 호출 시 lane 내 노드 (`allIds`) 사이 edge 만 인접리스트에 넣음.
cross-lane edge 가 있는 노드는 lane 내 다른 노드와 연결이 없으면 BFS 결과
`c.length === 1` → isolated 로 분류 → 위쪽에 단독 노드처럼 묶임.

수정:
- `hasExternalEdge: Set<number>` 추적 — cross-lane edge 한쪽 끝이 lane 안일 때
  그 노드 추가.
- isolated / cluster 분류 시 `c.length === 1 && !hasExternalEdge.has(c[0])` 만
  진짜 isolated. 외부 연결이 있는 single-member 는 cluster (size 1) 로 분류
  → 시각적으로 다른 lane 그룹의 일부임을 구분.

### 검증
- `npm run check`: 0 errors.
- `cargo test help_output_has_no_quest_id_leaks`: 통과 (BUG-016 정책).
- 사용자 환경 시각 검증 필요 (lane 내 group 정렬 후 cross-lane edge 노드의
  배치 확인).

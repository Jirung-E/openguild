## 기능
Quest Board toolbar 접기 토글 — 첫 lane 의 header 라벨이 가려질 때 사용.

## 사용
- toolbar 좌단의 `⇥` 버튼 클릭 → 나머지 버튼들 숨김, `☰` 한 버튼만 보임.
- `☰` 클릭으로 다시 펼침.
- 상태는 길드별 localStorage 영속 (key `{guild}.toolbarCollapsed`).

## 테스트
1. Board 진입 → toolbar 가 우상단에 보임.
2. `⇥` 클릭 → toolbar 접힘 (작은 `☰` 만 남음). 첫 lane 의 header 라벨이 보임.
3. `☰` 클릭 → 다시 펼침.
4. 페이지 새로고침 → 접은 상태 유지.
5. 다른 길드로 전환 → 그 길드의 영속 상태.

## 향후 (이 quest 범위 외)
- 옵션: 사이드 (세로) 배치 / 아래로 이동 — 더 영구적 해결.
- toolbar 자동 사라짐 (몇 초 hover 안 하면 fade out).
- lane header 와의 z-order / opacity 자동 조정.

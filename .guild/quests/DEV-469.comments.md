## 한 일

1. **플러그인끼리 순서** — `plugin.toml` 맨 위에 `run_after = ["다른 플러그인 name"]` · `run_before = [...]`.
   - 적지 않은 것끼리는 지금처럼 읽은 순서(길드 `.guild/plugins/` 폴더 이름순, 그 뒤 소스 플러그인).
   - 없는 이름은 넘어간다(그 플러그인이 이 길드에 없을 수 있다). 자기 이름은 적재 오류.
   - 돌고 도는 순서는 적재를 막지 않고, 그 플러그인들을 읽은 순서로 둔 채 경고한다.
2. **댓글 명령 `command`** — 줄에 `command = "/session"` 또는 `"${COMMAND}"`(입력값). `comment.added` 만 보는 줄에만 쓸 수 있고, 본문(앞뒤 공백 무시)이 정확히 그 명령일 때만 돈다.
3. **겹침 경고** — 같은 명령을 둘 이상의 플러그인이 잡으면(같은 자리 cli/gui/server 끼리) 경고:
   - 관리 → 플러그인: "플러그인끼리 겹침" 칸(아직 허락 안 한 것도 포함 — 허락할 때 봐야 해서).
   - `openguild plugin check`: 걸린 플러그인마다 `!` 줄.
   - 문장에 누가 먼저 도는지와, 막거나 대신 처리하면 뒤는 안 돈다는 것을 적는다.
4. `claude-session` 예제가 `command = "${COMMAND}"` 를 쓴다. 화면·`plugin check` 줄 설명에 명령이 보인다.
5. 스키마 파일 · 예제 README · 스킬 참고 문서 · CHANGELOG.

## 확인

- `just test` 통과. 새 시험: 이름순으로 앞 플러그인이 대신 처리, `run_after` 로 뒤집기, 화면/`check` 경고, 다른 명령은 경고 없음, 적재 검사, 순서 정렬 · 순환.
- 임시 길드(CLI): claude-session + 같은 `/session` 을 잡는 `my-commands`
  - 순서 없음 → claude-session 이 처리("터미널에서 DEV-001 세션을 엽니다"), my-commands 는 안 돎.
  - my-commands 에 `run_before = ["claude-session"]` → my-commands 가 처리.
  - 보통 글은 둘 다 안 건드리고 저장됨. `plugin check` 에 두 플러그인 모두 경고.

## 한계

명령은 줄에 `command` 로 적은 것만 안다. 스크립트 안의 `if` 로만 거르는 플러그인은 겹쳐도 경고가 안 뜬다.

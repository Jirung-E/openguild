아직도 '길드를 열었다가 welcome으로 돌아가서 확인했을때'가 그대로다

<!-- og-comment id="2" ts="2026-06-30T20:45:16+09:00" author="claude" reply_to="1" -->
재현 확인 — DEV-207 이 고친 건 "Welcome 에서 바로 설정 들어갔을 때"만이고,
"길드를 열었다가 Welcome 으로 돌아간 뒤" 케이스의 진짜 원인은 안 건드렸음.

## 원인
Rust 의 `launch_mode` 는 로컬 길드가 한 번 열리면 "guild" 로 고정되고
Welcome 으로 돌아가도 안 풀림 — Nav 로고 → `/welcome` 이동이 순수 frontend
라우팅(goto)이라 Rust invoke 자체가 없기 때문. 원격(`remoteServerUrl`/
`isRemoteSessionActive`)도 마찬가지로 Welcome 방문으로 안 풀림. 즉
"실제로 지금 뭘 보고 있나"는 Rust 상태만으로는 stale 할 수 있음.

## 수정
`lib/stores/guildSession.ts` 신설 — sessionStorage 플래그
(`isGuildContextActive`/`markGuildContextActive`/`markGuildContextInactive`):
- `routes/+page.svelte`(board) onMount 가 bounce 없이(=길드 컨텍스트 진짜
  활성, 로컬/원격 둘 다) 마운트될 때마다 active 로 마크.
- `routes/welcome/+page.svelte` onMount 는 도달할 때마다 항상 inactive 로
  마크(Welcome = "아직 안 골랐다"는 뜻이므로 직전 상태 무관하게 리셋).
- `settings/+page.svelte` 의 `anyGuildOpen` 이 `isGuildContextActive()` 까지
  같이 확인하도록 — Rust 상태가 stale 해도 "Welcome 을 마지막으로
  방문했는지"가 우선 적용됨.

확인 부탁드립니다 — 길드 열기 → Welcome 복귀 → 설정 확인 시 이제 줄 자체가
안 보이는지(anyGuildOpen=false).

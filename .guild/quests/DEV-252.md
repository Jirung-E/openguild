admin 지적: [[DEV-211]] 의 --table 이 quest list 에만 있음 — 다른 목록 명령에도 확장 + 이후 새 목록 명령이 옵션셋을 빠뜨리지 않게 하는 장치.

## 작업
1. --table 확장: campaign list / library list / type list / status list / quest deleted / comments 등 목록형 출력 전반. print_quest_table 의 "가변폭(한글) 컬럼은 마지막" 원칙 재사용 — 공용 테이블 렌더 헬퍼(fn render_table(headers, rows)) 추출로 명령별 복붙 방지.
2. 옵션셋 일관성 장치: clap 으로 컴파일 타임 강제는 불가(명령마다 인자 struct 가 별개) — 대신:
   - 공용 헬퍼(render_table/json_str)를 쓰면 자연히 일관되는 구조로.
   - 길드 규칙 `cli-list-command-options` 신설: "목록형 명령은 --json(--compact)/--table 을 지원한다" 를 명문화 — 새 명령 리뷰 체크리스트.
   - (선택) 테스트: 알려진 목록형 subcommand 목록에 대해 --table 파싱이 성공하는지 일괄 검사 — 새 명령 추가 시 목록에 안 넣으면 리뷰에서 걸리는 구조.

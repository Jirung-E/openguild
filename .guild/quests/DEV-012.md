Quest Detail 에 코멘트 + 비공개 메모 영역 추가.

## 구현 (2026-05-31)

### 설계
사용자 확정 안: **파일 분리** + DB 없음 (단순, 외부 편집 친화).
- 공개 댓글: `.guild/quests/{slug}.comments.md` — git **tracked**, 팀 공유.
- 비공개 메모: `.guild/quests/{slug}.memo.md` — **gitignored**, 개인 노트.
- 둘 다 frontmatter 없는 자유 markdown. 부재 = "아직 없음".
- 단일 사용자 데스크탑 단계라 작성자 이름 / 타임스탬프 자동화 없음.
- 작성자는 본문 안에 markdown 으로 직접 표기 (`> -- Alice 2026-05-31` 등).

### Core
- `core::repo::comments::{read,write}_{comments,memo}` (Result<Option<String>>).
- `GuildPaths::comments_path(slug)` / `memo_path(slug)`.
- `gitignore_content()` 에 `quests/*.memo.md` 라인 추가.
- `core::ops::comments::{get,set}_{comments,memo}` — set 시 journal append.
- 3 unit tests (comments roundtrip / memo roundtrip / 두 파일 독립 경로).

### Server
- `routes/comments.rs` — `GET/PUT /api/quests/by/{slug}/comments` +
  `/api/quests/by/{slug}/memo`. 응답 `{ content: string|null }`.

### GUI (Tauri)
- `commands::{get,set}_{comments,memo}` + `ContentResponse` 공용 shape
  (DEV-016 RulesResponse 와 동일 alias).
- `lib.rs` invoke_handler 등록.

### Frontend
- `lib/api/comments.ts::commentsApi`.
- `lib/api/transport.ts` — `/api/quests/by/{slug}/comments|memo` 라우팅.
- `lib/components/QuestNoteSection.svelte` 신규 — comments / memo 공용:
  - 부재: "[작성] / [메모 작성]" 안내.
  - 읽기: MarkdownView.
  - 편집: CodeMirror (markdown + oneDark), height key (`openguild.questEditorHeight`)
    공유.
- `routes/quests/[id]/+page.svelte` 의 Campaigns 다음, History 직전에
  댓글 / 메모 섹션 두 번 mount (mode prop 만 다름).

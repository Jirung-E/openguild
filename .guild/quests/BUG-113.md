증상: lane 별 grid snap col 수를 1 또는 2 로 설정해도, 노드를 옆쪽에
드롭하면 3열 grid 의 양 끝 셀 위치로 스냅되는 경우가 있음.

## 원인 (QuestBoard.svelte snapToGrid())
`colIdx = Math.round(localX / cellW)` 가 레인의 `cols`(1 이든 2 든)로
clamp 되지 않고 무제한. 레인 자체의 시각적 폭(LANE_W)은 항상 넉넉해서
(더 많은 열도 들어갈 만큼) col 수와 무관하게 옆쪽 여유 공간이 있는데,
그 여유 공간에 드롭하면 반올림된 colIdx 가 그 레인에 설정된 col 수를
넘어서 버렸음 — 그 값이 우연히 3열 grid 의 바깥쪽 셀과 겹쳐 "3열
snap 의 양 끝으로 스냅"되는 것처럼 보인 것.

## 수정
`colIdx` 를 `[0, cols-1]` 범위로 clamp.

## 테스트 방법
1. 레인 col 수를 1 로 설정.
2. 노드를 그 레인의 오른쪽 끝 여유 공간에 드롭.
3. 스냅된 위치가 항상 그 레인의 유일한(중앙) 컬럼 위치인지 확인 —
   더 이상 3열 grid 위치로 안 튐.
4. col 수 2 로도 동일 확인 (왼쪽/오른쪽 끝 각각).
5. `cd gui/frontend && npm run check && npm test -- --run` 통과.

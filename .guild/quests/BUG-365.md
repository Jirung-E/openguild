## 문제

admin 요청으로 스킬 전체(배포용 `openguild` · `openguild-plugins`, 이 저장소 작업용 `openguild-workflow`)를 실제 CLI(develop 빌드)와 대조했다. 명령 · 옵션 이름은 전부 맞지만(자동 대조), **설명이 실제 동작과 다르거나 빠진 곳**이 있다.

## 틀린 것

- `quest show` 가 첨부 목록을 보여 준다고 적혀 있다 — 실제로는 개수(`attachments : 2`)만. 목록은 `show --full` 이나 `attach list`.
- 이름으로 길드 찾기: `recents.json` 을 직접 읽으라고 한다 — `openguild guild list` 와 `--guild <이름>` 이 이미 있다.
- `quest list --json | jq '.[] | .id'`, `jq '{id, status}'` — `id` 는 DB 번호, `status` 키는 없다(`quest_id`, `status_slug`).
- `quest show --field` 목록에 `version` 이 빠졌다.
- 서버 띄우기가 `cargo run …` — 설치본 사용자는 `openguild-server host`.
- reference/plugins.md: 없는 명령 `openguild comment add`, 예제 "다섯 개" 라면서 넷만, 이벤트 수 55(지금 56).
- workflow 스킬: "시키지 않았는데 테스트 실행 금지" 가 AGENTS.md 의 "`just test` 는 커밋 직전에" 와 충돌.

## 빠진 것

- `rule delete` · `comment remove` 는 `--force`, `library delete` 는 `--yes` 가 없으면 **터미널이 없을 때 조용히 취소하고 exit 0** — AI 가 지운 줄 안다. Pitfalls 에 없다.
- 상태 `returned`(반려) — 기본 상태인데 수명주기 설명에 없다.
- `campaign update` · `history` · `attach`, `template new`, `rule history` · `new --empty`, `type` / `status` 의 add · update · delete(prefix · slug 를 바꾸면 모든 퀘스트로 번진다).
- `check drift` / `check counters` 는 보고만이 아니라 **자동으로 고친다**.

## 고친 것

위 항목을 전부 고쳤다 — 배포 스킬 SKILL.md · reference(setup · quest · campaign · templates · rules · meta-and-maintenance · backup-and-safety · plugins) · openguild-plugins SKILL.md(`echo -n` → `printf '%s'`), 작업 스킬 openguild-workflow.

- workflow 스킬의 테스트 금지는 **그대로 두고**, Testing 커밋 직전 `just test` 만 예외로 적었다(AGENTS.md 가 우선).
- 반려된 퀘스트: 배포 스킬 수명주기에 "댓글로 이유를 읽고, 같은 퀘스트를 In Progress 로 되돌려 고친다" 를 넣었다.
- 확인을 묻는 삭제의 exit 0 자체는 CLI 버그로 [[BUG-366]] 에 따로 적었다. 스킬에는 "플래그를 꼭 주고, exit code 말고 출력을 보라" 를 적었다.

## 확인

- 스킬에 적힌 `openguild …` 명령 전부를 develop 빌드의 `--help` 와 자동 대조 — 없는 하위 명령 · 옵션 0.
- 고친 설명은 시험용 길드 복사본에서 하나씩 돌려 봤다(`show` 와 `show --full` 의 첨부, `--guild <이름>`, `--json` 키, `rule delete </dev/null` 의 exit 0, 이벤트 56개).

## 한 일

검색어에 걸린 글자를 칠하는 부품 `HitText`(발췌와 같은 노랑 — `--search-hit-bg`)를 만들어 검색 결과의 제목 · 번호에 썼다. `{@html}` 없이 조각으로 그린다.

| 화면 | 칠하는 곳 |
|---|---|
| 검색 팔레트 | 제목 · 번호 칩 · 태그(`#태그` 검색이면 태그만) |
| 문서 검색 페이지 | 제목 · 번호 (쿼리 모드는 안 칠함) |
| 규칙 목록 | 규칙 이름 |
| 퀘스트 목록 | 번호 · 제목 |
| 퀘스트 보드 | 노드 제목 |
| 캠페인 목록 | 번호 · 제목 (쿼리 모드는 안 칠함) |
| 도서관 | 검색 결과 목록 · 타일의 번호 · 제목 |

## 확인

- 시험: `HitText.test.ts`(걸린 글자만 · 대소문자 무시 · 낱말마다, 검색어 없으면 글만 · 마크업 안 풀림), 검색 페이지 시험에 제목 mark.
- 웹 빌드(WebKit, 임시 길드): 팔레트 '코끼리' → 캠페인 제목의 '코끼리' 칠함. 검색 페이지 제목 '코끼리'. 퀘스트 목록 · 보드 '둘째'. 캠페인 '코끼리'. 도서관 '동물'(나머지 '문서' 는 안 칠함). 페이지 오류 0.

## 테스트 방법

팔레트 · 퀘스트 목록 · 보드 · 캠페인 · 도서관 · 규칙에서 제목에 있는 말로 검색 → 제목의 그 글자가 노랗게.

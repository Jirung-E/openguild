admin 요청: 커스텀 테마 프리셋([[DEV-114]])도 `~/.openguild/` 에 파일로 저장.

## 현황
DEV-114 는 프리셋을 WebView2 localStorage 에 저장 — LevelDB 바이너리라 사람이 파일로 열람/백업/이동 불가(admin 이 폴더를 뒤져도 안 보였던 이유). 공유는 export/import(JSON 클립보드)로만 가능.

## 작업
- 저장 위치: `~/.openguild/themes.json` ([[DEV-247]] 의 openguild_home() 사용) — 프리셋 배열 + activeCustomTheme.
- GUI(Tauri): 시동 시 파일 로드, 변경 시 파일 저장 — Tauri 커맨드(read/write) 경유.
- 브라우저/remote 모드: ~/.openguild 접근 불가 — localStorage fallback 유지.
- 마이그레이션: 기존 localStorage 에 프리셋이 있고 파일이 없으면 1회 파일로 이전.
- 파일을 외부에서 직접 편집한 경우: 시동 로드가 진리원이므로 자연 반영(핫리로드는 범위 밖).

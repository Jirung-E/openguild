보드 레인 배경에 그 레인(상태)의 색을 연하게 입힌다. 어느 레인인지 한눈에 보이게(admin 요청, 2026-10-08).

- 보드 설정 창에서 켜고 끈다. 길드별로 기억한다(다른 보드 표시 설정과 같은 방식).
- 드래그 중 놓일 레인 강조는 색을 입혀도 그대로 보인다.

## 한 일
- 레인 DOM(`.lane-col`)에 `--lane-color`(상태 색)를 넣고, 켜지면 `.lanes-bg.lane-tint` 가 배경을 `color-mix(상태 색 9%, --bg-elevated)` 로.
- 보드 설정 창(⚙ 보드 설정) 레인 표 아래에 체크박스 "레인 배경에 상태 색 입히기". localStorage `gk('laneTint')` — 길드별, 기본 꺼짐.
- 드래그 놓일 레인 강조(`.drag-target`)가 색 입힌 배경보다 우선하게 선택자를 올렸다.

## 테스트 방법
1. 보드 → ⚙ 보드 설정 → "레인 배경에 상태 색 입히기"를 켠다 → 각 레인 배경이 레인 제목 색으로 연하게 물들면 정상. 끄면 원래대로.
2. 노드를 끌고 다른 레인 위로 가져가면 그 레인 강조(파란 테두리·배경)가 여전히 보인다.
3. 다크·라이트 테마 둘 다에서 노드 글씨가 잘 읽히는지 본다.
4. 가로 모드(레인을 행으로)에서도 같은지, 앱을 다시 열어도 켠 상태가 기억되는지 본다.

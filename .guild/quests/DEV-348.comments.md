`docs list` / `docs show <name>` 하위 명령으로 전환. admin 결정에 따라 **옛
위치 인자 형태(`docs usage`)는 제거**했다 — 형태를 하나로 통일.

```
$ openguild docs list
usage      사용자 매뉴얼 (USAGE.md)
readme     프로젝트 소개 (README.md)
changelog  변경 이력 (CHANGELOG.md)

$ openguild docs show usage                    # 목차
$ openguild docs show usage --full             # 전체 본문
$ openguild docs show usage --section 설치     # 특정 절
$ openguild docs usage
error: unrecognized subcommand 'usage'
```

`--full` / `--section` 은 그대로이고 상호배타도 유지된다.

## 함께 고친 것

명령 안내 문구가 전부 옛 형태를 가리키고 있었다 — `docs list` 하단 사용법,
섹션 범위 초과/불일치 에러의 "목차 확인" 안내, 명령 설명(about). 전부
`docs show <name>` 으로 갱신했다. 이걸 놓치면 사용자가 에러 메시지가 시키는
대로 쳤다가 다시 실패한다.

스킬(`reference/quest.md`, `SKILL.md`)에는 docs 명령 언급이 없어 수정할 것이
없었다.

## 검증

파싱 테스트 갱신 — `docs list`, `docs show usage`, `--full`, `--section`,
상호배타, 그리고 **옛 형태(`docs usage` / 인자 없는 `docs`)가 이제 에러**인 것까지.

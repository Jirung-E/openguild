## 문제

출력을 `head` 같은 것에 넘기면 읽는 쪽이 먼저 닫을 때 CLI 가 panic 한다.

```
$ openguild plugin events | head -3
...
thread 'run' panicked at library/std/src/io/stdio.rs: failed printing to stdout: Broken pipe (os error 32)
```

`println!` 이 닫힌 파이프에 쓰다 터지는 흔한 Rust 문제다. 결과는 맞지만 스크립트 · AI 가 오류로 오해한다.

## 고칠 것

- 닫힌 파이프는 조용히 끝낸다(exit 0 또는 141). 모든 명령에 한 번에 적용.

﻿'표시' 탭의 .info-grid 가 6rem 1fr 2열 고정이라, 값 열의 컨트롤(슬라이더·버튼 묶음)이 요구하는 최소 폭 때문에 그리드가 화면보다 넓어졌다.

수정: ≤640px 에서 1열로 쌓고(라벨 위/값 아래), 값 쪽 요소에 min-width: 0; max-width: 100%.

검증(375px, 영어): 가로 스크롤 0, 넘치는 요소 0.

﻿admin 재보고 + 제안: 설정 페이지를 제목 / 내용 세로 2단으로.

**1차 수정이 실제로는 적용되지 않고 있었다.** 같은 override 를 파일 위쪽 @media 블록에 넣었는데, 기본 .info-grid { grid-template-columns: 6rem 1fr } 이 파일에서 더 뒤에 있어 같은 특이성에서 나중 규칙이 이겼다 — 실측하니 좁은 화면에서도 96px 231px 그대로였다(그래서 '표시' 탭 넘침도 그대로 남아 있었다).

수정: override 를 스타일 맨 끝으로 옮겨 순서로 이기게 하고, admin 제안대로 라벨/값을 세로로 쌓는다. 값 쪽(dd·자식)에 max-width: 100% 로 슬라이더·버튼 묶음이 남는 폭 안에서 줄어들게.

검증(375px, 영어) 세 탭 모두: grid-template-columns 343px(1열), panel scrollWidth == clientWidth(343), 넘치는 요소 0, 가로 스크롤 0.

교훈: 미디어 쿼리 override 는 **대상 규칙보다 뒤에** 둘 것 — 특이성이 같으면 순서가 결정한다.

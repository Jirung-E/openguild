macOS 실기(2026-08-01): (watch 모드) 실행 시 흰 화면에서 멈춰 진행이 안 됨. 원인: gui/build.rs 의 BUG-038 안전망이 매 빌드마다 npm run build 를 실행 → frontend/build 갱신 → tauri_build 가 그 경로를 rerun-if-changed 로 감시 중이라 다시 재빌드 트리거 → 다시 npm run build... 자기 강화 무한루프(Tauri CLI 의 outer watcher 도 같은 변경을 감지해 거듭 재기동, 앱이 계속 죽었다 뜨길 반복해 흰 화면으로 보임). cargo tauri dev 는 beforeDevCommand(npm run dev) 가 이미 frontend 를 서빙하므로 embed 자산(frontend/build) 자체가 필요 없음 — OPENGUILD_SKIP_FRONTEND=1 로 build.rs 의 npm 재빌드를 건너뛰면 루프 없이 정상 기동됨(검증 완료, 25초+ 안정). 수정: justfile 의 dev-desktop 레시피가 OPENGUILD_SKIP_FRONTEND=1 을 기본으로 넣도록 변경(unix/windows 플랫폼별 문법 분기).

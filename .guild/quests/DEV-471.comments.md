### 4. 흔들리던 스케줄 시험 — 원인과 고침
`claim_due` 가 차례 잠금(flock)을 **파일을 닫는 것으로** 풀었다. 그사이 다른 실이 자식 프로세스를 띄우면(fork 와 exec 사이) 자식이 같은 잠금을 잠깐 함께 쥐어, 다음 확인이 "다른 쪽이 고르는 중" 으로 보고 건너뛰었다. 전체 시험은 run 동작 시험이 프로세스를 많이 띄워 이 틈에 걸렸다. 다 고른 뒤 명시적으로 `unlock()` — flock 의 풀기는 함께 쥔 것까지 푼다. 실제 앱에서도 드물게 한 차례 건너뛸 수 있던 것이라 CHANGELOG Fixed 에 적었다.

(원인은 추론이다 — 재현을 강제하지는 못했다. 고친 뒤 코어 전체 시험 3회 연속 · `just test` 통과.)

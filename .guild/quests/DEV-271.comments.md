피드백 3건 모두 수정. 원인이 각각 달랐다.

## 1. "접힌 메뉴 클릭해도 안펼쳐짐" — nav 의 overflow: hidden 클리핑

☰ 버튼과 드롭다운이 `<nav>` **안**에 있었는데, nav 에는 넘친 링크를 자르기
위한 `overflow: hidden` 이 걸려 있다(DEV-260). 드롭다운은 `position:
absolute` 로 정상 렌더되지만 nav 경계에서 잘려 **화면에 안 보였다** —
클릭이 안 먹은 게 아니라 열린 메뉴가 잘린 것.

→ ☰ 를 nav 의 **형제**(header 직속)로 옮겨 클리핑을 벗어났다.

## 2. "버튼 아이콘이 gui와 다름" — ⋯ → ☰

데스크탑 타이틀바는 ☰ 인데 웹만 ⋯ 였다. ☰ 로 통일.

## 3. "검색팔레트를 gui와 동일하게(항상 중앙), 좌우 버튼도 동일하게"

웹은 오른쪽 끝에 작은 돋보기 버튼 + 자체 최근문서 드롭다운이라 데스크탑과
완전히 달랐다. 데스크탑 `.tb-center` 구조를 그대로 옮겼다:

- 폭 0 앵커를 화면 중앙에 두고 pill 은 그 중앙, '퀘스트 추가'(왼쪽)와
  '최근 본 문서'(오른쪽)는 pill **바깥에 절대 배치** — 버튼 유무가 pill
  위치를 흔들지 않는다(BUG-158 과 같은 이유).
- 최근 본 문서는 자체 드롭다운을 버리고 검색 팔레트 recent 모드 재사용
  (DEV-294 와 동일). 퀘스트 추가는 NewQuestModal(DEV-286).
- pill 라벨은 길드 이름 + 원격 표시. TitleBar 는 `$guildContextActive` 로
  가드하지만 웹에선 그 플래그가 절대 true 가 안 되므로 무조건 조회한다.
  (부수 효과: BUG-146 이후 웹에서 길드 이름이 어디에도 안 보였는데 다시 보인다.)

## 4. "검색팔레트랑 겹치는 메뉴는 접기"

pill 이 절대 배치라 nav 의 `clientWidth` 를 줄이지 않아, 링크가 pill 아래로
파고들어 겹쳤다. `availableNavWidth()` 를 만들어 **pill 그룹의 실측 왼쪽 끝**
까지를 가용 폭으로 삼았다(getBoundingClientRect — CSS 상수를 JS 에 복제하지
않으려고). 겹칠 항목은 자동으로 ☰ 로 접힌다.

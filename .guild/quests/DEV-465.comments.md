구현 · 확인 — 182b66e9 (develop 에 합침).

- 플러그인이 `#{instead: 문장}` 을 돌려주면 저장하지 않고 `AppError::Instead` 로 끝난다(막은 것과 같이 뒤 줄 · 뒤 플러그인은 묻지 않는다).
- 서버: 202 `{"instead": 문장}`. 앱(Tauri): 꼬리표 문자열. 프런트는 둘 다 같은 것으로 풀어 댓글 · 답글 입력에서 **파란 안내 "플러그인이 대신 처리했습니다 — …"** 를 띄우고 입력을 비운다.
- CLI(로컬 · 원격): 안내를 찍고 exit 0.
- 예제 claude-session 기본값을 '대신 처리' 로 바꿨다(설정 '명령 댓글은').

직접 확인(scratch 길드):
- CLI 로컬 `/session` → "플러그인이 대신 처리했습니다 — 터미널에서 DEV-001 세션을 엽니다", exit 0, 댓글 없음. 보통 글은 그대로 달림.
- 서버용 시험 플러그인(`/ping` → instead "pong"): HTTP 202 `{"instead":"pong"}`, 원격 CLI 안내 + exit 0, 웹 화면 댓글 · 답글 모두 파란 안내 + 입력 비움, 댓글 안 남음.
- claude-session 자체는 서버에서 돌지 않는다(scope 에 server 없음 — 창이 서버 기계에 뜬다). 그래서 원격 모드에서 `/session` 은 보통 댓글로 남는다.

남은 것: 데스크톱 앱(Tauri) 경로의 화면 확인 — 꼬리표 풀기는 시험으로만 확인. 퀘스트 생성 · 상태 변경 · 삭제에서 instead 를 쓰면 지금은 그 문장이 오류 자리에 뜬다(댓글만 안내로 다룸).

admin 질문: `docs` 는 왜 `list` / `show` 같은 하위 명령 없이 바로 내용을 보여주나.

## 현재 동작 (DEV-274 이후)

- `openguild docs` — 문서 **목록**
- `openguild docs <name>` — 그 문서의 **목차**
- `openguild docs <name> --full` — 전체 본문
- `openguild docs <name> --section <heading>` — 한 섹션

즉 목록/열람 기능은 이미 다 있고, **위치 인자 방식**이라 하위 명령이 없을 뿐이다.

## 문제

CLI 의 다른 명령은 전부 `명사 동사` 꼴이다 — `quest list/show`,
`library list/show`, `rule list/show`, `campaign list/show`. `docs` 만
`docs` / `docs <name>` 이라 일관성이 깨지고, 하위 명령을 기대한 사용자는
`docs list` 를 쳤다가 "그런 문서 없음" 류의 실패를 본다.

## 방향

`docs list` / `docs show <name>` 를 추가하고, 기존 위치 인자 형태는 **호환을
위해 유지**한다(에이전트 스킬·문서에 이미 그 형태로 적혀 있다).
`docs list` 는 이름 없는 `docs` 와 같은 출력, `docs show <name>` 은
`docs <name>` 과 같은 출력 + 같은 플래그(`--full`, `--section`).

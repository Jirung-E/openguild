## 증상

토론 댓글을 남기라고 지시했는데, 댓글의 **'토론(discussion)' 기능을 쓰지 않고**
본문 말머리에 그냥 `[토론]` 이라고 텍스트로 적는 경우가 발생한다.

말머리는 아무 기능도 하지 않는다 — 미해결 토론 차단(완료 전환 block), 미해결
필터(`openguild comments --unresolved`), GUI 토론 표시 어느 것도 동작하지 않아
사실상 토론을 남기지 않은 것과 같다.

## 추정 원인 (확인함)

`openguild quest comment add` 에 **`--discussion` 플래그가 없다.**
토론 댓글을 만들려면 반드시 2단계를 밟아야 한다:

```
openguild quest comment add {ID} --author me --file body.md   # 1) 추가
openguild quest comment discussion {ID} {댓글번호}             # 2) 토론 토글
```

한 번에 만드는 경로가 없으니, 작성자가 1단계만 하고 "토론임을 표시" 하려고
말머리를 붙이는 것으로 보인다.

## 제안

1. `comment add` 에 `--discussion` 플래그 추가 — 추가와 동시에 토론으로 생성.
   (가장 근본적. 2단계를 1단계로 만들면 말머리를 붙일 이유가 사라진다.)
2. 스킬/문서에 "토론은 말머리가 아니라 `discussion` 기능" 을 명시.
3. 선택 — 본문이 `[토론]` 등으로 시작하는데 discussion 플래그가 꺼져 있으면
   CLI 가 경고를 띄우는 방안.

1번만 해도 대부분 해소될 것으로 보인다.

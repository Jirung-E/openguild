admin 요청:
- 트리뷰에서 뷰 모드를 변경하는 버튼(☰/▦)이 트리 부분에도 있고 문서
  상세 부분에도 있는데 트리 부분에만 있으면 됨.
- 위처럼 바꾸면 아이콘 뷰에서 상세 페이지에 들어갔을 때 뷰 모드 변경
  버튼이 안 보이게 될 수도 있는데, 상세 페이지에서는 안 보여도 좋음
  (admin 확인).
- 아이콘 뷰에서, 현재 위치 왼쪽에 상위 폴더로 이동하는 버튼이 있으면
  좋겠음.

## 수정
- 문서 상세 패널(top-bar)의 `.view-toggle.inline` 중복 인스턴스 제거 —
  트리 사이드바 헤더 / 아이콘 뷰 툴바의 토글만 남김.
- 아이콘 뷰 breadcrumbs 왼쪽에 "⬆ 상위 폴더로" 버튼 추가
  (`parentOf(explorerPath)` 로 이동, 최상위에선 disabled).

## 테스트 방법
- `cd gui/frontend && npm run check && npm run check:no-hex && npm test -- --run`.
- 실기: 트리뷰에서 문서를 선택해 상세를 열었을 때 뷰모드 토글이 안 보이는지
  (사이드바 쪽엔 여전히 있는지). 아이콘 뷰에서 하위 폴더로 들어간 뒤 ⬆
  버튼으로 상위로 돌아가는지, 최상위에서는 버튼이 비활성인지.

DEV-056 fix1 의 후속. 현재는 laneHidden lane 의 col DIV 만 display:none — lane 자리가 비어있고 뒤 lane 안 당겨옴. 진정한 압축은 lane DOM left + 노드 X 좌표 + drag/arrange/DB save 모든 사이트의 절대↔시각 좌표 변환 (relX = lane 안 offset) 필요.

## 구현 (2026-05-25)

### Abstraction — 두 좌표계 + 변환
- **absolute X** = DB positions.x. `absoluteLaneLeftOfStatus(sid)` (laneOf
  기반) + lane 안 offset.
- **visual X** = cytoscape position.x. `visibleLaneLeftOfStatus(sid)` +
  lane 안 offset.
- hideSettings 없을 땐 둘이 같음.

새 헬퍼:
- `absoluteLaneLeftOfStatus(sid)` / `visibleLaneLeftOfStatus(sid)`.
- `absToVisualX(absX, sid)` / `visualToAbsX(visualX, sid)`.
- `statusIdAtVisibleIdx(visIdx)` — drag drop 시 사용자 시각 lane → status.
- `visibleLaneCount()`.
- `applyLaneVisualCompression()` — 모든 노드 visualX = absToVisualX(absX).
  노드 `data.absX` 가 진리원 (DB 좌표계).

### 사이트별 변환
| 사이트 | 변경 |
|---|---|
| **init 노드 추가** | `data.absX = pos.x`, position 은 absolute 그대로 두고 init 끝의 `applyLaneVisualCompression` 이 일관 변환 |
| **syncLanes** | lane-col / lane-hdr 의 left 가 visible idx 기준. hidden lane 은 `display:none` |
| **drag dragfree** | pos.x 가 visual. `Math.floor(pos.x / LANE_STRIDE)` = visible idx → `statusIdAtVisibleIdx` → 새 statusId. clamp 은 `visibleLaneLeftOfStatus` 기준 |
| **drag 후 DB save** | `absX = visualToAbsX(clampedX, finalStatusId)` + `node.data.absX` 갱신 + `updatePosition(absX, y)` |
| **arrangeNodes / arrangeNodesGrouped** | 계산 X 는 absolute (`laneFirstCellX`), 노드 position 적용은 `absToVisualX`. DB save `absX`, `data.absX` 갱신 |
| **snapToGrid** | input x = visual → visible idx → status. firstX (absolute) → `absToVisualX` → snap 결과 visual |
| **flashToQuest 새 노드 추가** | 동일 패턴 — absX 계산, visualX 변환, position visual, DB save absX |
| **applyRecord (undo/redo)** | history record.to.x 가 visual → `visualToAbsX` 변환 후 DB save |
| **toggleHideSetting laneHidden** | `applyLaneVisualCompression()` + `syncLanes()` 호출 — 모든 노드 즉시 재배치 |

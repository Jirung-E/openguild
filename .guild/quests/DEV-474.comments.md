**시간 실행 목록의 모양을 이벤트와 같게 했다** (admin: 왜 다른가 → 맞춰라)

다른 이유는 설계가 아니었다. 시간 실행 목록을 쿼리 키 이름에 맞춰 따로 썼기 때문이다.

- 이제 `e.items` 한 건은 `payload::quest` · `campaign` · `book` · `comment` 를 그대로 쓴다. 코드가 하나라 다시 갈라질 수 없다.
- 바뀐 이름: 캠페인 `start`/`end` → `started_at`/`ended_at`, 도서관 `folder` → `path`, 댓글 `parent` → `parent_id`, `created_at` → `ts`, `discussion: "unresolved"` → `discussion` · `resolved` true/false, `quest`/`campaign` → `target: {kind, id}`.
- 목록에만 더 있는 칸: 퀘스트의 기한 · `comment_count`, 댓글의 `target`.
- 이벤트 쪽 댓글에 `edited_at` 을 더했다.
- 쿼리 문법(`start:` · `folder:` · `discussion:unresolved`)은 그대로다.

**확인**: `just test` EXIT=0. 네 종류 모두 이벤트의 칸이 목록에 같은 값으로 있는지 시험을 넣었다.

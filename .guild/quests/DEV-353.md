## 배경

퀘스트·캠페인·규칙·도서관·메모·작업기록 등 편집 화면에서 저장 버튼을 누르면 저장과 함께 편집 모드가 종료된다. 반복 편집 중에는 저장한 뒤 다시 편집 모드로 들어가야 한다.

## 목표

- `Ctrl+S` / macOS `Cmd+S`를 누르면 현재 내용을 즉시 저장한다.
- 단축키 저장 성공 후에도 편집 모드와 커서·스크롤 맥락을 유지해 계속 편집할 수 있게 한다.
- 화면의 기존 저장 버튼은 현재처럼 저장 후 편집 모드를 종료한다.
- 저장 중 중복 호출과 브라우저 기본 "페이지 저장" 동작을 막는다.
- 공용 마크다운 편집기와 별도 편집기(작업기록)에서 동작을 일관되게 한다.

## 테스트 방법

1. 퀘스트·캠페인·규칙·도서관·메모·작업기록 편집 모드에서 내용을 바꾸고 `Ctrl+S` 또는 `Cmd+S`를 누른다.
2. 저장 결과가 반영되면서 편집 모드는 유지되는지 확인한다.
3. 계속 내용을 수정한 뒤 화면의 저장 버튼을 누르면 기존처럼 편집 모드가 종료되는지 확인한다.
4. 저장 중 단축키를 연속 입력해 중복 요청이나 브라우저 페이지 저장 창이 뜨지 않는지 확인한다.

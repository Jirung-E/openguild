- 버그: dim effect 가 cy/allQuests(비반응) 준비 전에 한 번 돌고 끝나 List→Board 전환 시 dim 누락 → applyFilterDim() 분리해 render 직후에도 호출.
- 신규: '보드 설정' 모달에 필터 섹션(List 와 동일 QuestListFilter). 편집 시 공유 store + localStorage(List 와 동일 키)에 반영 → dim 즉시 + List 일관 + Ctrl+R 후 유지.
- 직렬화는 quest-filter store 로 옮겨 List/Board 공용.

## 테스트 스텝 (사용자 GUI)
1. 리스트에서 필터 → 보드 전환 → 매치 안 되는 노드가 흐려지고 'N/M 매치 [× 해제]' 칩 표시.
2. 보드 '보드 설정'(⚙) → 필터 섹션에서 직접 필터 변경 → dim 즉시 갱신.
3. 리스트로 돌아가도 같은 필터 유지(양방향 동기).
4. Ctrl+R 새로고침 후에도 유지. '× 해제' → 전부 복원.

<!-- og-comment id="3" ts="2026-06-14T14:42:10+09:00" author="admin" discussion="true" resolved="true" -->
필터가 적용된 상태에서 보드 페이지에서 새로고침을 하면(또는 다시 시작 후 바로 보드 페이지로 들어가면) 필터 적용이 안되어있는것처럼 보인다. 그러나 리스트 페이지에 갔다가 다시 보드 페이지로 오면 다시 필터가 적용된다.

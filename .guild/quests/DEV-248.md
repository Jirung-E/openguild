문서 접근 권한 문제([[DEV-247]] 배경)를 원천 회피하는 보조 수단: 문서를 바이너리에 embed 해 stdout 으로 출력하는 CLI 명령. 에이전트는 경로를 알 필요도, 파일 읽기 권한도 필요 없음 — exec 만 되면 됨.

## 작업
- `openguild docs <name>` — name: agents | usage | readme | changelog. 해당 문서를 stdout 으로.
- 구현은 `include_str!("../../docs/...")` — **컴파일 타임에 리포의 md 파일을 그대로 embed** 하므로 진리원은 기존 md 파일 하나뿐, 문서 수정 시 코드 갱신 불필요(다음 빌드가 자동 반영). 이중 관리 없음(admin 우려 확인됨).
- `openguild docs` (인자 없음) — 목록 + 한 줄 설명.
- AGENTS_OPENGUILD_USAGE 에 자기 자신 조회법으로 이 명령 소개(부트스트랩: 에이전트에게 "openguild docs agents 실행해라" 한 줄만 알려주면 됨).

## 비고
- 설치 폴더의 docs/ 복사본(사람용)은 유지 — 이 명령은 대체가 아닌 보조.
- help-leak 테스트 주의: doc 주석에 quest id 금지.

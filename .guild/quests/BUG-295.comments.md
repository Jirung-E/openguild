간략하게 보기(단순 show) 일때는 첨부파일 개수만 나오면 좋겠다. 

현재:
```
> openguild quest show DEV-000
DEV-000  (제목)
  status   : In Progress (진행 중)
  urgency  : 3
  relations: sub 2  ·  succ 1
  attachments (3):
    - xxx.md  (attachments/xxx-3afd774800000000.md)
    - yyy.png  (attachments/yyy-430e6c3000000000.png)
    - zzz.json  (attachments/zzz-4387804800000000.json)
```

변경:
```
> openguild quest show DEV-000
DEV-000  (제목)
  status      : In Progress (진행 중)
  urgency     : 3
  relations   : sub 2  ·  succ 1
  attachments : 3
```

그 모양으로 바꿨습니다. 간략히 볼 때는 개수만 나옵니다.

```
attachments : 3
```

라벨 폭을 맞춰 두어 위 줄들과 세로로 떨어집니다. 파일 이름·크기까지 보려면
`--attachments` 를 붙이면 됩니다.

원래 이 퀘스트가 짚은 문제(에이전트가 첨부를 아예 못 보던 것)도 같이 고쳤습니다 —
`quest show` / `campaign show` / `library get` 이 로컬 모드에서 첨부를 빈 목록으로
내려보내고 있었습니다.

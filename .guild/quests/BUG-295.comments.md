간략하게 보기(단순 show) 일때는 첨부파일 개수만 나오면 좋겠다. 

현재:
```
> openguild quest show DEV-000
DEV-000  (제목)
  status   : In Progress (진행 중)
  urgency  : 3
  relations: sub 2  ·  succ 1
  attachments (3):
    - xxx.md  (attachments/xxx-3afd774800000000.md)
    - yyy.png  (attachments/yyy-430e6c3000000000.png)
    - zzz.json  (attachments/zzz-4387804800000000.json)
```

변경:
```
> openguild quest show DEV-000
DEV-000  (제목)
  status      : In Progress (진행 중)
  urgency     : 3
  relations   : sub 2  ·  succ 1
  attachments : 3
```

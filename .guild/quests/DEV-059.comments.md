## 기능
Quest Board 의 lane 순서를 사용자가 변경. '보여지는 순서' 만 — 파일 / DB / 다른 quest 영향 X.

## 사용
- 각 lane header 의 label 좌우 ◀ ▶ 버튼.
- ◀ : 한 칸 왼쪽으로. 첫 lane 의 ◀ 는 disabled.
- ▶ : 한 칸 오른쪽으로. 마지막 lane 의 ▶ 는 disabled.
- 변경 즉시 모든 노드의 lane 좌표 재배치 + localStorage (`{guild}.laneOrder`) 영속.
- 새 status 추가 시 자동으로 끝에 append (sort_order 기준).

## 구현
- `loadLaneOrder()` / `saveLaneOrder()` — slug 배열 영속.
- `loadFromData` 의 sorted 생성: localStorage 순서 우선 + 미저장 status 는 sort_order 끝에.
- `swapLane(li, dir)` — sorted 와 laneOf 갱신 + 모든 노드의 visX 재계산.

## 한계
- drag reorder 미지원 (◀ ▶ 만). 향후 drag 추가 가능.
- status sort_order (DB / file) 는 안 건드림 — Admin 의 sort_order 변경과 별개.
- 한 길드 내 사용자별 — localStorage 라 multi-user 시 각자.

## 테스트
1. lane 여러 개 (open / in_progress / testing / done / cancelled / on_hold).
2. testing lane 의 ▶ 클릭 → done 과 swap.
3. 그 lane 의 노드들 새 위치로 이동.
4. 새로고침 → 변경 유지.
5. Admin 에서 status sort_order 변경해도 본 순서 유지 (사용자 정의 우선).
6. 새 status 추가 → 끝에 append.

# [skill] SKILL.md에 '시작 전 체크리스트' 추가

## 배경

사용자 요청: 배포용 `openguild` 스킬을 쓰는 에이전트가 실제 작업(코드
수정, quest 생성 등)에 들어가기 전에 길드 규칙(`rule`)을 먼저 확인하고,
작업 중 궁금한 점이 생기면 웹 검색/추측 전에 먼저 도서관(`library`)을
확인하도록 유도할 수 있는지 문의.

## 검토한 방향

- **hooks(PreToolUse) 하드 게이트**: SKILL.md frontmatter의 `hooks` 필드로
  진짜 강제도 이론상 가능하나, 셸 스크립트가 필요하고 배포용(다른 사용자
  환경) 스킬에서 이식성/신뢰성이 떨어져 이번 성격(범용 배포 스킬)엔 과함.
- **지시문(soft guidance) — 채택**: SKILL.md 본문에 "작업 시작 전 필수
  체크" 절을 명시적으로 추가. 강제는 아니지만 이 repo의 `CLAUDE.md`/
  `AGENTS.md` 가 "⚠️ 절대 규칙" 식으로 에이전트를 통제하는 것과 동일한
  패턴이라 실제로 잘 먹힘.

## 구현

`skills/openguild-plugin/skills/openguild/SKILL.md` 의 Setup 절과 Quest
lifecycle 절 사이에 "## Before you start (do this first, every time)"
절 추가:
1. 실제 작업(코드/quest) 전에 `openguild rule list` 로 관련 규칙 확인.
2. 작업 중 의문이 생기면 웹검색/추측보다 먼저 `openguild library`
   list/show 로 확인.

## 테스트 방법

`claude plugin validate ./skills/openguild-plugin` 로 스키마 유효성
확인, `grep -noE "DEV-[0-9]+|BUG-[0-9]+|..."` 로 이 repo 고유 quest ID
누출 없는지 확인(둘 다 이미 로컬에서 확인 완료 — 실기 CLI 필요 없는
순수 문서 변경).

사용자 보고: 브라우저(127.0.0.1:3000)로 접속 시 탭 썸네일 아이콘이
앱 아이콘 대신 Svelte 기본 로고(빨간 S)로 표시됨.

## 원인

SvelteKit 프로젝트 생성 시 기본으로 포함되는 `static/favicon.svg` 가
Svelte 공식 로고 SVG 그대로였다. `src/app.html` 이 이 파일을
`<link rel="icon" href="/favicon.svg" type="image/svg+xml" />` 로
참조하고 있어, 브라우저 탭과 북마크 모두에 Svelte 로고가 표시됐다.

## 수정

- `gui/icons/32x32.png` → `static/favicon.png` (앱 아이콘 PNG)
- `gui/icons/icon.ico` → `static/favicon.ico` (앱 아이콘 ICO, 다중 해상도)
- `src/app.html`: `favicon.svg` 참조 제거, 아래로 교체:
  ```html
  <link rel="icon" href="/favicon.ico" sizes="any" />
  <link rel="icon" href="/favicon.png" type="image/png" />
  ```
  ICO는 레거시/IE 폴백, PNG는 모던 브라우저 우선 선택.

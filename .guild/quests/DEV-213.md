퀘스트 안에서 토론(discussion) 댓글만 모아보는 필터. 홈의 '토론 댓글' 섹션(DEV-150)은 길드 전체 — 이건 개별 퀘스트 상세 내.

## 구현 (2026-07-04, QuestCommentsSection.svelte 단일)
- 섹션 헤더에 토글 버튼 `💬 토론만 N (미해결 M)` — quest 전용(campaign 은 discussion 없음), 토론 댓글 0개면 숨김, 활성 시 accent 강조.
- 필터 on: **토론을 포함한 스레드(root 카드)만 표시**(discussionRoots — rootIdOf 로 자손 토론도 귀속), 스레드 안의 비토론 entry 는 숨기지 않고 **dim(opacity 0.45)** — 대화 문맥 보존.
- 필터 on 동안 스레드 접기(collapsedRoots) 무시하고 강제 펼침 — 접힘 때문에 안 보이면 필터 의미 없음(DEV-214 와 시너지).

## 테스트 방법 (재빌드 후 GUI/브라우저)
1. 토론 댓글이 있는 퀘스트 상세 → 헤더에 '💬 토론만 N (미해결 M)' 버튼 표시, 토론 없는 퀘스트에선 숨김.
2. 토글 on → 토론 없는 스레드 카드 사라짐, 토론 있는 스레드는 표시 + 비토론 댓글 흐림 + 접혀있던 스레드도 펼쳐짐.
3. 토글 off → 원상복구(접기 상태 보존). 캠페인 상세 댓글엔 버튼 없음.
4. resolve 토글 시 미해결 카운트 갱신.
5. cd gui/frontend && npm run check.

## 증상

원 댓글 본문이 길면 "↩ 답글" 을 눌러도 답글 입력 폼이 화면 밖 (스크롤 아래쪽) 에 나타나서 사용자가 눈치채지 못함. 클릭이 먹은 것처럼 안 보임.

## 수정

`QuestCommentsSection.svelte` 의 `enterReply()`:
- `await tick()` 으로 폼 mount 대기.
- `.reply-form textarea.body-input` 을 `scrollIntoView({ behavior: 'smooth', block: 'center' })`.
- `focus({ preventScroll: true })` — scrollIntoView 의 부드러운 스크롤을 부정하지 않도록.

한 번에 한 답글 폼만 떠 있으므로 `document.querySelector` 로 단일 폼 선택 충분.

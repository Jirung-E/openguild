QuestListFilter 의 '고급' 필터 패널(.adv-bar)이 삼성 인터넷(v30.0.0.67)에서
열리지 않음 — 화살표(▸→▾)는 반응하는데 패널 내용이 전혀 안 보임. 크롬(같은
폰)에서는 정상. 리스트 페이지/보드 설정 모달 양쪽에서 재현.

원인 조사: dev/prod 빌드, 폭/가로세로, 브라우저 확대율, JS 콘솔 에러 전부
배제. 화면에 직접 진단 정보를 띄워 확인한 결과 `.adv-bar` DOM 은 정상
마운트(children=7)됐지만 `getComputedStyle().display` 가 'none' — 소스엔
그런 규칙이 없음. 클래스명 `adv-*`(advertisement 약어)가 삼성 인터넷 광고
차단 기능의 제네릭 코스메틱 필터에 걸려 숨겨진 것으로 결론.

수정 (QuestListFilter.svelte, QuestBoard.svelte, app.html):
- `.adv-bar`/`.adv-toggle`/`.adv-clear` → `.xfilter-panel`/`.xfilter-toggle`/
  `.xfilter-clear` 로 클래스명 변경(광고 차단 오탐 회피).
- (부수 발견) `.filter-bar` 에는 좁은 화면용 padding 축소 미디어쿼리가 있는데
  `.adv-bar` 엔 없어 New Quest 버튼용 130px 우측 padding 이 좁은 화면에서도
  남아있던 버그도 같이 수정 + `<meta name="color-scheme">` 추가(다크모드
  강제 반전 대비).

사용자가 실기기(삼성 인터넷 30.0.0.67)에서 직접 검증 완료 — "잘 펼쳐짐".
[[BUG-217]] 과 같은 세션에서 발견/수정 — 작업 트리 공유.

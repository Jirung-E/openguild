## 테스트 방법 (구현 완료 — 2026-07-18 실기 검증)

우선순위: `--frontend-dist` > `FRONTEND_DIST` env > config파일(`frontend_dist`) > 자동 탐색.

```bash
cargo build --release -p openguild-server
target/release/openguild-server host --port 3000   # Ctrl+C 로 종료
```

시나리오(①~④ 실기 확인함):
1. repo root 실행 → 시동 로그 `static : gui/frontend/build` (자동 탐색 + 경로 표시). ✅
2. `host --frontend-dist <경로>` → 로그 `static : <그 경로>` (최우선). ✅
3. `host --config <toml>` (`[server]\nfrontend_dist="..."`) → `static : <config 경로>` + `config : <toml 경로>` 로그. ✅
4. `host --config /없는파일.toml` → `Error: --config 로 지정한 파일이 없음: ...`. ✅
5. API-only: frontend·config 둘 다 없는 격리 폴더에 exe만 복사해 실행 → "frontend 자산 없음 — API-only" + 지정 3방법 안내 로그. (이 머신은 exe 조상에서 repo build 를 찾아버려 강제 재현은 못 했음.)

참고: `~/.openguild/openguild-server.toml` 탐색은 DEV-247(후속). 현재 자동 탐색은 exe 옆 → cwd 순만.

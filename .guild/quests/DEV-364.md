## 요청

퀘스트 목록 / 홈 / 퀘스트 보드 / 검색 팔레트 등에서 표시되는 **slug pill 모양이
전부 다르다.** 게다가 **상태(status) pill** 도 비슷한 모양이라 같이 맞춰야 한다.
전수 조사해 통일한다.

## 이미 확인된 사실

[[DEV-362]] 에서 팔레트 칩을 만들다 드러났다 — **공통 정의가 없고 컴포넌트마다
각자 정의**한다. `global.css` 에 공용 클래스가 없다.

`border-radius: 20px|12px|9px` 를 쓰는 컴포넌트만 12개:

```
CampaignCombobox / CampaignHistory / Home / NewQuestModal / QuestHistory
QuestBoard / QuestCombobox / QuestList / QuestListFilter / QuestListItem
SearchPalette / TagPills
```

같은 `quest_id` 를 그리는데도 값이 제각각이다:

| | QuestListItem | QuestBoard `.badge` | QuestBoard `.node-pill` | QuestCombobox |
|---|---|---|---|---|
| radius | 20px | 20px | **9px** | **12px** |
| background | `--c` 18% | 18% | **16%** | **16%** |
| border | 40% | 40% | **55%** | 40% |
| font | sans | sans | **monospace** | **monospace** |
| font-size | 0.75rem | 0.7rem | **10px** | 0.7rem |
| height | auto | auto | **17px 고정** | auto |

**실제로 사고가 났다**: DEV-362 에서 팔레트 칩을 두 번 잘못 맞췄다. 처음엔
테두리를 빠뜨렸고(`.badge` 를 눈으로 베낌), 고친 뒤에도 보드 **노드**의
`.node-pill.mono` 와 또 달랐다. 정본이 없어서 생긴 일이다.

## 범위 — 전수 조사 후 통일

1. **slug/식별자 pill** — `--c`(타입 색) 기반. quest_id, campaign_slug, BOOK-NNN.
2. **상태(status) pill** — 모양이 slug pill 과 비슷해 함께 맞춰야 한다.
   (`QuestListItem` 의 상태 뱃지, 보드 컬럼 헤더, 홈 목록 등)
3. 성격이 다른 것은 **제외** — 태그 칩(`TagPills`), 필터 칩, 이력 칩.
   통일 대상인지 조사 단계에서 판단한다.

## 제안

`global.css` 에 `--c` 를 받는 공용 클래스를 두고 각 컴포넌트가 참조한다.
크기 차이(팔레트 행은 조밀, 보드 노드는 더 작음)는 modifier 나 CSS 변수
(`--pill-h`, `--pill-fs`)로 흡수한다.

Svelte 스타일 스코핑 때문에 컴포넌트 안에서 전역 클래스를 쓰려면 `:global()`
이 필요하다 — 확인하고 진행할 것.

## 주의

공용 UI 전반을 건드리므로 **시각 회귀 위험이 크다.** 각 화면을 실제로 열어
크기·색·테두리를 대조 확인할 것. 라이트/다크 모두.

## 테스트 방법

1. 퀘스트 목록 / 홈 / 보드(노드·컬럼 헤더) / 검색 팔레트 / 콤보박스를 차례로
   열어 slug pill 과 상태 pill 이 **같은 모양**인지.
2. 타입별 색(DEV/BUG/REQ)과 상태별 색이 그대로 반영되는지.
3. 라이트/다크 모두.
4. 보드 노드처럼 크기가 달라야 하는 곳은 **의도된 차이만** 남았는지.

고쳤습니다.

1. `resolve_guild_ref`(`core/src/guild_file.rs`) — 상대 경로는 작업 폴더 기준으로 절대 경로로 바꿔(`..` 없이 정규화) 견주고, 그 절대 경로를 돌려준다. 이름 찾기(recents)는 그다음 그대로.
2. 서버(`server/src/main.rs` `load_guild`) — 길드를 절대 경로(윈도우 `\\?\` 없이)로 연다. 그래서 훅의 `OPENGUILD_GUILD_DIR` · `OPENGUILD_PLUGIN_DIR` 도 절대 경로다.

확인(맥, 시험 길드, debug 빌드):
- `--guild .`(길드 안) · `--guild g`(부모 폴더) · `--guild ..`(`.guild` 안) 모두 목록이 나옴. 없는 경로 `--guild ./nope` 은 예전 오류 그대로.
- 길드 폴더에서 GUILD_PATH 없이 띄운 서버에 댓글 → 기다리는 훅이 받은 `GD=` 가 절대 경로, 답글이 바로 달림(고치기 전에는 `GD=.` 에 "no .guild file at .").
- 시험 `resolve_guild_ref_accepts_relative_path` 추가(`.`, `../<이름>`, 하위 폴더에서 `..`).

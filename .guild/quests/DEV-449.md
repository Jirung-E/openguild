형광펜(DEV-443)을 CLI 에서 읽게 한다 — 지금은 앱 · 웹(서버 API)에만 있고 CLI 명령이 없어서, AI 가 사용자가 칠한 곳을 볼 수 없다(admin, 2026-10-23: "형광펜 cli랑 서버에서는 어떻게 동작하는지?" → 목록 명령 붙이기로).

## 할 것
- `openguild quest highlight list <ID>` · `campaign highlight list <C-NNN>` · `rule highlight list <slug>` · `library highlight list <BOOK-NNN>` — 메모 · 댓글처럼 대상 명령 아래에 둔다.
- 출력: 어느 부분인지(본문 · 메모 · 댓글 #N), 칠한 글, 앞뒤 글자, 칠한 때. `--json` 은 서버 응답과 같은 모양.
- 이름은 다른 명령처럼 받는다(대소문자 등) — 없는 대상은 "형광펜 없음" 이 아니라 오류.
- 로컬 · `--remote` 둘 다(`GET /api/highlights`).
- 문서 · 스킬: 사용자가 칠한 곳은 중요하다고 본 곳 — 읽을 때 같이 본다.

## 범위 밖
- CLI 로 칠하기 · 지우기(필요하면 따로).

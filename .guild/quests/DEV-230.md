`openguild comments`(전역 검색)가 본문을 첫 줄 60자로 요약해서 보여줘,
여러 줄 댓글의 뒷내용을 놓치는 사고가 실제로 발생했음(2026-07-05,
BUG-105 댓글 두 번째 줄을 못 보고 잘못 답글).

`quest comment list <slug>` 는 이미 본문 전체를 보여주는데 전역
`comments` 만 예외적으로 잘랐던 것 — 논의 후 기본을 전체 출력으로
통일하기로 결정.

## 변경
- 기본 출력: 본문 전체 (quest comment list 와 동일).
- `--summary` 플래그: 여러 건 훑어볼 때만 opt-in 으로 첫 줄 60자 요약.
- `--json` 은 원래부터 body 전체를 실었으니 변경 없음.

## 테스트 방법
- `openguild comments` → 각 댓글 본문 전체 줄바꿈 그대로 출력.
- `openguild comments --summary` → 기존처럼 한 줄 요약.
- `cargo test -p openguild-cli` 통과.

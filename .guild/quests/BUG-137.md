`just dev-frontend`(순수 웹 dev 서버)로 `/` 접근 시 500:

```
[500] GET /
ReferenceError: window is not defined
    at src/lib/components/OverlayScrollbar.svelte:162  (onDestroy → window.removeEventListener)
```

## 원인
이 앱은 Tauri 데스크톱 SPA — `svelte.config.js` 도 "SSR 없이 SPA(fallback)로
동작"이라 명시. 그러나 SSR 을 실제로 끄는 `export const ssr = false` 가
어디에도 없어, dev 서버가 매 요청을 SSR 하다가 브라우저 전용 API(window/
document)를 만지는 컴포넌트(OverlayScrollbar, 그 외 다수)에서 크래시.

Tauri(webview) 실행에선 잘 보였던 이유는 실사용 경로가 client 렌더로 흘러서
표면화가 덜 됐을 뿐, 설계 의도(SSR off)와 어긋난 잠복 결함.

## 해결
루트 `src/routes/+layout.ts` 에 `export const ssr = false;` (SPA 전용). 필요 시
`prerender = false` 도. adapter-static + fallback:index.html 과 정합.

## 검증
- `just dev-frontend` 로 `/`, `/welcome`, `/quests/…` 500 없이 로드.
- `just build-frontend` 정상.

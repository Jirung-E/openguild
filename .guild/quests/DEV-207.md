사용자 피드백(원문): "그냥 웰컴에서 들어갈때는 '원격 서버' 탭을 안보여주면
되는거 아님? 그리고 애초에 '원격서버' 탭으로 분리된 이유가 뭐임? 그냥 '정보'
탭에 원격이면 주소, 로컬이면 경로 출력해서 보여주고, 웰컴페이지에서
들어간거면 표시 안하면 되는거 아님?"

BUG-099 로 '원격 서버' 탭에 3-state 표시(아직 안 열림/원격/로컬)를
추가했지만, "탭 자체가 Welcome 에서도 보인다"는 새 문제로 이어졌다.
사용자 제안대로 탭을 아예 없애고 '정보' 탭에 한 줄로 통합.

## 수정

`gui/frontend/src/routes/settings/+page.svelte`:

- `Tab` 타입에서 `'remote'` 제거 — tab 버튼 및 해당 콘텐츠 블록 삭제.
- `onMount` 에서 로컬 길드가 열려있을 때(`localGuildOpen === true`)
  `current_guild_path` invoke 로 `guildPath` 상태를 함께 채움.
- '정보' 탭에 `{#if isTauri && anyGuildOpen}` 조건 블록 추가:
  - 원격 활성(`isRemoteActive`) → `'원격 서버'` 레이블 + URL(`.remote-active`).
  - 로컬 → `'길드 경로'` 레이블 + 로컬 경로.
  - `anyGuildOpen` false(Welcome 에서 진입) → 블록 자체가 렌더되지 않음.
- 이제 사용되지 않는 `.remote-none` CSS 규칙 제거; `.remote-active` 유지.

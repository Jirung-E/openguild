[[DEV-166]]에서 CLI 삭제 서브커맨드를 `rm`에서 `remove`로 통일했지만, 현재 사용되는 에이전트 지침·스킬 레퍼런스·설계 문서 6곳에 구 `rm` 표기가 남아 있다. 실제 CLI는 `rm` alias를 제공하지 않아 문서대로 실행하면 `unrecognized subcommand 'rm'` 오류가 발생한다.

수정 대상:

- AGENTS.md의 `quest comment rm`
- 스킬 레퍼런스의 `campaign checklist rm`, `quest prereq rm`
- backup-and-safety 레퍼런스의 `quest prereq rm`
- docs/architecture.md의 `quest tag .../rm/...`
- docs/storage-design.md의 `campaign checklist .../rm`

CHANGELOG의 과거 명칭 설명, 셸 파일 삭제 명령 `rm`, 과거 퀘스트·댓글 기록은 수정하지 않는다.

## 테스트 방법

1. 현재 사용 문서에서 openguild 서브커맨드로 쓰인 `rm`을 검색해 대상 6곳이 더는 남지 않았는지 확인한다.
2. 셸 명령 `rm -rf`와 CHANGELOG의 `구 rm` 기록은 그대로 유지됐는지 확인한다.

admin 결정대로 정리했다.

- 옛 이름 제거: `--has-sub` · `--no-sub`, 서버 `?has_sub=` · `?no_sub=` → `--has-child` · `--no-child`, `?has_child=` · `?no_child=`. JSON · `--field` 의 `sub_quests` → `children`(화면도 함께). `quest show` 의 표시도 `children`.
- 플러그인 `of = "comment"` — `e.items` 에 본문까지(`id quest campaign author body parent discussion created_at updated_at`). 스키마 · 요약 · 문서 함께.
- `created` · `updated` · `commented` 가 시각도 받는다(`>=2026-11-01T10:00`). 시각은 비교 · 범위로만. 날짜는 이 기계 시간대의 날짜로 잰다 — 앞 10글자를 자르던 때는 UTC 로 적힌 옛 데이터가 하루 어긋날 수 있었다.
- `comments --since` · `--until` 은 글자 비교였다 → `datetime()` 으로. 분까지만 적은 시각(`T10:00`)에 시간대가 안 붙던 것도 고쳤다(`normalize_filter_ts`). `quest list --created-after` 들은 원래 맞았다.
- `id:DEV` 는 안 넣는다(`type:DEV` 가 있다).

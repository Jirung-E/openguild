## 무엇을 했나

CHANGELOG Unreleased 에 누락돼 있던 완료 퀘스트 **63건**을 주제별로 묶어
반영했다. 개별 나열이 아니라 사용자가 체감하는 단위로 묶고, 각 항목 끝에
퀘스트 번호를 달아 추적 가능하게 했다.

- **Added 9묶음** — 보드 전면 개편(DOM 렌더 + 가로 레인 + LOD), 뒤로/앞으로
  길드 복원, 생성 팝업에서 연관관계 지정, Ctrl+S 편집 유지, 표시 설정 2종
  (HDR·자동 서식), CLI 길드 이름 지정, `quest show` 요약화, 캠페인 진행도,
  Cmd+R.
- **Changed 7묶음** — 편집기 자동완성 통일, auto-block 폐지, `updated_at` 역류
  근본 수정, 증분 동기화 확대, 표시 다듬기(2단 배치·아이콘·툴바 대비·긴 제목),
  문서/도움말 정합성, 개발 편의(just recipe·시드 스크립트).
- **Fixed 19묶음** — 데스크톱 이미지 로드 실패, 최근 본 문서, 댓글 입력창 3종,
  삼성 인터넷 광고 차단 오탐, 첨부 파일명 충돌, 규칙 slug 공백, init 내용 유출,
  스냅샷 walk 성능, 자동완성/팝업, 웹 좁은 창 메뉴, 모바일 잔여, 보드 툴바
  클릭, HDR 동영상, CLI NotFound·원격 파리티, 스킬 2종, 릴리스 파이프라인.

상단 요약 문단도 이번 사이클 규모에 맞게 다시 썼다 — macOS 지원과 보드
재작성이 머리에 오고, 문서 탐색·첨부·모바일이 뒤따르는 구성.

## 어떻게 찾았나

`v0.4.1-beta..develop` 커밋 메시지에서 퀘스트 번호를 뽑아(269 커밋, 완료
퀘스트 132건), Unreleased 본문에 그 번호가 없고 **상위 umbrella 도 언급되지
않은 것**만 걸러냈다(모바일 정리처럼 DEV-257 아래 묶인 것은 이미 커버된
것으로 간주). 반영 후 같은 검사를 다시 돌려 **누락 0** 을 확인했다.

## 남은 판단

아직 없다. 릴리스 태그를 미는 건 admin 결정이라 손대지 않았다.

구현 완료 (Windows 한정, 계획대로):

- `tauri.windows.conf.json` 신설 — Windows 빌드만 decorations:false + shadow:true (타 OS 는 기존 네이티브 데코 유지, frontend 도 userAgent 로 분기).
- `TitleBar.svelte`: data-tauri-drag-region 드래그(더블클릭 최대화는 Tauri 내장 처리) + 최소화/최대화·복원(아이콘 토글, onResized 구독으로 스냅/Win+화살표 경로도 동기화)/닫기. SVG 아이콘 + 테마 토큰만 사용(no-hex) — 다크/라이트/커스텀 테마가 타이틀바에 즉시 반영.
- capabilities: core:window allow-start-dragging/internal-toggle-maximize/minimize/toggle-maximize/is-maximized/close 추가.
- 레이아웃: --titlebar-h CSS 변수(비표시 시 0px)로 Nav sticky top / 100vh 계산 4곳(QuestBoard overlay·높이, QuestList, main) offset.
- **Snap Layouts(최대화 버튼 호버 팝업)는 1차에서 문서화된 트레이드오프로 미지원** — Win+화살표/가장자리 스냅은 동작. 복원은 후속.

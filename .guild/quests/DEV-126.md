페이지 새로고침 (예: DEV-120 의 admin reindex 후 자동 reload, 사용자 F5) 시 항상 페이지 최상단으로 이동. 본문 중간을 보고 있다 reload 한 경우 다시 스크롤 내려야 함.

요구사항: reload 시 직전 스크롤 위치 복원.

구현 옵션:
- `sessionStorage` 에 페이지별 (path 기준) y offset 저장 — `scroll` 이벤트 throttle 로 기록. mount 시 복원.
- `history.scrollRestoration = 'manual'` 로 brower 의 자동 복원 끄고 직접 제어 (SvelteKit 의 기본 동작과 조율 필요).
- 페이지마다 다른 컨테이너 (예: Board 의 cytoscape pan) 도 동일 패턴으로 별도 처리 필요한지 검토.

DEV-058 (board viewport 저장) 와 유사 패턴 — 참고 가능.

사용자 요청: "스킬 업데이트 — USAGE 형태로 제공하는게 아닌 진짜 스킬을
제공하도록."

## 해석 (등록 시점)

현재 에이전트 연동은 `docs/AGENTS_OPENGUILD_USAGE.md`(+ `openguild docs
agents` 출력) — 즉 "사용법 문서를 읽혀서" 쓰게 하는 방식. 이걸 Claude Code
등 에이전트 런타임이 인식하는 **정식 스킬 패키지** 로 제공하자는 것:

- Claude Code 스킬 형식: `SKILL.md`(frontmatter: name/description) + 필요
  시 참조 파일. 프로젝트 스킬(`.claude/skills/openguild/`) 또는 배포용
  플러그인 형태.
- 스킬 트리거 조건(description)에 "openguild 길드에서 작업/퀘스트 관리"
  류를 명시해, 에이전트가 길드 디렉토리에서 작업할 때 자동 로드되게.
- 내용은 AGENTS_OPENGUILD_USAGE.md 의 워크플로(상태 전이, 브랜치 규칙,
  댓글 작성법, .guild 직접 편집 금지 등)를 스킬 구조로 재편 — 문서 전문을
  통째로 넣지 말고 단계/규칙 중심으로 압축, 상세는 `openguild docs` 명령
  참조로 위임.
- 배포 방식 결정 필요: (a) repo 에 스킬 파일 포함 + installer 가
  ~/.openguild 나 프로젝트에 설치, (b) `openguild skill install` 같은 CLI
  서브커맨드 신설, (c) 문서로 설치법만 안내.
- docs 퀘스트 ID 누출 이슈(별도 퀘스트)와 연동 — 스킬 본문도 이 repo 의
  퀘스트 ID 를 담지 않아야 함.

착수 전 배포 방식/대상 런타임(Claude Code 만? 기타 에이전트?) 확인 필요.

사용자 요청: "스킬 업데이트 — USAGE 형태로 제공하는게 아닌 진짜 스킬을
제공하도록."

## 해석 (등록 시점)

현재 에이전트 연동은 `docs/AGENTS_OPENGUILD_USAGE.md`(+ `openguild docs
agents` 출력) — 즉 "사용법 문서를 읽혀서" 쓰게 하는 방식. 이걸 Claude Code
등 에이전트 런타임이 인식하는 **정식 스킬 패키지** 로 제공하자는 것:

- Claude Code 스킬 형식: `SKILL.md`(frontmatter: name/description) + 필요
  시 참조 파일. 프로젝트 스킬(`.claude/skills/openguild/`) 또는 배포용
  플러그인 형태.
- 스킬 트리거 조건(description)에 "openguild 길드에서 작업/퀘스트 관리"
  류를 명시해, 에이전트가 길드 디렉토리에서 작업할 때 자동 로드되게.
- 내용은 AGENTS_OPENGUILD_USAGE.md 의 워크플로(상태 전이, 브랜치 규칙,
  댓글 작성법, .guild 직접 편집 금지 등)를 스킬 구조로 재편 — 문서 전문을
  통째로 넣지 말고 단계/규칙 중심으로 압축, 상세는 `openguild docs` 명령
  참조로 위임.
- 배포 방식 결정 필요: (a) repo 에 스킬 파일 포함 + installer 가
  ~/.openguild 나 프로젝트에 설치, (b) `openguild skill install` 같은 CLI
  서브커맨드 신설, (c) 문서로 설치법만 안내.
- docs 퀘스트 ID 누출 이슈(별도 퀘스트)와 연동 — 스킬 본문도 이 repo 의
  퀘스트 ID 를 담지 않아야 함.

착수 전 배포 방식/대상 런타임(Claude Code 만? 기타 에이전트?) 확인 필요.

## 실제 진행 (구현 완료)

조사 결과 배포 인프라 일부(`.claude/skills/openguild-workflow/`)는 이미
있었으나, 이건 "openguild 프로젝트 자체를 개발하는 에이전트"용이었다.
사용자 피드백으로 스킬을 두 종류로 분리:

- `openguild-workflow`(이 repo 개발자용, 퀘스트 ID 허용): 정본을
  `.agents/skills/`(크로스 에이전트 컨벤션)로 옮기고 `.claude/skills/`
  는 그 문서를 가리키는 포인터로 축소. 커밋 형식의 작성자 하드코딩
  (Codex/Claude Fable 5) 제거 — 에이전트가 자기 이름을 채우도록 지시문화.
- `openguild`(외부 배포용, 퀘스트 ID 금지, 신규): `skills/` 에 Claude Code
  plugin marketplace 구조(`.claude-plugin/marketplace.json` +
  `openguild-plugin/skills/openguild/SKILL.md`)로 작성. GUI 시동 시
  `~/.openguild/skill-marketplace/` 로 동기화(`sync_bundled_docs` 패턴
  재사용), `tauri.conf.json bundle.resources` 에도 포함. README(영/한)에
  `/plugin marketplace add` 등록 방법 안내.

## 테스트 방법

1. `.agents/skills/openguild-workflow/SKILL.md` / `.claude/skills/
   openguild-workflow/SKILL.md` 에 Codex/Claude Fable 5 하드코딩이
   사라지고, 정본/포인터 구조가 맞는지 육안 확인.
2. `skills/openguild-plugin/skills/openguild/SKILL.md` 에 이 repo 퀘스트
   번호(DEV-xxx/BUG-xxx)가 없는지 grep 확인(완료 — 예시 ID 형식 설명
   문구만 있고 실제 참조 없음).
3. 실제 Claude Code 에서 `/plugin marketplace add ./skills` →
   `/plugin install openguild-plugin@openguild` 로 로드되는지 확인
   (marketplace.json/plugin.json 은 JSON 파싱 통과 확인 완료, 실제 Claude
   Code 등록까지는 로컬에서 직접 확인 필요).
4. GUI 실행 시 `~/.openguild/skill-marketplace/` 로 동기화되는지 확인
   (`sync_bundled_skill_marketplace` 단위 테스트로 로직 검증 완료, 실제
   설치 빌드에서의 종단 확인은 별도).
5. `cargo test -p openguild-core` (356 passed), `cargo clippy -p
   openguild-core --all-targets -- -D warnings`, `cargo build -p
   openguild-gui` 전부 통과 확인 완료.

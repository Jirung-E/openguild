원격 모드(`--remote`)의 `quest list` 가 **`--tag` · `--search-comments` · `--search-attachments` 를 서버로 보내지 않는다** — 걸러지지 않은 전체가 나온다(2026-10-21, DEV-446 하며 발견).

- 재현(시험용 길드 사본 + develop 서버): `quest list --tag keepme --count` 로컬 1, 원격 **836**(전부).
- 원인: CLI 의 `list_query_to_querystring` 이 `ListQuery` 필드를 하나씩 옮겨 적는데, 나중에 생긴 세 필드(REQ-027 후속 태그, REQ-010 검색 범위)를 빠뜨렸다. 서버는 셋 다 받는다.
- 에이전트가 원격으로 "태그 X 인 것" 을 물으면 조용히 전부를 받는다 — 오류가 없어 알아채기 어렵다.

## 고칠 것

- 세 필드를 싣는다.
- 다음에 필드가 생겨도 빠뜨리지 않게: 모든 필드를 채운 `ListQuery` 가 빠짐없이 실리는지 보는 시험(구조체 분해로 필드가 늘면 컴파일이 깨지게).

## 고침 (2026-10-21)

- `list_query_to_querystring` 이 `ListQuery` 를 **빠짐없이 분해**한다 — 필드가 늘면 그 자리에서 컴파일이 깨진다. 태그 · 검색 범위(댓글 · 첨부)를 싣는다. 나머지 순서는 그대로.
- 시험 `querystring_carries_tag_and_search_scope`. `just test` 통과.
- 시험용 길드 사본 + develop 서버, 로컬 = 원격: `--tag keepme` 1 = 1(전엔 836), `--search 자동 --search-comments` 268 = 268, `--search png --search-attachments` 17 = 17.

## 테스트 방법

- 서버를 띄운 채 `openguild --remote <주소> quest list --tag <있는 태그> --count` 가 로컬 수와 같으면 정상.

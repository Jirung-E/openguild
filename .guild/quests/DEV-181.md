댓글별(per-comment) 첨부 — 본문/캠페인 첨부와 별개로, 각 댓글 entry 아래에 그 댓글 전용 첨부 목록을 표시/추가. (본문 첨부 ≠ 댓글 첨부, 댓글끼리도 각자 분리. admin BUG-083 #4) BUG-083 잠정 조치로 현재 댓글은 미디어 인라인만 허용 + 첨부 버튼 제거 상태. 본 기능 범위: (1) 저장 모델 — entry_id 별 첨부. 사이드카 {slug}.comments.attachments.json (entry_id -> [{path,name}]) 제안, 기존 {slug}.attachments.json 패턴과 일관. (2) core ops(list/add/remove per-comment attachment) + reindex 캐시. (3) server route. (4) GUI — 각 댓글 아래 첨부 표시 + 댓글 폼에 첨부 버튼 복원(섹션이 아니라 그 댓글로). (5) Ctrl+Z 완전 수정 — replaceInTextarea 의 ta.value 직접 대입이 undo 스택을 깨므로 placeholder 치환도 execCommand 로. quest/campaign 양쪽 scope 지원.

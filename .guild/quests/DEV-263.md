사용자 보고: docs 에 있는 문서가 퀘스트 번호를 언급하는데, 이 문서가
`openguild docs` 로 출력되면 문제가 될 수 있다.

## 배경

- BUG-016/DEV-248: `--help` 출력에 이 repo 의 퀘스트 ID(DEV-NNN 등)가 새면
  다른 길드에서 CLI 를 쓰는 에이전트가 그 ID 를 자기 길드의 퀘스트로
  오인함 — clap doc 주석에 ID 금지 + help-leak 회귀 테스트로 차단됨.
- 그런데 `openguild docs <name>` 는 리포의 md 문서를 컴파일 타임 embed 해
  그대로 stdout 출력(DEV-248) — 같은 누출 경로가 문서 본문에 열려 있음.

## 조사 결과 (2026-07-17, 퀘스트 ID 언급 줄 수)

- docs/AGENTS_OPENGUILD_USAGE.md: 34줄 (docs agents 로 출력)
- docs/USAGE.md: 8줄 (docs usage)
- README.md: 16줄 (docs readme)
- CHANGELOG.md: 50줄 (docs changelog)

## 방향 (착수 시 결정)

- CHANGELOG 는 성격상 퀘스트 ID 가 본문의 핵심 — 제거 불가. 선택지:
  (a) docs 출력에서 changelog 제외, (b) 출력 시 ID 마스킹/치환,
  (c) CHANGELOG 는 예외로 두고 나머지 3개 문서만 ID-free 로 재작성.
- AGENTS_OPENGUILD_USAGE.md 가 가장 중요(에이전트가 직접 읽는 문서) —
  "예: DEV-001" 식 예시는 가상의 접두(EX-001 등)나 플레이스홀더로 교체.
- 회귀 방지: help-leak 테스트와 동일한 find_quest_id 스캔을 embed 문서에도
  적용하는 테스트 추가(예외 문서 allow-list 지원).

# [skill] 에이전트가 도서관/댓글 확인 시 CLI 명령 대신 .guild 파일을 직접 뒤짐

사용자 보고 2건 (같은 원인이라 하나로 묶음):
- 도서관 문서 확인해보라니까 `library list` 명령을 안 쓰고 직접 파일을 뒤짐.
- 댓글 확인도 명령어를 안 씀.

## 원인

스킬(개발용 `.agents/skills/openguild-workflow` / 배포용
`skills/openguild-plugin/.../openguild`)에 **쓰기**에 대한 "직접 편집
금지 — CLI 사용" 규칙은 명확한데, **조회(read)** 는 규칙이 없어 에이전트가
습관적으로 파일 grep/Read 로 우회했다. 파일 직접 조회는 사이드카/캐시
구조를 우회해 반응·토론 상태·정렬 등 사용자에게 보이는 정보와 다른
결과를 읽게 되고, dogfooding 원칙에도 어긋난다.

DB 투영 불변식(BOOK-001) 구현 — 역류 경로 A2. DEV-242 대체.

reindex 의 counter self-heal([reindex.rs] DEV-242)이 DB 카운터가 파일보다
크면 types/*.toml 에 되쓴다. index.db 는 branch-blind 라, 다른 브랜치에서
오염된 카운터가 현재 브랜치 파일로 역류한다(실사고: 잘못된 브랜치 quest
new → ID 어긋남).

## 수정 방향
DB→파일 역류 제거. 다음 ID 는 **디스크 파일만으로**
`max(파일 카운터, 디스크 실존 최대번호)+1`. 파일 카운터가 실제 최대번호보다
낡았을 때만 파일-로컬 heal(브랜치-safe). DB 카운터는 순수 파생.

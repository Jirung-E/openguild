DEV-205(GUI 전역 다국어 스윕)에서 분리된 후속 — core/cli/server 메시지 다국어화.

DEV-205 는 GUI(Svelte 컴포넌트)에 한정해 완료됨(모듈1~5: Nav/Welcome,
홈/캠페인, Quest List/Board, 퀘스트 상세, 설정/Admin/rules — 전부 locale.ts
t() 사전 기반, 기본 한글 · 언어 토글로 영어 전환).

이 퀘스트는 GUI 가 다루지 않는 나머지 두 영역:

## CLI (core/cli)
- `println!`/에러 메시지 다국어화.
- GUI 처럼 localStorage 로 상태를 못 들고 있으므로 **명시적 선택 옵션**
  필요 — `--locale` 플래그 또는 `OPENGUILD_LOCALE` 환경변수 같은 설계 검토.
- clap doc 주석(`///`)에 quest ID 넣지 말 것 — help-leak 테스트 회귀 주의
  (guild rule: `openguild-cli-help-no-quest-ids` 유사 패턴 기존 확인).

## Server (server)
- API 응답 메시지(에러 등)의 언어를 **요청 헤더 또는 쿼리 파라미터**로
  받을지 설계.
- GUI 가 이미 자체 locale 을 갖고 있으므로, 프론트가 요청 시 언어를
  전달하고 서버가 그에 맞춰 메시지를 반환하는 흐름이 자연스러움(Accept-
  Language 헤더 활용 검토).

## 선행 확인 필요
- 사용자 재확인(DEV-205 초기 댓글, 2026-07-05): "cli, server 에도 언어
  변경 명령 필요" — 이 요청이 본 퀘스트의 근거.
- 착수 전 설계 결정(CLI 옵션 형태, 서버 언어 전달 방식)을 사용자와
  확인 후 진행 권장 — 범위가 크고 기존 CLI 사용 패턴(agent 파싱 등)에
  영향 가능.

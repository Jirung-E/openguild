## 구현 (간단)

`drift::detect_drift` 의 시간 임계값을 `index.db` 파일 mtime 에서 `app_meta.last_indexed_at` ISO 마커로 교체. 마커 없거나 빈 값이면 epoch fallback → 모든 파일 fresh → 첫 부트스트랩 reindex 강제.

- migration 0014: `app_meta(key, value)` 테이블 + 빈 마커 seed.
- `reindex()` 종료 시점에 마커 = NOW UPSERT.
- 신규 테스트 2: 마커 기반 비교 + 빈 마커 부트스트랩.

## 테스트 방법

### A. 부트스트랩 (새 빌드 첫 실행)

1. 빌드 + 실행 → GUI 시작.
2. 콘솔 (stderr) 에 `[openguild-gui] drift detected → auto reindex: ... quests / ... deps / ... campaigns` 로그가 한 번 찍혀야 함.
3. Welcome / Board 가 정상 표시.

### B. 외부 편집 감지

1. GUI 켜둔 상태에서 임의 quest mutation (예: 노드 드래그) 한 번. 마커 갱신.
2. GUI 종료.
3. 다른 에디터로 `.guild/quests/{SLUG}.md` 의 `title` 또는 description 수정 + 저장.
4. GUI 재시작.
5. 콘솔에 `drift detected → auto reindex` 로그가 다시 찍혀야 함.
6. Board / Detail 에서 수정한 내용이 즉시 보여야.

### C. 깨끗할 때 (불필요 reindex 안 일어남)

1. 두 번째 GUI 재시작 (편집 없이).
2. 콘솔에 drift 로그가 **안 찍혀야** (마커 ≥ file mtime).

### D. 신규 파일

1. GUI 종료 상태에서 `cp .guild/quests/DEV-001.md .guild/quests/DEV-999.md` (또는 신규 작성).
2. GUI 재시작 → 자동 reindex → Board 에 DEV-999 가 나타나야.

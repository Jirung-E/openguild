릴리스 실행 시 Actions 경고:

```
Warning: Node.js 20 is deprecated. The following actions target Node.js 20 but
are being forced to run on Node.js 24: actions/upload-artifact@v4.
```

## 조사 — 각 액션의 실제 런타임 (`action.yml` 의 `runs.using` 확인)

| 액션 | 현재 ref | using | 조치 |
|---|---|---|---|
| actions/checkout | v5 | node24 | 그대로 |
| actions/setup-node | v5 | node24 | 그대로 |
| actions/cache | v5 | node24 | 그대로 |
| Swatinem/rust-cache | v2 | node24 | 그대로 |
| dtolnay/rust-toolchain | stable | composite | 해당 없음 |
| **actions/upload-artifact** | **v4** | **node20** | **→ v7** |
| **softprops/action-gh-release** | **v2** | **node20** | **→ v3** |

경고 문구에는 upload-artifact 만 나왔지만 `action-gh-release@v2` 도 node20 이라
같이 걸린다(릴리스 잡에서만 실행돼 경고 목록에 늘 보이지는 않는다).

## v5 로 올리면 안 고쳐진다 (함정)

`upload-artifact@v5` 는 릴리스 노트에 "supports Node v24" 라고 적혀 있지만
`runs.using` 이 **여전히 node20** 이다("v5 had preliminary support for Node.js
24, however this action was by default still running on Node.js 20" — v6 노트).
경고를 없애려면 **v6 이상**이 필요하다. v6 은 러너 2.327.1+ 요구(GitHub-hosted
는 충족), v7 은 그 위에 `archive` 파라미터(옵트인)와 내부 ESM 전환만 추가돼
기존 사용법과 호환 — 최신인 v7 으로 간다.

`action-gh-release@v3.0.0` 은 런타임 전환만 있는 메이저(입력 변경 없음):
*"3.0.0 is a major release that moves the action runtime from Node 20 to Node 24."*

## 수정

- `actions/upload-artifact@v4` → `@v7` (check.yml 1곳, release.yml 4곳)
- `softprops/action-gh-release@v2` → `@v3` (release.yml 2곳)
- 두 워크플로 헤더에 근거 주석 — 특히 "v5 는 여전히 node20" 함정.

입력 호환 확인(액션 `action.yml` 의 inputs 대조):
- upload-artifact v7: `name`/`path`/`if-no-files-found`/`retention-days` 모두 존재.
  `archive` 는 신규 옵트인(기본 true = 기존 동작).
- gh-release v3: `files`/`body_path`/`append_body`/`draft`/`prerelease`/
  `fail_on_unmatched_files` 모두 존재. v3.0.0 은 런타임 전환만 있는 메이저.

## Test plan

1. develop 푸시 → `check` 워크플로 실행 후 **로그에 Node.js 20 deprecation
   경고가 없는지** 확인(upload-artifact 를 쓰는 `release notes extraction` 잡).
2. artifact 업로드가 정상인지 — `release-notes-preview` 가 이전과 같이 올라오고
   내려받아 열리는지.
3. 다음 릴리스(태그 push) 때 `action-gh-release@v3` 로 릴리스 생성/첨부가
   정상인지 + 경고가 사라졌는지. 첨부물: setup.exe, .sig, latest.json,
   deb/rpm/AppImage.

체크리스트를 고쳐도 인덱스의 `campaigns.description` 과 `updated_at` 은 그대로라서 생기는 문제.

재현:
1. `campaign new` → `checklist add C-001 zebra` → `campaign start C-001`
2. `checklist remove C-001 1` — 본문이 비게 된다
3. `campaign update C-001 --title x`
→ 파일에 `- [ ] zebra` 가 되살아나고 reindex 뒤 목록에도 나온다.

원인: `write_campaign_file(.., false)` 가 파일 본문이 비어 있으면 낡은 DB 값으로 되돌린다. 체크리스트를 고치는 세 함수가 DB 의 본문을 갱신하지 않기 때문이다.

같은 뿌리: `body:` 쿼리가 체크리스트 변경 뒤 낡은 값을 보고, `updated` 도 파일과 달리 안 바뀐다(reindex 하면 맞아진다).
v0.5.3 에도 있는 문제.

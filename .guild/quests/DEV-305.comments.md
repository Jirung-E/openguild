## 수정 (2026-08-01, macOS 실기 발견)

`settings/+page.svelte` 의 "업데이트 자동 확인" 켜기/끄기 버튼 둘 다
다른 segmented-toggle(테마/에디터 설정 등)과 달리 `class="th-btn"` 베이스
클래스가 빠져 있었음(`class:active` 만 있음) — 그래서 켜짐/꺼짐 어느 쪽도
시각적으로 구분이 안 됨(둘 다 밋밋한 기본 버튼). `class="th-btn"` 추가로
수정.

## 재검증 방법
1. 설정 > 정보 탭에서 "업데이트 자동 확인" 켜기/끄기 버튼 중 현재 상태에
   해당하는 쪽이 배경/글자색으로 강조돼 보이는지 확인.
2. 클릭해서 전환 시 강조가 즉시 반대쪽으로 옮겨가는지 확인.

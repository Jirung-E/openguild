사용자 지적 (2026-08-01): 웹/앱 둘 다 접힌 메뉴 동작이 잘못됨.

## 현재 동작 (둘 다 문제)
- 앱: 캠페인 목록/작업기록/태그 목록이 항상 ☰ 메뉴에 고정(맞음). 나머지
  (홈/보드/목록/관리/규칙/도서관)는 창이 좁을 때만 ☰ 로 접힘(맞음).
- 웹: 9개 항목(6개 핵심 + 캠페인/작업기록/태그)이 전부 같은 우선순위로
  너비 기반 접힘 계산에 들어가 있어서, 창이 넓으면 캠페인 목록 등이
  메뉴바에 그냥 나열됨 — 항상 접혀 있어야 하는데 그렇지 않음.

## 요구 사항
1. 캠페인 목록/작업기록/태그 목록: **항상** 접힌 메뉴 안(앱/웹 둘 다) —
   창이 넓어져도 메뉴바로 안 나옴.
2. 나머지(홈/보드/목록/관리/규칙/도서관): 창이 좁아져 표시 곤란할 때만
   접힌 메뉴로.
3. 접힌 메뉴 버튼 위치: 앱은 현재 위치 그대로, **웹은 맨 왼쪽으로 이동**.

## 참고
TitleBar.svelte(앱)는 이미 정확히 구현돼 있음(하드코딩 3개 + 응답형
navOverflowItems 스토어를 구분선으로 분리) — 참고 패턴으로 삼을 것.
Nav.svelte(웹)만 수정 필요 — navItems 를 "핵심 6개(측정 대상)" +
"항상 접힘 3개(측정 제외)" 로 분리.

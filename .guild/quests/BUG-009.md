## 증상

Quest Board 의 lane header / toolbar 에서 1/2/3열 선택해도 페이지 새로고침
(브라우저 Ctrl+R) 또는 GUI 재시작 시 다시 2 로 reset.

## 원인

`gui/frontend/src/lib/components/QuestBoard.svelte`:
- `globalCols = $state(2)` — 항상 2 로 초기화.
- `laneCols = sorted.map(() => 2)` — buildLaneDivs 마다 2 로 재설정.
- 영속 저장 (localStorage / SQL) 없음. `gridSnap` 만 영속화 되어있고 cols 는 누락.

## 수정 (2026-05-20)

`localStorage` 에 영속화. status slug 키로 lane 별 저장 (sort_order / id 변경에도
안정 — BUG-002 의 reindex 영향 같은 패턴 회피).

추가된 헬퍼:
- `LANE_COLS_KEY = 'openguild.laneCols'` — `Record<slug, number>` JSON.
- `GLOBAL_COLS_KEY = 'openguild.globalCols'` — 단일 정수.
- `statusSlug(nameEn)` — `"In Progress"` → `"in_progress"` 정규화.
- `loadLaneColsMap` / `saveLaneColsMap` / `loadGlobalCols` / `saveGlobalCols`.

변경된 곳:
- 초기화: `globalCols = $state(loadGlobalCols())`.
- `buildLaneDivs`: `laneCols = sorted.map(s => savedLaneCols[slug] ?? globalCols)`.
  lane select 의 초기 selected 도 그 값.
- `setGlobalCols(cols)`: `saveGlobalCols` + 모든 lane slug 에 같은 값으로
  `saveLaneColsMap`.
- lane 별 `sel.onchange`: 변경 후 `loadLaneColsMap` → 그 slug 만 갱신 →
  `saveLaneColsMap`.

## 영향

- localStorage 사용 — Tauri webview 와 브라우저 모두 동일 동작.
- guild 별 분리 안 함 (현재 한 사용자 한 길드 가정). 멀티-guild 시 별도 quest 로
  guild 식별자 prefix 추가.

## 회귀

- 기존 `gridSnap` 영속화 그대로.
- localStorage 비어있으면 globalCols=2 default.
- status name_en 변경 시 새 slug 로 매핑 — 이전 값 잃을 수 있음 (rare event).

namespace 방식 동의 — 예약 prefix 강제보다 좋은 방향입니다. 충돌을 "금지"가 아니라 "구분"으로 푸는 것이라 사용자 자유(타입 prefix 커스텀)를 안 뺏습니다.

## 설계 제안 (구체화)

- 문법: `[[namespace:id]]` — `quest:` / `campaign:` / `rules:` / `library:` (+ 짧은 alias `q:` `c:` `r:` `lib:` 검토).
- **namespace 는 선택**: `[[DEV-001]]` 처럼 무접두 링크도 계속 동작 — 무접두 해석 우선순위를 quest > campaign > library > rules 로 고정(충돌 시에만 의미). 매번 접두어 강제는 타이핑 비용이 커서 비권장.
- 자동완성: `[[` 안에서 namespace 접두 입력 시 해당 종류만 필터(`[[rules:` → 규칙만). 무접두 입력은 전체에서 매칭하되 삽입 시 **충돌하는 ID 에만** 자동으로 접두 부착(모호성 있는 경우만 명시).
- 렌더: 링크 텍스트는 접두 없이 표시(툴팁에 종류) — 본문 가독성 유지. 원문에는 접두 보존.
- 기존 본문의 무접두 링크는 전부 하위호환(우선순위 해석).

## 무엇이 불편한가

플러그인의 **시험 파일(`*.test.rhai`)만 고쳐도 동의가 풀린다.** 주석 한 줄을 더해도 목록이
"동의 대기 — 안 돕니다" 로 바뀐다.

```
$ echo "// 주석" >> .guild/plugins/deleted-audit/main.test.rhai
$ openguild plugin list
· deleted-audit … (동의 대기 — 안 돕니다)
```

## 왜

동의 지문은 **폴더의 모든 파일**을 본다([[DEV-381]]). 정의가 지목해 실행하는 코드가 바뀌면
다시 물어야 하니 맞는 규칙인데, [[DEV-412]] 가 들여온 시험 파일은 **돌지 않는 파일**이다
(`scripts` 에 안 적고, `plugin test` 로만 부른다).

## 무엇을 정해야 하나

- 시험 파일을 지문에서 뺄까? 뺀다면 "안 도는 파일" 을 무엇으로 판정하나 —
  `*.test.rhai` 라는 이름만으로 충분한가(그 이름을 `scripts` 에 적으면 도는 코드가 된다).
- 같은 논리로 README·이미지 같은 곁다리 파일도 뺄 수 있다. 어디까지 뺄지 선을 그어야 한다.
- **조심할 것**: 지문에서 빼는 파일은 "바뀌어도 안 묻는 파일" 이 된다. 시험 파일에 비밀값을
  적어 두는 사람이 있을 수 있고, `import` 로 끌어다 쓰면 도는 코드가 될 수도 있다.

## 테스트 방법

- 시험 파일만 고치면 동의가 유지된다.
- 시험 파일을 `scripts` 나 `import` 로 끌어 쓰면 다시 묻는다(도는 코드가 됐으므로).
- 정의·스크립트·옆 파일을 고치면 지금처럼 다시 묻는다.

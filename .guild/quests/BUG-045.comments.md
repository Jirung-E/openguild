## 변경 (옵션 A — 즉시 가능)

`gui/frontend/src/lib/api/updater.ts` 의 `checkForUpdate` 의 catch 에서 raw error → 사용자 친화 메시지 매핑.

## 분류

| 케이스 (raw 키워드) | 메시지 |
|---------------------|--------|
| `404` / `not found` | "릴리즈가 아직 없거나 endpoint URL 이 잘못됐습니다. (GitHub Releases 에 latest.json 이 attach 되어 있어야 합니다.)" |
| `network` / `fetch` / `timeout` / `connection` / `dns` | "네트워크 연결을 확인해 주세요." |
| `signature` / `signing` / `pubkey` | "릴리즈의 서명 검증에 실패했습니다. (public key 가 잘못됐거나 release 의 .sig 파일이 누락 / 손상.)" |
| `debug` / `dev` / `untagged` | "개발 빌드에서는 자동 업데이트가 동작하지 않습니다 (서명된 production binary 만 지원)." |
| 그 외 | "업데이트 확인 실패." + 원본 |

모든 경우 원본 message 도 같이 표시 — 디버그 가능.

DB schema-ahead 경고(SchemaAheadBanner)가 화면 상단에 in-flow `<div>` 로
표시돼 타이틀바/메뉴바를 포함한 아래 UI 전체를 밀어낸다. 앱 전역 알림
표준(UpdateBanner 의 우하단 floating toast — position:fixed, layout 안
밀어냄)과 어긋난다.

## 조사 결과
`+layout.svelte` 에 마운트되는 전역 알림 컴포넌트는 3개:
- `SchemaAheadBanner` — in-flow `<div class="banner">`, layout 최상단에
  박혀 다른 UI 를 아래로 밀어냄. **유일한 위반 사례.**
- `UpdateBanner` — `position: fixed; right/bottom` 플로팅 카드. 정상.
- `ToastHost` — `position: fixed; top/right` 플로팅 스택. 정상.

## 해결 방향
SchemaAheadBanner 를 UpdateBanner 와 동일한 플로팅 패턴으로 전환.
- 위치: 우하단(UpdateBanner)과 겹치지 않게 우상단(Toast 영역)이나 다른
  코너 — 두 배너가 동시에 뜰 가능성 낮지만 좌표 충돌 방지 필요.
- 기존 내용(버전 정보, "최신 버전 받기", 닫기)은 그대로 유지, 컨테이너만
  in-flow → position:fixed 로 전환.

BUG-035 의 class:marquee 기반 fix 가 사용자 환경에서 미반영. 인라인 style:mask-image 로 변경 — class 분리 의존성 제거. 캠페인 편집 버튼 위치는 코드상 이미 top-actions 안 — 사용자 빌드 캐시 가능성.

## 수정 (2026-05-27)

### 1) QuestNodeConveyor fade mask 안 사라짐 (재발)
BUG-035 가 `class:marquee={needsMarquee}` + `.conveyor.marquee` CSS 로
fade mask 를 조건부 적용했는데, 사용자 환경에서 fade 가 여전히 표시됨.

가능한 원인:
- Vite HMR 의 CSS 갱신 누락 (간헐적).
- Svelte 의 scoped CSS hash 와 class:marquee 토글 사이 race.
- 사용자가 `npm run tauri build` 로 만든 정적 번들을 테스트 중이라
  HMR 안 됨.

해결: class 의존성 제거. 직접 인라인 `style:mask-image` /
`style:-webkit-mask-image` / `style:cursor` 사용 — `needsMarquee` 가
바뀌면 인라인 style 도 직접 reactive 갱신.

```svelte
<div class="conveyor"
     style:cursor={needsMarquee ? 'grab' : 'default'}
     style:-webkit-mask-image={needsMarquee ? 'linear-gradient(...)' : 'none'}
     style:mask-image={needsMarquee ? 'linear-gradient(...)' : 'none'}>
```

`.conveyor.marquee.dragging` 셀렉터는 드래그 중 슬롯 click 차단용으로만
유지 (별개 동작).

### 2) 캠페인 편집 버튼 위치 (재발)
코드상 이미 `.top-actions` (top-bar 우측) 안에 위치 — `grep btn-edit
campaigns/[slug]/+page.svelte` 결과 1건 (title-row 아님). 빌드 캐시
가능성 — 사용자 환경 완전 재빌드 필요.

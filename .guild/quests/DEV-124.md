DEV-070 으로 후속 퀘스트 (이 quest 를 선행으로 가진 quest 목록) 가 표시되지만, **추가 버튼이 없음**. 추가하려면 그 후속 quest 의 detail 로 이동해 prereq 추가하거나 새 quest 만들고 거기서 prereq 추가 — 흐름이 멀음.

요구사항: "Successors" 섹션에 `+ 추가` 버튼. 클릭 시:
- (옵션 A) 기존 quest 를 후속으로 지정 — combobox 로 선택 → 그 quest 의 prereq 에 본 quest 추가.
- (옵션 B) 신규 quest 를 후속으로 작성 — `NewQuestModal` 띄우되 prereq 가 본 quest 로 prefilled.

두 옵션 모두 또는 신규만 우선 — 디자인 단계 결정. sub-quest 추가 UI 의 패턴 그대로 미러링 가능.

## 관련
- DEV-070: Successors 섹션 표시 (현재).
- sub-quest 추가 UI (구현 완료) — 동일 UX 패턴 재사용.

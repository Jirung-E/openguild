## 기능
Quest Detail 의 "Successors" 섹션 — 이 quest 를 선행으로 가진 quest 들 (역방향 참조).

## 사용
- `/quests/DEV-001` 같은 Detail 페이지 열기.
- "Prerequisites" 섹션 바로 아래 "Successors" 섹션 표시 (있을 때만, 빈 vec 면 섹션 자체 숨김).
- 각 row 클릭으로 그 quest 의 Detail 로 이동.
- 편집은 그 quest 의 Detail 에서 prereq 추가/제거 (역방향 read-only).

## 구현 위치
- `core/src/services/quests.rs::fetch_successors` — `quest_dependencies` 의 prerequisite_id = ? row 의 quest_id 들.
- `QuestDetail.successors: Vec<QuestRow>` 필드.
- `gui/frontend/.../routes/quests/[id]/+page.svelte` 의 새 section.

## 테스트
1. Quest A 생성. Quest B 생성.
2. B 의 Detail 에서 A 를 prereq 로 추가.
3. A 의 Detail 열면 "Successors" 섹션에 B 표시.
4. B 의 "Prerequisites" 에 A 있는지 (양방향 일관).
5. B 를 soft-delete → A 의 successor 에서 사라지는지.
6. B 의 prereq 에서 A 제거 → A 의 successor 에서 사라지는지.

## 자동 검증
core::services::quests 4 테스트:
- `successors_empty_when_no_dependent`
- `successor_contains_dependent_quest`
- `successors_excludes_deleted_quests`
- `get_quest_detail_includes_successors`

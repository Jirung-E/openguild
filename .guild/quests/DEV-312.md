macOS(Apple Silicon)를 지원 플랫폼으로 추가한다.

## 결정 사항 (admin)
- **미서명 배포** — Apple Developer 계정 없이 진행. 첫 실행 시 Gatekeeper 경고가 뜨므로 우회 방법을 문서에 안내한다. 나중에 인증서가 생기면 CI 시크릿만 추가하면 된다.
- **arm64(Apple Silicon) 전용** — macos-14 러너 하나로 빌드. Intel 맥은 대상 외.
- **동작 검증은 admin 이 실제 맥에서** — 나(claude)는 CI 빌드 통과까지만 확인 가능.

## 이미 있는 것 (조사 결과)
- `gui/tauri.macos.conf.json` — `titleBarStyle: "Overlay"` + `hiddenTitle`(네이티브 traffic light 유지).
- 프론트 `utils/platform.ts` 의 `isMacOverlay()`, `TitleBar.svelte` 의 mac 분기(창 버튼 미렌더 + 좌측 여백).
- Rust 의 플랫폼 분기: `titlebar_win`/`titlebar_linux` 와 non-Windows 스텁, `lock.rs` 의 windows/not-windows, Cargo 의 `[target.'cfg(...)'.dependencies]` 게이팅.
- 프론트 단축키는 이미 `ctrlKey || metaKey` 를 쓰거나(보드 줌은 트랙패드 pinch=ctrlKey 규약과 일치) macOS 에서도 성립.

## 비어 있는 것
1. 번들 타깃에 `app`/`dmg` 없음 → macOS 산출물이 안 만들어짐.
2. CI 에 macOS 잡 없음 (release/check 둘 다).
3. updater `latest.json` 에 `darwin-aarch64` 없음. 게다가 현재는 windows 잡이 자기 것만 담아 릴리스에 올리는 구조라, 플랫폼을 추가하려면 **합치는 단계**가 필요하다.
4. 설치 안내(README/USAGE)에 macOS 없음 + Gatekeeper 우회 안내 없음.

## 하위 작업
- 번들/CI: 하위 퀘스트
- updater 매니페스트 합치기: 하위 퀘스트
- 문서: 하위 퀘스트

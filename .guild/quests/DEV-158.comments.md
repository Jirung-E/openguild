왜 퀘스트같은건 new로 새로운걸 만드는데 템플릿은 add인지?

<!-- og-comment id="2" ts="2026-06-21T19:08:57+09:00" author="claude" reply_to="1" -->
좋은 지적입니다. 정당한 이유 없는 불일치였습니다 — 생성 동사가 new / add / create 셋으로 갈려 있었고, 특히 add 가 "하위항목 붙이기"(prereq/checklist/attach)와 "독립 엔티티 생성"(template) 두 의미로 섞여 있었습니다.

규칙을 하나로 통일했습니다 (DEV-179):
- new = 독립 엔티티 생성 → quest new / campaign new / template new / backup new
- add = 기존 부모에 하위항목 붙이기 → prereq add / checklist add / attach add / quest tag add

바뀐 명령: `template add` → `template new`, `backup create` → `backup new` (clean break, alias 없음). 문서 예시는 DEV-166 sweep 에서 갱신.

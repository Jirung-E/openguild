## 개요

`.guild/index.db` 에 직접 raw SQL SELECT 가능하게 하는 별도 명령. 분석 / ad-hoc
조회용. quest list 가 미지원하는 JOIN, GROUP BY, 집계 가능.

```bash
openguild query "SELECT q.id, q.title, COUNT(d.prerequisite_id) AS prereq_count
  FROM quests q LEFT JOIN quest_dependencies d ON q.id = d.quest_id
  WHERE q.deleted_at IS NULL GROUP BY q.id ORDER BY prereq_count DESC LIMIT 5"
```

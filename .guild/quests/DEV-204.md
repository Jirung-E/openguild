Welcome 폴더에서 열기 시 네이티브 폴더 선택 대화상자에 .guild 파일이 안 보여(폴더만 표시) 그 위치에 길드가 있는지 판단 불가. 네이티브 폴더 다이얼로그는 파일 표시 불가라 대안 필요: (a) 폴더 선택 후 .guild 존재를 검증해 명확히 안내(길드 발견: 이름 / 이 폴더엔 길드 없음), (b) .guild 파일을 직접 선택하는 파일 피커 모드 추가(파일이라 보임), (c) 선택 다이얼로그 진입 전 최근 길드/후보 표시. (a)+(b) 권장.

## 최종 결정 — 전체 폐기, DEV-053 원래 동작으로 revert (2026-06-28)

(b) 방향(파일 피커 추가 → 단일 파일 다이얼로그로 전환 → 폴더 다이얼로그
복원 + 보조 링크)으로 여러 차례 반복했으나, admin 이 최종적으로 "revert
해라" — **이 퀘스트가 추가한 모든 변경을 폐기**하고 DEV-053 의 원래 단일
폴더 다이얼로그(`pickFolder`: 마커 있으면 바로 열기, 없으면 인라인
초기화 prompt)로 되돌리기로 결정. `.guild` 마커 파일 직접 선택
(`pickGuildFile`) 기능과 그 보조 링크 UI 는 완전히 제거.

(주: `e0eff2b`(폴더 열기 복원 커밋)는 이 "revert 해라" 댓글보다 *먼저*
커밋됐다 — 즉 그 댓글은 `e0eff2b` 가 이미 적용된 뒤에도 admin 이 여전히
이 방향 전체에 불만족해서 단 것이었다. 처음엔 `e0eff2b` 가 그 댓글에 대한
응답인 줄 잘못 판단해 "이미 해소됨"으로 처리했었음 — 사용자 확인 후
정정.)

길드 열기 안내 문구 정확화(05ba722, "마커는 `.guild/` 폴더 아니라
`이름.guild` 파일")는 정확성 개선이라 별개로 판단해 유지.

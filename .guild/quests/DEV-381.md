## 왜

[[DEV-380]] 이 리뷰 지적 5건을 처리했지만, 32건 중 12건은 세션 한도로 검증이
끊겼고 15건은 관점당 상한에 잘려 있었다. 저널에서 전부 복구해 다시 검증했다.
여기서는 **직접 코드를 열어 확인한 것**부터 고친다.

## 확인한 것 (인라인 확인 — 워크플로 검증과 별개)

**1 (HIGH) — `run` 의 stdin 쓰기가 시한 밖에 있다.** `write_all` 이 `deadline`
루프보다 **앞**이다. 자식이 stdin 을 안 읽고 페이로드가 파이프 버퍼(~64KB)를
넘으면 그 자리에서 영원히 막힌다. 전달 스레드는 **하나**라 그 순간 모든
플러그인이 멈추고 `drain` 도 못 구한다.

**2 (HIGH) — 서버를 Ctrl+C 로 못 끄게 됐다.** [[DEV-379]] 에서 넣은
`with_graceful_shutdown` 에 시한이 없다. 브라우저의 keep-alive 연결 하나가
남아 있으면 무한정 기다리고, `tokio::signal::ctrl_c()` 가 SIGINT 의 기본 동작을
가로챈 뒤라 **두 번째 Ctrl+C 도 안 먹는다.** 내가 만든 회귀다.

**3 (HIGH) — 실패 이벤트가 실제로는 안 나간다.** `emit_post_failed` 의 호출
지점이 **0곳**이다. [[DEV-373]] 이 "실패는 같은 이벤트에 `ok`/`error` 로" 를
확정했는데 코드에 그 결정이 없다. 구독자는 성공만 본다.

**4 (MEDIUM) — 전달 실패를 아무도 못 읽는다.** `PluginRuntime::problems()` 는
있는데 부르는 곳이 없다. GUI 의 `notes` 는 항상 비어 있고, 서버는 안 찍는다.
게다가 장수 프로세스에서 무한히 쌓인다.

**5 (MEDIUM) — `pre:` 가 조용히 안 돈다.** `validate` 는 21종 전부에 대해
`pre:` 구독을 받아주는데 실제로 pre 를 내는 곳은 `comment.added` 와
`quest.deleted` 둘뿐이다. 오타 난 이벤트 이름은 적재 때 잡으면서, 있지도 않은
phase 는 통과시킨다.

**6 (MEDIUM) — `truncate(200)` 이 패닉한다.** 응답 본문 200바이트째가 UTF-8
문자 경계가 아니면 `String::truncate` 가 패닉한다. `catch_unwind` 안이라
길드는 안 죽지만, 500 보고가 패닉 보고로 바뀐다.

## 테스트 방법

- stdin 을 안 읽는 자식에게 큰 페이로드를 보내도 전달 스레드가 안 막힌다.
- 서버가 시한 안에 반드시 종료된다(연결이 남아 있어도).
- mutation 이 실패하면 `ok: false` 와 `error` 가 실린 이벤트가 나간다.
- 전달 실패가 CLI stderr / 설정 화면에 보인다. 목록이 무한히 안 자란다.
- 없는 phase 를 구독하면 적재 때 걸린다.
- 멀티바이트 응답 본문에 패닉하지 않는다.

## 결과

리뷰 32건을 저널에서 전부 복구해 다시 검증했다. [[DEV-380]] 이 6건을 이미
처리했고, 남은 것 중 **직접 확인한 6건 + 워크플로 검증을 통과한 7건**을 고쳤다.
반박된 8건은 안 건드렸다.

### 되돌림 시험 12건 전부 물었다

stdin 쓰기(영영 안 돌아옴) · 태그 미충전 · cascade 이벤트 제거 · 실패 이벤트
제거 · comment.deleted 를 id 만 · 길이 예외 복원 · 스크립트 검사 제거 ·
지문을 스크립트 하나로 · pre phase 검사 제거 · problems 상한 제거 ·
카탈로그 스캔 축소.

서버 종료는 시험 대신 **실측**했다 — keep-alive 연결을 열어 둔 채 SIGINT 를
보내 0.2초 만에 종료하는 것을 확인했다(고치기 전에는 안 끝난다).

### 반박된 8건 (안 고침)

no-op mutation 의 이벤트(실제로는 다 쓴다) · 동의 파일 원자 쓰기(경로가
비현실적) · CLI 유예 2초가 짧다(의도된 비대칭, 조절 가능) · 닫히지 않은 `${` ·
손자 프로세스 · Ctrl+C 등록 실패(그래도 SIGTERM 쪽과 대칭으로 맞춰 뒀다) ·
discussion 끄기의 resolved · 동의 전 파일 읽기.

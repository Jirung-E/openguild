DEV-011 testing 피드백 두 가지: 1) Home / Campaign 페이지들의 badge 모양이 Quest List 의 pill 스타일 (radius 20px + color-mix 18%/40%) 과 달리 각진 border-only. 기존 Quest List 패턴으로 통일. 2) 캠페인 detail 의 본문 편집은 textarea — Quest Detail 의 CodeMirror (라인 번호 + markdown syntax highlighting) 와 통일.

## 구현 (2026-05-25)

### Part 1 — badge 스타일 통일
Quest List (`QuestListItem.svelte`) 의 표준 pill 패턴 (BUG 이전부터 사용):
```css
.badge {
    flex-shrink: 0;
    padding: 0.15rem 0.55rem;
    border-radius: 20px;
    font-size: 0.75rem;
    font-weight: 500;
    background: color-mix(in srgb, var(--c) 18%, transparent);
    color: var(--c);
    border: 1px solid color-mix(in srgb, var(--c) 40%, transparent);
}
```

신규 페이지들의 badge / status 표시를 위 패턴으로:
- `lib/components/Home.svelte` 의 `.badge`.
- `routes/campaigns/+page.svelte` 의 `.status` + `.status-active` / `.status-done`.
- `routes/campaigns/[slug]/+page.svelte` 의 `.status-badge` 와 `.badge` (linked quest).
- `routes/quests/[id]/+page.svelte` 의 `.campaign-badge` (Campaigns 섹션) +
  `.badge.status.status-active|done`.

각 status badge 는 `--c` CSS 변수로 색 주입 — green (`#56d364` active) /
gray (`#8b949e` done).

`CampaignCardSlider.svelte` 의 `.slug` 는 카드 안의 작은 메타 라벨 (badge
아님) — 변경 안 함.

### Part 2 — 캠페인 본문 편집기 통일
`routes/campaigns/[slug]/+page.svelte` 의 본문 편집을 textarea → CodeMirror
(Quest Detail 패턴):
- `EditorView` + `basicSetup` + `markdown()` + `oneDark` 동일.
- `editorContainer` div + `bind:this`.
- `initEditor()` / `destroyEditor()` 패턴 + `tick()` 후 init.
- DEV-057 의 height 영속화: `localStorage.openguild.questEditorHeight`
  공유 (Quest Detail 과 동일 키 — 사용자가 한 번 조정한 높이가 두 페이지
  모두 적용).
- `ResizeObserver` 가 사용자 drag 감지 → debounce 250ms 후 저장.
- `.editor-wrap` CSS (resize: vertical, max-height 90vh) 동일.

`saveBody()` 가 `editorView.state.doc.toString()` 으로 내용 추출. cancel /
slug 변경 / save 모든 path 에서 `destroyEditor()` 호출.

표시 (rendered markdown) 는 그대로 — 기존 `.md` CSS 가 헤더 사이즈 명확
(브라우저 기본 h1/h2/h3) + 앱 테마 일체감.

### 검증
- `npm run check` → 0 errors / 1 pre-existing warning.
- `npm test` → 116.
- `npm run build` → ✔.
- 라이브: 캠페인 편집 진입 → CodeMirror (라인 번호 + 마크다운 하이라이팅) +
  드래그 핸들로 크기 조절. 저장 시 본문 보존. badge 모양 Quest List 와 동일.

### 의식적 결정 (변경 안 함)
- Quest Detail 의 `.md-body` 헤더 크기 (h1 1.2rem 등) 는 그대로. 사용자
  명시는 "캠페인 본문 표시가 좋다" 였고 quest detail 표시 비교 / 변경
  요청 없었음. 짧은 task 본문 컨텍스트라 컴팩트 스타일 의도일 수도.
  필요 시 별도 quest.

## 증상

퀘스트 보드에서 **두 노드가 가까우면 연관관계 화살표가 노드 안으로 들어간다.**
선이 노드 경계에서 끝나지 않고 안쪽에서 끊기며, 화살촉도 노드에 가려진다.

## 원인 (조사 완료)

`utils/quest-board-render.ts` 의 `boardEdgePath()` 에서 선 끝을 노드 경계까지
물리는 `inset` 계산에 `dist / 3` 클램프가 들어 있다:

```js
const inset = Math.min(
    nodeWidth / 2 / |ux|,    // 노드 경계까지 필요한 거리
    nodeHeight / 2 / |uy|,
    dist / 3                 // ← 가까우면 이게 이긴다
);
```

노드가 멀면 `dist/3` 가 커서 무해하지만, **가까우면 노드 반폭보다 작아진다.**

예 — 가로로 이웃한 노드(폭 284, 간격 40):

| | 값 |
|---|---|
| 중심 간 거리 | 324 |
| 노드 경계까지 | **142** |
| `dist / 3` | **108** ← 채택됨 |

결과적으로 끝점이 노드 경계보다 **34px 안쪽**에 찍히고, 화살표 마커는 경로 끝에
그려지므로 노드에 파묻힌다.

## 왜 그 클램프가 있었나 (추정)

노드가 겹치거나 아주 가까울 때 양끝 inset 합이 거리를 넘으면 **경로가 뒤집혀**
화살표가 반대로 그려진다. `dist/3` 은 그걸 막으려던 장치로 보인다. 그래서 단순
제거하면 안 되고, 뒤집힘은 따로 막아야 한다.

## 수정 방향

경계까지의 inset 은 그대로 쓰되, **뒤집힘만** 따로 막는다:

```js
const boundary = min(폭/2/|ux|, 높이/2/|uy|);
// 양끝 합이 거리를 넘으면 뒤집힌다 — 화살촉이 보일 최소 길이를 남긴다.
const inset = min(boundary, max(0, (dist - MIN_VISIBLE) / 2));
```

- 멀 때: `boundary` 가 선택 → **기존과 동일**(회귀 없음).
- 가까울 때: `boundary` 를 그대로 써서 경계에 정확히 붙는다.
- 겹칠 때: 짧은 선만 남고 뒤집히지 않는다.

## 테스트 방법

1. 보드에서 선행 관계가 있는 두 노드를 **바짝 붙여** 놓고 화살표가 노드 밖
   경계에 그려지는지.
2. 멀리 떨어뜨렸을 때 기존과 같은지(회귀).
3. 노드를 겹쳐 놓았을 때 화살표가 반대로 뒤집히지 않는지.
4. 서브퀘스트 화살표(`arrow-sub`)도 같이 확인.

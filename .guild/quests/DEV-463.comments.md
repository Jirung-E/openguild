**새로 남는 이력**(화면의 변경 이력 · `campaign history` · `.guild/history/C-NNN.jsonl`):

| 이름표 | 값 | 언제 |
|---|---|---|
| 체크리스트 추가 | 항목 글 | 항목을 더할 때 |
| 체크 / 체크 해제 | 항목 글 | 바뀔 때만(이미 체크된 것을 다시 체크하면 안 남음) |
| 체크리스트 삭제 | 항목 글 | 지울 때 |
| 체크리스트 모두 완료 | `2/2` | 모두 체크된 **순간** — 마지막 칸을 체크할 때, 체크 안 된 마지막 항목을 지울 때, 본문을 직접 고쳐 다 체크할 때 |
| 연결 퀘스트 모두 완료 | `3/3` | 연결된 퀘스트가 모두 완료가 된 **순간** — 마지막 퀘스트를 완료할 때, 남은 미완료 퀘스트를 떼어 낼 때 |

- '완료'는 캠페인 진행 막대와 같은 기준입니다(완료로 치는 상태, 지운 퀘스트는 빼고).
- 되돌렸다가 다시 완료하면 그 순간이 또 남습니다.
- 퀘스트 상태를 바꿀 때 그 퀘스트가 든 캠페인들도 함께 잠급니다. 이력 파일을 동시에 쓰지 않게 하기 위해서입니다.
- 체크리스트를 본문에서 직접 고친 경우에는 '모두 완료' 순간만 남깁니다. 항목별 체크 · 해제는 체크 버튼으로 바꿀 때 남습니다.

**시험:** core 3개(체크리스트 흐름, 본문 직접 수정, 연결 퀘스트 완료 · 떼어 내기 · 되돌렸다 다시 완료).

**확인:** scratch 길드에서 CLI와 화면 모두 봤습니다. 화면에는 `[연결 퀘스트 모두 완료] 1/1`처럼 보입니다.

**테스트 방법:** 캠페인에서 체크리스트를 체크하고, 연결된 마지막 퀘스트를 완료로 옮긴 다음, 캠페인 아래 '변경 이력'을 펼쳐 보세요.

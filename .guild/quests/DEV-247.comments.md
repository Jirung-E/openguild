admin 추가 요청: [[DEV-229]] 의 서버 설정 파일(openguild-server.toml)도 ~/.openguild/ 를 탐색 경로에 포함할 것 — 현재 탐색(--config 명시 / exe 옆 / cwd)에 `~/.openguild/openguild-server.toml` 추가(우선순위: --config > cwd > exe 옆 > ~/.openguild).

frontend dist(서버가 호스팅하는 html/js)는 이전 대상 아님 — 사용자 데이터가 아니라 서버 바이너리와 버전이 결합된 프로그램 자산이라, ~/.openguild 에 두면 exe 업데이트 후 낡은 dist 가 남아 미묘한 버전 불일치를 만든다. 설치 폴더 유지 + 특수 배치는 config 의 frontend_dist 로 지정하는 것으로 충분(admin 논의 확정).

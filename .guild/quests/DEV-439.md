## 한 것 (2026-10-11)

레인 열 수와 정렬(Arrange) 열 수의 기본값을 2 → 3. `QuestBoard.svelte` 에 흩어져 있던 `?? 2`
일곱 곳을 상수 `DEFAULT_COLS = 3` 하나로 묶었다.

**이미 고른 값은 그대로다** — 툴바의 열 수와 레인별 열 수는 길드별로 기억되므로, 전에 2 를 골라 둔
길드는 계속 2 다. 고른 적 없는 길드(새 길드 · 새 레인)만 3 으로 시작한다.

확인(헤드리스 WebKit, 빈 OPENGUILD_HOME + 길드 사본): 레인 열 수 선택 8개 모두 3, 툴바 "3열",
정렬 후 레인마다 3열로 놓임. 페이지 오류 없음.

## 테스트 방법

1. 열 수를 바꾼 적 없는 길드(또는 새 길드)에서 보드를 연다 → 툴바와 레인 머리의 열 수가 3 이다.
2. 정렬을 누르면 레인마다 3열로 놓인다.
3. 열 수를 2 로 바꾸고 앱을 다시 열면 2 가 유지된다(고른 값은 덮어쓰지 않는다).

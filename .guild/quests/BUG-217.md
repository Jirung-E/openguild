모바일(375~412px)에서 QuestBoard 두 가지 렌더링 문제:
1. '보드 설정' 모달이 min-width 30rem 고정이라 화면 밖으로 넘침.
2. 레인 헤더의 ⚙(레인별 설정) 펼칠 때, 좁은 zoom 배율의 헤더 폭 안에 열/정렬
   컨트롤을 인라인으로 넣던 구조라 `.lane-hdrs{overflow:hidden}`에 잘려 사라짐.

수정 (QuestBoard.svelte):
- .hide-modal 폭을 `min(40rem, 100vw - 2rem)`로 clamp + 내부 테이블은
  overflow-x:auto 래퍼로 감쌈.
- 레인 설정 컨트롤을 헤더 아래로 뜨는 별도 팝오버(.lane-settings-pop)로 분리,
  화면 오른쪽 끝이면 좌우 반전(pop-right), 열려있는 동안 z-index 를 상단
  toolbar 위로 올림(:has() 사용).

헤드리스 크롬(375/412px, 라이트/다크)으로 검증 완료. 사용자 실기기(폰) 확인은
아직.

## 테스트 방법
1. 폰(또는 브라우저 폭 400px 이하)에서 퀘스트 보드 → '보드 설정' 클릭 —
   모달이 화면 안에 다 들어오는지.
2. 레인 헤더의 ⚙ 클릭 — 열/정렬 컨트롤 팝업이 잘리지 않고 온전히 보이는지.

## 전수조사 — `updateState` 표시 위치

`updateState`(updater.ts) 상태: idle/checking/available/downloading/ready/uptodate/error. 이걸 렌더하는 곳이 **3개 컴포넌트**, 위치·대상 상태가 제각각:

| # | 위치 | 컴포넌트 | 위치/스타일 | 렌더 상태 | 트리거 |
|---|------|----------|------------|-----------|--------|
| 1 | 전역 **상단 배너** | `UpdateBanner.svelte` (layout:286, Nav 아래) | layout 밀어냄(상단 bar) | available / downloading / ready 만 | startup·주기 자동 감지 (모든 라우트) |
| 2 | welcome **하단 고정** | `welcome/+page.svelte` `.upd-toast` | `position:fixed; bottom:1.25rem` (중앙 하단) | checking/available/downloading/ready/uptodate/error 전부 | 수동 "업데이트 확인"(updateRequested) |
| 3 | settings **우하단 고정** | `settings/+page.svelte` `.upd-toast` | `position:fixed; bottom:1.5rem` (우하단) | checking/uptodate/available/downloading/ready/error 전부 | 수동 "업데이트 확인"(status!=idle) |

(admin 페이지의 "최신"은 백업 복원 문구로 update 와 무관 — 제외.)

### 드러난 문제
1. **위치 불일치**: 상단 배너(1) vs 중앙 하단(2) vs 우하단(3). 같은 "새 버전 N 사용 가능"이 트리거에 따라 다른 곳에 뜸. (사용자 지적: welcome 에서 자동=위, 수동=아래)
2. **중복 표시**: welcome/settings 에서 수동 확인 시 available/downloading/ready 가 **전역 배너(1) + 페이지 토스트(2/3)** 에 동시에 뜸.
3. **커버리지 구멍**: transient(checking/uptodate/error)는 페이지 토스트(2/3)에만 존재 → home 등 다른 라우트에서 수동 확인하면 결과 피드백이 안 보임(전역 배너는 이 상태들을 DEV-085 로 제외했음).

## 통일안 (토론)

**옵션 A — 전역 단일 update UI 로 통합 (권장)**
- welcome/settings 의 페이지별 `.upd-toast` 제거. 전역 컴포넌트 1개(예: `UpdateToast`)를 layout 에 mount → **모든 상태를 한 위치(우하단 floating toast)** 에서 처리.
- actionable(available/downloading/ready)도 같은 토스트에서 버튼 포함 + sticky(자동 안 사라짐), transient(checking/uptodate/error)는 자동 dismiss.
- 장점: 위치/중복/커버리지 3문제 모두 근본 해결. 상단 배너의 "layout 밀어냄"(DEV-085 발단)도 사라짐. 단점: 상단 배너의 강한 가시성 포기 → 우하단이라 놓칠 수 있음(→ 신규 버전일 때만 살짝 강조/펄스로 보완).

**옵션 B — 역할 분리 + 단일화**
- 전역 상단 배너(1) = actionable(available/downloading/ready) 전용 유지. transient(checking/uptodate/error) = **전역 floating toast 1개**로 통일(welcome/settings 중복 제거). 페이지 토스트에선 actionable 제외 → 중복 해소.
- 장점: 새 버전은 여전히 눈에 띄는 상단 배너. 변경 최소. 단점: 컴포넌트 2개 유지(배너+토스트), 위치는 여전히 상단/하단 2종.

**권장: A** — "같은 메시지는 항상 같은 위치" 원칙에 가장 부합하고 중복·커버리지 구멍까지 한 번에 정리. 가시성 우려는 available 시 토스트 강조로 보완.

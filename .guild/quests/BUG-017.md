## 증상

`.github/workflows/check.yml` 의 push / PR 트리거 결과 — Ubuntu runner 에서:

### (a) cargo job 빌드 실패
```
error: failed to run custom build command for `gio-sys v0.18.1`
  Package gio-2.0 was not found in the pkg-config search path.
  The system library `gio-2.0` required by crate `gio-sys` was not found.
```
원인: `gui` crate 가 Tauri / wry transitive dep → Linux 에선 GTK / webkit
시스템 라이브러리 필요. workflow 가 apt install 단계 없이 cargo 호출.

### (b) Node 20 deprecation 경고 (양 job)
`actions/checkout@v4` / `setup-node@v4` / `cache@v4` 가 내부 Node.js 20.
2026-06-02 부터 Node 24 강제 (이후 09-16 에 Node 20 runner 제거).

### (c) job key / name 부정확
`backend` / `frontend` — 실제 워크스페이스 구조 (`core/`, `cli/`, `server/`,
`gui/` + `gui/frontend/`) 와 불일치. "backend" 가 core / server / cli /
gui 의 Rust 부분 다 가리키는지 모호.

## 수정

### (a) Tauri Linux deps 설치
cargo job 의 checkout 직후 apt install 단계 추가 (Tauri v2 공식 목록):
```
libwebkit2gtk-4.1-dev libxdo-dev libssl-dev
libayatana-appindicator3-dev librsvg2-dev build-essential
```

### (b) Node 24 옵트인
workflow 최상단 `env:` 에 `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: 'true'`.
action 자체 (v4) 는 여전히 latest major — v5 release 시점 재검토.

### (c) job 이름 정정
- `backend` → `cargo`, name `cargo (core + cli + server + gui)`
- `frontend` → `gui-frontend`, name `gui/frontend (svelte-kit)`

## 검증

- 푸시 후 GitHub Actions UI 에서 두 job 통과 + deprecation 경고 사라짐.
- 로컬 빌드는 무관 (Linux deps 는 runner 전용; Windows 개발기는 그대로).

## 후속 fix (returned 1회차, 2026-05-24)

푸시 후 추가 회귀 3건:

### (d) gui crate compile 실패
```
error: proc macro panicked
  --> gui/src/lib.rs:259:14
    | message: The `frontendDist` configuration is set to
    | `"./frontend/build"` but this path doesn't exist
```
`tauri::generate_context!` proc macro 가 build-time 에 `frontendDist`
(gui/frontend/build) 의 존재를 검증. cargo job 에 frontend build 단계
없어서 실패.

**fix**: cargo job 의 Rust toolchain 설치 *전* 에 Node setup + `npm ci` +
`npm run build` 추가. cargo job 안에서 frontend artifact 도 생성.

### (e) clippy 2건 (core test 코드)
```
error: manual implementation of `str::repeat` using iterators
error: this `repeat().take()` can be written more concisely
  → core/src/ops/meta.rs:828
    std::iter::repeat('가').take(33).collect()
```
**fix**: `"가".repeat(33)` 으로 단순화.

### (f) Node 20 deprecation 경고 여전
`FORCE_JAVASCRIPT_ACTIONS_TO_NODE24=true` env 가 작동 안 함 (env 가
runner pre-init 단계에는 visible 안 됨으로 추정).

**fix**: action 버전 v4 → v5 일괄 업그레이드 (`actions/checkout@v5`,
`actions/setup-node@v5`, `actions/cache@v5`). v5 는 Node 24 default —
env 의존 제거. env var 도 제거.

### 검증
- 로컬 `cargo clippy -p openguild-core --all-targets -- -D warnings` → clean.
- frontend build / cargo build / cargo test 모두 로컬에서 통과 (이전부터).
- 다음 push 결과로 (d) (e) (f) 모두 해소되는지 확인.

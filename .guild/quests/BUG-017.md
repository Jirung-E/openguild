## 증상

`.github/workflows/check.yml` 의 push / PR 트리거 결과 — Ubuntu runner 에서:

### (a) cargo job 빌드 실패
```
error: failed to run custom build command for `gio-sys v0.18.1`
  Package gio-2.0 was not found in the pkg-config search path.
  The system library `gio-2.0` required by crate `gio-sys` was not found.
```
원인: `gui` crate 가 Tauri / wry transitive dep → Linux 에선 GTK / webkit
시스템 라이브러리 필요. workflow 가 apt install 단계 없이 cargo 호출.

### (b) Node 20 deprecation 경고 (양 job)
`actions/checkout@v4` / `setup-node@v4` / `cache@v4` 가 내부 Node.js 20.
2026-06-02 부터 Node 24 강제 (이후 09-16 에 Node 20 runner 제거).

### (c) job key / name 부정확
`backend` / `frontend` — 실제 워크스페이스 구조 (`core/`, `cli/`, `server/`,
`gui/` + `gui/frontend/`) 와 불일치. "backend" 가 core / server / cli /
gui 의 Rust 부분 다 가리키는지 모호.

## 수정

### (a) Tauri Linux deps 설치
cargo job 의 checkout 직후 apt install 단계 추가 (Tauri v2 공식 목록):
```
libwebkit2gtk-4.1-dev libxdo-dev libssl-dev
libayatana-appindicator3-dev librsvg2-dev build-essential
```

### (b) Node 24 옵트인
workflow 최상단 `env:` 에 `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: 'true'`.
action 자체 (v4) 는 여전히 latest major — v5 release 시점 재검토.

### (c) job 이름 정정
- `backend` → `cargo`, name `cargo (core + cli + server + gui)`
- `frontend` → `gui-frontend`, name `gui/frontend (svelte-kit)`

## 검증

- 푸시 후 GitHub Actions UI 에서 두 job 통과 + deprecation 경고 사라짐.
- 로컬 빌드는 무관 (Linux deps 는 runner 전용; Windows 개발기는 그대로).

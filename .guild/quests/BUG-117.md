설정의 UI 크기(uiScale — root font-size 스케일, rem 기반)를 조절해도
크기가 안 바뀌는 요소들 (admin 보고 + 전수 확인):

## 보고된 3건 + 원인
1. **홈 퀘스트 노드(마감 임박/Overdue conveyor) 크기·글자**:
   QuestNodeConveyor 가 SVG data-URI 이미지를 고정 px(width=284)로 렌더
   — SVG 안 글자 포함 전부 px 고정. marquee 폭 계산(CARD_W/GAP_PX)도 px.
2. **홈 작업기록 히트맵**: WorklogSummaryCard 셀이 11px/간격 3px 고정.
3. **빈 캠페인 페이지 '본문 추가' 글자**: `.link` 버튼에 font 상속이 없어
   브라우저 기본(13.33px 고정) 사용 — button 은 기본적으로 font 를 상속
   안 하는데 global.css 의 button 리셋이 font-family 만 상속시키고
   font-size 는 안 시킴. **같은 원인의 잠재 사례가 전역에 존재** (font-size
   명시 안 한 모든 button/input/select/textarea).

## 추가 발견 (전수 확인)
4. **홈 캠페인 conveyor(곧 시작)**: CampaignConveyor 카드 슬롯 고정
   200px — 안의 rem 글자만 커져 200% 에서 넘침. marquee 계산도 px.
   (또한 track gap 은 0.75rem 인데 계산은 GAP_PX=12 고정 — 스케일과
   무관하게 이미 미세 불일치.)

## 수정
- global.css: button/input/select/textarea 에 `font: inherit` — 3번과
  같은 부류를 전역에서 일괄 해결.
- WorklogSummaryCard: 히트맵 셀/간격을 px → rem.
- QuestNodeConveyor/CampaignConveyor: uiScale store 를 구독해 카드
  폭/간격을 scale 배율로 계산 (이미지 width, flex-basis, marquee 폭/속도
  계산 일관 적용).

## 테스트 방법
- 설정 → UI 크기 50%/100%/200% 로 바꾸며:
  1. 홈 마감 임박/Overdue 노드가 글자 포함 비례 확대/축소.
  2. 홈 작업기록 히트맵 셀 크기 비례.
  3. 빈 캠페인 상세의 '본문 추가' 글자 비례 (다른 .link 류 버튼도).
  4. 홈 '곧 시작' 캠페인 카드 폭 비례 + 200% 에서 글자 안 넘침.
  5. conveyor marquee 흐름/드래그가 각 배율에서 정상 (폭 계산 일치).
- `cd gui/frontend && npm run check && npm test -- --run`.

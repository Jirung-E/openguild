## 추가된 server CLI

### `vacuum`
```
$ openguild-server vacuum
VACUUM 실행 중...
✓ VACUUM 완료
  before : 733184 bytes
  after  : 720896 bytes
  saved  : 12288 bytes (1.7%)
```

SQLite VACUUM 명령으로 deleted row 의 공간 회수. snapshot 직전 또는 큰 reindex 후 권장.

### `journal-tail [-n N]`
```
$ openguild-server journal-tail -n 3
journal.db: 18 row(s) total — showing last 3

#    16  2026-06-06T05:06:06Z  add_comment_entry
         args   : {"author":"claude","len":1660,"parent_id":null,"slug":"DEV-093"}

#    17  2026-06-06T05:09:44Z  ...
```

journal.db 의 최근 N row (op + ts + args + result). debug / audit / 변경 추적용. journal.db 가 없으면 명시 안내.

## 테스트
1. 빈 길드 → `journal-tail` → "(journal.db 없음 — ...)" 안내.
2. quest mutation 1~5 회 → `journal-tail` → 같은 수 row 표시.
3. `journal-tail -n 1` → 가장 최근 1 개만.
4. `vacuum` → before/after/saved 출력 + index.db file size 감소.
5. `vacuum` 직후 `journal-tail` → 동일 row count (vacuum 은 index.db 만).

## 테스트 스텝 (사용자)
1. 퀘스트에 댓글 작성 → '💬 토론' 토글 ON (미해결 배지 표시).
2. 그 퀘스트를 완료(counts_as_done status: done 등) 로 전환 시도 → 차단 + 사유 메시지.
3. 보드에서 done 레인으로 드래그 → 노드 되돌아오고 우상단 toast.
4. 미해결 배지 클릭(resolve) → 다시 완료 시도 → 통과.
5. (CLI) openguild quest move <slug> done → 차단 에러 확인.

CLI `types` / `statuses` — list 외에 add / update / delete / rename
subcommand 추가. backend `core::ops::meta` 의 CRUD + DEV-061 의 rename
함수들이 이미 있어서 thin wrapper.

## 인터페이스

### Types
```bash
openguild types                                         # 목록 (default)
openguild types list                                    # 같음 (명시)
openguild types add <PREFIX> --color <#hex> [--description <desc>]
openguild types update <PREFIX> [--color <#hex>] [--description <desc>] [--clear-description]
openguild types delete <PREFIX>
openguild types rename <PREFIX> <NEW_PREFIX>            # DEV-061: 모든 quest slug cascade
```

### Statuses
```bash
openguild statuses                                      # 목록
openguild statuses list
openguild statuses add <name_en> --color <#hex> [--name-ko <ko>] [--sort-order <N>]
openguild statuses update <slug> [--name-en <en>] [--name-ko <ko>] \
                                  [--color <#hex>] [--sort-order <N>] [--clear-name-ko]
openguild statuses delete <slug>
openguild statuses rename <slug> <new_slug>             # DEV-061
```

- `--json` 모든 mutation 에서 지원.
- 호환성: `openguild types` (sub 없음) 는 기존처럼 list (TypesCmd 가 `Option`).

## 구현 (2026-05-24)

### Backend wrapper (`Backend::*`)
- `create_type` / `update_type` / `delete_type` / `rename_type`.
- `create_status` / `update_status` / `delete_status` / `rename_status_slug`.
- 각각 `Backend::Http` 는 `http_unsupported_meta` 에러 — remote 모드는
  별도 quest (HTTP server 의 admin meta 라우트). local 만 지원.

### Subcommand enum
- `TypesCmd { List, Add, Update, Delete, Rename }`.
- `StatusesCmd` 동일 (필드만 다름).
- `Command::Types { sub: Option<TypesCmd> }`, `Command::Statuses { sub:
  Option<StatusesCmd> }` — `None` 은 List 와 동일 동작 (기존 호환).

### 핸들러
- update: `description` / `name_ko` 의 unset vs no-change 구분을
  `--clear-description` / `--clear-name-ko` 플래그로. 두 옵션 동시 지정 시
  명시적 BadRequest.
- 출력: 사람용 (color 적용) / `--json` 둘 다.
- rename 메시지에 "cascade" 안내 (DEV-061 의 effect 강조).

### 테스트 +6 (cli 68 → 74)
- `types` (sub 없음) 가 List 로 파싱.
- `types add` / `types update --clear-description` / `types rename`.
- `statuses add` (--name-ko + --sort-order) / `statuses rename`.

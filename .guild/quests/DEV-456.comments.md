만들었습니다 — **설정 → 표시 → 상단바 메뉴**.

- 페이지마다 체크 + [▲][▼] 로 켜고 끄고 순서를 바꿉니다. 고를 수 있는 것: 홈 · 퀘스트 · 규칙 · 도서관 · 관리 · 캠페인 · 작업 기록 · 태그.
- 기본은 예전과 같습니다(홈 · 퀘스트 · 규칙 · 도서관). **홈은 끌 수 없고 늘 맨 앞**입니다. [초기화] 로 기본값.
- 상단바에 없는 페이지는 왼쪽 위 메뉴(데스크톱은 타이틀바의 ☰, 웹은 상단바의 메뉴 단추)에 갑니다. 기본일 때 메뉴는 예전 그대로(관리 · 캠페인 · 작업 기록 · 태그, 같은 아이콘). 퀘스트 · 규칙 · 도서관을 메뉴로 내리면 쓸 아이콘을 새로 그렸습니다.
- 창이 좁아 상단바에 다 안 들어가면 뒤쪽부터 메뉴로 접히는 것(DEV-260)은 그대로입니다.
- 이 기계의 취향이라 localStorage(`openguild.navPages`)에 둡니다. 새 창으로 연 창에도 바로 반영됩니다(storage 이벤트).
- 코드: 규칙은 `utils/nav-pages.ts`(시험 6개), 값은 `stores/navPages.ts`. Nav 의 페이지별 '지금 여기' 판정도 여기로 모았습니다. USAGE 에 한 줄.

확인(웹 빌드 · 시험용 길드): 기본 상단바 [홈 퀘스트 규칙 도서관] · 메뉴 [관리 캠페인 작업 기록 태그] → 규칙 끄고 캠페인 켜고 앞으로 → 상단바 [홈 퀘스트 캠페인 도서관], 새로고침해도 그대로, 메뉴에 규칙이 들어감, /campaigns 에서 '캠페인' 이 강조, [초기화] 로 원래대로. 홈 체크는 잠겨 있음.
데스크톱 타이틀바의 ☰ 메뉴는 웹에 없어서 브라우저로는 못 봤습니다 — 앱에서 확인 부탁드립니다.

자주 안 쓰는 앱 정보/업데이트를 상단 nav 큰 버튼 대신 ⚙ 설정 페이지로. /settings 좌측 세로 서브탭 (정보 / 업데이트 / 추후). New Quest 버튼은 nav → 각 뷰의 기존 상단 바/툴바 우측 끝으로 이동. 업데이트 수동 체크도 설정으로 흡수. ⚙ 아이콘이 New Quest 자리(우상단) 차지.

## 구현 (2026-05-29)

### Nav
- New Quest / "⟳ 업데이트" 버튼 제거 → 우상단에 ⚙ 설정 아이콘 (그 자리).
  hover 45° 회전. `/settings` active 표시.

### 설정 페이지 `/settings`
- 좌측 세로 서브탭 (정보 / 업데이트 / 추후 항목 자리).
- 정보: 앱 이름 / 버전 (Tauri `getVersion`, 브라우저 placeholder) / 식별자 /
  저장소 링크.
- 업데이트: 수동 체크 + 상태 (DEV-063 `updater` store 재사용). Tauri 전용,
  브라우저는 안내문.

### New Quest 버튼 배치
- 처음엔 본문 우하단 FAB 안이었으나, 사용자 피드백 — 각 뷰에 이미 상단
  바/툴바가 있으니 거기 묶는 게 자연스러움 (제일 오른쪽).
- 최종:
  - **Quest Board**: 우상단 toolbar 제일 오른쪽에 primary(초록) `+ New Quest`.
  - **Quest List**: filter-bar 제일 오른쪽 (`margin-left:auto`) `+ New Quest`.
- 모달 + 생성 로직 (onCreated → flashQuestId 펄스 + 보드 이동) 은 `+page.svelte`
  소유. 각 뷰엔 `onNewQuest?: () => void` 콜백 prop 만 내려 버튼 클릭 위임.
  (QuestBoard / QuestList / QuestListFilter 에 prop 추가.)

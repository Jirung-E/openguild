## ⚠️ 수동 검증 필요 (testing 사유)

검색 팔레트(`SearchPalette`)는 **`TitleBar.svelte`(Windows 전용 Tauri
desktop 셸)에서만 마운트**됨 — `+layout.svelte` 의 `showTitleBar` 조건이
`detectEnvironment() === 'tauri' && navigator.userAgent.includes('Windows')`.
이 세션의 브라우저 프리뷰(HTTP 모드)는 애초에 TitleBar 자체가 렌더 안 되므로
검색 팔레트에 진입할 수 없어 실제 클릭 테스트 불가능했음 (guildContextActive
sessionStorage 를 강제로 켜도 TitleBar 컴포넌트 자체가 마운트 안 됨을
코드로 확인).

**실제 데스크탑 앱(`cargo tauri dev` 또는 `just dev`)에서 아래 확인 필요:**
1. 검색 팔레트 결과 행에 아이콘 3개(미리보기/새 창/페이지이동) 표시되는지.
2. "새 창" 아이콘 클릭 → 실제 Tauri 창이 새로 뜨는지(quest/campaign 상세
   내용이 정상 로드되는지, 네이티브 타이틀바로 뜨는지).
3. 같은 항목/다른 항목에서 여러 번 "새 창" 클릭 시 창이 여러 개 동시에
   뜨는지(재사용 아님 확인).
4. 미리보기 팝업 안의 "새 창으로 열기" 버튼도 동일하게 동작하는지.
5. "페이지로 이동" 아이콘/버튼은 기존과 동일하게 현재 창에서 라우팅되는지.

## 2026-07-14 실사용 버그 리포트 반영

1. **방향키 스크롤 안 됨** — `SearchPalette.svelte`: `rowsEl` 참조 추가 +
   `selIndex` 변경 시 `scrollIntoView({block:'nearest'})` 하는 `$effect` 추가.
2. **타이틀바 클릭해도 팔레트 안 꺼짐(메뉴 버튼 포함)** — 기존 backdrop 은
   `inset: titlebar-h` 로 타이틀바 영역을 제외해 그 위 클릭이 안 잡혔음.
   `<svelte:window onclick>` 으로 팔레트 바깥 아무 클릭이나 닫히게 함
   (버블링상 타이틀바 버튼 자체 동작 뒤에 실행 — 메뉴는 열리면서 팔레트도 닫힘).
3. **팔레트 열린 채 뒤로/앞으로가기 가능** — `afterNavigate(() => onclose())`
   추가. 트리거 방식(마우스 사이드버튼/단축키/타이틀바 버튼) 무관하게 라우트가
   바뀌면 팔레트가 닫힘.
4. **자식윈도우에 메뉴바/뒤로앞으로/검색팔레트 안 필요** — 새 store
   `windowKind.ts` (`isChildWindow`, 창 label `item-*` 판정 — Tauri internals
   동기 접근으로 깜빡임 없이). `+layout.svelte` 가 이 값으로 Nav 숨김,
   `TitleBar.svelte` 가 `.tb-left`(홈/뒤로/앞으로/☰메뉴) + 검색 pill 전체 숨김.
5. **자식윈도우에 네이티브+커스텀 타이틀바 이중 표시** — `open-item.ts` 의
   `openInWindow()` 에서 Windows 일 때만 `decorations:false, shadow:true`
   명시(메인 창과 동일 조건) — 네이티브 타이틀바 안 뜨고 커스텀 하나만 표시.
6. **'이동'/'자식윈도우로 열기' 시 표시 안 됨** — 두 가지 원인 결합:
   - (a) `SearchPalette`의 quest href 가 `q.id`(숫자 row id) 를 쓰고 있었는데
     `[id]` 라우트는 `questsApi.getBySlug(quest_id 문자열)` 로 조회 — 항상
     실패. `q.quest_id` 로 수정.
   - (b) 자식윈도우는 Tauri asset protocol 이 딥링크 경로를 직접 서빙한다는
     보장이 없어 새 창에서 즉시 그 경로로 뜨면 빈 화면 위험. 항상 존재가
     보장된 `/` 로 띄운 뒤 `?winTarget=<encoded href>` 를 `+layout.svelte`
     onMount 가 읽어 client-side `goto()` 로 이동시키는 방식으로 변경.

## 답변만(코드 변경 없음)

7. **타이틀바 최소화/최대화/닫기 버튼이 Windows 스타일 고정, OS 별 스타일
   불가능한지** — 이미 해결되어 있음: 커스텀 타이틀바(`TitleBar.svelte`)는
   `+layout.svelte` 의 `showTitleBar` 조건(`detectEnvironment()==='tauri' &&
   navigator.userAgent.includes('Windows')`)에 의해 **Windows 에서만** 렌더됨.
   macOS/Linux 는 애초에 이 컴포넌트가 안 뜨고 OS 네이티브 데코레이션(진짜
   맥 신호등 버튼 등)을 그대로 사용 — 이미 "OS 에 따라 스타일이 맞음". Windows
   버전(10 vs 11) 간 세부 스타일까지 맞추길 원하시면 별도로 알려주세요.

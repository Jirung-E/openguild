## 증상

- Quest description / 댓글 / 메모 안의 `https://...` 링크를 클릭하면
  openguild Tauri 윈도우 안의 webview 가 그 URL 로 navigate → 앱이
  "다른 사이트" 가 되어버림 (SPA 가 사라짐).
- 정상 동작: 시스템 기본 브라우저에서 새 탭으로 열려야 함.

## 원인

- MarkdownView 의 `<a href="...">` 가 plain anchor — Tauri webview 가
  내부 navigation 으로 처리.
- Tauri 의 link intercept 핸들러 미설정.

## 작업

### A. Tauri 의 `WindowEvent` 또는 navigation hook
- `tauri.conf.json` 의 `app.windows[].url` 외부 URL 차단.
- `tauri::Builder` 에 `on_page_load` / `on_navigation` 핸들러 — 외부 URL
  감지 시 `tauri::api::shell::open(...)` 으로 시스템 브라우저 호출 + 차단.

### B. Frontend 차원에서 `a[href^="http"]` click intercept
- MarkdownView 의 marked renderer 커스터마이즈 — `target="_blank"` +
  `rel="noopener noreferrer"`.
- Tauri 명령 `open_external(url)` 를 만들고, click handler 에서 호출.
- A 와 병행 — A 는 안전망, B 는 의도 명확.

## 권장
- 우선 B (frontend) — 즉시 완화.
- A (Tauri 핸들러) — 안전망. 잘못된 link 라도 시스템 브라우저로.

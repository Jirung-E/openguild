## E2E 스모크 결과 — 격리된 temp 길드 + 실제 서버 바이너리

연결된 Chrome 브라우저가 없어 실제 GUI 클릭 자동화는 불가. 대신 격리된 temp 길드(`%TEMP%/og-e2e-smoke`, 실 저장소 밖)에 `openguild init` → `openguild-server.exe host`(FRONTEND_DIST=빌드된 build/, DEV-195 단일 origin) 실제 기동 후 curl로 18단계 전부 실행·확인. 단위테스트(DEV-196)와 달리 진짜 프로세스+디스크+포트로 검증.

| # | 단계 | 결과 |
|---|---|---|
| 1 | SPA 루트 `/` | 200 |
| 2-4 | quest 생성 → 목록 → status 변경(in_progress) | OK |
| 5-6 | 댓글 추가, 메모 설정 | OK |
| 7-11 | campaign 생성 → quest 링크 → checklist 추가/체크 → detail(진행도) | OK |
| 12-14 | admin snapshot / drift / reindex | OK |
| 15 | SPA 딥링크 `/quests/DEV-001` (새로고침 시나리오) | 200 (DEV-195 fallback 정상) |
| 16 | 존재하지 않는 quest 조회 | 404 (에러 처리 정상) |
| 17-18 | admin restore(최신 snapshot) + 데이터 무결성 | OK |

**첨부(attachment)**: `AttachmentSection.svelte`에서 `isTauri` 게이트로 브라우저 모드는 명시적으로 차단(`"첨부 추가는 데스크탑 앱에서만 지원됩니다"`) — **버그 아님, 의도된 데스크탑 전용 제약**으로 확인.

## 작업 중 발견·수정한 사고 (기록)
이 검증 도중 `openguild init --guild .e2e-tmp`를 저장소 루트에서 실행했다가 `--guild` 플래그가 무시되고(또는 init이 cwd 고정) 실 저장소의 길드 마커 `openguild.guild`(git tracked)가 덮어써졌음. 즉시 `git checkout -- openguild.guild`로 복구, 이후 모든 검증은 `cd`로 격리된 절대경로 temp 디렉토리에서만 수행. **별도 갭 발견**: `openguild init` 이 `--guild` 옵션을 cwd 대신 인식하지 않는 듯함 — 후속 확인 필요(별도 이슈로 분리할지는 사용자 판단).

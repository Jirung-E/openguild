첨부/본문의 동영상(video)은 HDR 표시 제한(DEV-335) 설정을 무시하고 항상 HDR로 표시됨 — 이미지는 정상.

## 원인

DEV-335 가 `dynamic-range-limit: var(--hdr-limit, no-limit)` 를
`AttachmentSection.svelte`(`.thumb img`)와 `MarkdownView.svelte`
(`.md :global(img)`) 양쪽에 넣었는데, **둘 다 `img` 선택자에만 걸고
`video` 는 빠뜨렸다.** `dynamic-range-limit` 은 스펙상 `<video>` 에도
적용 가능(HDR 동영상도 CSS 로 제한 가능 — MDN 확인)한데 셀렉터에서
누락됨.

## 수정

두 파일 모두 `video` 셀렉터를 추가:
- `AttachmentSection.svelte`: `.thumb img` → `.thumb img, .thumb video`
- `MarkdownView.svelte`: `.md :global(img)` → `.md :global(img), .md :global(video)`

## 테스트 방법

HDR로 촬영된 동영상(예: 아이폰 Dolby Vision)을 첨부/본문에 올리고 HDR
설정을 '끄기'(standard)로 바꿨을 때 동영상도 이미지처럼 밝기가 억제되는지
확인. (Safari 26+ 에서만 유효 — WebKit 은 constrained 미지원, DEV-335/
방금 사용자와 확인된 별개 제약사항.)

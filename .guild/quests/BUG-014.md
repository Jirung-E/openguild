## 증상

Windows 에서 `recents.json` 등 OpenGuild 사용자 데이터가
`%APPDATA%\openguild\openguild\data\` (= `~/AppData/Roaming/...`) 에 저장.
Roaming 은 도메인 환경에서 다른 PC 로 sync 되는 경로 — 개별 PC 단위
캐시는 `Local` 이 맞음.

## 원인

`core/src/recents.rs::recents_path`:
```rust
let dirs = directories::ProjectDirs::from("io", "openguild", "openguild")?;
let data_dir = dirs.data_dir();  // → Roaming\openguild\openguild\data
```
`directories` crate 의 `data_dir()` 는 Windows 에서 Roaming. Local 에 두려면
`data_local_dir()`.

## 수정

- `recents_path()` — `dirs.data_dir()` → `dirs.data_local_dir()` 로 변경.
- 다른 user data 사용 사이트도 grep 후 동일 처리 (snapshot 경로 등 — 검토).
- **마이그레이션 없음** (사용자 명시 결정): 기존 Roaming 의 recents.json
  은 그대로 두고 (필요 시 사용자가 직접 삭제), 새 경로 (Local) 부터 신규
  파일로 시작. 새 진입부터 정상.
- 문서 갱신: `recents.rs` 모듈 doc 의 OS 경로 예시.

## 검증

- Windows: 새 진입 시 `%LOCALAPPDATA%\openguild\openguild\data\recents.json`
  에 생성.
- Linux / macOS: `data_local_dir` 가 그쪽 OS 에선 `data_dir` 와 동일
  (또는 가까운 경로) — 회귀 없는지 확인.

## 후속 (이 quest 범위 외)

- 만약 사용자 요청 들어오면 1회용 마이그레이션 헬퍼 (옛 Roaming →
  새 Local 복사) 별도 quest.

## 구현 (2026-05-25)

### `core/src/recents.rs::recents_path`
- `dirs.data_dir()` → `dirs.data_local_dir()` 한 줄.
- 모듈 doc 의 Windows 경로 예시 `%APPDATA%\...` → `%LOCALAPPDATA%\...`
  로 갱신. BUG-014 노트 + 마이그레이션 없음 정책 명시.

### 영향 범위
- `directories::ProjectDirs` 사용 사이트 grep — `core/src/recents.rs`
  한 곳만. 다른 user data 경로 (snapshot / backup 등) 는 길드 폴더 안
  (`.guild/...`) 또는 `OPENGUILD_RECENTS_DIR` env 로 처리되어 영향 없음.

### 검증
- `cargo test --workspace -- --test-threads=1` → 모든 test 통과
  (recents 7개 포함).
- `cargo clippy --workspace --all-targets -- -D warnings` → 0 errors.
- Windows: 새 진입 시 `%LOCALAPPDATA%\openguild\openguild\data\recents.json`
  생성됨 — 사용자 검증.
- Linux / macOS: `data_local_dir` == `data_dir` 라 회귀 없음.

## 테스트
Local에 생성되는건 확인 했는데, 폴더 이름이 전부 소문자여야한다. 지금은 OpenGuild인데 openguild로 해야함.

## fix1 (2026-05-25)

### 사용자가 본 "OpenGuild" 폴더의 정체
우리 `recents_path()` 는 `ProjectDirs::from("io", "openguild", "openguild")`
로 항상 소문자. 따라서 `%LOCALAPPDATA%\openguild\openguild\data\recents.json`
경로는 정확.

사용자가 본 `%LOCALAPPDATA%\OpenGuild\` 폴더는 **Tauri 가 productName
기반으로 자동 생성하는 WebView2 / app state 디렉토리**. tauri.conf.json
의 `productName: "OpenGuild"` 에서 옴 — 우리 recents 코드와 무관.

### 해결 — DEV-072 가 처리
**[DEV-072](DEV-072.md)** 의 `OpenGuild → openguild` 일괄 변경에 포함되어
`productName: "openguild"` 로 변경됨. 새 빌드부터는 `%LOCALAPPDATA%\openguild\`
폴더가 생성됨. 옛 `OpenGuild\` 폴더는 잔재 — 사용자가 수동 삭제 가능.

### 추가 코드 변경 없음
본 quest 의 원래 수정 (`data_dir` → `data_local_dir`) 은 그대로. 폴더
이름 문제는 productName 변경으로 해결되어 별도 코드 작업 불필요.

### 검증 절차 (재테스트)
1. 새 NSIS installer 빌드 (DEV-035 캐시 함정 절차 참고: `cargo clean -p
   openguild-gui && rm -rf target/release/build/openguild-gui-*`).
2. 설치 후 첫 진입 → `%LOCALAPPDATA%\openguild\openguild\data\recents.json`
   생성 확인 (전부 소문자).
3. Tauri 가 자동 생성하는 WebView 폴더도 `%LOCALAPPDATA%\openguild\`
   하위인지 확인.

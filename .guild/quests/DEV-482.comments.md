## 고침 (admin 이 시안 B′ 로 정함)
- 문서는 검색 팔레트와 같은 종류 칩 + 번호 칩 + 제목(`DocKindPills`). 규칙은 번호 칩 없이 slug 가 이름 자리.
- 상태 변경은 "상태" 칩 대신 흐름 칩만(`open → done`). 묶으면 그날 처음 → 마지막 하나.
- 캠페인의 "다 끝남" 기록은 무엇이 끝났는지를 앞에(`퀘스트 180/180` · `체크리스트 6/6`). 이를 위해 서버 `ActivityRow` 에 `op` 를 더함(캠페인 상태 줄 · 규칙 · 도서관 줄만, 없으면 생략 — 옛 클라이언트 영향 없음).
- 규칙 · 도서관은 한 일(수정 · 생성 · 삭제 · 이름 바꿈)로.
- 펼친 줄 · 전체 보기(시간순)도 같은 칩. 전체 보기는 문서 칩을 시각 바로 뒤에 둠(흐름 칩 폭이 달라 줄이 어긋나지 않게).

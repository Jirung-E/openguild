1) Campaigns 섹션의 '+ 캠페인 연결' 버튼이 리스트 아래에 있어 sub/prereq 의 'title 옆 + 추가' 배치와 다름. 2) 편집 모드 기한 input 의 picker icon 이 다시 검정. color-scheme:dark 추가로 BUG-026 의 global invert 와 충돌.

## 수정 (2026-05-27)

### Part 1 — 버튼 배치 통일
Campaigns 섹션의 `.section-head` 안으로 `+ 연결` 버튼 이동. sub-quest
의 `+ 신규` / `+ 기존 지정`, prereq 의 `+ 추가` 와 동일하게 title 옆.
- 라벨도 `+ 캠페인 연결` → `+ 연결` 로 단축 (다른 두 섹션과 길이 통일).
- 기존 `.campaign-add` wrapper / 인라인 입력 / 관련 스타일 모두 삭제.

### Part 2 — 기한 input picker icon
DEV-076 에서 `.edit-date` 에 `color-scheme: dark` 추가한 것이 BUG-026 의
`input[type='date']::-webkit-calendar-picker-indicator { filter: invert }`
와 충돌:
- `color-scheme: dark` 가 native icon 을 흰색으로 렌더.
- 위에서 global invert 가 다시 검정으로 inversion → 다시 안 보임.

해결: `.edit-date` 에서 `color-scheme` 제거. 어두운 배경은 `background`
속성으로만 표현, picker icon 색은 BUG-026 의 global 규칙이 일관 처리.

또한 `global.css` 의 BUG-026 주석에 ⚠ 경고 추가 — 향후 어느 컴포넌트도
`color-scheme: dark` 를 date input 에 다시 붙이지 않도록 안내.

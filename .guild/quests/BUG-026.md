1) 캠페인 페이지의 <input type=date> 캘린더 아이콘이 어두운 테마에 안 보임. webkit-calendar-picker-indicator filter invert. 2) 곧 시작 캠페인의 무한 marquee 컨베이어가 여러 문제 — 적은 수에도 돌고, 끝 인지 어렵고, 지나간 거 보려면 기다리고, 회전 중 처음 카드가 갑자기 사라졌다 나옴. carousel (좌우 화살표, 끝 도달 시 화살표 disabled, 자동 회전 없음) 로 재작성.

## 구현 (2026-05-26)

### Part 1 — date input picker indicator
`lib/styles/global.css` 에 전역 규칙 추가:
```css
input[type='date']::-webkit-calendar-picker-indicator {
    filter: invert(0.85);
    opacity: 0.7;
    cursor: pointer;
}
input[type='date']::-webkit-calendar-picker-indicator:hover { opacity: 1; }
```
모든 date input 에 자동 적용 (캠페인 신규/편집 포함, 추후 추가되는 곳도).
Chrome / Edge / Tauri WebView2 = webkit 기반. Firefox 는 기본 아이콘 없음
(영향 없음).

### Part 2 — CampaignConveyor 재작성 (marquee → finite carousel)
무한 marquee 폐기. 동적 측정 + 페이지네이션 carousel:

- **viewport / track ref** + `ResizeObserver` 로 width 측정.
- `overflow = trackW > viewportW` — 다 들어가면 화살표 disabled, transform
  적용 안 함.
- `visibleCount = floor((viewportW + gap) / (cardW + gap))` — 한 화면 카드 수.
- `maxIdx = summaries.length - visibleCount` — 끝 도달 가능 인덱스.
- `canPrev` / `canNext` derived — 양 끝 도달 시 화살표 disabled 시각화.
- 화살표 클릭 시 `idx ± 1` (한 카드씩). `transform: translateX(-idx × (cardW+gap)px)`.
- 자동 회전 **없음** — 사용자 컨트롤만.
- summaries.length 변화 시 다시 measure (캠페인 추가/삭제 시).

해결된 문제 (사용자 피드백):
- "적은 양에 돌아 산만" → overflow 측정 후 다 들어가면 단순 flex (화살표 disabled).
- "끝 인지 어려움" → 양 끝 화살표 시각적으로 disabled.
- "지나간 카드 다시 보려면 기다림" → 좌측 화살표로 즉시 이동.
- "첫 카드 갑자기 사라졌다 나옴" → marquee 복제 제거, finite list.

admin 지적: CLI 로 도서관 문서에 태그를 달 수 없다.

## 현황 (파리티 구멍)

| 대상 | 코어 | 서버 | GUI | CLI |
|---|---|---|---|---|
| 퀘스트 | ✅ | ✅ | ✅ | ✅ `quest tag list/add/remove/set` |
| 도서관 | ✅ `set_book_tags` | ✅ `PATCH /api/library/{id}/tags` | ✅ | **❌** |
| 규칙 | ✅ `set_rule_tags` | ✅ `PUT /api/rules/{slug}/tags` | ✅ | **❌** |

`library update` 는 `--title / --file / --path` 만 받고, `rule` 에는 태그 명령
자체가 없다. 정작 `tag`(태그 정의 카탈로그) 명령의 설명은 "shared by
quests/library/rules" 라고 돼 있는데 CLI 로 붙일 방법이 없다.

## 할 일

`quest tag` 와 같은 모양으로 `library tag` / `rule tag` (list/add/remove/set)
추가. 로컬·원격 모두 지원한다 — 코어 함수와 서버 라우트가 이미 있으므로
CLI 배선만 하면 된다.

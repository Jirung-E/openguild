## 사용자 design 명확화 (2026-06-04)

- **git 은 사용자 선택사항** → 정식 백업은 DB.
- **`backups/journal.db` (AOF) + `backups/snapshots/*.db` (RDB)** 가 진짜
  백업 시스템 (`docs/storage-design.md` 의 "독립 복구 시스템").
- **메모의 "사적" = 다른 사용자에게 안 보임** (멀티유저 시나리오).
  **"백업 안 됨" 이 아님.** 본인 입장에선 잃으면 안 되는 데이터.

현재 상태 (DEV-094 / DEV-099):
- 댓글 `.guild/quests/{slug}.comments.md` — git tracked. git 안 쓰는 환경에선
  안전망 없음.
- 메모 `.guild/quests/{slug}.memo.md` — gitignored. 어디서도 백업 안 됨
  (PC 손실 / 디스크 장애 시 손실).

→ snapshot 에 들어가도록 `index.db` 의 캐시 테이블로 sync 필요.

### File ↔ DB sync (양방향)

진리원은 여전히 파일 (사용자가 git pull / 외부 편집 가능). DB 는 캐시.

- **mutation (ops/comments)**: 기존 file write 후 같은 transaction 으로 DB
  UPSERT. journal 에 의도 기록은 이미 함.
- **read (services/comments)**: 옵션 — DB 우선 (빠름) 또는 file (현행 그대로).
  쿼리/검색 가속이 필요하면 DB 우선. 단순 list/show 는 file 직접도 OK.
- **reindex**: `.comments.md` / `.memo.md` 파일들을 parse → DB 에 INSERT.
  BUG-047 의 sibling 제외는 `quests` 테이블 용이고, 본 작업의 `quest_comments`
  / `quest_memos` 용은 별도 list (sibling 만).
- **drift**: 캐시 정합 검사 확장 — quest 본문 + comments + memos 모두 비교.

### memo 의 user 격리 (preparation)

- 현재는 single-user (desktop Tauri) → 모든 memo row 의 `user_id` NULL.
- multi-user / 서버 모드 (DEV-021 JWT) 진입 시:
  * `user_id` 컬럼이 이미 있음 → migration 추가 없이 활성화.
  * file 저장 경로도 `{slug}.memo.{user}.md` 같은 식 분리. 또는 DB-only 로 가
    파일 안 만듦 (file-only 패턴 X — 사용자 한정).

## 작업

1. migration 0011 작성.
2. core/src/repo/comments.rs 에 DB UPSERT 추가 (file write 후).
3. core/src/services/comments.rs 가 DB 우선 read 옵션.
4. core/src/reindex.rs 가 sibling 파일들도 parse → DB sync (BUG-047 의 list 와
   별도 helper — `list_quest_comment_files`, `list_quest_memo_files`).
5. core/src/drift.rs 가 sibling drift 도 감지 (BUG-047 의 "comment / memo 의
   외부 편집 추적 불가" 한계 해소).
6. ops::create_quest / delete_quest 가 cascade — 이미 FK CASCADE 로 자동.
7. snapshot 자동 포함 — `index.db` binary copy 라 별도 작업 없음.

## 검증

- 회귀: 기존 file-only 동작 보존 (사용자가 외부 편집 후 reindex 시 DB 갱신).
- 신규: comment add → DB row 생성. snapshot 만들기 → 복원 시 댓글 살아있음.
- memo: `user_id = NULL` 로 single-user 모드 동작.
- BUG-047 의 sibling 제외 회귀 테스트와 별도로, sibling 의 DB sync 회귀 테스트
  추가 (drift::tests + reindex::tests).
- BUG-016 의 help_output_has_no_quest_id_leaks 통과.

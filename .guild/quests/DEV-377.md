## 코어가 소유하는 동작은 둘뿐

```
post   HTTP 로 이벤트를 보낸다        ← 1단계
run    프로세스를 띄우고 stdin 으로   ← 2단계
```

"밖으로 내보낸다"의 최소 완전집합이다. slack/discord/email 같은 통합을 코어에
쌓기 시작하면 끝없이 따라다녀야 한다 — 그건 사용자 프로그램의 몫이다.

## post (1단계)

- URL, 메서드, 헤더. 본문은 rhai 의 `payload` 또는 기본 이벤트 JSON.
- **비밀값 — 리터럴은 거부한다**(admin 확정). API 키를
  `.guild/plugins/*.json` 에 적으면 **git 에 커밋된다.** 환경변수 참조
  (`${OPENAI_API_KEY}`)만 허용하고, 키처럼 보이는 리터럴이 있으면 그
  플러그인을 **적재하지 않는다**(경고만으로는 무시된다).
  판정을 너무 넓게 잡으면 멀쩡한 값이 막히므로, 무엇을 "키처럼 보인다" 로
  볼지는 보수적으로 시작하고 테스트로 고정한다.
- 타임아웃 필수. 비동기라 길드는 안 멈추지만 무한정 붙들면 안 된다.
- `core` 에 HTTP 클라이언트가 **없다**(cli 에만 reqwest 가 있다). 어디에 둘지
  정해야 한다 — core 에 넣을지, 각 컴포넌트가 주입할지.

## run (2단계)

- 프로세스를 띄우고 이벤트 JSON 을 **stdin** 으로. 인자로 넘기면 길이 제한과
  이스케이프 문제가 생긴다.
- **임의 실행**이라 동의(DEV-375)가 반드시 선행돼야 한다.
- 작업 디렉터리·환경변수·타임아웃·좀비 프로세스 정리.

admin 판단: `run` 이 되는지가 **동작의 한계를 정한다**. 다만 안 되면 빼면
그만이므로 2단계로 미룰 수 있다.

## 테스트 방법

**post**
- 구독한 이벤트에서 실제로 요청이 나간다(대역 서버로 수신 확인).
- 받는 쪽이 죽어 있어도 길드 동작이 멀쩡하다.
- 타임아웃이 걸린다.
- 리터럴 API 키가 든 정의가 거부되거나 경고된다.

**run**
- stdin 으로 이벤트 JSON 이 들어간다.
- 프로세스가 죽거나 오래 걸려도 길드가 안 멈춘다.
- 동의 없이 실행되지 않는다.

## 결과 — post 와 run 둘 다 넣었다

`core/src/plugins/delivery.rs` 의 `Outbound` 하나가 둘을 다 한다.
`Delivery` 트레이트는 남겼다 — 테스트가 네트워크 없이 돌고, 나중에 다른
전송을 끼울 자리가 된다.

`run` 은 2단계로 미룰 수 있다고 적어 뒀지만 **미루지 않았다.** `Action::Run`
이 이미 정의 스키마에 있어서, 안 만들면 `run` 을 적은 정의가 적재는 되고 아무
일도 안 하는 상태가 된다. 그게 미루는 것보다 나쁘다. 구현은 `Command` +
stdin + 시한 감시로 40줄이었다.

### HTTP 클라이언트는 코어가 갖는다

컴포넌트 주입도 검토했지만, 셋이 각자 구현하면 같은 코드가 셋으로 갈라지고
gui 와 server 는 어차피 클라이언트를 새로 들여야 한다. cli 와 **같은 기능
조합**(`blocking` + `rustls-tls`)으로 맞춰 TLS 스택이 겹치지 않게 했다.
`blocking` 인 이유는 전달이 전용 스레드에서 돌기 때문이다 — tokio 밖이라
오히려 이쪽이 맞다.

### 시한

`timeout_ms` 를 정의에 둘 수 있게 하되 기본 10초, 상한 60초. 상한이 필요한
이유는 하나가 전달 스레드를 영원히 잡으면 **뒤에 줄 선 것이 다 막히기**
때문이다.

`run` 은 시한이 지나면 죽이고(`kill`) **거둔다**(`wait`). 거두지 않으면
좀비가 남는다. 시험은 자식이 살아 있으면 계속 커지는 파일을 두고, 돌아온 뒤로
더 안 커지는지를 본다 — 시간만 재면 "포기하고 돌아왔다" 까지만 보이고 자식이
계속 도는지는 안 보인다.

### 비밀값은 보내기 직전에 푼다

정의에는 `${OPENAI_API_KEY}` 참조만 있고([[DEV-375]]), 값은 전송 직전에
환경에서 읽는다. 참조한 변수가 없으면 **빈 헤더로 보내지 않고 실패로 남긴다**
— 조용히 빈 값으로 보내면 인증 실패 원인을 못 찾는다.

### 크기 실측은 [[DEV-378]] 로 넘긴다

reqwest 를 core 에 넣었지만 아직 어느 바이너리도 플러그인을 배선하지 않아
링커가 통째로 걷어낸다([[DEV-376]] 에서 겪은 것과 같다). 배선이 들어가는
DEV-378 에서 rhai + reqwest 를 합쳐 한 번에 잰다.

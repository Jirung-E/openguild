## 정할 것 — 이렇게 정했다

1. '전체' 탭의 쿼리 — **막는다.** 종류마다 키가 달라 공통 키만 받으면 헷갈린다. "쿼리는 퀘스트 · 캠페인 · 도서관 탭에서 씁니다" 안내. 규칙은 쿼리가 없어 같은 안내.
2. 메모 — **'메모 포함' 을 켤 때만**(서버 기본 · CLI `--in memo` 와 같다). 검색 모드에서만 보인다.
3. 정렬 — **제목 · 번호에서 맞은 것 먼저**, 그 안은 종류 · 번호 순. 정렬 선택은 두지 않았다.

## 쿼리 문법 확장 (admin 논의 2026-10-31 — 제안대로)

| 쓰는 법 | 뜻 |
|---|---|
| 띄어쓰기 · `&` · `AND` | 그리고 |
| `\|` · `OR` | 또는 (대문자만 — `or` 는 낱말). 그리고가 먼저 묶인다: `a b \| c` = `(a b) \| c` |
| `-` | 아닌 것. `-(a \| b)` 도 된다 |
| `( )` | 묶기 |
| `[a, b]` | 여러 값 중 하나. 쉼표만 쓰면 오류 — "여러 값은 [ ] 로 묶으세요 — status:[open, done]" |
| `a..b` · `a..=b` · `a..` · `..=b` | 범위(끝 제외 · 포함) — urgency 와 모든 날짜 키. 예전 `1-3` 은 없앰. 비교(`<=2`)는 그대로 |
| `*` | 아무 글 — 칸 전체에 대해(`tag:ui-*`) |
| `/…/` | 정규식, 대소문자 무시 — 낱말 · tag · type · folder · title · body |
| `title:` · `body:` | 칸을 정해 찾기 — 부분일치, `=값` 은 완전일치(`title:="로그인 화면"`). 퀘스트 · 캠페인 · 도서관 |

키 있는 값은 완전일치(태그는 이제 대소문자 무시), 키 없는 낱말은 부분일치(`%` · `_` 도 글자 그대로).

### 어떻게
- `core/src/query.rs` 를 식(그리고 · 또는 · 아닌 것) 해석기로 다시 썼다. SQL 로 그대로 옮긴다 — Rust 로 옮기지 않았다.
- 정규식은 SQLite `REGEXP` — sqlx `regexp` 기능(`with_regexp()`)이 연결마다 Rust `regex` 로 등록한다(입력 길이에 비례해 끝나서 서버에 안전). 해석할 때 컴파일해서 틀리면 그 자리를 짚는다.
- 강화 검색(`/api/search` — 팔레트 '넓게' · 검색 페이지)도 `/…/` 토막을 정규식으로 받는다(발췌는 맞은 곳 주변). 팔레트의 바로 찾기도 `/…/` 를 JS 정규식으로.
- **쿼리 결과 하이라이트**: 코어가 칠할 말(낱말 · title · body · 정규식, `-` 아래는 뺌)을 뽑아 준다 — `GET /api/query/highlights?q=&of=` · 앱 `query_highlights`. 화면은 받은 말로 칠하기만 한다(정규식은 JS 로 다시 판단 — JS 가 못 읽으면 안 칠함). 퀘스트 목록 · 보드 · 캠페인 · 도서관(목록 · 타일) · 검색 페이지.
- 쓰는 법(`?`) · 예시 · CLI `-q` 도움말 · USAGE · 스킬 문서 · CHANGELOG 를 새 문법으로. `title` · `body` 키를 쓰는 법에 추가.

### 확인
- 코어 시험: 해석(묶음 순서 · 괄호 · 소문자 or/and · `f(x)` · 목록 · 정규식 · `=` · 오류 위치 15가지), 범위, SQL, 칠할 말. 실제 DB: `tag:ui | status:done`, `(tag:ui OR urgency:1) -status:done`, `urgency:1..=1`, `/^로그인\s화/`, `title:/화면$/`, `title:="로그인 화면"`, `title:로그인*`, `tag:U*`, `tag:/^u/`, 도서관 `folder:설계/*` · `folder:/^보/` · `updated:2020-01-01..2021-01-01` · `title:` · `body:`. 강화 검색 정규식(발췌 · 틀린 정규식 오류).
- 화면 시험: 하이라이트(정규식 · 섞기 · 못 읽는 정규식), 검색 페이지 쿼리 하이라이트, transport.
- `just test` 통과. (중간에 `plugins::schedule` 의 시간 시험 하나가 한 번 실패 — 단독 · 재실행은 통과, 이번 변경과 무관.)
- 웹 빌드 + 임시 서버(WebKit): 목록 `(title:/^둘/ | t) -status:done` → 2건, '둘' · 't' 칠함. `status:open,done` → [ ] 안내. 쓰는 법 새 문장. 보드 '둘째' · 't' 칠함. 캠페인 `title:/코.리/` → '코끼리'. 도서관 `body:코끼리 | title:동물*` → '동물'. 검색 페이지 `/코.리/` → 4건 칠함, 쿼리 `title:/^둘/` → '둘'. 팔레트 `/^코/` → 코끼리 원정. 페이지 오류 0.

# BUG-158: 최근 본 문서 버튼이 타이틀바 검색 pill 을 밀어냄

사용자 지적: 최근 본 문서 버튼이 검색 팔레트를 밀어내면 안 됨.

## 원인

DEV-276 에서 검색 pill + 최근 버튼을 `.tb-center` wrapper 로 묶어 **묶음
전체를 중앙 정렬**했다. 그래서 최근 버튼이 나타나거나 사라질 때마다
묶음 폭이 바뀌어 pill 이 좌우로 움직였다(기록 없으면 버튼을 숨기므로
첫 문서 방문 순간 pill 이 왼쪽으로 밀린다).

## 수정

wrapper 를 **폭 0 의 중앙 앵커**로 만들고(`width: 0`), pill 은 그 앵커
기준 중앙에, 최근 버튼은 `position: absolute` 로 pill 오른쪽 **바깥**에
띄운다 — 버튼 유무가 pill 위치에 전혀 영향을 주지 않는다.

## 검증

데스크탑 전용(웹엔 타이틀바 없음) — CSS 로직으로 보장. 사용자 실기 확인
필요.

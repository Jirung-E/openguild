## 구현

### Migration 0012
- `quest_statuses` 에 `counts_as_done INTEGER NOT NULL DEFAULT 0` 추가.
- 기존 길드의 `done` / `cancelled` slug 자동 backfill = 1.

### StatusFile + seed
- frontmatter `counts_as_done: bool` (기본 false, skip_serializing_if).
- 새 길드의 seed: `done` / `cancelled` = true, 나머지 false.

### reindex
- file → DB sync 시 `counts_as_done` 도 binding (file 진리원).

### summarize (services::campaigns)
- 링크된 quest 중 alive + status.counts_as_done=1 인 수 계산.
- `quest_progress = quest_done / quest_total` (0 일 때 0.0).

## 테스트
1. 새 길드 init → done/cancelled status file 의 `counts_as_done = true`.
2. 기존 길드 reindex → DB 의 quest_statuses 의 done/cancelled 가 1.
3. 캠페인에 quest 링크 + status done 으로 → API 응답의 quest_progress 갱신.
4. status 정의 file 의 counts_as_done 직접 toggle → reindex 후 quest_progress 변화.

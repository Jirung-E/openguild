## 고침
- `write_quest_file` · `write_quest_file_as_deleted`: 파일 쓰기가 실패하면 `restore_cache_after_failed_write` — 실패한 퀘스트는 바로 파일 내용으로 캐시를 되돌리고(파일이 없으면 = 새로 만들다 실패, 행을 지움), 모든 행의 `cached_mtime` 을 0 으로 해 같은 작업이 앞서 바꾼 다른 행(부모 · 하위 · 선행)도 다음 동기화가 파일에서 다시 옮기게 한다. 26곳의 호출이 모두 이 길을 탄다.
- `change_status`: 파일을 먼저 쓰고 기록(quest_history · 사이드카)은 그 뒤 — 실패하면 기록 줄이 남지 않는다.
- `repo::fs::write_atomic`: 임시 파일 쓰기 · rename 이 실패하면 `.tmp` 를 지운다.
- `change_type`(이름 바꾸기)은 순서를 그대로 두었다 — 여러 파일을 옮기는 작업이라 위의 일반 복구에 맡긴다.

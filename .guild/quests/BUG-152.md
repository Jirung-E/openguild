# [skill] .guild 없는 디렉토리에서 openguild 스킬이 트리거되지 않음

사용자 보고: `.guild` 가 없는 곳에서 openguild 스킬이 로드되지 않는 것
같음.

## 원인

배포 스킬(`skills/openguild-plugin/skills/openguild/SKILL.md`)의
`description` 이 "...run any `openguild` command **in a directory
containing a `.guild` marker**" 로 끝나 있었다. Claude Code 는 이
description 텍스트로 스킬 사용 여부를 판단하는데, 이 한정 문구가
".guild 가 있어야만 쓰는 스킬"로 읽혀 `.guild` 가 없는 디렉토리(= 바로
새 길드를 만들어야 하는 상황!)에서 스킬을 안 여는 방향으로 작용했다.
정작 `openguild init` 안내가 제일 필요한 순간에 스킬이 빠지는 역설.

## 수정

description 재작성 — `.guild` marker 는 "강한 신호일 뿐 필수 조건이
아님(do NOT require one)"을 명시하고, "아직 `.guild` 가 없는 프로젝트에
새 길드를 셋업/init 하려는 경우에도 사용"을 트리거 문구에 추가.

## 테스트 방법

1. `claude plugin validate ./skills/openguild-plugin` 통과 + description
   길이(818자, 1536 상한 내) 확인 — 완료.
2. (사용자 확인) 플러그인 재설치(버전 캐시) 후, `.guild` 없는 임의
   디렉토리에서 "이 프로젝트 openguild로 관리하고 싶어" 류 요청 시
   스킬이 로드되어 `openguild init` 을 안내하는지 확인.

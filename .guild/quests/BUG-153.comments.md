실기 테스트 후속: 침범은 막았으나 3줄 말줄임(-webkit-line-clamp:3)으로 긴
제목이 잘려 전체를 볼 수 없었다. 타일 라벨(문서·폴더, 두 뷰 분기 4곳)에
hover 툴팁(title 속성) 추가 — Windows 탐색기 아이콘 뷰처럼 잘린 제목을
hover 로 전체 확인 가능. 3줄 clamp 자체는 유지(레이아웃 안정).

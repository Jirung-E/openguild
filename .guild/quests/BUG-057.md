## 증상

Quest Board 의 노드 (특히 노드 안 텍스트 — 퀘스트 ID, 제목, urgency 라벨, due) 가 흐릿하게 보임. Cytoscape 캔버스가 그리는 보더 / 그림자 / 배경색 등 vector 부분은 또렷.

## 의심 원인

### (1) 노드 본문 = SVG 를 data URL 로 background-image 사용

`QuestBoard.svelte:1571` 의 노드 스타일:

```ts
'background-image': 'data(nodeBg)',  // data:image/svg+xml;...
'background-fit': 'cover',
```

Cytoscape 의 `background-image` 는 SVG 를 vector 로 매 프레임 다시 그리지 않고 **일정 사이즈 텍스처로 한 번 rasterize → 캔버스에 그림**. SVG intrinsic 사이즈는 `width="284" height="80"` (= `NODE_W`, `NODE_H`) — 1× 비트맵으로 캐시됨.

→ 줌인하면 vector 재생성 안 하고 비트맵 보간 → 텍스트 가장자리 번짐.
→ HiDPI 모니터 (1.25x / 1.5x) 에서도 동일 — devicePixelRatio 만큼 추가 raster 안 됨.

### (2) Cytoscape `pixelRatio` 미설정

`cytoscape({...})` (line 2231) 옵션에 `pixelRatio` 없음 → 기본 `'auto'`. WebView2 에서 `'auto'` 가 `window.devicePixelRatio` 와 일치 안 하는 사례 있음. HiDPI 에서 전체적으로 흐릿하다면 이쪽.

## 수정 후보 (선택)

- (A) `cytoscape({ pixelRatio: window.devicePixelRatio || 1, ... })` — HiDPI 캔버스. 1-line.
- (B) `nodeBg` SVG 의 `width` / `height` 를 `NODE_W * dpr` / `NODE_H * dpr` 로 발급 + viewBox 추가. Cytoscape 가 받는 텍스처가 dpr 배 해상도 → cover 로 노드 크기 맞춰지면서 텍스트 또렷.
- (C) SVG 대신 cytoscape 의 multiline label + box 으로 텍스트를 cytoscape 가 직접 vector 그리게 (label 기반). 큰 리팩터.

권장: (A) + (B) 조합. (A) 만으로 보더 / 그림자 등 vector 부분 또렷해지고, (B) 로 SVG 텍스처 해상도까지 끌어올림. (C) 는 비용 큼.

## 검증 방법

- DevTools console: `window.devicePixelRatio` — 1.25 / 1.5 면 HiDPI.
- 줌인 (Ctrl+휠) → 노드 텍스트가 vector 처럼 깨끗하면 (A) 만으로 해결. 비트맵 확대로 번지면 (B) 도 필요.

## 비고

- `motionBlur` / `textureOnViewport` 같은 cytoscape 성능 옵션은 켜져 있지 않음. 빌트인 rendering 만 영향.
- 노드 SVG 의 `font-family="system-ui,..."` 는 fallback OK — 폰트 문제 아님.

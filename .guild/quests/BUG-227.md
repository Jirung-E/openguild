admin 보고: 없는 slug 를 넣어도 `(no history)` 가 나온다. 실측:

```
$ openguild rule history 없는규칙xyz
(no history)                 # exit 0
$ openguild library history BOOK-999
(no history)                 # exit 0
```

## 왜 문제인가

"이력이 없는 문서" 와 "존재하지 않는 문서" 가 **구분되지 않는다.** 오타를 쳐도
성공(exit 0)으로 끝나므로 스크립트가 조용히 잘못된 결론을 내린다. `quest show`
는 없는 slug 에 NotFound 를 준다 — 같은 CLI 안에서 동작이 다르다.

## 원인 (추정)

DEV-290 의 이력 조회는 사이드카(`.jsonl`)를 직접 읽는데, 파일이 없으면 빈
목록으로 처리한다. 대상 문서가 실제로 있는지는 확인하지 않는다.

## 방향

이력을 읽기 전에 대상 존재를 확인하고, 없으면 NotFound(비-0 종료). 있는데
이력만 없으면 지금처럼 `(no history)`.

## #3 '3번 안됨' 재확인 — 내가 오독했음

처음에 '3번'을 댓글 #2의 case3(bare DEV-001 렌더링)으로 봤는데, 이 댓글은 #1(테스트 스텝)에 대한 답글이라 **'3번 = 테스트 스텝 3 = 편집기 자동완성 '🔗 링크 걸기''** 가 맞다. 그걸 안 고쳤다. 미안.

**진짜 원인(자동완성)** → BUG-072:
편집기는 `markdown()`(기본 base=commonmark)인데 자동완성 소스를 GFM `markdownLanguage` 에만 등록해서, 커서 위치의 활성 언어와 불일치 → 소스가 안 잡혀 'DEV-0' 타이핑해도 후보가 안 떴음. commonmark/GFM 양쪽에 등록해 수정.

**정리:**
- 테스트 스텝 3 (자동완성) → BUG-072 (방금 수정).
- 댓글 #2 case3 (bare `DEV-001` 렌더 → 상세 링크) → BUG-071. **실재하는 ID 만** 링크(오탐 방지)이므로 존재하는 ID 로 테스트 필요.
- 댓글 #2 case1/2 (`[[DEV-001]](url)`, `[DEV-001]`): 이건 marked 가 먼저 표준 링크/텍스트로 파싱해버리는 비정상 입력. 의도된 경로는 bare `DEV-001` 또는 트레일링 괄호 없는 `[[DEV-001]]`. case1/2 자체를 openguild 링크로 강제 변환하려면 marked 전처리가 필요한데, 필요하면 별도로 진행.

검증: npm check 통과. 자동완성은 GUI 재빌드 후 'DEV-0' 등 타이핑해 확인 필요.

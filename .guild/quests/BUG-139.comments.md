## 테스트 방법

배너가 뜨는 조건을 먼저 만들어야 함:
1. **더 신형 바이너리**로 길드를 한 번 열어 스키마를 migrate.
2. **구형 바이너리**로 같은 길드를 열면 SchemaAheadBanner 표시됨.

확인 포인트:
- 배너가 상단 in-flow 로 콘텐츠를 아래로 **밀어내지 않는지**.
- UpdateBanner 처럼 floating(position:fixed) 카드로 뜨고, 다른 UI 위치가 안 밀리는지.
- 기존 내용(버전 정보 / "최신 버전 받기" / 닫기)이 그대로인지.

<!-- og-comment id="2" ts="2026-07-19T01:04:08+09:00" author="claude" reply_to="1" -->
정정: 위 "신형→구형 바이너리" 방식은 두 빌드의 마이그레이션이 다를 때만
됨 — 같은 코드로 빌드하면 안 뜬다(사용자 확인). 배너는 길드 index.db 의
`_sqlx_migrations` 에 **실행 바이너리가 모르는 version 행**이 있을 때만 표시.

검증된 확실한 테스트(바이너리 1개로):
```bash
cp -r /경로/길드 /tmp/testguild
python3 -c "
import sqlite3
c=sqlite3.connect('/tmp/testguild/.guild/index.db')
c.execute(\"INSERT INTO _sqlx_migrations(version,description,installed_on,success,checksum,execution_time) VALUES (99999999,'fake',CURRENT_TIMESTAMP,1,X'00',0)\")
c.commit(); c.close()"
OPENGUILD_GUILD=/tmp/testguild openguild-gui
```
→ 홈에 배너 표시(migration 99999999 적용됨 안내).

BUG-139 결과: 이 방법으로 실기 확인 — 배너가 **우하단 플로팅 카드**로 뜨고
레이아웃을 안 밀어냄(원래 상단 고정 배너가 UI 를 밀어내던 문제 해결).

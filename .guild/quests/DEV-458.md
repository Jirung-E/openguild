[[REQ-026]] 의 구현 — 플러그인 줄을 **시간마다** 돌린다(`every` + `query` + `of`). 정한 것은 REQ-026 댓글.

## 할 것

- 코어
  - 줄 칸 `every` · `query` · `of`. 검증: `every` 해석(최소 1m), `query` 를 대상의 쿼리로 해석, 섞을 수 없는 칸(`pre` · `post` · `when` · `with` · `wait` · `group` · 순서).
  - 실행기: 앱 · 서버에서만 도는 스케줄러(30초마다).
    - 플러그인 데이터 폴더의 기록 + 파일 잠금으로 한 기계에서 한 번만.
    - 맞는 목록을 실어 그 줄만 부른다.
    - 다시 불러오거나 길드를 바꾸면 멈춘다.
- `plugin test` 의 `tick(줄, 목록)`, `plugin check` 경고(`scope` 에 gui · server 가 없음).
- 허용 화면 · CLI 요약: "1h 마다 · 퀘스트 `status:open …`".
- 앱: 길드를 바꿀 때 옛 길드의 플러그인을 뗀다 — 안 떼면 옛 길드의 주기 실행이 계속 돈다.
- 문서: 스킬 · 참고 문서 · 스키마 · BOOK-004 · CHANGELOG.

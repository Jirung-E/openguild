## 문제

AI 가 퀘스트 하나의 댓글을 볼 때 `openguild quest comment list <slug>` 대신 `openguild comments` 를 쓴다(admin 보고).

## 원인

스킬(`skills/openguild-plugin/skills/openguild/`)이 둘을 같은 자리에 늘어놓는다.

- SKILL.md 의 명령 목록 끝에 `openguild comments --unresolved` 가 "읽기" 명령처럼 따로 나온다.
- Pitfalls 표의 "읽기도 CLI 로" 칸에 `quest comment list <slug>` 와 `comments` 가 나란히 있다.
- reference/comments.md 가 **길드 전체 검색(`comments`)을 맨 앞**에 두고, 퀘스트 하나 댓글은 그 뒤에 둔다.

그래서 어느 것을 언제 쓰는지가 안 보인다.

## 고칠 것

- 퀘스트 · 캠페인 하나의 댓글은 `quest comment list` · `campaign comment list` 로 읽는다고 못 박는다.
- `comments` 는 "어느 퀘스트인지 모를 때 길드 전체에서 찾기" 로만 남기고, 그 문서 안에서도 뒤로 옮긴다.

## 고친 것

- 배포 스킬 SKILL.md: 명령 목록에서 `quest comment list` 를 "퀘스트 하나 댓글 읽기" 로, `comments` 를 "길드 전체 검색 전용" 으로 적었다. Pitfalls 의 읽기 칸에서 `comments` 를 빼고, "퀘스트 하나 댓글을 `comments` 로 읽기" 를 함정 줄로 따로 두었다.
- 배포 스킬 reference/comments.md: 첫머리에 어느 것을 쓰는지 한 줄로 적고, 길드 전체 검색 절을 맨 뒤로 옮겼다.
- 이 저장소 작업 스킬 `.agents/skills/openguild-workflow/SKILL.md`: 같은 구분을 적었다.

`comments` 명령 자체는 코드에서 deprecated 가 아니다(길드 전체 댓글 검색으로 살아 있다). 이번에는 스킬만 고쳤다.

## Test plan

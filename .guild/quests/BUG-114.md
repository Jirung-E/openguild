증상: 댓글 편집기의 cross-link 추천 목록에서 스크롤바를 마우스로
클릭해서 드래그할 수 없음(스크롤이 안 움직이거나 바로 되돌아감).

## 원인 (QuestCommentsSection.svelte)
```js
$effect(() => {
    void wikiSel;
    void wiki;
    wikiPopEl?.querySelector('.wiki-opt.sel')?.scrollIntoView({ block: 'nearest' });
});
```
DEV-171 후속으로 ↑/↓ 키보드 이동 시 선택 항목을 스크롤로 보여주기 위한
effect 인데, `wikiSel` 은 키보드뿐 아니라 각 옵션의 `onmouseenter`
(`wikiSel = i`)로도 바뀐다. 스크롤바를 마우스로 드래그하는 동안 커서가
스크롤바 옆 목록 항목 위를 스치기만 해도 `mouseenter` → `wikiSel` 변경
→ 이 effect 가 `scrollIntoView` 를 호출해 스크롤 위치를 강제로 되돌려
버려, 사용자가 드래그하는 스크롤과 계속 싸우는 상태였음(체감상 "스크롤이
안 움직인다").

## 수정
`wikiSelFromKeyboard` 플래그 도입 — ArrowUp/ArrowDown 핸들러에서만 true
로 세팅하고, effect 는 이 플래그가 true 일 때만 scrollIntoView 실행 후
리셋. 마우스 호버로 인한 wikiSel 변경은 스크롤을 건드리지 않음.

## 테스트 방법
1. 댓글 편집 시 규칙/퀘스트가 많은 길드에서 `[[` 입력 → 추천 목록이
   스크롤 필요할 만큼 길게 뜨는지 확인.
2. 마우스로 스크롤바를 클릭+드래그 → 정상적으로 스크롤되는지 확인
   (이전엔 옆 항목 hover 때문에 튕겨나갔음).
3. ↑/↓ 로 선택 이동 시 여전히 자동 스크롤 되는지 확인(회귀 없음).
4. `cd gui/frontend && npm run check && npm test -- --run` 통과.

## 수정 (2026-05-27)

대부분의 항목이 BUG-032 commit 이후에도 재현된 사용자 보고. 원인 분석:
- 일부는 **Tauri 바이너리 rebuild 누락** (Rust 변경분 미반영) — 사용자에게
  rebuild 안내.
- 일부는 **fix 자체가 충분치 못함** — 더 견고하게.

### 1) 곧 시작 conveyor 클릭 → 캠페인 이동 (재발)
BUG-032 의 임계값 기반 setPointerCapture 지연이 일부 환경에서 여전히
click 을 막음. 근본 해결: `CampaignCard` 의 `<button onclick={goto}>` →
`<a href={url}>` 로 변경. anchor 의 native navigate 는 conveyor 가
명시적으로 `e.preventDefault()` 호출하지 않는 한 무조건 작동.
- conveyor 는 드래그 (임계값 5px 초과) 직후 한 번의 click 만 swallow
  하도록 `onclickcapture` 핸들러 + `suppressNextClick` flag.

### 2) 캠페인 편집 메타 / 본문 분리 → 통합
이전: `editMeta` / `editBody` 따로, 별도 편집 / 저장 / 취소 버튼 2 세트.
변경 후: 단일 `editMode`. 진입 시 title / dates / body 모두 편집 가능.
저장 / 취소 1 세트. Quest Detail 페이지와 동일 UX.

### 3) 캠페인 생성 / 변경 시각 표시
`Campaign` 모델은 원래부터 `created_at` / `updated_at` 보유. UI 만 미노출.
캠페인 detail 메타 섹션에 `.meta-times` 추가 — Quest Detail 의 동일 톤
(생성 = 절대 시각 / 변경 = relative).

### 4) 우클릭 안 막힘 (재발)
BUG-032 fix 의 `addEventListener('contextmenu', block)` 가 일부 버블링
순서에서 다른 핸들러에게 가로채임. 보강:
- `{ capture: true }` 로 capture phase 등록 — 가장 먼저 받음.
- `document` + `window` 둘 다 등록 (WebView2 환경 fallback).
- `e.stopPropagation()` + `return false` 추가.

### 5) 본문 ↔ Sub-Quests 간격 (재발)
BUG-032 fix 의 `margin-bottom: 2rem` 이 인접 `<section>` 의 margin-top
과 collapse 가능. 변경:
- margin → `padding-bottom: 2.5rem` (collapse 불가).
- 다음 section 에도 `padding-top: 1rem` 추가.

### 6) Quest 마감 기한 설정 안 됨 (재발)
DEV-076 → BUG-032 의 Tauri 핸들러 추가 코드는 commit 되어 있음. 사용자가
**Tauri 앱을 rebuild 하지 않으면 미반영**. transport.ts (frontend) +
commands.rs (Rust) + lib.rs invoke_handler — 셋 다 검증 완료.

### 7) 진행중 남은기간 빨강 (재발)
BUG-032 의 `.urgent` modifier + `activeRemainingIsUrgent` derived 는
commit 되어 있음. Tauri rebuild 후 반영. (frontend dev 모드면 HMR 으로
이미 반영 — 사용자의 실제 환경 확인 필요.)

### 8) 곧 시작 fade mask (재발)
BUG-032 의 `.conveyor.marquee` 조건부 클래스 + mask CSS — commit 되어
있음. rebuild 후 반영.

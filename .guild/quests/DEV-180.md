quest_history 가 index.db 에만 있고 .md/스냅샷에 백업 안 됨 → index.db 삭제 시 영구 소실, 'index.db 는 재생성 가능한 캐시' 원칙을 깨는 유일한 비-파일 권위 데이터. (이번 git reset 때 index.db 만 안 건드려서 운좋게 살아남음.) 파일 기반으로 이전해 reindex 가 재구축 가능하게. 설계 결정: (A) 사이드카 {slug}.history.jsonl — append-only, 기존 comments/memo/attachments 사이드카 패턴과 일관, 전체 재작성 없이 append (추천). (B) quest frontmatter history 배열 — 단일 파일, 퀘스트와 함께 이동, 매 status 변경마다 전체 재작성. reindex 가 이 소스에서 quest_history 재구축 + 스냅샷 포함되도록.

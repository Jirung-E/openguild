DEV-027 의 옵션 조합이 매번 길어지면 alias 저장 기능. 예:

```bash
openguild view save my-bugs --type BUG --status open --sort urgency
openguild view list
# my-bugs        --type BUG --status open --sort urgency
openguild view run my-bugs
# (= openguild quest list --type BUG --status open --sort urgency)
openguild view run my-bugs --limit 3  # 추가 옵션 override 가능
openguild view delete my-bugs
```

## 설계 결정

- **저장 위치**: 
  - guild-local: `.guild/views.toml` — quest 와 함께 git tracked, 팀 공유 가능.
  - user-global: `~/.config/openguild/views.toml` — 개인 환경.
  - 일단 guild-local 만 (팀 공유 가치 큼).
- **format**: TOML
  ```toml
  [views.my-bugs]
  type = "BUG"
  status = "open"
  sort = "urgency"
  ```
- **override**: `view run <name> [추가 옵션]` 시 saved 옵션과 새 옵션 머지. 새 옵션 우선.

## 영향 범위

- `core/src/repo/views.rs` (신설) — `ViewFile { name, ListQuery }` + read/write.
- `core/src/ops/views.rs` (신설) — save / delete / list / get.
- `cli` 에 `openguild view {save,list,run,delete,show}` 명령군 추가.
- 자동 테스트 — 저장 / 로드 / 머지 / 누락 view 에러.

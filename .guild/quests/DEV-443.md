읽는 화면에서 글을 골라 노랗게 칠하는 개인 형광펜(admin, 2026-10-16 논의).

## 정한 것 (admin)
- **어디서:** 전부 — 퀘스트 본문 · 댓글 · 메모 · 캠페인 · 규칙 · 도서관. 모두 MarkdownView 로 그리므로 한 번 만들면 다 붙는다.
- **누가 보나:** 나만 — 본문은 건드리지 않는다(고친 기록 · git 에 안 남는다).
- **저장:** 메모처럼 길드 안, git 제외(`.guild/highlights/`). 앱 · 웹 · 다른 기기에서 그 길드를 열면 보이고 백업에 들어간다. 원격 서버 길드는 서버에 저장 — 서버에 사용자 구분이 없어서 그 서버 접속자끼리는 같이 보인다(지금 메모와 같다).
- **칠하는 법:** 읽기 화면에서 글을 고르면 옆에 [형광펜] 버튼. 칠한 곳을 누르면 [지우기].
- **색:** 노랑 하나(라이트 · 다크 각각 맞춤).

## 설계 (제안)
- **자리 따라가기:** 칠한 글 + 앞뒤 약 30자를 저장(W3C TextQuoteSelector 방식). 본문이 바뀌어도 같은 글을 다시 찾아 칠한다. 앞뒤가 맞는 곳이 없으면 칠한 글만으로 찾고, 그것도 없으면 "못 찾음".
- **못 찾음:** 말없이 버리지 않는다 — "형광펜 N개를 찾지 못했습니다 [지우기]" 로 알린다.
- **저장 단위:** 대상(퀘스트 · 캠페인 · 규칙 · 도서관 문서)마다 파일 하나, 안에 부분(본문 · 댓글 #n · 메모)별 목록. 읽기 · 쓰기는 대상 단위로 통째로(메모 API 와 같은 모양).
- **통로:** 앱(Tauri 명령) + 서버(`/api/highlights/...`) 둘 다. 앱 API 감사 때처럼 빠진 쪽이 없게 시험으로 고정.
- **여러 블록:** 문단 · 목록 · 표를 넘겨 골라도 칠한다(글자 조각마다 따로 감싼다). 코드 블록 안도 된다.

`openguild comments`(DEV-221, 길드 전체 댓글 횡단 검색)로 출력되는 댓글
중 답글(parent_id 있는 것)이 어떤 댓글에 달린 답글인지 표시가 안 됨.

`quest comment list <slug>` 는 이미 `↩ #N` 으로 부모 entry_id 를 표시하는데
(core::ops::comments 의 parent_id 를 읽어 렌더), 전역 `comments` 검색의
`GlobalComment` 구조체/SQL 에는 애초에 parent_id 컬럼이 빠져있었음
(quest_comments/campaign_comments 테이블엔 parent_id 컬럼이 있는데
SELECT 목록에 안 넣었음).

## 수정
- `GlobalComment` 에 `parent_id: Option<i64>` 추가.
- SQL UNION 양쪽 절에 `c.parent_id` 추가.
- 출력 포맷에 `quest comment list` 와 동일하게 `↩ #N` 표시.
- `comments_search_union_filters_and_order` 테스트에 답글 케이스 +
  parent_id 검증 추가.

## 테스트 방법
- 어떤 quest 에 댓글 + 답글을 만든 뒤 `openguild comments` 실행 →
  답글 줄에 `↩ #부모entry_id` 표시되는지 확인.
- `--json` 출력에도 `parent_id` 필드 포함되는지 확인.
- `cargo test -p openguild-cli` 통과.

## 무엇이 어긋났나

`discussion-to-ai` 예제가 admin 의 뜻과 다르게 만들어졌다.

> api 통신이 아니라 현재 컴퓨터에 있는 프로그램(세션)에 메세지를 전달하는거임.

지금은 토론 댓글을 `https://my-service.example/discussion` 으로 **밖에 보낸다**. 웹훅 토큰까지
받는다. 뜻은 그게 아니라 **이 컴퓨터에서 돌고 있는 것에게 건네주는 것**이다 — 예를 들어
옆 터미널에서 돌고 있는 AI 세션.

## 고칠 방향

`post`(바깥으로 보내기)를 걷어내고 `run`(이 컴퓨터에서 띄우기)으로 바꾼다. 밖으로 나가는
것이 없으니 웹훅 토큰도 없어진다.

건네주는 길은 셋을 둔다 — 셋 다 이 컴퓨터 안이다.

- **받은 편지함 파일**(기본) — 정해 둔 파일 뒤에 붙인다. 세션이 그 파일을 지켜보면 된다.
  가장 단순하고 어디서나 된다.
- **프로그램에 넘기기** — 설정에 적은 명령을 띄우고 본문을 그 입에 넣어 준다.
- **tmux 창에 넣기** — 돌고 있는 세션 창에 그대로 타이핑해 준다.

윈도우 갈래도 같이 둔다(`sh` 가 없다).

## 테스트 방법

- `openguild plugin check examples/plugins/discussion-to-ai` 가 통과한다.
- 기본값으로 토론 댓글을 달면 받은 편지함 파일에 한 덩이가 쌓인다.
- '프로그램에 넘기기' 로 두고 `cat >> 어디` 같은 것을 적으면 거기로 간다.
- tmux 를 띄워 두고 창 이름을 적으면 그 창에 글이 들어간다.
- 플러그인 권한에 '바깥 통신' 이 더는 안 뜬다.

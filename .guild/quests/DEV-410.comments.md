**다시 고침 (2026-10-23, Testing 확인에서 나옴)**

1. **(높음) 값이 화면 · HTTP 로 샜다.** 비밀 여부를 변수 **이름**(token · secret …)으로만 정해서, `Authorization: Bearer ${MY_CRED}` 의 값이 앱 카드와 인증 없는 `GET /api/plugins` 로 그대로 나갔다. 화면의 "이름만 — 값은 이 화면에 오지 않습니다" 와도 어긋났다.
   - **헤더에 쓰인 값은 이름과 상관없이 비밀**(선언이 `secret = false` 라도).
   - **환경변수에서 온 글자 값은 보내지 않는다** — 있다는 것(`has_value`)과 출처(`source`)만. 고르는 칸(체크 · 목록)은 정의가 정한 값이라 그대로.
   - 화면: 값이 안 온 칸에는 "설정됨 — 바꾸려면 새로 입력".
2. **줄 안에 적은 `post` 를 요약이 놓쳤다** — 한 줄 요약(일괄 허용이 보는 것) · 경고에 "밖으로 안 나감". 이름 붙인 `[actions]` 만 봤다. 줄 안의 동작도 "내보내는 곳" 에 넣는다.
3. **"쓰는 환경변수" 가 URL 안(`bot${TELEGRAM_BOT_TOKEN}`)과 `run` 인자를 빠뜨렸다** — 값을 채우는 쪽과 같은 목록(`referenced_keys`)을 쓴다.
4. CLI 의 "아직 허용하지 않은 플러그인" 경고가 함수만 있는 플러그인에 빈 괄호 — 한 줄 요약과 같은 표시(`밖으로 안 나감` 등).

**시험:** `values_do_not_leak_into_the_view`, `an_inline_post_is_still_where_it_sends`, `every_referenced_variable_is_listed` — 셋 다 고치기 전 코드에서 실패. just test 통과.
**실제 프로그램:** 서버를 `MY_CRED=CREDSECRET42 MY_CHAT=CHATSECRET` 로 띄우고 `/api/plugins` → 두 값 0건, `MY_CRED` secret · 값 null · has_value · env. CLI 경고: `cred (post 127.0.0.1:3613)` · `inl (post …)` · `quiet (밖으로 안 나감)`. 텔레그램: "쓰는 환경변수: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID".

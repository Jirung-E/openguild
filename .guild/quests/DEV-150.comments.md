## 🗨 vs 💬, 그리고 색 질문

- **의도**: 한눈에 '일반 댓글(💬)'과 '토론(discussion)'을 구분하려고 다른 글리프(🗨)를 썼음.
- **색 관련 — 정확한 지적**: 💬/🗨 같은 이모지는 OS/폰트가 **자체 색으로 렌더**해서 CSS `color`/SVG `fill`이 대부분 안 먹습니다. 그래서 현재 빨강/초록은 **글리프 자체가 아니라** 리스트의 배지 배경+카운트 텍스트(`.discussion-count.unresolved/.resolved`), 노드 SVG의 배지 fill로 표현됩니다. 즉 기존 💬를 색칠해도 글리프엔 색이 안 들어가는 건 동일합니다.
- **선택지**:
  - (a) 현행 — 🗨 + 색 배지.
  - (b) 💬로 통일 + 색 배지로만 상태 구분(요청하신 방향. 단 일반 댓글 배지와 모양 같아져 색으로만 구분).
  - (c) 이모지 대신 **색이 적용되는 글리프**(예: ● 점 / 'i' 아이콘) — 빨강/초록이 글리프에 또렷이 + 일반 댓글과도 구분.
- **추천: (c)**. 이모지 색 미적용 문제를 근본 해결. 어느 쪽 원하시는지 알려주시면 DEV-150 수정 진행하겠습니다.

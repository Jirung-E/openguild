## 번들 타깃
`gui/tauri.macos.conf.json` 에 `bundle.targets = ["app", "dmg"]` + `macOS.minimumSystemVersion = "11.0"` 추가. 플랫폼별 설정은 base 위에 병합되고 배열은 교체되므로, base 의 `["nsis","deb","rpm","appimage"]` 대신 이 둘만 남는다 — 맥에서 그냥 `cargo tauri build` 해도 CI 와 같은 산출물이 나온다.

`createUpdaterArtifacts: true` 는 base 에 이미 있어 `.app.tar.gz` + `.sig` 도 함께 생성된다.

## release 워크플로
`macos` 잡 추가 (macos-14 = arm64 네이티브). linux 잡과 같은 구조:
- npm ci → tauri-cli → `cargo tauri build --bundles app,dmg`
- artifact: `dmg/*.dmg`, `macos/*.app.tar.gz(.sig)`
- 태그 push 면 같은 릴리스에 첨부 (본문은 CHANGELOG 절 — 기존 잡들과 동일 규칙)

Intel 맥은 대상 외(admin 결정)라 러너 하나면 된다. 서명 시크릿이 생기면 이 잡에 env 만 추가하면 되도록 자리와 주석을 남겨뒀다.

## check 워크플로
`macos` 잡 추가 (macos-14): 프론트 빌드 → `cargo build --workspace --all-targets` → `cargo test --workspace`.
플랫폼 분기(`titlebar_win`/`titlebar_linux`/non-Windows 스텁, `lock.rs`)가 맥에서 깨지면 **릴리스 태그를 밀 때가 아니라 PR 단계에서** 잡힌다. clippy 는 리눅스 잡이 워크스페이스 전체를 이미 보므로 중복하지 않았다.

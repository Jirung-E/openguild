## 원인

아이콘 보기의 빈 곳을 누르면 사각형 선택(DEV-422)이 시작된다. 그 `pointerdown` 이 글자 긁힘을 막으려고 `preventDefault()` 를 부르는데, 그러면 브라우저가 원래 하던 **포커스 옮기기(= 입력칸 포커스 풀기)도 안 일어난다.** 그래서 직접 거두는 코드가 있었지만 **격자 안**의 포커스(방향키로 남긴 타일 테두리)만 대상이었다 — 검색칸처럼 밖에 있는 입력칸은 그대로 남았다.

## 고침

빈 곳을 누르면 어디에 있든 지금 포커스를 거둔다(`document.body` 가 아니면 `blur()`). 사각형 선택 · 빈 곳 눌러 선택 풀기는 그대로.

## 확인 (웹 빌드, WebKit, 도서관 아이콘 보기 · 아키텍처 폴더)

- 고치기 전 코드: 검색칸에 포커스 → 빈 곳을 누르는 동안(사각형 선택 시작) · 뗀 뒤 모두 포커스가 **INPUT** 에 남음 — 재현.
- 고친 뒤: 누르는 순간 **body** 로(포커스 풀림). 빈 곳에서 끌어 사각형 선택 → 타일 3개, 빈 곳 누름 → 선택 0. 페이지 오류 0.

## 테스트 방법

도서관 아이콘 보기 → 검색칸을 누른 뒤 아이콘 사이 빈 곳을 누른다 → 검색칸의 파란 테두리가 사라진다(포커스가 풀린다).

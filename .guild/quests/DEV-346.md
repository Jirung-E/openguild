`just build`의 release 대응 명령으로, frontend 정적 자산을 먼저 만들고 Rust
workspace 전체를 debug profile로 빌드하는 `just build-debug` recipe를 추가한다.

데스크톱 `.app`/installer 패키징은 범위에 포함하지 않는다.

## 테스트 방법

1. `just --list`에 `build-debug`가 표시되는지 확인한다.
2. `just build-debug`가 frontend build 후 `cargo build --workspace`를 실행하는지 확인한다.

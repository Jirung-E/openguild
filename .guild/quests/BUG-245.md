# [gui] 최근 길드 목록이 최근 순으로 정렬되지 않는 경우가 있다

admin 보고: "뒤로가기 할 때만 그런지는 모르겠으나, 가장 최근에 들어갔던 길드가
맨 위에 오지 않는 경우가 있다."

## 코드에서 확인된 의심 지점 (welcome/+page.svelte)

1. **비교 함수가 일관적이지 않다** — `(a, b) => (a.last_opened < b.last_opened ? 1 : -1)`
   는 같은 값에도 `-1` 을 돌려준다. 값이 같은 항목이 있으면 정렬 결과가
   구현 정의(V8 TimSort)로 흐트러질 수 있다.
2. **타임스탬프 형식이 두 소스에서 다르다** — 로컬 recents 는 Rust `now_iso()`
   가 만드는 초 단위(`...:29Z`), 원격 길드는 JS `toISOString()` 의 밀리초
   (`...:29.123Z`). 문자열 비교에서 `'.'`(0x2E) < `'Z'`(0x5A) 이므로 **같은 초**에
   기록된 원격 항목이 로컬 항목보다 오래된 것으로 정렬된다.
3. **목록 갱신 시점** — `onMount` 에서만 다시 읽는다. 길드를 열고 뒤로 돌아왔을 때
   컴포넌트가 재사용되는 경로가 있으면 옛 목록이 그대로 남는다.

로컬 recents 는 Tauri 데스크톱 앱에서만 존재한다(HTTP 모드는 빈 배열) — 재현·
검증도 데스크톱 앱에서 해야 한다.

admin 지적 (BUG-133 후속): 도서관 세부 문서로 들어갈 때 문서 내용을 다시
불러오지 않는다. 인덱스(list 캐시) 내용을 읽는 것 같음. 퀘스트처럼, 인덱스
에는 내용이 저장될 필요가 없음.

## 원인
quest 상세는 별도 라우트(`/quests/[id]`)라 열 때마다
`questsApi.getBySlug()`로 서버에서 새로 조회하는데, 도서관은 하나의
페이지 안에서 목록+상세를 같이 보여주는 구조라 최초 `list()` 스냅샷을
그대로 표시만 하고 재조회가 없었음 — BUG-133 에서 attachments 만 재조회
하도록 고쳤는데, title/body/path 는 여전히 최초 list() 시점 그대로였다.

## 수정
`selectedId` 가 바뀔 때마다 실행되는 재조회 effect(BUG-133 에서 추가)가
이제 attachments 뿐 아니라 `libraryApi.get()` 응답 전체(title/body/path/
attachments)로 그 문서를 덮어쓰도록 확장 — quest 상세와 동일하게 "열 때
마다 서버에서 새로 조회"가 진리원이 되도록.

## 테스트 방법
- `cd gui/frontend && npm run check && npm run check:no-hex && npm test -- --run`.
- 실기: 문서를 연 상태에서 (다른 세션/CLI 로) 그 문서 본문을 바꾼 뒤,
  다른 문서로 갔다가 다시 그 문서를 선택 → 바뀐 본문이 반영되는지.

## 아이디어

Quest Board (그래프 뷰) 에서 부모 quest 를 접으면 서브퀘스트도 숨겨지는 toggle.

## 사용자 메모

> "보드에서 서브퀘스트 숨기기 기능 — 이건 어려울듯. 선행퀘랑 엮일수도 있다."

→ 백로그 / Low priority.

## 어려움

- **선행 관계와 충돌**: 서브퀘스트가 다른 quest 의 선행 (prerequisite) 일 수
  있음. 부모를 접어서 서브를 숨기면 선행 edge 가 갈 곳이 없어짐 → 보드 그래프
  깨짐.
- **edge re-route**: 숨겨진 서브가 가진 선행/후행 edge 를 부모로 collapse 할지,
  아예 끊을지 정책 결정 필요.
- **자식의 자식**: 다단 트리. 토글 상태 저장 / 복원.

## 설계 후보

### A. 단순 hide (edge 끊기)
- 부모 접으면 서브 노드 + 모든 관련 edge 숨김.
- 선행 관계가 있는 quest 가 "그래프에서 사라진" 것처럼 보이는 부작용.
- 가장 적은 코드. 부적합.

### B. Edge collapse — 서브의 in/out edge 를 부모로 redirect
- 서브가 가진 선행 / 후행 edge 를 부모 노드로 연결.
- 시각적으로 부모 그룹이 dependency 를 대표.
- 구현: graph re-render 단계에서 hidden node 의 edge 를 ancestor 로 hop.

### C. Toggle 상태를 quest position 처럼 저장
- `quest_positions` 와 비슷하게 `quest_collapsed(quest_id)` 테이블.
- 부모마다 ON/OFF.

## 관련 컴포넌트
- `QuestBoard.svelte`
- `gui/frontend/src/lib/utils/quest-node-svg.ts`
- `core/migrations/*_quest_positions.sql` 패턴 참고

## 향후
- 다른 그래프 라이브러리로 마이그레이션 시 자동 collapse 지원 활용.

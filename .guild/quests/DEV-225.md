현재 `.guild/quests/{slug}.md` 본체 + `.comments.md` / `.memo.md` /
`.attachments.json` 사이드카가 확장자 규칙으로 한 디렉토리에 평면 배치됨.
(history 사이드카는 DEV-180 에서 `.guild/history/` 로 분리 완료 — 이건 별개.)

퀘스트가 늘수록 quests/ 가 파일 종류 4개 x N개로 계속 난잡해짐. 대안:
`.guild/quests/{slug}/` 디렉토리를 만들어 quest.md / comments.md /
memo.md / attachments.json 을 그 안에 모으는 구조.

## 장점
- 확장자 기반 구분(.comments.md 등) 없이도 파일명이 명확해짐 (quest.md 등).
- change_type 의 slug rename cascade 가 파일 4개 개별 rename 대신
  디렉토리 하나만 옮기면 됨 (현재 core/src/ops/quests.rs 의 rename 로직 단순화).

## 비용 (반드시 검토)
- quest_path/comments_path/memo_path/attachments_meta_path 전부와
  reindex 의 `.guild/quests/*.md` 글롭(현재 확장자로 본체 vs 사이드카 구분)
  전면 수정.
- GUI/CLI 파일 목록·탐색 로직도 함께 수정.
- 기존 331개 퀘스트 파일을 폴더 구조로 옮기는 **1회성 마이그레이션** 필요
  (git mv 로 rename 추적되게 신경써야 함).

## 결정 보류 사유
당장 급한 문제(history 사이드카 위치)는 DEV-180 에서 이미 해결. 이건
훨씬 큰 리팩터라 별도로 설계/일정 잡고 착수. 지금은 백로그.

필터는 기존 `quest list` 필터 컨벤션을 그대로 따라 구현 완료 (모두 AND 결합):

- `--author <NAME>` (부분일치)
- `--since <DATE>` (해당 일시 이후)
- `--grep <TEXT>` (본문 부분일치 — quest list 의 --search/--grep 와 동일 의미)
- `--top-only` (top-level 댓글만, --reply-to 와 상호배타)
- `--reply-to <ID>` (특정 댓글의 답글만)

`quest list` 의 --type/--status/--sort 처럼 플래그 AND 조합 방식과 일관. 커밋: `ea68b79`(구현) / `288b832`(parse 테스트) / `659496b`(help leak fix).

→ 본문의 "확인 필요"는 위 셋으로 확정. 사용자 검증만 남음.

## 테스트 스텝 (CLI)
1. openguild quest comment list <slug> --author <name>  (작성자 필터)
2. ... --since 2026-06-01   (날짜 이후)
3. ... --grep "키워드"      (본문 부분일치)
4. ... --top-only / --reply-to <id>  (상호배타 — 함께 쓰면 에러)
   → 각 필터가 AND 로 결합되어 결과가 좁혀지는지 확인.

길드를 열려고 하면 `database disk image is malformed` 로 **아예 안 열린다**(admin, 2026-10-24 — 다른 PC 에서 겪음).

## 원인

`.guild/index.db` 는 파일(퀘스트 · 캠페인 · 도서관 …)에서 다시 만들 수 있는 **캐시**다. 그런데 이게 망가지면:

- `Store::open` 이 마이그레이션에서 `failed to migrate index db` (SQLite 코드 11) 로 실패한다.
- `openguild reindex` 도 같은 `Store::open` 을 거치므로 **고치는 명령조차 못 돈다.**
- 손으로 `index.db` 를 치우고 `reindex` 해야 했다(시험용 사본에서 재현 · 복구 확인).

왜 망가졌는지는 모른다(전원 · 동기화 폴더 · 다른 프로세스 등). 원인과 상관없이 캐시는 버리고 다시 만들면 된다.

## 할 것

- 열 때 `index.db` 가 망가져 있으면(SQLite `CORRUPT` · `NOTADB`) 그 파일을 `backups/` 로 치우고 새로 만든다. 다음 진입 훅(자동 재색인)이 파일에서 다시 채운다.
- 치운 옛 파일은 지우지 않는다 — 원인을 볼 수 있게 `backups/index.db.corrupt` 로 한 벌만 남긴다.
- `journal.db` 는 캐시가 아니다(되돌리기 기록) — 자동으로 버리지 않는다. 대신 무엇이 망가졌는지 알 수 있게 알린다.
- CLI 는 한 줄로 알린다(무엇을 했는지 · 옛 파일 어디).

## 시험

- 망가진 index.db 로 열면 열리고, 퀘스트가 다시 보인다(재색인 뒤).
- 옛 파일이 backups 에 남는다.
- 멀쩡한 길드는 아무것도 안 바뀐다.

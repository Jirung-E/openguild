**길드 밖에 둔 백업 파일로도 복원한다**(2026-10-03, admin: "외부 백업을 복원할 수 있어야 함. 지금은 길드에서 직접 생성하는
백업만 복원이 가능한데 backup-archive 를 이용해 복사해둔 백업을 복구하고 싶을 수도 있음").

길드 안의 백업은 7개만 남고 오래된 것이 지워진다. backup-archive 플러그인은 만들어진 백업 파일(`{시각}.db`)을 정해 둔 폴더에
그대로 복사해 쌓는다 — 그런데 그 파일을 되돌릴 길이 없었다(복원은 길드 안 목록에서만 고른다).

## 정한 것 (만들며 — 기본값)

- **앱**: 관리 → 백업에 "파일에서 복원…" — 파일을 고르면 그 백업의 시각 · 파일 수 · 어느 길드의 것인지를 보여 주고 확인 뒤 복원.
- **CLI**: `openguild restore --file <파일>`.
- openguild 백업 파일이 아니면(표 `files` · `meta` 가 없으면) 거부한다.
- 다른 길드의 백업이면(백업 안의 `*.guild` 이름이 지금 길드와 다르면) 경고 — 앱은 한 번 더 묻고, CLI 는 `--force` 가 있어야 한다.
- 복원 전 지금 상태는 예전처럼 `.pre-restore/` 에 둔다. 복원 자체는 길드 안 백업과 같은 길(`restore_snapshot`, 길드 독점).
- **웹(서버)은 이번엔 안 한다** — 브라우저는 서버의 파일을 고를 수 없고, 올리기(업로드)는 따로 정할 일이다. 원격 모드 CLI 도 같은 이유로 거부.
- 옛 폴더형 백업(BUG-076 시절)은 대상이 아니다 — backup-archive 는 `.db` 파일만 복사한다.

## 시험

- 백업을 길드 밖으로 복사하고 원래 것을 지운 뒤, 길드를 바꿨다가 그 파일로 복원하면 백업 때 모습으로 돌아온다.
- 백업 파일이 아니면 거부, 다른 길드 백업은 허락 없이는 거부 · 허락하면 된다.

## 한 것 (2026-10-03)

- 코어 `snapshot::inspect_backup_file` — 길드 밖 `.db` 를 읽기 전용으로 열어 시각 · 파일 수 · 백업 안 길드 마커를 읽는다. 표
  `files` · `meta` 가 없으면 "openguild 백업 파일이 아닙니다". 지금 길드 마커와 이름이 겹치는지(`same_guild` — 어느 쪽이든 마커가
  없으면 가를 수 없어 true). 열어 봐도 파일 옆에 아무것도 안 남는다.
- `snapshot::restore_backup_file` — 다른 길드 것이면 허락 없이는 거부, 아니면 `restore_snapshot` 과 같은 길.
- CLI `openguild restore --file <파일> [--force]` — 원격 모드는 거부. 결과에 시각 · 파일 수 · `.pre-restore` 위치.
- 앱: 관리 → 백업에 "파일에서 복원…"(로컬 데스크톱일 때만) → 파일 고르기(`.db`) → 확인 창(경로 · 시각 · 파일 수, 다른 길드면 경고와
  "그래도 복원") → 복원 뒤 새로고침.
- 이벤트 카탈로그: 복원과 같은 까닭으로 내지 않음. USAGE · 스킬 문서.

## 시험

- 코어: 길드 밖으로 복사해 둔 백업(원본 삭제 · 길드 변경 뒤)으로 복원하면 백업 때 모습 / 백업이 아닌 파일 거부 / 다른 길드 것은
  허락 없이 거부 · 허락하면 된다.
- 앱: 로컬 데스크톱이 아니면 버튼 없음 / 고른 파일 정보와 다른 길드 경고가 보이고 허락을 실어 복원 / 백업이 아니면 확인 창도 안 뜨고 복원 안 함.
- 사본 길드 CLI: 백업을 밖으로 복사 → 원본 지움 → 퀘스트 하나 더 → `restore --file` 로 되돌아옴, 잡파일은 거부(종료 1).

## 테스트 방법

1. backup-archive 플러그인을 켜 두었거나, `.guild/backups/snapshots/` 의 백업 파일 하나를 길드 밖 폴더로 복사해 둔다.
2. 퀘스트를 하나 만들거나 고친다.
3. 앱의 관리 → 백업 → "파일에서 복원…" 에서 그 파일을 고른다 → 언제 만든 백업인지와 파일 수가 보이고, 복원하면 2 의 변경이 사라지면 정상.
4. 다른 길드의 백업 파일을 고르면 경고와 "그래도 복원" 이 뜨면 정상(누르지 않아도 됨).

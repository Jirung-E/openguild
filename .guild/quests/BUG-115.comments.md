1차 수정(tooltips parent)은 실제로는 부수적 개선이었고 진짜 원인이
아니었음 — 사용자가 재확인: `[[` 입력 시 여전히 BUG-102 부근까지만
표시됨.

## 진짜 원인
CodeMirror `autocompletion()` 의 기본 `maxRenderedOptions` 가 100.
빈 `[[` 는 길드 전체 quest/campaign/rule(현재 300개 이상, BUG 만 113개)
를 다 후보로 주는데, 알파벳 정렬(BUG < DEV < REQ) 상 100번째에서
렌더링이 잘려 "BUG-1xx 까지만 보임"으로 나타난 것 — overflow 클리핑이
아니라 렌더 개수 자체의 하드 캡이었음.

## 추가 수정
`autocompletion({ activateOnTyping: true, maxRenderedOptions: 1000 })`
로 상향 — 길드가 커도 전부 렌더링(스크롤로 접근 가능, BUG-115 tooltips
parent 수정 덕에 스크롤도 이제 안 잘림).

## 테스트 방법
- 이 길드처럼 quest 가 많은 데서 `[[` 입력 → 스크롤해서 REQ-*/규칙까지
  전부 보이는지 확인 (100개 제한 없이).
- `[[BUG` 처럼 prefix 좁혀도 정상 필터링되는지 확인(회귀 없음).

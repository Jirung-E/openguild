앱/창/작업표시줄 아이콘의 투명 배경이 검정으로 표시됨. 확인: gui/icons/icon.ico, 32x32.png 는 이미 RGBA(알파 있음)라 파일 평탄화 문제는 아님. 추정 원인 후보: (1) Windows 아이콘 캐시 stale(.ico 교체 후에도 구/검정 표시 — 캐시 재생성/리부트 필요), (2) 소스의 '투명' 영역이 실제론 불투명 검정(alpha=255)인 채 RGBA 로 저장됨, (3) 클린 재빌드 안 됨. 작업: 투명 확인된 소스에서 cargo tauri icon 으로 .ico/.png 세트 재생성 + Windows 아이콘 캐시 클리어 + 클린 재빌드로 검증. (검정이 보이는 위치 — 작업표시줄/타이틀바/인앱 — 에 따라 원인 좁혀짐.)

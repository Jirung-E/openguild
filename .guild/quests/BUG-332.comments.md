**다시 고침 (2026-10-23, Testing 확인 중 발견):** `deliver.ps1` 에 한글(오류 문구 · 영수증 표시 `명령` · `파일` · `명령 실패`, 주석)이 **BOM 없이** 들어 있었다. Windows PowerShell 5.1 은 BOM 없는 `.ps1` 을 시스템 코드 페이지로 읽으므로 한국어 윈도우(CP949)에서 이 글자들이 깨진다 — 같은 폴더의 `archive.ps1` · `notify.ps1` 은 이 때문에 ASCII 로만 썼다. 따옴표는 CP949 의 둘째 바이트가 될 수 없어 스크립트가 멈추지는 않을 것으로 보지만, `delivered.log` 와 실패 문구가 깨진다.

- 고침: `deliver.ps1` 에 UTF-8 BOM — PS 5.1 도 UTF-8 로 읽는다. 문구는 `deliver.sh` 와 같게 둔다.
- 시험 `shipped_powershell_scripts_are_ascii_or_have_a_bom` — 함께 배포하는 `.ps1` 은 ASCII 이거나 BOM. 고치기 전 파일에서 실패. just test 통과.
- **윈도우에서 볼 것(테스트 방법에 더함):** 실패시켰을 때 `delivered.log` 의 `명령 실패` 와 오류 문구의 한글이 안 깨진다.

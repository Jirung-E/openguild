자동 업데이트 확인 테스트 방법:

1. **전제**: GitHub 릴리즈에 `latest.json` + `*-setup.exe` + `*.sig`가 올라가 있어야 함(서명 secret 설정된 release.yml이 자동 생성). 0.2.1-beta 릴리즈가 이 상태.
2. **버전 차이 만들기**: 더 낮은 버전(예: 0.2.0-beta) 설치본으로 GUI 실행 → updater가 endpoint의 `latest.json`을 폴링해 새 버전(0.2.1-beta)을 감지 → 업데이트 배너/토스트 표시. (0.2.0→0.2.1 릴리즈가 마침 이 시나리오)
3. **즉시 확인**: 6시간 주기를 기다릴 필요 없이 welcome 페이지의 "업데이트 확인" 수동 트리거로 바로 폴링.
4. **설치까지 검증**: 배너에서 설치 진행 → 재시작 후 버전이 0.2.1-beta로 올라갔는지 확인.
5. **음성 케이스**: signing secret 미설정이면 `.sig`/`latest.json`이 빠져 updater가 "release json 없음" 에러(humanizeUpdaterError). 정상 동작은 secret 설정 후에만.

즉 현재 0.2.1-beta 릴리즈를 대상으로, 0.2.0-beta 설치본에서 "업데이트 확인"을 눌러 감지→설치→버전 확인까지 보면 됨.

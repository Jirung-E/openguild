- 빈 곳을 끌어 **사각형 선택**.
- `⌘/Ctrl+A` 전체 선택 (`utils/multi-select.ts` 의 `all()` 은 이미 있다).
- 방향키로 옮겨 다니기, `Enter` 로 열기, `Delete` 로 지우기.

## 곁들여

- [[REQ-028]] 의 복사·내보내기를 **고른 것** 대상으로 돌리기. 지금은 "열어 둔 문서" 또는
  "지금 폴더" 만 된다.

## 한 것 (2026-10-11)

아이콘 보기에서 고르는 방법 셋을 더했다. 규칙은 `utils/multi-select.ts` 에(`arrow` · `hitsIn` ·
`marquee`), 시험 7개를 더해 15개로 고정했다.

- **사각형 선택**: 빈 곳에서 끌면 사각형이 그려지고 걸친 타일이 고른 것이 된다.
  - 그냥 끌기는 바꾸기, `Shift` 는 더하기, `⌘/Ctrl` 은 뒤집기(Finder 와 같다).
  - 수식키는 **끌기 시작할 때** 것으로 정한다 — 도중에 눌렀다 떼도 결과가 흔들리지 않는다.
  - 4px 이상 움직여야 끌기로 본다. 끌고 난 직후의 클릭은 "빈 곳 누름 = 해제" 로 치지 않는다.
- **`⌘/Ctrl+A`**: 지금 폴더의 전부. **`Esc`**: 선택 해제.
- **방향키**: 좌우는 한 칸, 위아래는 한 줄(줄 칸 수는 창 너비에서 잰다). 끝에서는 머문다.
  `Shift+방향키` 는 기준점을 두고 범위를 늘리고 줄인다. 포커스와 스크롤도 따라간다.
- **`Enter`**: 하나만 골랐을 때 연다(폴더는 들어가고 문서는 상세). **`Delete`/`Backspace`**:
  고른 것 지우기 확인 창.
- 키는 아이콘 격자가 보일 때만 받는다 — 상세 · 검색 결과 · 트리 · 입력칸 · 확인 창에서는 안 가로챈다.

곁들여 — [[REQ-028]] 복사 · 내보내기를 고른 것 대상으로: 이미 되어 있었다(`takeOutTarget` 이
고른 것을 먼저 본다). 따로 손대지 않았다.

확인(헤드리스 WebKit, 길드 사본에 시험 문서 12개): 끌기 중 사각형 보임 · 오른쪽 아래에서 첫 줄
다섯째까지 끌어 6개, 도중 Shift 를 눌러도 같은 결과, 빈 곳 클릭으로 해제, ⌘A 3/3(글자 선택 안 됨),
→ ↓ 가 한 줄 아래 칸으로, Delete 로 확인 창, Enter 로 폴더 진입과 문서 열기, 상세에서는 ⌘A 를
안 가로챔. 페이지 오류 없음.

남긴 것: 끄는 동안 화면 끝에 닿으면 저절로 스크롤되는 것은 없다(목록이 화면보다 길 때).

## 테스트 방법

1. 도서관 → 아이콘 보기(▦). 빈 곳에서 끌면 파란 사각형이 생기고 걸친 타일이 고른 것이 된다.
   `Shift` 를 누르고 끌면 더해지고, `⌘` 를 누르고 끌면 뒤집힌다. 끄는 도중에 키를 눌러도 어긋나지 않는다.
2. 빈 곳을 그냥 누르면 풀린다. `⌘A` 로 전부, `Esc` 로 해제.
3. 방향키로 옮겨 다니고, `Shift+방향키` 로 범위가 늘어난다. `Enter` 로 폴더에 들어가거나 문서가 열린다.
4. 키보드만으로: 골라서 `Delete` → 확인 → 지워진다. 옮기기는 고른 뒤 [폴더 이동].
5. 이름 바꾸기 입력칸 안에서는 `⌘A` · 방향키가 글자에 대해 평소처럼 동작한다.

테스트용 데이터를 자동으로 집어넣기 위한 스크립트. 초기화 안 된 폴더에서 실행하며, 이미 .guild가 있으면 에러.

## 구현 (2026-05-26)

`scripts/seed-test-data.ps1` (PowerShell 5.1 / pwsh 7 양쪽 호환).

### 안전장치
- cwd 에 `.guild` 가 있으면 `Write-Error` + `exit 1` — 실수로 기존 길드를 오염시키는 사고 방지.

### 바이너리 해상도
우선순위: `$env:OPENGUILD_BIN` > `<repo>/target/release/openguild.exe` >
`<repo>/target/debug/openguild.exe` > PATH 의 `openguild`.

PATH 의 설치본보다 repo build 가 우선 — 시스템 설치 버전이 outdated 라
신규 subcommand (예: `campaign`) 가 없는 경우 회피.

### Encoding
Windows PowerShell 5.1 은 native exe 의 stdout/stdin 을 OEM (cp949) 으로
처리해 한글이 깨짐. 스크립트 상단에서 `[Console]::OutputEncoding` /
`InputEncoding` / `$OutputEncoding` 를 UTF-8 로 강제 + `chcp 65001`.

### 주입되는 데이터
- 퀘스트 12 개 (DEV / BUG / REQ 타입 섞임, urgency 1~4). 일부 `in_progress` /
  `on_hold` 상태로 전환.
- 진행 중 캠페인 5 개 (carousel 회전 + 화살표 + dot 검증):
  - 기간 / 진행률 다양 (25% / 40% / 50% / 80% / 100% 완료)
- 곧 시작 캠페인 7 개 (1주 이내 시작 — marquee 임계값 발동):
  - 카드 7 × (200+12)px = 1484px > viewport ~1100px → marquee 자동.
- Future 캠페인 1 개 (1주 이후, fallback 경로 자체는 위 set 가 채우므로
  실제로 노출은 안 됨 — 데이터만 존재).
- 일부 캠페인 ↔ 퀘스트 link.

### 사용
```pwsh
cd <빈 폴더>
pwsh -File <repo>/scripts/seed-test-data.ps1 [-Name <guild-name>]
```

### 검증
- 빈 폴더에서 실행 → init + 데이터 주입 정상.
- `.guild` 있는 폴더에서 재실행 → `exit 1` + 에러 메시지.

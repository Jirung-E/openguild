## 문제

캠페인 다음 번호는 `index.db` 의 `campaign_counters` 에만 있다. git 에 안 들어간다.
퀘스트는 `.guild/types/{PREFIX}.toml` 의 `last_number` 가 "발급한 번호를 다시 쓰지 않게" 막는데, 캠페인엔 그런 파일이 없다.

- 색인 재구축(reindex)은 counter 를 0 으로 두고 **살아 있는** 캠페인 파일의 최대 번호로 맞춘다 (`core/src/reindex.rs:171`, `:1071`).
- 그래서 마지막 캠페인을 지우거나, 다른 컴퓨터에서 clone/pull 한 뒤엔 같은 번호가 다시 나온다 → 예전 C-NNN 을 가리키던 댓글 · 기록 · 링크가 엉뚱한 캠페인에 붙는다.

발견: 시험용 C-008 이 실제 길드에 생겨서 지우다가 (2026-11-09).

## 할 일

- 캠페인 번호도 git 에 들어가는 파일에 둔다 (퀘스트 types/*.toml `last_number` 와 같은 뜻 — 줄어들지 않는 값).
- 새 캠페인 만들 때 그 파일을 올리고, reindex · check counters 가 그 값을 아래로 내리지 않게.
- 파일이 없는 기존 길드는 처음 열 때 지금 최대 번호로 만들어 준다.
- 시험: 마지막 캠페인 삭제 → reindex → 새 캠페인 번호가 재사용되지 않음.

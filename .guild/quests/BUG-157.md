0.4.1 에서 여전히 안 고쳐진 이유 — 두 가지가 겹쳐 있었다.

## (1) 이 브랜치엔 배선 자체가 없었다
BUG-157 원 수정(develop c44c97a)이 release-0.4.1 로 체리픽된 적이 없다.
release 의 SearchPalette 는 헤더 주석에만 OverlayScrollbar 를 언급할 뿐
import·렌더·native 숨김 CSS 가 전부 없었다(= 계속 native 스크롤바).
앞서 "release 에도 있음"으로 판단했던 것은 checkout 이 abort 된 상태에서
develop 파일을 grep 한 내 오판.

## (2) 컨테이너 모드 배선이 onMount 1회라 죽어 있었다 (공통)
자식의 onMount 시점엔 호출측 bind:this 가 아직 null → 리스너/옵저버/측정이
전부 window 모드로 붙고 재배선이 없어 thumb 이 렌더되지 않았다.
→ $effect 로 옮겨 target 변화 시 재측정+재배선(1235f15).

## 이번 수정 (release-0.4.1)
- SearchPalette: OverlayScrollbar import + `.rows`/`.dp-body` 에 렌더
  (`{#if el}` 가드), previewBodyEl 바인딩 추가.
- `.rows` / `.dp-body` 에 `scrollbar-width: none` + `::-webkit-scrollbar
  { display:none }` — native 숨김.

## 테스트 방법
검색 팔레트를 열어 결과가 340px 를 넘길 만큼 나오게 한 뒤:
1. native 스크롤바가 안 보이고, 목록 위에서 스크롤하면 오른쪽에 얇은
   overlay thumb 가 나타나는지(1.2초 후 사라짐, hover 시 유지).
2. thumb 드래그로 목록이 스크롤되는지.
3. 결과를 클릭해 미리보기를 열고 본문이 길 때 동일하게 동작하는지.

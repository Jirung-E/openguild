# BUG-157: 검색 팔레트 스크롤바가 커스텀(overlay)이 아님

사용자 질문: 검색 팔레트 스크롤바가 커스텀이 맞는지?

## 원인

**아니었다.** SearchPalette 의 헤더 주석은 "기존 OverlayScrollbar 사용"
이라고 적혀 있었지만 실제로는 **import 조차 없었다**(DEV-253 작성 당시
주석만 남고 구현이 빠진 것으로 보임). 결과 목록(`.rows`)과 미리보기
본문(`.dp-body`) 둘 다 native scrollbar 를 썼다.

global.css 의 `::-webkit-scrollbar` 커스텀이 적용돼 "얇고 반투명"하게
보이긴 했지만, 그건 native scrollbar 를 칠한 것일 뿐 **컨텐츠 폭을
차지한다**(global.css 주석에도 "한계: overlay 아님"이라 명시). 콤보박스·
퀘스트 목록·에디터 등 다른 스크롤 영역은 모두 OverlayScrollbar 를 쓰고
있어 팔레트만 규칙에서 벗어나 있었다.

## 수정

`.rows` / `.dp-body` 에 `<OverlayScrollbar target={...} />` 연결 +
native scrollbar 숨김(`scrollbar-width: none` / `::-webkit-scrollbar`
display:none) — QuestCombobox 와 동일 규칙. stale 주석도 정정.

## 검증

웹 실기: `.rows` 의 `scrollbar-width: none` 적용 + overlay thumb 렌더 +
`offsetWidth - clientWidth = 0`(폭 안 뺏김) 확인.

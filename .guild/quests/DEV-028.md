DEV-027 MVP 후속. `quest list` 의 작은 확장 묶음.

## 제안 옵션

### urgency 범위 / 다중
- `--urgency 1,2` — 복수 단일 값. CSV 또는 반복.
- `--urgency 1-3` — 범위. 1 이상 3 이하.
- 현재 `--urgency N` 단일만 지원.

### 시간 범위
- `--created-after <ISO date>` / `--created-before <ISO date>`.
- `--updated-after <ISO date>` / `--updated-before <ISO date>`.
- ISO 8601 (`2026-05-15` 또는 `2026-05-15T10:00:00Z`) 입력.
- SQL `datetime()` 비교.

### 조합 예시
```bash
openguild quest list --urgency 1,2 --status open
openguild quest list --urgency 1-2
openguild quest list --updated-after 2026-05-15 --sort updated
openguild quest list --created-after 2026-05-15 --created-before 2026-05-17
```

## 영향 범위

- `core/src/models/quest.rs::ListQuery` — 필드 추가:
  `urgency: Option<String>` (CSV/범위 표기 raw), `created_after/before`,
  `updated_after/before: Option<String>`.
- `core/src/services/quests.rs::list` — urgency parser (단일 / CSV / "a-b" 범위)
  + SQL `IN` 또는 `BETWEEN`. 시간은 `datetime(?)` 비교.
- `server::routes::quests::list_quests` — Query<ListQuery> 자동 확장.
- `cli::QuestCmd::List`:
  - `--urgency` 가 `Option<String>` 으로 변경 (현재 i64).
  - `--created-after`/`-before` / `--updated-after`/`-before` 추가.
- 자동 테스트 (예상 ~12건).

확인" 용도. 작업량 S — 한 사이클.

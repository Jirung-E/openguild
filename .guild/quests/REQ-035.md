`run` 훅은 **이 플러그인의 데이터 폴더**에서 돈다.

```
~/.openguild/plugin-data/<길드>-<해시>/<플러그인>/
```

`delivery.rs` 의 `.current_dir(&workdir)` 이고, `workdir` 은 `plugin.data_dir()` 이다.

## 왜 거기인가 — 한쪽만 정해져 있다

BUG-279 가 정한 것은 "**플러그인 폴더가 아니다**" 까지다. 동의 지문이 플러그인 폴더의 모든
파일을 보므로, 훅이 자기 출력을 옆에 쓰는 순간 **자기 동의를 스스로 깨고** 조용히 멈췄다.

"길드 폴더는 왜 아닌가" 는 정한 적이 없다. 그냥 데이터 폴더로 간 것이다.

## 무엇이 걸리나

AI 를 부르는 훅에서는 작업 폴더가 곧 **AI 가 보는 세상**이다. `claude -p` 를 데이터
폴더에서 띄우면 그 AI 는 길드도 코드도 못 본다 — 댓글 한 줄만 들고 답한다. 정작 묻고 싶은
것은 대개 "이 퀘스트/이 코드에 대해" 인데 그걸 볼 수가 없다(admin).

지금은 명령 앞에 이걸 붙여서 피한다.

```sh
cd "$OPENGUILD_GUILD_DIR" && claude -p ...
```

## 정할 것

1. `[actions.*.run]` 에 `cwd` 를 둘까 — `${OPENGUILD_GUILD_DIR}` 같은 참조도 받게
2. 아니면 기본을 길드 루트로 옮길까 — 그러면 훅이 아무 생각 없이 쓴 출력이 길드 안에 떨어진다
   (`.guild` 쓰기는 ops 를 거쳐야 한다는 규칙과도 부딪힌다)
3. 둘 다 — 기본은 지금대로 두고 `cwd` 로 고르게

3번이 가장 얌전해 보이지만, 그러면 "왜 AI 가 아무것도 모르나" 를 사람이 한 번은 겪어야
알게 된다. 기본값을 어디에 둘지가 이 퀘스트의 요점이다.

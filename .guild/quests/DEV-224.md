사용자 실사(2026-07-05) 2건:
1. **fresh clone 에서 cargo build 실패**: gui 의 tauri bundle resources 가 `frontend/build` 를 요구하는데 gitignored 라 새 클론엔 없음 → 'resource path frontend\build doesn't exist'.
   - **근본 원인 확정 (BUG-107)**: `just install`/`just build-frontend` 안내 부재 문제가 아니라, justfile 의 `build: build-rust build-frontend` **의존성 순서 자체가 반대**였음 — `just build` 를 그대로 실행해도 frontend 보다 rust 가 먼저 빌드되어 항상 실패. BUG-107 에서 `build: build-frontend build-rust` 로 수정 완료.
   - 남은 문서화 과제: README/USAGE 에 "처음 빌드는 `just install` → `just build`" 한 줄 명시 (순서는 이제 justfile 이 알아서 보장하므로 사용자가 신경 쓸 건 install 뿐).
2. **Linux 에서 gui 빌드 불가**: Tauri v2 Linux 사전 패키지 미설치 시 실패.
   - **실제 목록 확정** — 이 repo CI(`.github/workflows/check.yml:32-41`)에서 이미 검증되어 쓰이고 있음:
     ```
     sudo apt-get install -y \
       libwebkit2gtk-4.1-dev \
       libxdo-dev \
       libssl-dev \
       libayatana-appindicator3-dev \
       librsvg2-dev \
       build-essential
     ```
   - 이 목록을 README/USAGE 에 그대로 옮기면 됨 (추측 아닌 CI 실사용 목록).

## 작업
- README Development 절(또는 docs/USAGE)에 '처음 빌드' 순서: `just install` → `just build`.
- Linux: 위 CI 검증된 apt 패키지 목록 + '빌드 없이 쓰려면 browser 모드(openguild-server + 브라우저)' 대안 명시.
- (완료, BUG-107) justfile `build` 레시피 의존성 순서 수정 — 더 이상 gui/build.rs 쪽 에러 메시지 개선은 불필요.

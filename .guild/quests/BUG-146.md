사용자 보고: 메뉴바(Nav)에 "openguild" 로고 글자 + 현재 길드 이름이
리눅스에서는 표시되는데 Windows 에서는 표시 안 됨. 커스텀 타이틀바가
이미 길드 이름을 보여주므로 리눅스에선 중복 표시가 됨.

## 현재 원인 (코드 확인됨)

`gui/frontend/src/lib/components/Nav.svelte` 의 `hasTitleBar` 판별이
**Windows UA 만** 검사한다:

```js
const hasTitleBar =
    detectEnvironment() === 'tauri' &&
    navigator.userAgent.includes('Windows');
```

이 값이 true 면 Nav 의 로고/길드명 블록(`{#if !hasTitleBar}`)을 숨긴다.
DEV-253 에서 "커스텀 타이틀바는 Windows 전용"이던 시절 작성됨. 이후
BUG-140(리눅스)·DEV-265(macOS)도 커스텀 타이틀바를 쓰게 됐는데 이 조건이
갱신 안 돼 Linux/macOS 에선 Nav 가 로고+길드명을 그려 타이틀바와 중복.

## 수정 방향 (사용자 확정)

플랫폼별로 분기하지 말고, **이 로고/길드명 블록을 아예 항상 그리지 않는다**
— 앱(모든 OS)이든 웹(브라우저 dev)이든 전부. 따라서 `hasTitleBar` 검사
자체가 불필요하며 통째로 제거.

제거 범위(전부 이 블록 전용으로만 쓰임 확인됨):
- `{#if !hasTitleBar}` 로고/길드명/원격배지 블록
- `hasTitleBar` const
- `guildName`, `isRemoteGuild` state 와 이를 채우는 `$effect`
  (`metaApi.getGuildDisplayInfo()` 조회)
- 그로 인해 미사용이 되는 import: `metaApi`, `guildContextActive`,
  `detectEnvironment`
- 미사용 CSS: `.logo`, `.guild-name`, `.remote-badge`

참고(의도된 결과): 웹(타이틀바 없음)에서는 상단 로고 = /welcome 진입
링크가 사라진다. 사용자가 웹 포함 제거를 명시 확정함.

## 테스트 방법

- 리눅스 앱: 메뉴바에 로고/길드명이 더 이상 안 뜨고 타이틀바 pill 에만
  길드명이 뜨는지.
- 브라우저 dev(`npm run dev`): 메뉴바에 로고가 없어도 나머지 탭/기능이
  정상인지(회귀 확인).

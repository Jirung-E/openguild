## 베타 1.0.0

openguild 의 첫 베타 마일스톤. 핵심 기능군 + 품질 polish 를 묶어 "남에게
보여줄 수 있는" 수준을 목표로 함.

### 범위 (테마별)

**신규 기능**
- 홈 캠페인 배너 이미지 (글자쪽 불투명 → 이미지쪽 fade)
- openguild-server 기능 강화 (info / JWT / server CLI 포함 umbrella)
- UI 완성도 향상 (polish umbrella)

**필수 기능**
- 다크/라이트 모드, 다국어 (영/한)
- Quest List 필터·정렬 UI / 평면·트리 토글
- 길드 규칙, 댓글·메모, 첨부파일 링크, tag
- Journal replay (시점 복원)
- Quest Board: 레인 순서 변경 / 노드 그룹 정렬 / 도구 버튼 위치
- 퀘스트 상세의 후속 퀘스트 표시
